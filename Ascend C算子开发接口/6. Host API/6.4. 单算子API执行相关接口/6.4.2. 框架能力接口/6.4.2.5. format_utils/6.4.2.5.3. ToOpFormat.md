# ToOpFormat

#### 功能说明
将aclFormat转为对应的op::Format。
- aclFormat：AscendCL（Ascend Computing Language）框架对外提供的数据格式，具体定义参见“[aclFormat](https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/appdevgapi/aclcppdevg_03_1348.html)”。
- op::Format：算子框架内部定义的数据格式，本质使用的是GE定义的[ge::Format](https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/basicdataapi/atlasopapi_07_00515.html)。

#### 函数原型
**Format ToOpFormat(aclFormat format)**

#### 参数说明
<table border="1" cellpadding="4" cellspacing="0" frame="border" rules="all"><thead><tr><th>参数</th><th>输入/输出</th><th>说明</th></tr></thead><tbody><tr><td>format</td><td>输入</td><td>待转换的原始数据格式aclFormat。</td></tr></tbody></table>

#### 返回值说明
返回op::Format类型。

#### 约束说明
无

#### 调用示例
```cpp
// 获取ACL_FORMAT_ND对应的Format枚举
void Func() {
    Format format = ToOpFormat(ACL_FORMAT_ND);
}
```
