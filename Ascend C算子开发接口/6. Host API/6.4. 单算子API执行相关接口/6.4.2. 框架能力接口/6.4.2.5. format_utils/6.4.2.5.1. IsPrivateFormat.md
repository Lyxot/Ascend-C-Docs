# IsPrivateFormat

#### 功能说明
判断输入的format是否为私有格式。

#### 函数原型
**bool IsPrivateFormat(Format format)**

#### 参数说明
<table>
<thead><tr><th>参数</th><th>输入/输出</th><th>说明</th></tr></thead>
<tbody><tr><td>format</td><td>输入</td><td>待校验的数据格式，数据类型为op::Format（即<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/basicdataapi/atlasopapi_07_00515.html">ge::Format</a>）。</td></tr></tbody>
</table>

#### 返回值说明
format为私有格式返回true，否则返回false。

#### 约束说明
无

#### 调用示例
```cpp
// 判断当input的storage format为私有格式时，返回
void Func(const aclTensor *input) {
    if (IsPrivateFormat(input->GetStorageFormat())) {
        return;
    }
}
```
