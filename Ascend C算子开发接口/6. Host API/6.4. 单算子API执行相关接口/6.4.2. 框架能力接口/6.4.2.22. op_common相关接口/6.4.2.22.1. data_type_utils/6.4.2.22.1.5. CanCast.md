# CanCast

#### 功能说明
判断源数据类型是否可以cast到目的数据类型。

#### 函数原型
**bool CanCast(const DataType from, const DataType to)**

#### 参数说明
<table><thead><tr><th>参数</th><th>输入/输出</th><th>说明</th></tr></thead><tbody><tr><td>from</td><td>输入</td><td>源数据类型。</td></tr><tr><td>to</td><td>输入</td><td>目的数据类型。</td></tr></tbody></table>

#### 返回值说明
若成功cast返回true，否则返回false。

#### 约束说明
无

#### 调用示例
```cpp
// 判断dtype不可以转为int8类型时，返回
void Func(const DataType dtype) {
    if (!CanCast(dtype， DT_INT8)) {
        return;
    }
}
```
