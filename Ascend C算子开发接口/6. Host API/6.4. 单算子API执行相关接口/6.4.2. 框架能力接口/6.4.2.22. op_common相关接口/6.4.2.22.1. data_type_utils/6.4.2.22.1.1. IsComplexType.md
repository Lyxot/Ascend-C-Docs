# IsComplexType

#### 功能说明
判断输入的数据类型是否为复数类，包括Complex128、Complex64、Complex32。

#### 函数原型
**bool IsComplexType(const DataType dtype)**

#### 参数说明
<table>
  <thead>
    <tr><th>参数</th><th>输入/输出</th><th>说明</th></tr>
  </thead>
  <tbody>
    <tr><td>dtype</td><td>输入</td><td>输入的数据类型。</td></tr>
  </tbody>
</table>

#### 返回值说明
若为复数类型返回true，否则返回false。

#### 约束说明
无

#### 调用示例
```cpp
// 判断dtype不为复数类型时，返回
void Func(const DataType dtype) {
  if (!IsComplexType(dtype)) {
    return;
  }
}
```
