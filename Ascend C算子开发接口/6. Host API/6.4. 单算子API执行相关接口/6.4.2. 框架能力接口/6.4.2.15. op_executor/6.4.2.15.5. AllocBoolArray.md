# AllocBoolArray

#### 功能说明
申请一个aclBoolArray，并使用指定内存中的值对其进行初始化。

#### 函数原型
**aclBoolArray *AllocBoolArray(const bool *value, uint64_t size)**

#### 参数说明
<table border="1" rules="all" cellpadding="4" cellspacing="0"><thead align="left"><tr><th align="left">参数</th><th align="left">输入/输出</th><th align="left">说明</th></tr></thead><tbody><tr><td>value</td><td>输入</td><td>源数据，用于初始化aclBoolArray。</td></tr><tr><td>size</td><td>输入</td><td>源数据的元素个数。</td></tr></tbody></table>

#### 返回值说明
返回申请到的aclBoolArray对象，申请失败返回nullptr。

#### 约束说明
入参指针不能为空。

#### 调用示例
```cpp
// 申请一个长度为10的aclBoolArray
void Func(aclOpExecutor *executor) {
    bool myArray[10];
    aclBoolArray *array = executor->AllocBoolArray(myArray, 10);
}
```
