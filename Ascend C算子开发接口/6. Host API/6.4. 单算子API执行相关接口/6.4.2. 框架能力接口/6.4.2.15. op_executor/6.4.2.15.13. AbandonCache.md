# AbandonCache

#### 功能说明
关闭aclnn cache缓存功能。  
该功能是指首次调用aclnn算子后框架会记录cache缓存，后续再次调用时，将跳过一阶段aclnnXxxGetWorkspaceSize函数，从而达到性能优化的目的。

#### 函数原型
`void AbandonCache(bool disableRepeat = false)`

#### 参数说明
<table>
<thead><tr><th>参数</th><th>输入/输出</th><th>说明</th></tr></thead>
<tbody><tr><td>disableRepeat</td><td>输入</td><td>设置aclOpExecutor是否支持复用。默认为false，不复用。</td></tr></tbody>
</table>

#### 返回值说明
无

#### 约束说明
对于一阶段aclnnXxxGetWorkspaceSize函数必须要执行的场景，需要在aclnnXxxGetWorkspaceSize函数中显示调用AbandonCache。

#### 调用示例
```cpp
void aclnnAddGetWorkspaceSize(..., uint64_t *workspaceSize, aclOpExecutor **executor) {
    auto uniqueExecutor = CREATE_EXECUTOR();
    ......
    uniqueExecutor.get()->AbandonCache();
}
```
