<h1 class="topictitle1">AllocHostTensor</h1>
<div><div class="section"><h4 class="sectiontitle">功能说明</h4><p>申请一个host侧tensor，提供多个重载函数，可以指定不同的输入属性，如不同的数据类型。</p>
</div>
<div class="section"><h4 class="sectiontitle">函数原型</h4><ul><li>根据不同的输入信息组合，申请一个host侧tensor。<p><a name="ZH-CN_TOPIC_0000002370251377__zh-cn_topic_0000001949510813_li210933417134"></a><a name="zh-cn_topic_0000001949510813_li210933417134"></a><strong>aclTensor *AllocHostTensor(const Shape &amp;shape, DataType dataType, Format format = FORMAT_ND)</strong></p>

</li><li>申请一个host侧tensor，将指定数据类型的内存作为该tensor内容。<p><a name="ZH-CN_TOPIC_0000002370251377__zh-cn_topic_0000001949510813_li62894447139"></a><a name="zh-cn_topic_0000001949510813_li62894447139"></a><strong>aclTensor *AllocHostTensor(const int64_t *value, uint64_t size, DataType dataType)</strong></p>
<p><strong>aclTensor *AllocHostTensor(const uint64_t *value, uint64_t size, DataType dataType)</strong></p>
<p><strong>aclTensor *AllocHostTensor(const bool *value, uint64_t size, DataType dataType)</strong></p>
<p><strong>aclTensor *AllocHostTensor(const char *value, uint64_t size, DataType dataType)</strong></p>
<p><strong>aclTensor *AllocHostTensor(const int32_t *value, uint64_t size, DataType dataType)</strong></p>
<p><strong>aclTensor *AllocHostTensor(const uint32_t *value, uint64_t size, DataType dataType)</strong></p>
<p><strong>aclTensor *AllocHostTensor(const int16_t *value, uint64_t size, DataType dataType)</strong></p>
<p><strong>aclTensor *AllocHostTensor(const uint16_t *value, uint64_t size, DataType dataType)</strong></p>
<p><strong>aclTensor *AllocHostTensor(const int8_t *value, uint64_t size, DataType dataType)</strong></p>
<p><strong>aclTensor *AllocHostTensor(const uint8_t *value, uint64_t size, DataType dataType)</strong></p>
<p><strong>aclTensor *AllocHostTensor(const double *value, uint64_t size, DataType dataType)</strong></p>
