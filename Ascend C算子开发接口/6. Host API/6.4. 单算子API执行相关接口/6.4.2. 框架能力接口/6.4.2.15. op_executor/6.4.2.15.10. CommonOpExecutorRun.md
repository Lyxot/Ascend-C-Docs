# CommonOpExecutorRun

#### 功能说明
根据workspace、stream，执行算子executor上下文中的所有任务。

#### 函数原型
`aclnnStatus CommonOpExecutorRun(void *workspace, uint64_t workspaceSize, aclOpExecutor *executor, aclrtStream stream)`

#### 参数说明
<table><thead><tr><th>参数</th><th>输入/输出</th><th>说明</th></tr></thead><tbody><tr><td>workspace</td><td>输入</td><td>根据L2一阶段接口计算出的workspaceSize，在device侧申请的片上内存指针。</td></tr><tr><td>workspaceSize</td><td>输入</td><td>L2一阶段接口计算出的workspaceSize。</td></tr><tr><td>executor</td><td>输入</td><td>L2一阶段接口调用后生成的op执行器对象。</td></tr><tr><td>stream</td><td>输入</td><td>在AscendCL stream指定的流上执行executor中的算子任务。</td></tr></tbody></table>

#### 返回值说明
执行成功返回ACLNN_SUCCESS，否则返回[aclnn错误码](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_1042.html#ZH-CN_TOPIC_0000002370171629__table2070319561334)。

#### 约束说明
- executor不能为空。
- workspaceSize大于0时，workspace不能为空。

#### 调用示例
```cpp
// aclnnAdd的二阶段函数，执行executor任务队列中的算子
aclnnStatus aclnnAdd(void *workspace, uint64_t workspaceSize, aclOpExecutor *executor, aclrtStream stream) {
    return CommonOpExecutorRun(workspace, workspaceSize, executor, stream);
}
```
