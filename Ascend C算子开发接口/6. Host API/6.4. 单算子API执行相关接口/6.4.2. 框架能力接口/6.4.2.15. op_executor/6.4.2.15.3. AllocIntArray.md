# AllocIntArray

#### 功能说明
申请一个aclIntArray，并使用指定内存中的值对其进行初始化。

#### 函数原型
**aclIntArray *AllocIntArray(const int64_t *value, uint64_t size)**

#### 参数说明
<table>
<thead><tr><th>参数</th><th>输入/输出</th><th>说明</th></tr></thead>
<tbody><tr><td>value</td><td>输入</td><td>源数据，用于初始化aclIntArray。</td></tr><tr><td>size</td><td>输入</td><td>源数据的元素个数。</td></tr></tbody>
</table>

#### 返回值说明
返回申请到的aclIntArray对象，申请失败返回nullptr。

#### 约束说明
入参指针不能为空。

#### 调用示例
```cpp
// 申请一个长度为10的aclIntArray
void Func(aclOpExecutor *executor) {
    int64_t myArray[10];
    aclIntArray *array = executor->AllocIntArray(myArray, 10);
}
```
