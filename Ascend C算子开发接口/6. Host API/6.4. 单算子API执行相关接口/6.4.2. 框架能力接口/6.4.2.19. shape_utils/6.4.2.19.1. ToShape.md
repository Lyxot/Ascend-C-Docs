# ToShape

#### 功能说明
将指定内存维度数据转为op::Shape（即[gert::Shape](https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/basicdataapi/atlasopapi_07_00149.html)）对象。

#### 函数原型
- 用给定的dims维度数组构造op::Shape。  
  **void ToShape(const int64_t *dims, uint64_t dimNum, Shape &shape)**
- 用给定的[op::ShapeVector](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_1042.html#ZH-CN_TOPIC_0000002370171629__li9714135618311)维度数组构造op::Shape。  
  **void ToShape(const FVector<int64_t, 25> shapeVector, Shape &shape)**

#### 参数说明
<table>
<thead><tr><th>参数</th><th>输入/输出</th><th>说明</th></tr></thead>
<tbody><tr><td>dims</td><td>输入</td><td>源数据指针，指向存放每一维shape大小的内存。</td></tr><tr><td>dimNum</td><td>输入</td><td>dims指向的源数据中，共有多少维shape信息。</td></tr><tr><td>shapeVector</td><td>输入</td><td>源数据，列表中存放每一维的shape大小。</td></tr><tr><td>shape</td><td>输出</td><td>通过源数据构造出的Shape对象。</td></tr></tbody>
</table>

#### 返回值说明
无

#### 约束说明
无

#### 调用示例
```cpp
// 生成一个shape信息为[1, 2, 3, 4, 5]的Shape对象。
void Func() {
    int64_t myArray[5] = {1, 2, 3, 4, 5};
    Shape shape;
    ToShape(myArray, 5, shape);
}
```
