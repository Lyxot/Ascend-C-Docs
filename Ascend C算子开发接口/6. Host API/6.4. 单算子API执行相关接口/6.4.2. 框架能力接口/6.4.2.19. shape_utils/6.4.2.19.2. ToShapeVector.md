# ToShapeVector

#### 功能说明
提取输入Shape对象中的维度信息到一个[ShapeVector](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_1042.html#ZH-CN_TOPIC_0000002370171629__li9714135618311)容器。

#### 函数原型
**FVector<int64_t, 25> ToShapeVector(const Shape &shape)**

#### 参数说明
<table><thead><tr><th>参数</th><th>输入/输出</th><th>说明</th></tr></thead><tbody><tr><td>shape</td><td>输入</td><td>记录了一组shape信息，例如一个三维shape：[10, 20, 30]。</td></tr></tbody></table>

#### 返回值说明
返回一个[FVector](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_1042.html#ZH-CN_TOPIC_0000002370171629__li1071411561236)对象，其中存放着每一维的shape大小。

#### 约束说明
无

#### 调用示例
```cpp
// 生成一个shape信息为[1, 2, 3, 4, 5]的Shape对象，并将它转为FVector。
void Func() {
    gert::Shape newShape;
    for (int64_t i = 1; i <= 5; i++) {
        newShape.AppendDim(i);
    }
    auto shapeVec = ToShapeVector(newShape);
}
```
