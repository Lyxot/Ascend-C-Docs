# SetViewFormat

#### 功能说明
设置aclTensor的ViewFormat。ViewFormat为aclTensor的逻辑Format。

#### 函数原型
**void SetViewFormat(op::Format format)**

#### 参数说明
<table cellpadding="4" cellspacing="0" summary="" frame="border" border="1" rules="all"><thead><tr><th align="left"><p>参数</p></th><th align="left"><p>输入/输出</p></th><th align="left"><p>说明</p></th></tr></thead><tbody><tr><td><p>format</p></td><td><p>输入</p></td><td><p>数据类型为 op::Format（即 <a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/basicdataapi/atlasopapi_07_00515.html">ge::Format</a>），本身是一个枚举，包含多种不同的Format，例如NCHW、ND等。</p></td></tr></tbody></table>

#### 返回值说明
无

#### 约束说明
无

#### 调用示例
```cpp
// 将input的ViewFormat置为ND格式
void Func(const aclTensor *input) {
    input->SetViewFormat(ge::FORMAT_ND);
}
```
