# SetDataType

#### 功能说明
设置aclTensor的数据类型。

#### 函数原型
**void SetDataType(op::DataType dataType)**

#### 参数说明
<table cellpadding="4" cellspacing="0" frame="border" border="1" rules="all">
 <thead>
  <tr><th align="left">参数</th><th align="left">输入/输出</th><th align="left">说明</th></tr>
 </thead>
 <tbody>
  <tr><td>dataType</td><td>输入</td><td>数据类型为<span>op::DataType（即<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/basicdataapi/atlasopapi_07_00514.html">ge::DataType</a>）</span>，将aclTensor设置为dataType类型。</td></tr>
 </tbody>
</table>

#### 返回值说明
无

#### 约束说明
无

#### 调用示例
```cpp
// 将input的数据类型设置为int64
void Func(const aclTensor *input) {
    input->SetDataType(DT_INT64);
}
```
