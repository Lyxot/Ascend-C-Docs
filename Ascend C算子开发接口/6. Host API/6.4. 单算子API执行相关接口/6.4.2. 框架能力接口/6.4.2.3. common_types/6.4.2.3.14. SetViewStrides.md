# SetViewStrides

## 功能说明
设置aclTensor的ViewStrides。

## 函数原型
**SetViewStrides(const op::Strides &amp;strides)**  
**SetViewStrides(op::Strides &amp;&amp;strides)**

## 参数说明
<table>
  <thead>
    <tr><th>参数</th><th>输入/输出</th><th>说明</th></tr>
  </thead>
  <tbody>
    <tr><td>strides</td><td>输入</td><td>类型为<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_1042.html#ZH-CN_TOPIC_0000002370171629__li1071411561236">FVector</a>&lt;int64_t&gt;，表示aclTensor每一维的stride大小，取值不支持负数。</td></tr>
  </tbody>
</table>

## 返回值说明
void

## 约束说明
无

## 调用示例
```cpp
// 将input最后一维的stride扩大8倍。
void Func(const aclTensor *input) {
  auto strides = input->GetViewStrides();
  strides[strides.size() - 1] *= 8;
  input->SetViewStrides(strides);
}
```
