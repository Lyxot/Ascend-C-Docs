# GetDataType

#### 功能说明
获取aclTensor的数据类型。

#### 函数原型
**op::DataType GetDataType()**

#### 参数说明
无

#### 返回值说明
op::DataType（即[ge::DataType](https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/basicdataapi/atlasopapi_07_00514.html)）表示aclTensor中元素的数据类型，包含多种数据类型，例如float16、float32等。

#### 约束说明
无

#### 调用示例
```cpp
// 获取input的数据类型
void Func(const aclTensor *input) {
    op::DataType dataType = input->GetDataType();
}
```
