# GetOriginalShape

## 功能说明

获取aclTensor的OriginShape属性。

## 函数原型

`gert::Shape GetOriginalShape()`

## 参数说明

无

## 返回值说明

返回值为[gert::Shape](https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/basicdataapi/atlasopapi_07_00149.html)，记录了一组shape信息，例如一个三维shape：[10, 20, 30]。

## 约束说明

无

## 调用示例

```cpp
void Func(const aclTensor *input) {
    auto shape = input->GetOriginalShape();
}
```
