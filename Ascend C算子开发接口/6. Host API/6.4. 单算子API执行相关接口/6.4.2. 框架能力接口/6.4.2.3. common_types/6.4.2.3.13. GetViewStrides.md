# GetViewStrides

#### 功能说明
获取aclTensor的ViewStrides。

#### 函数原型
**FVector<int64_t>** **GetViewStrides()**

#### 参数说明
无

#### 返回值说明
返回一个[FVector](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_1042.html#ZH-CN_TOPIC_0000002370171629__li1071411561236)对象，里面存放aclTensor各个维度的stride大小。

#### 约束说明
无

#### 调用示例
```cpp
// 获取input的View Stride并依次打印出每一维的stride大小
void Func(const aclTensor *input) {
    auto strides = input->GetViewStrides();
    for (int64_t stride : strides) {
        std::cout << stride << std::endl;
    }
}
```
