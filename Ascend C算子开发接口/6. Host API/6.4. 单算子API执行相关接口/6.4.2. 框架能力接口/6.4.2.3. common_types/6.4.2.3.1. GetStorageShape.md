# GetStorageShape

#### 功能说明

获取aclTensor的StorageShape属性。  
OriginShape表示aclTensor在经历transdata节点前（如果存在该节点）的原始shape信息，即tensor的shape数学描述。  
StorageShape表示aclTensor在内存上的实际排布，即OriginShape实际运行时的shape格式。

#### 函数原型

`gert::Shape GetStorageShape()`

#### 参数说明

无

#### 返回值说明

返回值为[gert::Shape](https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/basicdataapi/atlasopapi_07_00149.html)，记录了一组shape信息，例如一个三维shape：[10, 20, 30]。

#### 约束说明

无

#### 调用示例

```cpp
void Func(const aclTensor *input) {
  auto shape = input->GetStorageShape();
}
```
