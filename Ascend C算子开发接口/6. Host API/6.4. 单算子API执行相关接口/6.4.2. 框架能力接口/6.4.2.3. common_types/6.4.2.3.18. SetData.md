# SetData

## 功能说明

针对通过AllocHostTensor申请得到的host侧tensor，设置指定位置的数据。

## 函数原型

- 针对tensor，设置指定索引处的值  
  **void SetData(int64_t index, const T value, op::DataType dataType)**
- 针对tensor，用一块已有内存初始化tensor数据  
  **void SetData(const T *value, uint64_t size, op::DataType dataType)**

## 参数说明

1. 设置指定索引处的值的接口说明  
   <table>
    <thead><tr><th>参数</th><th>输入/输出</th><th>说明</th></tr></thead>
    <tbody>
     <tr><td>index</td><td>输入</td><td>需要修改aclTensor的第几个元素。</td></tr>
     <tr><td>value</td><td>输入</td><td>将aclTensor的指定元素修改为value的值。</td></tr>
     <tr><td>dataType</td><td>输入</td><td>数据类型为op::DataType（即<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/basicdataapi/atlasopapi_07_00514.html">ge::DataType</a>）。将value转为指定的dataType后，再写入aclTensor。</td></tr>
    </tbody>
   </table>
2. 用一块已有内存初始化tensor数据的接口说明  
   <table>
    <thead><tr><th>参数</th><th>输入/输出</th><th>说明</th></tr></thead>
    <tbody>
     <tr><td>value</td><td>输入</td><td>指向需要写入aclTensor的数据内存指针。</td></tr>
     <tr><td>size</td><td>输入</td><td>需要写入的元素个数。</td></tr>
     <tr><td>dataType</td><td>输入</td><td>数据类型为op::DataType（即<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/basicdataapi/atlasopapi_07_00514.html">ge::DataType</a>）。将数据转为指定的dataType后，再写入aclTensor。</td></tr>
    </tbody>
   </table>

## 返回值说明

无

## 约束说明

入参指针不能为空。

## 调用示例

```cpp
// 初始化一块int64_t内存，分别将input的前10个数字，置为该内存的内容。并将input的第11个数字置为myArray的第一个数字。
void Func(const aclTensor *input) {
  int64_t myArray[10];
  input->SetData(myArray, 10, DT_INT64);
  input->SetData(10, myArray[0], DT_INT64);
}
```
