# GetOriginalFormat

## 功能说明
获取aclTensor的OriginFormat。  
OriginFormat一般表示aclTensor在经历transdata节点前（如果存在该节点）的原始Format信息。

## 函数原型
**op::Format GetOriginalFormat()**

## 参数说明
无

## 返回值说明
返回一个op::Format（即[ge::Format](https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/basicdataapi/atlasopapi_07_00515.html)），本身是一个枚举，包含多种不同的Format，例如NCHW、ND等。

## 约束说明
无

## 调用示例
```Cpp
void Func(const aclTensor *input) {
    auto format = input->GetOriginalFormat();
}
```
