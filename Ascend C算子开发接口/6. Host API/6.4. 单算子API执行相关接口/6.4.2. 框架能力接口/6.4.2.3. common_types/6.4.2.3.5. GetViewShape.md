  <h1 class="topictitle1">GetViewShape</h1>
  <div>
   <div class="section">
    <h4 class="sectiontitle">功能说明</h4>
    <p>获取aclTensor的ViewShape。ViewShape表示aclTensor的逻辑shape。</p>
    <p>假设一个aclTensor的StorageShape和ViewShape如下：</p>
    <ul>
     <li>StorageShape为[10, 20]：表示该aclTensor在内存上是按照[10, 20]排布的。</li>
     <li>ViewShape为[2, 5, 20]：在算子使用时，表示该aclTensor可被视为一块[2, 5, 20]的数据使用。</li>
    </ul>
   </div>
   <div class="section">
    <h4 class="sectiontitle">函数原型</h4>
    <p><strong>gert::Shape GetViewShape()</strong></p>
   </div>
   <div class="section">
    <h4 class="sectiontitle">参数说明</h4>
    <p>无</p>
   </div>
   <div class="section">
    <h4 class="sectiontitle">返回值说明</h4>
    <p>返回值为<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/basicdataapi/atlasopapi_07_00149.html">gert::Shape</a>，记录了一组shape信息，例如一个三维shape：[10, 20, 30]。</p>
   </div>
   <div class="section">
    <h4 class="sectiontitle">约束说明</h4>
    <p>无</p>
   </div>
