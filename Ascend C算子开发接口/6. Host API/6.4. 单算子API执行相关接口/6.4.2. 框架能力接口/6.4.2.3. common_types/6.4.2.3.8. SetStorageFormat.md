# SetStorageFormat

#### 功能说明

设置aclTensor的StorageFormat。

StorageFormat表示aclTensor在内存中的排布格式，例如NCHW、ND等。

#### 函数原型

**void SetStorageFormat(op::Format format)**

#### 参数说明

<table><thead><tr><th>参数</th><th>输入/输出</th><th>说明</th></tr></thead><tbody><tr><td>format</td><td>输入</td><td>数据类型为op::Format（即<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/basicdataapi/atlasopapi_07_00515.html">ge::Format</a>），本身是一个枚举，包含多种不同的Format，例如NCHW、ND等。</td></tr></tbody></table>

#### 返回值说明

无

#### 约束说明

无

#### 调用示例

```cpp
// 将input的Storage Format置为ND格式
void Func(const aclTensor *input) {
    input->SetStorageFormat(ge::FORMAT_ND);
}
```
