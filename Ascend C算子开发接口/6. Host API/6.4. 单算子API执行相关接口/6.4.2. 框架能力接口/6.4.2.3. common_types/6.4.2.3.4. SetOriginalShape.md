# SetOriginalShape

#### 功能说明
设置aclTensor的OriginShape。

#### 函数原型
`void SetOriginalShape(const op::Shape &shape)`

#### 参数说明
<table><thead><tr><th>参数</th><th>输入/输出</th><th>说明</th></tr></thead><tbody><tr><td>shape</td><td>输入</td><td>数据类型为 op::Shape（即 <a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/basicdataapi/atlasopapi_07_00149.html">gert::Shape</a>），记录了一组shape信息，例如一个三维shape：[10, 20, 30]。</td></tr></tbody></table>

#### 返回值说明
无

#### 约束说明
无

#### 调用示例
```cpp
// 将input的OriginShape设置为[1, 2, 3, 4, 5]
void Func(aclTensor *input) {
    gert::Shape newShape;
    for (int64_t i = 1; i <= 5; i++) {
        newShape.AppendDim(i);
    }
    input->SetOriginalShape(newShape);
}
```
