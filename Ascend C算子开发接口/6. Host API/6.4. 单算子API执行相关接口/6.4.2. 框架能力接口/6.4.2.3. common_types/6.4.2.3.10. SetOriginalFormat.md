# SetOriginalFormat

#### 功能说明

设置aclTensor的OriginFormat。

OriginFormat一般表示aclTensor在经历transdata节点前（如果存在该节点）的原始Format信息。

#### 函数原型

**void SetOriginalFormat(op::Format format)**

#### 参数说明

<table border="1" rules="all"><thead><tr><th align="left" valign="top" width="17.22%"><p>参数</p></th><th align="left" valign="top" width="15.41%"><p>输入/输出</p></th><th align="left" valign="top" width="67.37%"><p>说明</p></th></tr></thead><tbody><tr><td valign="top" width="17.22%"><p>format</p></td><td valign="top" width="15.41%"><p>输入</p></td><td valign="top" width="67.37%"><p>数据类型为op::Format（即<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/basicdataapi/atlasopapi_07_00515.html">ge::Format</a>），本身是一个枚举，包含多种不同的Format，例如NCHW、ND等。</p></td></tr></tbody></table>

#### 返回值说明

无

#### 约束说明

无

#### 调用示例

```cpp
// 将input的OriginFormat置为ND格式
void Func(const aclTensor *input) {
    input->SetOriginalFormat(ge::FORMAT_ND);
}
```
