# OP_INPUT

#### 宏功能
用于封装算子的输入aclTensor和aclTensorList。

#### 宏原型
**OP_INPUT（x...）**

#### 参数说明
<table>
<thead><tr><th>参数</th><th>输入/输出</th><th>说明</th></tr></thead>
<tbody><tr><td>x...</td><td>输入</td><td>输入的aclTensor和aclTensorList。</td></tr></tbody>
</table>

#### 约束说明
如果算子包含非aclTensor且非aclTensorList的输入参数，需要先调用aclOpExecutor::ConvertToTensor将参数转换为aclTensor。

#### 调用示例
```cpp
// 封装算子的两个输入参数，self和other
OP_INPUT(self, other);
```
