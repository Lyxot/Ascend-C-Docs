# L0_DFX

#### 宏功能
用于L0接口时延统计及入参打印，必须在L0接口最前方调用。

#### 宏原型
**L0_DFX（profilingName, ...）**

#### 参数说明
<table border="1"><thead><tr><th>参数</th><th>输入/输出</th><th>说明</th></tr></thead><tbody><tr><td>profilingName</td><td>输入</td><td>Host侧L0接口名，例如AddAiCore。</td></tr><tr><td>...</td><td>输入</td><td>Host侧L0接口的入参，可变长参数。</td></tr></tbody></table>

#### 约束说明
必须在L0接口的入口处调用，否则可能导致时延统计出现误差。

#### 调用示例
```cpp
// 统计L0接口AddAiCore的时延及参数打印，AddAiCore是L0接口的名字，self，other和addOut是L0接口参数
L0_DFX(AddAiCore, self, other, addOut);
```
