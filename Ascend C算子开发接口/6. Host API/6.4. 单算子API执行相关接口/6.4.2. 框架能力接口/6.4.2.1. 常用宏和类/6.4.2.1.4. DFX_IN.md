# DFX_IN

#### 宏功能
用于封装L2一阶段接口aclnn*Xxx*GetWorkspaceSize的输入参数。

#### 宏原型
**DFX_IN（。）**

#### 参数说明
<table><thead><tr><th>参数</th><th>输入/输出</th><th>说明</th></tr></thead><tbody><tr><td>...</td><td>输入</td><td>Host侧L2一阶段接口的输入参数，可变长参数。</td></tr></tbody></table>

#### 约束说明
无

#### 调用示例
```cpp
// add算子的输入参数，共有3个：self，other和alpha
DFX_IN(self, other, alpha);
```
