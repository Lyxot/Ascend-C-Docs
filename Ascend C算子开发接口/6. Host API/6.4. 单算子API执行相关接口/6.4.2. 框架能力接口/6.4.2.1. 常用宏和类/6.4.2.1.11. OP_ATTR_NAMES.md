# OP_ATTR_NAMES

#### 宏功能
用于封装AI CPU算子的属性名字。

#### 宏原型
**OP_ATTR_NAMES ::op::FVector<std::string>**

#### 参数说明
<table border="1"><thead><tr><th>参数</th><th>输入/输出</th><th>说明</th></tr></thead><tbody><tr><td>/</td><td>输入</td><td>AI CPU算子的属性名，类型为std::string的<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_1042.html#ZH-CN_TOPIC_0000002370171629__li1071411561236">FVector</a>。默认值为空的FVector，即OP_ATTR_NAMES()。</td></tr></tbody></table>

#### 约束说明
无

#### 调用示例
```cpp
// 封装AI CPU算子的3个属性名为Tindices，T和use_locking
OP_ATTR_NAMES({"Tindices", "T", "use_locking"});
```
