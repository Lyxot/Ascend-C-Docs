# OP_MODE

#### 宏功能
用于封装算子的运行模式，算子计算过程中是否使能HF32数据类型。

#### 宏原型
**OP_MODE（x...）**

#### 参数说明
<table cellpadding="4" cellspacing="0" border="1"><thead><tr><th>参数</th><th>输入/输出</th><th>说明</th></tr></thead><tbody><tr><td>x...</td><td>输入</td><td>指定算子运行模式，具体取值参见<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_1065.html">OpExecMode</a>。默认为0，即Default模式。</td></tr></tbody></table>

#### 约束说明
无

#### 调用示例
```cpp
// 封装算子的运行模式
OP_MODE(OP_EXEC_MODE_DEFAULT);
```
