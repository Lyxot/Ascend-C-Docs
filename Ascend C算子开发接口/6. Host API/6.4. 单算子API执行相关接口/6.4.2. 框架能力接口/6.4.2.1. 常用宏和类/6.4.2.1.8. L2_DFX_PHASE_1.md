# L2_DFX_PHASE_1

#### 宏功能
用于L2一阶段接口aclnn*Xxx*GetWorkspaceSize时延统计及入参打印，必须在一阶段接口最前方调用。

#### 宏原型
`L2_DFX_PHASE_1（APIName, IN, OUT）`

如下接口是上述宏定义会调用到的关联接口。

```cpp
#define DFX_IN(...) std::make_tuple(__VA_ARGS__)
#define DFX_OUT(...) std::make_tuple(__VA_ARGS__)
```

#### 参数说明
<table>
  <thead><tr><th>参数</th><th>输入/输出</th><th>说明</th></tr></thead>
  <tbody>
    <tr><td>APIName</td><td>输入</td><td>Host侧L2接口名，如aclnn<em>Xxx</em>。</td></tr>
    <tr><td>IN</td><td>输入</td><td>算子的输入参数，由<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_1048.html">DFX_IN</a>封装。</td></tr>
    <tr><td>OUT</td><td>输入</td><td>算子的输出参数，由<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_1049.html">DFX_OUT</a>封装。</td></tr>
  </tbody>
</table>

#### 约束说明
必须在L2一阶段接口的入口处调用，否则可能导致时延统计出现误差。传入参数必须与L2接口的参数列表严格一致。

#### 调用示例
```cpp
// abs算子的L2接口一阶段时延统计及参数打印，self为abs算子的输入，out为abs算子的输出
L2_DFX_PHASE_1(aclnnAbs, DFX_IN(self), DFX_OUT(out));
```
