# OP_ATTR

#### 宏功能

用于封装算子的属性参数。

#### 宏原型

**OP_ATTR（x...）**

#### 参数说明

<table>
<thead><tr><th>参数</th><th>输入/输出</th><th>说明</th></tr></thead>
<tbody><tr><td>x...</td><td>输入</td><td>算子的属性参数（即算子原型中属性参数）。</td></tr></tbody>
</table>

#### 约束说明

无

#### 调用示例

```cpp
// 封装算子的2个属性参数，dstType和sqrtMode
OP_ATTR(dstType, sqrtMode);
```
