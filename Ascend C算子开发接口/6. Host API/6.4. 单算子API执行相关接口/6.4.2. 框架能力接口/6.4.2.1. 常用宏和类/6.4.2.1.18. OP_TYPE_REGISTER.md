# OP_TYPE_REGISTER

#### 宏功能
注册一个L0算子，生成对应的算子名称和TypeID。

#### 宏原型
**OP_TYPE_REGISTER（kernelName）**

#### 参数说明
<table><thead><tr><th>参数</th><th>输入/输出</th><th>说明</th></tr></thead><tbody><tr><td><strong>kernelName</strong></td><td>输入</td><td>算子名，例如Abs。</td></tr></tbody></table>

#### 约束说明
必须在L0接口最开始处使用。

#### 调用示例
```cpp
namespace l0op{
OP_TYPE_REGISTER(Abs);
...
}
```
