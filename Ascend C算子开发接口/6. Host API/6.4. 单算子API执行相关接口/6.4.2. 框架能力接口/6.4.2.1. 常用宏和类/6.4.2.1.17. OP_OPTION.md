# OP_OPTION

#### 宏功能
用于封装算子的精度模式。

#### 宏原型
**OP_OPTION（x...）**

#### 参数说明
<table><thead><tr><th>参数</th><th>输入/输出</th><th>说明</th></tr></thead><tbody><tr><td>x...</td><td>输入</td><td>指定算子精度模式，具体取值参见<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_1064.html">OpImplMode</a>。</td></tr></tbody></table>

#### 约束说明
无

#### 调用示例
```cpp
// 封装算子的精度模式为高精度模式
OP_OPTION(IMPL_MODE_HIGH_PRECISION);
```
