# OP_WORKSPACE

#### 宏功能
用于封装算子显式指定的workspace参数。

#### 宏原型
**OP_WORKSPACE（x...）**

#### 参数说明
<table><thead><tr><th>参数</th><th>输入/输出</th><th>说明</th></tr></thead><tbody><tr><td>x...</td><td>输入</td><td>算子的workspace参数，表示算子计算过程中需要的Device内存。支持aclTensor或aclTensorList类型。</td></tr></tbody></table>

#### 约束说明
无。

#### 调用示例
```cpp
// 封装算子的workspace参数a
OP_WORKSPACE(a);
```
