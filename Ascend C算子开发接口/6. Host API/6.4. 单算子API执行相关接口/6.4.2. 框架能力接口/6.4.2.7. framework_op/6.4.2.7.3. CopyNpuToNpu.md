# CopyNpuToNpu

## 功能说明
创建一个device侧到device侧的数据拷贝任务，并放入executor的任务队列中。

## 函数原型
**aclnnStatus CopyNpuToNpu(const aclTensor *src, const aclTensor *dst, aclOpExecutor *executor)**

## 参数说明
<table><thead><tr><th>参数</th><th>输入/输出</th><th>说明</th></tr></thead><tbody><tr><td>src</td><td>输入</td><td>拷贝的源tensor。</td></tr><tr><td>dst</td><td>输入</td><td>拷贝的目的tensor。</td></tr><tr><td>executor</td><td>输入</td><td> </td></tr></tbody></table>

## 返回值说明
创建拷贝任务成功，则返回ACLNN_SUCCESS（状态码值0），否则返回其他[aclnn错误码](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_1042.html#ZH-CN_TOPIC_0000002370171629__table2070319561334)。

## 约束说明
入参指针不能为空。

## 调用示例
```cpp
// 创建src到dst的拷贝任务， 如果不成功则返回
void Func(const aclTensor *src, const aclTensor *dst, aclOpExecutor *executor) {
    if (CopyNpuToNpu(src, dst, executor) != ACLNN_SUCCESS) {
        return;
    }
}
```
