# GetSocLongVersion

#### 功能说明
获取昇腾AI处理器的长型号信息，格式形如Ascend_xxxyy_。

#### 函数原型
`const std::string &GetSocLongVersion()`

#### 参数说明
无

#### 返回值说明
返回字符串形式的长型号信息。

#### 约束说明
无

#### 调用示例
```cpp
void func() {
    // Ascendxxx请替换为实际版本型号
    if (GetCurrentPlatformInfo().GetLongSocVersion() != "Ascendxxx") {
        return;
    }
}
```
