# GetSocVersion

#### 功能说明
获取昇腾AI处理器的短型号信息，格式形如Ascendxxx。

#### 函数原型
`SocVersion GetSocVersion()`

#### 参数说明
无

#### 返回值说明
返回SocVersion。

#### 约束说明
无

#### 调用示例
```cpp
void func() {
    // ASCENDXXX请替换为实际版本型号
    if (GetCurrentPlatformInfo().GetSocVersion() != SocVersion::ASCENDXXX) {
        return;
    }
}
```
