# TypeSize

## 功能说明
计算输入的数据类型一个元素占用多少Byte。对于不满一个Byte大小的数据类型，会在基础bit大小上额外加1000，例如Int4，将返回1004，表示一个元素占用4bit。

## 函数原型
`size_t TypeSize(DataType dataType)`

## 参数说明
<table><thead><tr><th>参数</th><th>输入/输出</th><th>说明</th></tr></thead><tbody><tr><td>dataType</td><td>输入</td><td>输入的数据类型，返回该数据类型单元素大小。</td></tr></tbody></table>

## 返回值说明
返回输入数据类型单元素的大小。

## 约束说明
无

## 调用示例
```cpp
// 获取dtype的单个元素size大小
void Func(const DataType dtype) {
    size_t size = TypeSize(dtype);
}
```
