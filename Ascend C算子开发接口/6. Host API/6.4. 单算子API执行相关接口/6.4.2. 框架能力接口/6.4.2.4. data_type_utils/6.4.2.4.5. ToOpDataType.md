# ToOpDataType

#### 功能说明

将aclDataType转换为对应的op::DataType。

- aclDataType：AscendCL（Ascend Computing Language）框架对外提供的数据类型，具体定义参见“[aclDataType](https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/appdevgapi/aclcppdevg_03_1346.html)”。
- op::DataType：算子框架内部定义的数据类型，本质使用的是GE定义的[ge::DataType](https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/basicdataapi/atlasopapi_07_00514.html)。

#### 函数原型

**DataType ToOpDataType(aclDataType type)**

 </thead>
 <tbody>
  <tr><td width="17.22%">type</td><td width="15.39%">输入</td><td width="67.39%">待转换的原始数据类型aclDataType。</td></tr>
 </tbody>
</table>

#### 返回值说明

返回op::DataType类型。

#### 约束说明

无

#### 调用示例

```cpp
// 获取ACL_FLOAT对应的DataType枚举
void Func() {
    DataType type = ToOpDataType(ACL_FLOAT);
}
```
