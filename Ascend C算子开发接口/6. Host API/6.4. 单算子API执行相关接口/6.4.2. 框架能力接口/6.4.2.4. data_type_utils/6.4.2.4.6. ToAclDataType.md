# ToAclDataType

#### 功能说明

将op::DataType转换为对应的aclDataType。

- aclDataType：AscendCL（Ascend Computing Language）框架对外提供的数据类型，具体定义参见“[aclDataType](https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/appdevgapi/aclcppdevg_03_1346.html)”。
- op::DataType：算子框架内部定义的数据类型，本质使用的是GE定义的[ge::DataType](https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/basicdataapi/atlasopapi_07_00514.html)。

#### 函数原型

**aclDataType ToAclDataType(DataType type)**

#### 参数说明

<table border="1"><thead><tr><th><p>参数</p></th><th><p>输入/输出</p></th><th><p>说明</p></th></tr></thead><tbody><tr><td><p>type</p></td><td><p>输入</p></td><td><p>待转换的原始数据类型op::DataType。</p></td></tr></tbody></table>

#### 返回值说明

返回aclDataType类型。

#### 约束说明

无

#### 调用示例

```cpp
// 获取DT_FLOAT对应的aclDataType枚举
void Func() {
    aclDataType type = ToAclDataType(DT_FLOAT);
}
```
