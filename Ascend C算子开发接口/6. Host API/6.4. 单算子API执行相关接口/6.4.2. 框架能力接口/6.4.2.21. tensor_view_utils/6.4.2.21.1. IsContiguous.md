# IsContiguous

#### 功能说明
判断输入tensor是否为一个连续tensor。

#### 函数原型
`bool IsContiguous(const aclTensor *tensor)`

#### 参数说明
<table><thead><tr><th>参数</th><th>输入/输出</th><th>说明</th></tr></thead><tbody><tr><td>tensor</td><td>输入</td><td>目标tensor。</td></tr></tbody></table>

#### 返回值说明
若为连续tensor返回true，否则返回false。

#### 约束说明
- 传入tensor非空。
- 对于空指针场景，将返回true，输出ERROR提示："check tensor != nullptr failed"。

#### 调用示例
```cpp
// 判断当tensor非连续时，返回。
void Func(aclTensor *tensor) {
    if (!IsContiguous(tensor)) {
        return;
    }
}
```
