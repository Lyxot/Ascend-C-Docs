# Pad

#### 支持的产品型号
- Atlas 训练系列产品
- Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件
- Atlas A3 训练系列产品/Atlas A3 推理系列产品
- Atlas 推理系列产品

#### 功能说明
将输入tensor按照paddings的大小对各个维度进行填充，填充值为0。

#### 函数原型
`const aclTensor* Pad(const aclTensor* self, const aclTensor* paddings, aclOpExecutor* executor)`

#### 参数说明
<table>
<thead><tr><th>参数</th><th>输入/输出</th><th>说明</th></tr></thead>
<tbody><tr><td>self</td><td>输入</td><td>待填充的输入tensor，数据类型支持FLOAT16、FLOAT、INT16、UINT16、INT32、INT64、BFLOAT16、INT8。数据格式支持ND。说明：BFLOAT16和INT8适用于如下产品型号：Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件；Atlas A3 训练系列产品/Atlas A3 推理系列产品。</td></tr>
<tr><td>paddings</td><td>输入</td><td>输入tensor每个维度被填充的大小，形状为[self.dim，2]，数据类型支持INT32、INT64。数据格式支持ND。</td></tr>
<tr><td>executor</td><td>输入</td><td>op执行器，包含了算子计算流程。</td></tr>
</tbody>
</table>

#### 返回值说明
返回被填充了0的tensor。

#### 约束说明
无

#### 调用示例
```Cpp
//调用l0op::Pad对self进行补维
l0op::Pad(self, paddingsTensor, executor);
```
