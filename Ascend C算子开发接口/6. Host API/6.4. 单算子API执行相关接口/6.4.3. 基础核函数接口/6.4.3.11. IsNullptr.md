<h1 class="topictitle1">IsNullptr</h1>
<div><div class="section"><h4 class="sectiontitle">支持的产品型号</h4><p><span><term>Atlas 训练系列产品</term></span></p>
<p><span><term>Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件</term></span></p>
<p><span><term>Atlas A3 训练系列产品/Atlas A3 推理系列产品</term></span></p>
<p><span><term>Atlas 推理系列产品</term></span></p>
</div>
<div class="section"><h4 class="sectiontitle">功能说明</h4><p>判断输入的指针是否为空。若为空指针返回true、并打印错误日志，否则返回false。</p>
</div>
<div class="section"><h4 class="sectiontitle">函数原型</h4><ul><li><strong>static inline bool IsNullptr(const aclTensor *tensor, const char *name)</strong></li><li><strong>static inline bool IsNullptr(const aclTensorList *tensorList, const char *name)</strong></li><li><strong>static inline bool IsNullptr(const aclScalar *scalar, const char *name)</strong></li><li><strong>static inline bool IsNullptr(const aclIntArray *intArr, const char *name)</strong></li><li><strong>static inline bool IsNullptr(const aclBoolArray *boolArr, const char *name)</strong></li><li><strong>static inline bool IsNullptr(const aclFloatArray *floatArr, const char *name)</strong></li></ul>
</div>
