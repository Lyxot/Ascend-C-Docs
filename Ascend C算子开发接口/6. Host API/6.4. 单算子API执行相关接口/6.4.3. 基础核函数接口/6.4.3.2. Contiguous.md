<h1 class="topictitle1">Contiguous</h1>
<div><div class="section"><h4 class="sectiontitle">支持的产品型号</h4><p><span><term>Atlas 训练系列产品</term></span></p>
<p><span><term>Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件</term></span></p>
<p><span><term>Atlas 200I/500 A2 推理产品</term></span></p>
<p><span><term>Atlas A3 训练系列产品/Atlas A3 推理系列产品</term></span></p>
<p><span><term>Atlas 推理系列产品</term></span></p>
</div>
<div class="section"><h4 class="sectiontitle">功能说明</h4><p>该函数为公共的L0接口，作用是将非连续tensor转换为连续tensor。</p>
<p>由于L2级API的输入tensor可能是非连续的，一般L0级算子只支持连续tensor作为输入，因此需要将tensor转为连续后再作为其他L0算子的输入。</p>
<p>输入tensor可以是连续的，接口内部会兼容处理。</p>
</div>
<div class="section"><h4 class="sectiontitle">函数原型</h4><p><strong>const aclTensor *Contiguous(const aclTensor *x, aclOpExecutor *executor)</strong></p>
</div>

<div class="section"><h4 class="sectiontitle">返回值说明</h4><p>若转换成功，则返回一个连续的aclTensor， 若失败，则返回nullptr。</p>
</div>
<div class="section"><h4 class="sectiontitle">约束说明</h4><p>要求输入tensor是合法的tensor，Shape和Stride所表示的数据在Storage大小范围内。例如：shape=(2，3), stride = (10, 30), storageSize=8，数据实际空间超过了Storage大小8，该Tensor为非法，Contiguous接口返回nullptr。</p>
</div>
