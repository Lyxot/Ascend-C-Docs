  <h1 class="topictitle1">Reshape</h1>
  <div>
   <div class="section">
    <h4 class="sectiontitle">支持的产品型号</h4>
    <p><span><term>
       Atlas 训练系列产品
      </term></span></p>
    <p><span><term>
       Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件
      </term></span></p>
    <p><span><term>
       Atlas 200I/500 A2 推理产品
      </term></span></p>
    <p><span><term>
       Atlas A3 训练系列产品/Atlas A3 推理系列产品
      </term></span></p>
    <p><span><term>
       Atlas 推理系列产品
      </term></span></p>
   </div>
   <div class="section">
    <h4 class="sectiontitle">功能说明</h4>
    <p>该函数不改变算子tensor数据，只是将用户传入的输入tensor x的shape转换成该函数的第二个参数shape。</p>
   </div>
   <div class="section">
    <h4 class="sectiontitle">函数原型</h4>
    <p><strong>const aclTensor *Reshape(const aclTensor *x, const op::Shape &amp;shape, aclOpExecutor *executor)</strong></p>
    <p><strong>const aclTensor *Reshape(const aclTensor *x, const aclIntArray *shape, aclOpExecutor *executor)</strong></p>
   </div>

   <div class="section">
    <h4 class="sectiontitle">返回值说明</h4>
    <p>若reshape转换成功，则返回带有目标shape信息的aclTensor给调用者；若失败，则返回nullptr。</p>
   </div>
   <div class="section">
    <h4 class="sectiontitle">约束说明</h4>
    <ul>
     <li>reshape转换成功的前提是x的ShapeSize需要和第二个参数shape的ShapeSize相等，所谓的ShapeSize举例如下：A的shape=(1, 3, 256, 256)， 则A的ShapeSize=1*3*256*256。</li>
     <li>当前不支持转换成空tensor，所谓的空tensor即shape中包含0。</li>
    </ul>
   </div>
