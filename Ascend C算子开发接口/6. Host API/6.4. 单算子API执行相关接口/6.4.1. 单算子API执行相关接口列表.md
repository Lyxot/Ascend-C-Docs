  <h1 class="topictitle1">单算子API执行相关接口列表</h1>
  <div>
   <div class="section">
    <h4 class="sectiontitle">整体说明</h4>
    <p>无论是基于Ascend C自定义的算子还是CANN提供的内置算子，都可以通过<strong>aclnn前缀API</strong>（简称aclnn接口）形式调用算子，这种方式称为“<strong>单算子API执行</strong>”。该方法简单且灵活，更便于用户进行AI业务开发与应用。</p>
    <div class="note">
     <img src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/public_sys-resources/note_3.0-zh-cn.png"><span class="notetitle"> </span>
     <div class="notebody">
      <ul>
       <li>aclnn前缀API：简称aclnn接口，属于<a href="#ZH-CN_TOPIC_0000002370171629__zh-cn_topic_0000001917744184_li572474119382">Level2层接口</a>，本质是一类C语言API，调用算子时无需提供IR（Intermediate Representation）定义。</li>
       <li>内置算子：CANN的算子加速库（Ascend Operator Library，简称AOL），包含一系列高性能算子和aclnn接口，用户可直接使用，无需自定义，详细介绍请参考<span>《<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/apiref/aolapi/operatorlist_00001.html" target="_blank" rel="noopener noreferrer">AOL算子加速库接口参考</a>》</span>。</li>
       <li>“<strong>单算子API执行</strong>”是一种单算子调用方式，其调用流程和其他调用方式介绍请参考<span>“<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/appdevg/acldevg/aclcppdevg_000017.html">单算子调用流程</a>”</span>。</li>
      </ul>
     </div>
    </div>
    <p>为实现API形式直调算子，本章提供了单算子API执行依赖的底层框架接口和基础核函数接口（即<a href="#ZH-CN_TOPIC_0000002370171629__zh-cn_topic_0000001917744184_li1543255153717">Level0层接口</a>），详细阐述了接口的原型、功能、参数说明、约束与限制、调用示例等，指导开发者快速掌握接口含义和使用方法。</p>
    <ul>
     <li>框架能力接口：提供实现aclnn前缀接口相关的基础能力接口，比如算子执行器（opExecutor）处理、数据类型/格式/shape等操作，具体如<a href="#ZH-CN_TOPIC_0000002370171629__table2070319561334">表1</a>所示；此外还包括常用类和宏，具体参见<a href="#ZH-CN_TOPIC_0000002370171629__table370875616310">表2</a>、<a href="#ZH-CN_TOPIC_0000002370171629__table2712056035">表3</a>。</li>
     <li>基础核函数接口：提供实现aclnn前缀接口的基础核函数接口，比如Tensor数据类型转换、shape重构等，具体如<a href="#ZH-CN_TOPIC_0000002370171629__table177150561835">表4</a>所示。</li>
    </ul>
    <p>使用上述接口时，注意请根据实际情况include依赖的头文件，头文件路径为<span>${INSTALL_DIR}</span>/include目录，其中<span>${INSTALL_DIR}请替换为CANN软件安装后文件存储路径。若安装的Ascend-cann-toolkit软件包，以root安装举例，则安装后文件存储路径为：/usr/local/Ascend/ascend-toolkit/latest。</span></p>
    <p>为更好指导开发者应用本章接口，<strong>端到端的接口调用示例</strong>可参考Gitee <strong>cann-ops-adv仓</strong>，该仓开放了融合算子实现的源代码，单击<a href="https://gitee.com/ascend/cann-ops-adv" target="_blank" rel="noopener noreferrer">Link</a>访问“/src/transformer/${OpType}/ophost/”获取不同算子源码，${OpType}表示算子类型。如果您需要对算子Host侧API实现进行<strong>定制化修改</strong>，建议先熟悉本章接口。</p>

    <h4 class="sectiontitle">基本概念</h4>
    <ul>
     <li><a name="ZH-CN_TOPIC_0000002370171629__zh-cn_topic_0000001917744184_li1543255153717"></a><a name="zh-cn_topic_0000001917744184_li1543255153717"></a><strong>Level0层接口</strong>
      <p>简称L0接口，表示调用单Kernel的Host侧API，提供了细颗粒API（单Kernel下发）和算子API开发的基础结构体（如Tensor定义等）和公共基础能力（如workspace复用、引擎调度等），上层应用或者L2接口可通过L0接口的快速组装实现高性能计算。</p>
      <p>L0接口返回值类型是Tensor的类型结构，如aclTensor*、std::tuple&lt;aclTensor*, aclTensor*&gt;、aclTensorList*，最后一个参数固定为aclOpExecutor *executor，类型与名称均不可变，示例如下：</p>
      <div class="codecoloring" codetype="Cpp">

     <li><a name="ZH-CN_TOPIC_0000002370171629__zh-cn_topic_0000001917744184_li572474119382"></a><a name="zh-cn_topic_0000001917744184_li572474119382"></a><strong>Level2层接口</strong>
      <p>简称L2接口，是对L0接口的高层级封装（内部通过调用单个或多个L0接口实现更灵活功能），表示更上层的Host侧API。该类接口提供单算子直调方式，屏蔽了算子内部实现逻辑，用户直接调用L2接口即可实现调用算子。</p>
