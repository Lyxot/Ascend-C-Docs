# GetCoreMemBw

## 功能说明
获取硬件平台存储空间的带宽大小。硬件存储空间类型定义如下：
```cpp
enum class CoreMemType {
    L0_A = 0, // 预留参数，暂不支持
    L0_B = 1, // 预留参数，暂不支持
    L0_C = 2, // 预留参数，暂不支持
    L1 = 3,   // 预留参数，暂不支持
    L2 = 4,
    UB = 5,   // 预留参数，暂不支持
    HBM = 6,
    RESERVED
};
```

## 函数原型
```cpp
void GetCoreMemBw(const CoreMemType &memType, uint64_t &bwSize) const
```

## 参数说明
<table>
<thead><tr><th>参数</th><th>输入/输出</th><th>说明</th></tr></thead>
<tbody><tr><td>memType</td><td>输入</td><td>硬件存储空间类型。</td></tr>
<tr><td>bwSize</td><td>输出</td><td>对应硬件的存储空间的带宽大小。单位是Byte/cycle，cycle代表时钟周期。</td></tr></tbody>
</table>

## 返回值说明
无

## 约束说明
无
