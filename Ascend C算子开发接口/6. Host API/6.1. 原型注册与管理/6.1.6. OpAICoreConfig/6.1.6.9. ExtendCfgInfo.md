    <p>ExtendCfgInfo支持的参数如下表：</p>
    <div class="tablenoborder">
     <table cellpadding="4" cellspacing="0" summary="" frame="border" border="1" rules="all">
      <caption>
       <b>表2 </b>ExtendCfgInfo支持配置的参数
      </caption>
      <thead align="left">
       <tr>
        <th align="left" class="cellrowborder" valign="top" width="16.919999999999998%">
         <p>参数</p></th>
        <th align="left" class="cellrowborder" valign="top" width="83.08%">
         <p>功能介绍</p></th>
       </tr>
      </thead>
      <tbody>
       <tr>
        <td class="cellrowborder" valign="top" width="16.919999999999998%" headers="mcps1.3.3.4.2.3.1.1 ">
         <p>aclnnSupport.value</p></td>
        <td class="cellrowborder" valign="top" width="83.08%" headers="mcps1.3.3.4.2.3.1.2 ">
         <ul>
          <li>support_aclnn：此模式下，静态Shape场景中该算子通过模型下沉执行，动态Shape场景则在Host侧调用fallback函数下发算子。如果调用了<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_00055.html">EnableFallBack</a>则默认采用该模式。
           <pre class="screen">// 如下为动态Shape场景的示例
OpAICoreConfig aicore_config;
aicore_config.DynamicShapeSupportFlag(true)   // 动态Shape场景需要设置DynamicShapeSupportFlag为true
             .ExtendCfgInfo("aclnnSupport.value", "support_aclnn");
this-&gt;AICore().AddConfig("ascendxxx", aicore_config);

// 如下为静态Shape场景的示例
OpAICoreConfig aicore_config;
aicore_config.DynamicCompileStaticFlag(true)  // 静态Shape场景需要设置DynamicCompileStaticFlag为true
             .ExtendCfgInfo("aclnnSupport.value", "support_aclnn");
this-&gt;AICore().AddConfig("ascendxxx", aicore_config);</pre></li>
          <li>aclnn_only：此模式下，动静态Shape场景中该算子均以fallback形式下发。不建议用户使用该模式，后续版本待废弃。
           <pre class="screen">// 如下为动态Shape场景的示例
OpAICoreConfig aicore_config;
aicore_config.DynamicShapeSupportFlag(true) // 动态Shape场景需要设置DynamicShapeSupportFlag为true
			 .ExtendCfgInfo("aclnnSupport.value", "aclnn_only");
this-&gt;AICore().AddConfig("ascendxxx", aicore_config);
// 如下为静态Shape场景的示例
OpAICoreConfig aicore_config;              // 无需配置DynamicCompileStaticFlag/DynamicShapeSupportFlag，算子均以fallback形式下发，即动态Shape模型的下发方式
aicore_config.ExtendCfgInfo("aclnnSupport.value", "aclnn_only");
this-&gt;AICore().AddConfig("ascendxxx", aicore_config);</pre></li>
         </ul>
         <p>关于fallback下发算子的详细介绍请参考<span><a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/graph/graphdevg/atlasag_25_0080.html">基于fallback形式下发算子</a></span>章节。</p></td>
       </tr>
