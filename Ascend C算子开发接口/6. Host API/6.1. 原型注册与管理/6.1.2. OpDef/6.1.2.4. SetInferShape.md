# SetInferShape

#### 功能说明
使用图模式时，需要调用该接口注册Shape推导函数。

#### 函数原型
```cpp
OpDef &SetInferShape(gert::OpImplRegisterV2::InferShapeKernelFunc func)
```

<thead>
<tr><th>参数</th><th>输入/输出</th><th>说明</th></tr>
</thead>
<tbody>
<tr><td>func</td><td>输入</td><td>Shape推导函数。InferShapeKernelFunc类型定义如下，入参类型参考<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/basicdataapi/atlasopapi_07_00094.html">InferShapeContext</a>：```cpp
using InferShapeKernelFunc = UINT32 (*)(InferShapeContext *);
```</td></tr>
</tbody>
</table>

OpDef算子定义，OpDef请参考<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0946.html">OpDef</a>。
