# Input

### 功能说明
注册算子输入，调用该接口后会返回一个OpParamDef结构，后续可通过该结构配置算子输入信息。

### 函数原型
```cpp
OpParamDef & Input(const char *name)
```

### 参数说明
<table border="1">
<thead><tr><th>参数</th><th>输入/输出</th><th>说明</th></tr></thead>
<tbody><tr><td>name</td><td>输入</td><td>算子输入名称。</td></tr></tbody>
</table>

### 返回值说明
算子参数定义，OpParamDef实例，具体请参考[OpParamDef](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0957.html)。

### 约束说明
参数注册的顺序需要和算子kernel入口函数一致。
