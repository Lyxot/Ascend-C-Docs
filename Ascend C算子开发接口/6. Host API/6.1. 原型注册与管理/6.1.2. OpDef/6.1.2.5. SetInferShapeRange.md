# SetInferShapeRange

## 功能说明
使用图模式时，需要调用该接口注册ShapeRange推导函数。

## 函数原型
```cpp
OpDef &SetInferShapeRange(gert::OpImplRegisterV2::InferShapeRangeKernelFunc func)
```

## 参数说明
<table cellpadding="4" cellspacing="0" summary="" frame="border" border="1" rules="all">
 <thead>
  <tr><th>参数</th><th>输入/输出</th><th>说明</th></tr>
 </thead>
 <tbody>
  <tr><td>func</td><td>输入</td><td>ShapeRange推导函数。InferShapeRangeKernelFunc类型定义如下，入参类型参考[InferShapeRangeContext](https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/basicdataapi/atlasopapi_07_00103.html)：  
```cpp
using InferShapeRangeKernelFunc = UINT32 (*)(InferShapeRangeContext *);
```</td></tr>
 </tbody>
</table>

## 返回值说明
OpDef算子定义，OpDef请参考[OpDef](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0946.html)。
