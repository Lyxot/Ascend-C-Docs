# NodeIoNum

## 功能说明

声明算子定义的输入与输出个数

## 函数原型

```cpp
ContextBuilder &NodeIoNum(size_t inputNum, size_t outputNum)
```

## 参数说明

<table border="1" rules="all"><thead><tr><th>参数</th><th>输入/输出</th><th>说明</th></tr></thead><tbody><tr><td>inputNum</td><td>输入</td><td>算子IR原型定义中的输入个数</td></tr><tr><td>outputNum</td><td>输入</td><td>算子IR原型定义中的输出个数</td></tr></tbody></table>

## 返回值说明

当前ContextBuilder的对象

## 约束说明

必须配合<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_1016.html">IrInstanceNum</a>一同使用。

## 调用示例

```cpp
auto builder = ContextBuilder().NodeIoNum(5, 3); // 该算子有5个输入，3个输出
```
