# SetOpNameType

#### 功能说明
设置算子的名字与类型

#### 函数原型
```cpp
ContextBuilder &SetOpNameType(const std::string& opName, const std::string& opType)
```

#### 参数说明
<table>
<tr><th><p>参数</p></th><th><p>输入/输出</p></th><th><p>说明</p></th></tr>
<tr><td><p>opName</p></td><td><p>输入</p></td><td><p>算子名字</p></td></tr>
<tr><td><p>opType</p></td><td><p>输入</p></td><td><p>算子类型</p></td></tr>
</table>

#### 返回值说明
当前ContextBuilder的对象。

#### 约束说明
无

#### 调用示例
```cpp
std::string opName = "tmpNode";
std::string opType = "FlashAttentionScore";
context_ascendc::ContextBuilder builder;
(void)builder.SetOpNameType(opName, opType);
```
