# AddPlatformInfo

#### 功能说明
设置硬件平台信息便于用户在算子Tiling函数调测中使用。支持以下两种设置方式：
1. **自动获取当前硬件平台信息**：传入空指针，自动获取当前硬件信息并添加到ContextBuilder类中。
2. **指定硬件平台信息**：传入具体的昇腾AI处理器型号，添加对应硬件信息至ContextBuilder类中。

若设置失败，会打印报错信息。关于日志配置和查看，请参考[日志](https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/maintenref/envvar/envref_07_0118.html)。

#### 函数原型
```cpp
ContextBuilder &AddPlatformInfo(const char* customSocVersion)
```

<tbody><tr><td>customSocVersion</td><td>输入</td><td>昇腾AI处理器型号。配置方式如下：<ul><li>非Atlas A3 训练系列产品/Atlas A3 推理系列产品：在安装昇腾AI处理器的服务器执行<strong>npu-smi info</strong>命令进行查询，获取<strong>Name</strong>信息。实际配置值为AscendName，例如<strong>Name</strong>取值为<em>xxxyy</em>，实际配置值为Ascend<em>xxxyy</em>。</li><li>Atlas A3 训练系列产品/Atlas A3 推理系列产品：在安装昇腾AI处理器的服务器执行<strong>npu-smi info -t board -i </strong><em>id</em><strong> -c </strong><em>chip_id</em>命令进行查询，获取<strong>Chip Name</strong>和<strong>NPU Name</strong>信息，实际配置值为Chip Name_NPU Name。例如<strong>Chip Name</strong>取值为Ascend<em>xxx</em>，<strong>NPU Name</strong>取值为1234，实际配置值为Ascend<em>xxx</em><em>_</em>1234。<p>其中：</p><ul><li>id：设备id，通过<strong>npu-smi info -l</strong>命令查出的NPU ID即为设备id。</li><li>chip_id：芯片id，通过<strong>npu-smi info -m</strong>命令查出的Chip ID即为芯片id。</li></ul></li></ul></td></tr></tbody>
</table>

#### 返回值说明
当前ContextBuilder对象。

#### 约束说明
AddPlatformInfo调用后需要通过[BuildTilingContext](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_1024.html)来构建Tiling的上下文，并传递给Tiling函数来使用。

#### 调用示例
```cpp
void AddPlatformInfoDemo(......)
{
    auto holder = context_ascendc::ContextBuilder()
        // ... ... // 增加算子输入输出接口的调用
        .AddPlatformInfo("Ascendxxxyy")
        .BuildTilingContext();
    auto tilingContext = holder->GetContext<gert::TilingContext>();
    // ... ...
}
```
