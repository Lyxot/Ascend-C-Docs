         <p>ASCENDC_TPL_UINT_DECL(args0, args1, args2, ...)</p></td>
        <td class="cellrowborder" valign="top" width="20.59205920592059%" headers="mcps1.3.3.2.2.4.1.2 ">
         <p>自定义UINT类型（无符号整形）的模板参数定义。</p></td>
        <td class="cellrowborder" valign="top" width="47.83478347834784%" headers="mcps1.3.3.2.2.4.1.3 ">
         <ul>
          <li>args0：参数名。</li>
          <li>args1：最大位宽，模板参数的个数不能超过最大位宽。</li>
          <li>args2：参数定义的模式。支持以下三种模式：
           <ul>
            <li>ASCENDC_TPL_UI_RANGE：范围模式，设置该模式，后续紧跟着第一个值表示范围个数，第一个值后面的每两个数值为一组分别表示该范围的起、终位置；注意定义的范围个数要和后续的组数保持一致。
             <p><a name="ZH-CN_TOPIC_0000002336173104__li9721164520145"></a><a name="li9721164520145"></a><strong>举例：</strong>ASCENDC_TPL_UINT_DECL(args0, args1,ASCENDC_TPL_UI_RANGE,2,0,2,3,5)表示2组参数，这2组参数范围为{0, 2}，{3, 5}，因此该参数定义的UINT参数合法值为{0, 1, 2, 3, 4, 5}。</p></li>
            <li>ASCENDC_TPL_UI_LIST：穷举模式，设置该模式，则表示后续将穷举出所有的参数值。
             <p><a name="ZH-CN_TOPIC_0000002336173104__li14387132511544"></a><a name="li14387132511544"></a><strong>举例：</strong>ASCENDC_TPL_UINT_DECL(args0, args1,ASCENDC_TPL_UI_LIST,10,12,13,9,8,7,6)表示1组穷举参数，[10, 12, 13, 9, 8, 7, 6]为穷举值，因此该参数定义的UINT参数合法值为{10, 12, 13, 9, 8, 7, 6}。</p></li>
            <li>ASCENDC_TPL_UI_MIX：混合模式，设置该模式，则表示前n个数值为范围模式的参数定义，后m个数值为穷举模式的参数定义。
             <p><a name="ZH-CN_TOPIC_0000002336173104__li672284571411"></a><a name="li672284571411"></a><strong>举例</strong>：</p>
             <p>ASCENDC_TPL_UINT_DECL(args0, args1,ASCENDC_TPL_UI_MIX,2,0,2,3, 5, 10, 12, 13, 9, 8)表示2组穷举参数，这2组范围为{0, 2}, {3, 5}，[10, 12, 13, 9, 8]为穷举值，因此该参数定义的UINT参数合法值为{0, 1, 2, 3, 4, 5, 10, 12, 13, 9, 8}。</p></li>
           </ul></li>
          <li>args3-argsn：对应不同范围模式的参数数值。</li>
         </ul></td>
       </tr>
