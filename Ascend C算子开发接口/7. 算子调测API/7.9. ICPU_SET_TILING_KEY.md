<h1 class="topictitle1">ICPU_SET_TILING_KEY</h1>
<div><div class="section"><h4 class="sectiontitle">功能说明</h4><p>用于指定本次CPU调测使用的tilingKey。调测执行时，将只执行算子核函数中该tilingKey对应的分支。</p>
</div>
<div class="section"><h4 class="sectiontitle">函数原型</h4><div class="codecoloring" codetype="Cpp"><div class="highlight"><table class="highlighttable"><tr><td class="linenos"><div class="linenodiv"><pre><span class="normal">1</span></pre></div></td><td class="code"><div><pre><span class="n">ICPU_SET_TILING_KEY</span><span class="p">(</span><span class="n">tilingKey</span><span class="p">)</span>
</pre></div></td></tr></table></div>
</div>
</div>
<div class="section"><h4 class="sectiontitle">参数说明</h4>

<th align="left" class="cellrowborder" valign="top" width="11.93%"><p>输入/输出</p>

</td>
<td class="cellrowborder" valign="top" width="71.58%" headers="mcps1.3.3.2.1.4.1.3 "><p>指定本次CPU调测使用的tilingKey，参数类型为int32_t。</p>
</td>
</tr>
</tbody>
</table>
</div>
</div>
<div class="section"><h4 class="sectiontitle">返回值</h4><p>无</p>
</div>
<div class="section"><h4 class="sectiontitle">约束说明</h4><ul><li>未使用该接口设置tilingKey的情况下，tilingKey将会为默认值0，在调测执行时，会有告警提示Tiling Key是0，并继续进行调测。如果核函数中有tilingKey分支，将会执行tilingKey为0的分支，其他tilingKey对应的分支不会执行。</li><li>tilingKey建议传入正整数，如果设置为负数或者0，将会告警并继续调测。如果传入0，将会执行tilingKey为0的分支；tilingKey传入负数，将导致未定义的行为。</li><li>该接口需要在<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_1208.html">ICPU_RUN_KF</a>前调用。</li></ul>
</div>
