#### 功能说明

进行核函数的CPU侧运行验证时，CPU调测总入口，完成CPU侧的算子程序调用。

#### 函数原型

```cpp
#define ICPU_RUN_KF(func, blkdim, ...)
```

#### 参数说明

<table border="1" rules="all"><thead><tr><th align="left">参数名</th><th align="left">输入/输出</th><th align="left">描述</th></tr></thead><tbody><tr><td valign="top">func</td><td valign="top">输入</td><td valign="top">算子的kernel函数指针。</td></tr><tr><td valign="top">blkdim</td><td valign="top">输入</td><td valign="top">算子的核心数，corenum。</td></tr><tr><td valign="top">...</td><td valign="top">输入</td><td valign="top">所有的入参和出参，依次填入，当前参数个数限制为32个，超出32时会出现编译错误。</td></tr></tbody></table>

#### 返回值

无

#### 约束说明

除了func、blkdim以外，其他的变量都必须是通过GmAlloc分配的共享内存的指针；传入的参数的数量和顺序都必须和kernel保持一致。

#### 调用示例

```cpp
ICPU_RUN_KF(sort_kernel0, coreNum, (uint8_t*)x, (uint8_t*)y);
```
