# GmFree

#### 产品支持情况
<table cellpadding="4" cellspacing="0" border="1"><thead><tr><th>产品</th><th>是否支持</th></tr></thead><tbody><tr><td>Atlas A3 训练系列产品/Atlas A3 推理系列产品</td><td>√</td></tr><tr><td>Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件</td><td>√</td></tr><tr><td>Atlas 200I/500 A2 推理产品</td><td>√</td></tr><tr><td>Atlas 推理系列产品AI Core</td><td>√</td></tr><tr><td>Atlas 推理系列产品Vector Core</td><td>x</td></tr><tr><td>Atlas 训练系列产品</td><td>√</td></tr><tr><td>Atlas 200/300/500 推理产品</td><td>x</td></tr></tbody></table>

#### 功能说明
进行核函数的CPU侧运行验证时，用于释放通过[GmAlloc](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_1207.html)申请的共享内存。

#### 函数原型
```cpp
void GmFree(void *ptr)
```

#### 参数说明
<table cellpadding="4" cellspacing="0" border="1"><thead><tr><th>参数名</th><th>输入/输出</th><th>描述</th></tr></thead><tbody><tr><td>ptr</td><td>输入</td><td>需要释放的共享内存的指针。</td></tr></tbody></table>

#### 返回值
无

#### 约束说明
传入的指针必须是之前通过GmAlloc申请过的共享内存的指针。

#### 调用示例
```cpp
AscendC::GmFree((void*)x);
```
