## 功能说明
用于设置性能数据采集信号启动，和MetricsProfStop配合使用。使用[msProf](https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/devaids/optool/atlasopdev_16_0081.html)工具进行算子上板调优时，可在kernel侧代码段前后分别调用MetricsProfStart和MetricsProfStop来指定需要调优的代码段范围。

## 函数原型
```cpp
__aicore__ inline void MetricsProfStart()
```

无
