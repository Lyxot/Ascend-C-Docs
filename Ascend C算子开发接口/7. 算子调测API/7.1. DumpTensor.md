    <h4 class="sectiontitle">功能说明</h4>
    <p>基于算子工程开发的算子，可以使用该接口Dump指定Tensor的内容。同时支持打印自定义的附加信息（仅支持uint32_t数据类型的信息），比如打印当前行号等。</p>
    <div class="p">
     在算子kernel侧实现代码中需要打印Tensor数据的地方调用DumpTensor接口打印相关内容。样例如下：
     <div class="codecoloring" codetype="Cpp">
      <div class="highlight">
       <table class="highlighttable">
        <tbody>
         <tr>
          <td class="linenos">
           <div class="linenodiv">
            <pre><span class="normal">1</span></pre>
           </div></td>
          <td class="code">
           <div>
            <pre><span class="n">AscendC</span><span class="o">::</span><span class="n">DumpTensor</span><span class="p">(</span><span class="n">srcLocal</span><span class="p">,</span><span class="mi">5</span><span class="p">,</span><span class="w"> </span><span class="n">dataLen</span><span class="p">);</span>
</pre>
           </div></td>
         </tr>
        </tbody>
       </table>
      </div>
     </div>
     <div class="caution">
      <span class="cautiontitle"><img src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/public_sys-resources/caution_3.0-zh-cn.png"> </span>
      <div class="cautionbody">
       <div class="p">

           <div class="codecoloring" codetype="Cpp">
            <div class="highlight">
             <table class="highlighttable">
              <tbody>
               <tr>
                <td class="linenos">
                 <div class="linenodiv">
                  <pre><span class="normal">1</span>
<span class="normal">2</span></pre>
                 </div></td>
                <td class="code">
                 <div>
                  <pre><span class="c1">// 关闭所有算子的printf打印功能</span>

</pre>
                 </div></td>
               </tr>
              </tbody>
             </table>
            </div>
           </div>
          </div></li>
         <li>Kernel直调工程
          <div class="p">

           <div class="codecoloring" codetype="Cpp">

    <p>Dump时，每个block核的dump信息前会增加对应信息头DumpHead（32字节大小），用于记录核号和资源使用信息；每次Dump的Tensor数据前也会添加信息头DumpTensorHead（32字节大小），用于记录Tensor的相关信息。如下图所示，展示了多核打印场景下的打印信息结构。</p>
    <p><img class="eddx" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002336334562.png"></p>
    <p><strong>DumpHead的具体信息如下：</strong></p>
    <ul>
     <li>opType：当前运行的算子类型；</li>
     <li>CoreType：当前运行的核的类型；</li>
     <li>block dim：开发者设置的算子执行核数；</li>
     <li>total_block_num：参与dump的核数；</li>
     <li>block_remain_len：当前核剩余可用的dump的空间；</li>
     <li>block_initial_space：当前核初始分配的dump空间；</li>
     <li>rsv：保留字段；</li>
     <li>magic：内存校验魔术字。</li>
    </ul>
    <p>DumpHead打印时，除了上述打印还会自动打印当前所运行核的类型及对应的该类型下的核索引，如：AIV-0。</p>
    <p><strong>DumpTensorHead的具体信息如下：</strong></p>
    <ul>
     <li>desc：用户自定义附加信息；</li>
     <li>addr：Tensor的地址；</li>
     <li>data_type：Tensor的数据类型；</li>
     <li>position：表示Tensor所在的物理存储位置，当前仅支持<span>Unified Buffer</span>/<span>L1 Buffer</span>/<span>L0C Buffer</span>/<span>Global Memory</span>。</li>
    </ul>
    <p>DumpTensor打印结果的最前面会自动打印CANN_VERSION_STR值与CANN_TIMESTAMP值。其中，CANN_VERSION_STR与CANN_TIMESTAMP为宏定义，CANN_VERSION_STR代表CANN软件包的版本号信息，形式为字符串，CANN_TIMESTAMP为CANN软件包发布时的时间戳，形式为数值（uint64_t）。开发者也可在代码中直接使用这两个宏。</p>

   <div class="section">
    <h4 class="sectiontitle">约束说明</h4>
    <ul>
     <li><strong>该功能仅用于NPU上板调试，且仅在如下场景支持</strong><strong>：</strong>
      <ul>
       <li>通过<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0056.html">Kernel直调</a>方式调用算子。</li>
      </ul>
      <ul>
       <li>通过<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0070.html">单算子API调用</a>方式调用算子。</li>
       <li>间接调用单算子API(aclnnxxx)接口：Pytorch框架单算子直调的场景。</li>
      </ul></li>
     <li><strong>当前仅支持打印存储位置为<span>Unified Buffer</span>/<span>L1 Buffer</span>/<span>L0C Buffer</span>/<span>Global Memory</span>的Tensor信息。</strong></li>
     <li>操作数地址偏移对齐要求请参见<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0004.html">通用约束</a>。</li>
     <li>该接口使用Dump功能，所有使用Dump功能的接口在每个核上Dump的数据总量不可超过1M。请开发者自行控制待打印的内容数据量，超出则不会打印。</li>
    </ul>
