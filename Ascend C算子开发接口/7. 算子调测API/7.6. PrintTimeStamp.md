    <h4 class="sectiontitle">功能说明</h4>
    <p>提供时间戳打点功能，用于在算子Kernel代码中标记关键执行点，调用后会打印如下信息：</p>
    <ul>
     <li>descId： 用户自定义标识符，用于区分不同打点位置；</li>
     <li>rsv ：保留值，默认为0，无需关注；</li>
     <li>timeStamp ： 当前系统cycle数，用于计算时间差，时间换算规则可参考<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0282.html">GetSystemCycle(ISASI)</a>；</li>
     <li>pcPtr：pc指针数值，若无特殊需求，用户无需关注。</li>
    </ul>
    <p>打印示例如下：</p>
    <div class="codecoloring" codetype="ColdFusion">
     <div class="highlight">
      <table class="highlighttable">
       <tbody>
        <tr>
         <td class="linenos">
          <div class="linenodiv">
           <pre><span class="normal">1</span></pre>
          </div></td>
         <td class="code">
          <div>
           <pre><span class="nv">descId</span> <span class="o">is</span> <span class="m">65577</span><span class="p">,</span> <span class="nv">rsv</span> <span class="o">is</span> <span class="m">0</span><span class="p">,</span> <span class="nv">timeStamp</span> <span class="o">is</span> <span class="m">13806084506158</span><span class="p">,</span> <span class="nv">pcPtr</span> <span class="o">is</span> <span class="m">20619064414544</span><span class="p">.</span>

    <div class="p">
     <div class="caution">
      <span class="cautiontitle"><img src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/public_sys-resources/caution_3.0-zh-cn.png"> </span>
      <div class="cautionbody">
       <p>该功能主要用于<strong>调试和性能分析</strong>，开启后会对算子性能产生一定影响，<strong>生产环境建议关闭</strong>。</p>
       <div class="p">
        默认情况下，该功能关闭，开发者可以按需通过如下方式开启打点功能。
        <ul>
         <li>Kernel直调工程
          <p><a name="ZH-CN_TOPIC_0000002370251517__li1082864111110"></a><a name="li1082864111110"></a>修改cmake目录下的npu_lib.cmake文件，在ascendc_compile_definitions命令中增加-DASCENDC_TIME_STAMP_ON，打开时间戳打点功能，示例如下：</p>
          <div class="codecoloring" codetype="Cpp">
           <div class="highlight">
            <table class="highlighttable">
             <tbody>
              <tr>
               <td class="linenos">
                <div class="linenodiv">
                 <pre><span class="normal">1</span>
<span class="normal">2</span>
<span class="normal">3</span></pre>
                </div></td>
               <td class="code">
                <div>
                 <pre><span class="n">ascendc_compile_definitions</span><span class="p">(</span><span class="n">ascendc_kernels_$</span><span class="p">{</span><span class="n">RUN_MODE</span><span class="p">}</span><span class="w"> </span><span class="n">PRIVATE</span>
<span class="w">    </span><span class="o">-</span><span class="n">DASCENDC_TIME_STAMP_ON</span>
<span class="p">)</span>
</pre>
                </div></td>
              </tr>
             </tbody>
            </table>
           </div>
          </div>
          <p>CPU域调试时，不支持该功能。</p></li>
         <li>自定义算子工程
          <div class="p">
           <a name="ZH-CN_TOPIC_0000002370251517__li782211794413"></a><a name="li782211794413"></a>修改算子工程op_kernel目录下的CMakeLists.txt文件，首行增加编译选项-DASCENDC_TIME_STAMP_ON，打开时间戳打点功能，示例如下：
           <div class="codecoloring" codetype="Cpp">
            <div class="highlight">
             <table class="highlighttable">
              <tbody>
               <tr>
                <td class="linenos">
                 <div class="linenodiv">
                  <pre><span class="normal">1</span></pre>
                 </div></td>
                <td class="code">
                 <div>
                  <pre><span class="n">add_ops_compile_options</span><span class="p">(</span><span class="n">ALL</span><span class="w"> </span><span class="n">OPTIONS</span><span class="w"> </span><span class="o">-</span><span class="n">DASCENDC_TIME_STAMP_ON</span><span class="p">)</span>
</pre>
                 </div></td>
               </tr>
              </tbody>
             </table>
            </div>
           </div>
          </div></li>
        </ul>

    <h4 class="sectiontitle">约束说明</h4>
    <ul>
     <li><strong>该功能仅用于NPU上板调试，且仅在如下场景支持</strong><strong>：</strong>
      <ul>
       <li>通过<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0056.html">Kernel直调</a>方式调用算子。</li>
       <li>通过<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0070.html">单算子API调用</a>方式调用算子。</li>
       <li>间接调用单算子API(aclnnxxx)接口：Pytorch框架单算子直调的场景。</li>
      </ul></li>
     <li>该接口使用Dump功能，所有使用Dump功能的接口在每个核上Dump的数据总量不可超过1M。请开发者自行控制待打印的内容数据量，超出则不会打印。</li>
    </ul>
   </div>
