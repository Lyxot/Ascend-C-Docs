<div class="section"><h4 class="sectiontitle">功能说明</h4><p>通过CAModel进行算子性能仿真时，可对算子任意运行阶段打点，从而分析不同指令的流水图，以便进一步性能调优。</p>
<p>用于表示起始位置打点，一般与<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_1213.html">TRACE_STOP</a>配套使用。</p>
</div>

</div>

<div class="section"><h4 class="sectiontitle">返回值</h4><p>无</p>
</div>
<div class="section"><h4 class="sectiontitle">约束说明</h4><ul><li>TRACE_START/TRACE_STOP需配套使用，若Trace图上未显示打点，则说明两者没有配对。</li><li>不支持跨核使用，例如TRACE_START在AI Cube打点，则TRACE_STOP打点也需要在AI Cube上，不能在AI Vector上。</li><li>宏支持所有的产品型号，但实际调用时需与调测工具支持的型号保持一致。</li></ul>
</div>
