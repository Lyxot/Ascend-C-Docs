<div class="section"><h4 class="sectiontitle">功能说明</h4><p>针对分离架构，CPU调测时，设置内核模式为单AIV模式，单AIC模式或者MIX模式，以分别支持单AIV矢量算子，单AIC矩阵算子，MIX混合算子的CPU调试。不调用该接口的情况下，默认为MIX模式。为保证算子代码在多个硬件平台兼容，耦合架构下也可以调用，该场景下接口不会生效，不影响正常调试。</p>
</div>
