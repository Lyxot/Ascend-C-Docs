   <div class="section">
    <h4 class="sectiontitle">功能说明</h4>
    <p>基于算子工程开发的算子，可以使用该接口实现CPU/NPU域assert断言功能。算子执行中，如果assert内部条件判断不为真，则输出assert条件并将输入的信息格式化打印在屏幕上。</p>
    <div class="p">
     在算子kernel侧实现代码中需要增加断言的地方使用assert检查代码，并格式化输出一些调测信息。示例如下：
     <div class="codecoloring" codetype="Cpp">
      <div class="highlight">
       <table class="highlighttable">
        <tbody>
         <tr>
          <td class="linenos">
           <div class="linenodiv">
            <pre><span class="normal">1</span>
<span class="normal">2</span>
<span class="normal">3</span>
<span class="normal">4</span>
<span class="normal">5</span></pre>
           </div></td>
          <td class="code">
           <div>
            <pre><span class="kt">int</span><span class="w"> </span><span class="n">assertFlag</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="mi">10</span><span class="p">;</span>

<span class="n">assert</span><span class="p">(</span><span class="n">assertFlag</span><span class="w"> </span><span class="o">==</span><span class="w"> </span><span class="mi">10</span><span class="p">);</span>
<span class="n">assert</span><span class="p">(</span><span class="n">assertFlag</span><span class="w"> </span><span class="o">==</span><span class="w"> </span><span class="mi">10</span><span class="p">,</span><span class="w"> </span><span class="s">"The assertFlag value is 10.</span><span class="se">\n</span><span class="s">"</span><span class="p">);</span>
<span class="n">assert</span><span class="p">(</span><span class="n">assertFlag</span><span class="w"> </span><span class="o">==</span><span class="w"> </span><span class="mi">10</span><span class="p">,</span><span class="w"> </span><span class="s">"The assertFlag value is %d.</span><span class="se">\n</span><span class="s">"</span><span class="p">,</span><span class="w"> </span><span class="n">assertFlag</span><span class="p">);</span>
</pre>

   <div class="caution">
    <span class="cautiontitle"><img src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/public_sys-resources/caution_3.0-zh-cn.png"> </span>
    <div class="cautionbody">
     <div class="p">
      assert接口打印功能会对算子实际运行的性能带来一定影响（每一条assert，系统会额外增加一条逻辑判断，具体性能影响取决于代码中assert的使用数量），通常在调测阶段使用。开发者可以按需通过如下方式关闭打印功能。
      <ul>
       <li>自定义算子工程
        <div class="p">
         <a name="ZH-CN_TOPIC_0000002336333124__li1082864111110"></a><a name="li1082864111110"></a>修改算子工程op_kernel目录下的CMakeLists.txt文件，首行增加编译选项-DASCENDC_DUMP=0，关闭ASCENDC_DUMP开关，示例如下：
         <div class="codecoloring" codetype="Cpp">
          <div class="highlight">
           <table class="highlighttable">
            <tbody>
             <tr>
              <td class="linenos">
               <div class="linenodiv">
                <pre><span class="normal">1</span>
<span class="normal">2</span></pre>
               </div></td>
              <td class="code">
               <div>
                <pre><span class="c1">// 关闭所有算子的printf打印功能</span>
<span class="n">add_ops_compile_options</span><span class="p">(</span><span class="n">ALL</span><span class="w"> </span><span class="n">OPTIONS</span><span class="w"> </span><span class="o">-</span><span class="n">DASCENDC_DUMP</span><span class="o">=</span><span class="mi">0</span><span class="p">)</span>
</pre>
               </div></td>
             </tr>
            </tbody>
           </table>
          </div>
         </div>
        </div></li>
       <li>Kernel直调工程
        <div class="p">
         <a name="ZH-CN_TOPIC_0000002336333124__li14828104112119"></a><a name="li14828104112119"></a>修改cmake目录下的npu_lib.cmake文件，在ascendc_compile_definitions命令中增加-DASCENDC_DUMP=0宏定义来关闭ASCENDC_DUMP开关；关闭CPU侧的断言打印，则修改cpu_lib.cmake文件。示例如下：
         <div class="codecoloring" codetype="Cpp">
          <div class="highlight">
           <table class="highlighttable">
            <tbody>
             <tr>
              <td class="linenos">
               <div class="linenodiv">
                <pre><span class="normal">1</span>
<span class="normal">2</span>
<span class="normal">3</span>
<span class="normal">4</span></pre>
               </div></td>
              <td class="code">
               <div>
                <pre><span class="c1">// 关闭所有算子的printf打印功能</span>
<span class="n">ascendc_compile_definitions</span><span class="p">(</span><span class="n">ascendc_kernels_$</span><span class="p">{</span><span class="n">RUN_MODE</span><span class="p">}</span><span class="w"> </span><span class="n">PRIVATE</span>
<span class="w">    </span><span class="o">-</span><span class="n">DASCENDC_DUMP</span><span class="o">=</span><span class="mi">0</span>
<span class="p">)</span>
</pre>
               </div></td>
             </tr>
            </tbody>
           </table>
          </div>
         </div>
        </div></li>
      </ul>
     </div>
    </div>
   </div>

    <h4 class="sectiontitle">约束说明</h4>
    <ul>
     <li><strong>该功能仅在如下场景支持</strong><strong>：</strong>
      <ul>
       <li>通过<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0056.html">Kernel直调</a>方式调用算子。</li>
      </ul>
      <ul>
       <li>通过<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0070.html">单算子API调用</a>方式调用算子。</li>
       <li>间接调用单算子API(aclnnxxx)接口：Pytorch框架单算子直调的场景。</li>
      </ul></li>
     <li>kernel开发不要包含系统的assert.h，会导致宏定义冲突。</li>
     <li>assert接口调用形式与C语言一致，不需要使用AscendC命名空间。</li>
    </ul>
    <ul>
     <li>本接口不支持打印除换行符之外的其他转义字符。</li>
     <li>该接口使用Dump功能，所有使用Dump功能的接口在每个核上Dump的数据总量不可超过1M。请开发者自行控制待打印的内容数据量，超出则不会打印。</li>
     <li>程序中只调用assert接口，assert接口使用空间每个核上不可超过1k。请开发者自行控制待打印的内容数据量，超出则不会打印。</li>
    </ul>
   </div>
