# SetSingleOutputShape

## 功能说明
设置单核上结果矩阵Output的形状。

## 函数原型
```cpp
void SetSingleOutputShape(int64_t singleCo, int64_t singleDo, int64_t singleM)
```

## 参数说明
<table>
  <thead>
    <tr><th>参数名</th><th>输入/输出</th><th>描述</th></tr>
  </thead>
  <tbody>
    <tr><td>singleCo</td><td>输入</td><td>单核上输出通道的大小。</td></tr>
    <tr><td>singleDo</td><td>输入</td><td>单核上Output D维度大小。</td></tr>
    <tr><td>singleM</td><td>输入</td><td>单核上Output M维度大小。</td></tr>
  </tbody>
</table>

## 返回值说明
无

## 约束说明
无

## 调用示例
```cpp
// 实例化Conv3D Api
auto ascendcPlatform = platform_ascendc::PlatformAscendC(context->GetPlatformInfo());
Conv3dTilingApi::Conv3dTiling conv3dApiTiling(ascendcPlatform);
conv3dApiTiling.SetSingleOutputShape(singleCo, singleDo, singleM);
```
