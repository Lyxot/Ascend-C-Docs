# SetWeightType

#### 功能说明
设置Weight在内存上的位置、数据格式和数据类型。

#### 函数原型
```cpp
void SetWeightType(const ConvCommonApi::TPosition pos, const ConvCommonApi::ConvFormat format, const ConvCommonApi::ConvDtype dtype)
```

#### 参数说明
<table>
<thead><tr><th>参数名</th><th>输入/输出</th><th>描述</th></tr></thead>
<tbody><tr><td>pos</td><td>输入</td><td>Weight在内存上的<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0004.html#ZH-CN_TOPIC_0000002370252365__table07372185712">位置</a>。当前仅支持TPosition::GM。</td></tr><tr><td>format</td><td>输入</td><td>Weight的数据格式。当前仅支持ConvFormat::FRACTAL_Z_3D。</td></tr><tr><td>dtype</td><td>输入</td><td>Weight的数据类型。当前仅支持ConvDtype::FLOAT16、ConvDtype::BF16。</td></tr></tbody>
</table>

#### 返回值说明
无

#### 约束说明
在调用GetTiling接口前，本接口可选调用。若未调用本接口，默认Weight为pos=TPosition::GM，format=ConvFormat::FRACTAL_Z_3D，dtype=ConvDtype::FLOAT16。

#### 调用示例
```cpp
// 实例化Conv3D Api
auto ascendcPlatform = platform_ascendc::PlatformAscendC(context->GetPlatformInfo());
Conv3dTilingApi::Conv3dTiling conv3dApiTiling(ascendcPlatform);
conv3dApiTiling.SetWeightType(ConvCommonApi::TPosition::GM, ConvCommonApi::ConvFormat::FRACTAL_Z_3D, ConvCommonApi::ConvDtype::BF16);
```
