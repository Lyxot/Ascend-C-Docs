# SetStride

#### 功能说明
设置Stride信息。

#### 函数原型
```cpp
void SetStride(int64_t strideD, int64_t strideH, int64_t strideW)
```

#### 参数说明
<table>
<thead><tr><th>参数名</th><th>输入/输出</th><th>描述</th></tr></thead>
<tbody><tr><td>strideD</td><td>输入</td><td>D方向Stride大小。</td></tr><tr><td>strideH</td><td>输入</td><td>H方向Stride大小。</td></tr><tr><td>strideW</td><td>输入</td><td>W方向Stride大小。</td></tr></tbody>
</table>

#### 返回值说明
无

#### 约束说明
在调用GetTiling接口前，本接口可选调用。若未调用本接口，默认strideD=1, strideH=1, strideW=1。

#### 调用示例
```cpp
// 实例化Conv3D Api
auto ascendcPlatform = platform_ascendc::PlatformAscendC(context->GetPlatformInfo());
Conv3dTilingApi::Conv3dTiling conv3dApiTiling(ascendcPlatform);
conv3dApiTiling.SetStride(strideD, strideH, strideW);
```
