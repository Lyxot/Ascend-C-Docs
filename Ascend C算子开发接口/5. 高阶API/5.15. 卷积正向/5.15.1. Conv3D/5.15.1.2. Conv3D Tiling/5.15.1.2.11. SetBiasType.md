# SetBiasType

#### 功能说明
设置Bias在内存上的位置、数据格式和数据类型。

#### 函数原型
```cpp
void SetBiasType(const ConvCommonApi::TPosition pos, const ConvCommonApi::ConvFormat format, const ConvCommonApi::ConvDtype dtype)
```

#### 参数说明
<table border="1" rules="all" cellpadding="4" cellspacing="0"><thead><tr><th align="left" valign="top" width="24.25%">参数名</th><th align="left" valign="top" width="17.29%">输入/输出</th><th align="left" valign="top" width="58.46%">描述</th></tr></thead><tbody><tr><td valign="top" width="24.25%">pos</td><td valign="top" width="17.29%">输入</td><td valign="top" width="58.46%">Bias在内存上的<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0004.html#ZH-CN_TOPIC_0000002370252365__table07372185712">位置</a>。当前仅支持TPosition::GM。</td></tr><tr><td valign="top" width="24.25%">format</td><td valign="top" width="17.29%">输入</td><td valign="top" width="58.46%">Bias的数据格式。当前仅支持ConvFormat::ND。</td></tr><tr><td valign="top" width="24.25%">dtype</td><td valign="top" width="17.29%">输入</td><td valign="top" width="58.46%">Bias的数据类型。当前仅支持ConvDtype::FLOAT16、ConvDtype::FLOAT。</td></tr></tbody></table>

#### 返回值说明
无

#### 约束说明
在调用GetTiling接口前，本接口可选调用。若未调用本接口，默认Bias为pos=TPosition::GM，format=ConvFormat::ND，dtype=ConvDtype::FLOAT16。

#### 调用示例
```cpp
// 实例化Conv3D Api
auto ascendcPlatform = platform_ascendc::PlatformAscendC(context->GetPlatformInfo());
Conv3dTilingApi::Conv3dTiling conv3dApiTiling(ascendcPlatform);
conv3dApiTiling.SetBiasType(ConvCommonApi::TPosition::GM, ConvCommonApi::ConvFormat::ND, ConvCommonApi::ConvDtype::FLOAT32);
```
