# SetBias

#### 产品支持情况
<table border="1"><thead><tr><th align="left">产品</th><th align="center">是否支持</th></tr></thead><tbody><tr><td>Atlas A3 训练系列产品/Atlas A3 推理系列产品</td><td align="center">√</td></tr><tr><td>Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件</td><td align="center">√</td></tr><tr><td>Atlas 200I/500 A2 推理产品</td><td align="center">x</td></tr><tr><td>Atlas 推理系列产品AI Core</td><td align="center">x</td></tr><tr><td>Atlas 推理系列产品Vector Core</td><td align="center">x</td></tr><tr><td>Atlas 训练系列产品</td><td align="center">x</td></tr><tr><td>Atlas 200/300/500 推理产品</td><td align="center">x</td></tr></tbody></table>

#### 功能说明
设置偏置矩阵Bias。

#### 函数原型
```cpp
__aicore__ inline void SetBias(const AscendC::GlobalTensor<BiasT>& bias)
```

#### 参数说明
<table border="1"><thead><tr><th align="left">参数名</th><th align="left">输入/输出</th><th align="left">描述</th></tr></thead><tbody><tr><td>bias</td><td>输入</td><td>Bias在Global Memory上的地址。类型为<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0007.html">GlobalTensor</a>。偏置矩阵Bias支持的数据类型为：half/bfloat16_t。</td></tr></tbody></table>

#### 返回值说明
无

#### 约束说明
在卷积计算中，如果涉及偏置矩阵Bias，必须调用此接口；若卷积计算不涉及Bias，则不应调用此接口。

#### 调用示例
```cpp
GlobalTensor<float> biasGm;
biasGm.SetGlobalBuffer(reinterpret_cast<__gm__ half *>(bias));
if (biasFlag) {
  conv3dApi.SetBias(biasGm);
}
```
