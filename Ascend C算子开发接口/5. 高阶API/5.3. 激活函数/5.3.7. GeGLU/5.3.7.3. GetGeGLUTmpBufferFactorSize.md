<h1 class="topictitle1">GetGeGLUTmpBufferFactorSize</h1>
<div><div class="section"><h4 class="sectiontitle">功能说明</h4><p>kernel侧GeGLU接口的计算需要开发者预留/申请临时空间，最大临时空间（maxTmpBuffer）和输入所占空间（inputSize * typeSize）存在以下关系：</p>
<p><strong>maxTmpBuffer = maxLiveNodeCount * inputSize * typeSize + </strong><strong>extraBuf</strong></p>
<p>其中maxLiveNodeCount表示最大临时空间是输入所占空间的多少倍；extraBuf表示使用的额外临时空间大小。</p>
<p>该接口用于获取maxLiveNodeCount和extraBuf，在固定空间大小的情况下，通过maxLiveNodeCount和extraBuf可以推算算子单次最大计算元素数量。</p>
<p>示例如下：</p>
<p>算子实现需要调用GeGLU接口，开发者为其预留currBuff大小的空间，利用GetGeGLUTmpBufferFactorSize接口得到maxLiveNodeCount 、extraBuf输出值，反推GeGLU算子单次最大计算元素数量为：</p>
<p><strong>currentShapeSize = (currBuff - extraBuf) / maxLiveNodeCount / typeSize</strong></p>
</div>
