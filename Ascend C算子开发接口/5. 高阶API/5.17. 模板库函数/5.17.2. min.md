#### 功能说明
比较相同数据类型的两个数，返回最小值。

#### 函数原型
```cpp
template <typename T, typename U>
__aicore__ inline T min(const T src0, const U src1)
```

#### 参数说明
<table border="1"><caption>表1 模板参数说明</caption><thead><tr><th align="left">参数名</th><th align="left">含义</th></tr></thead><tbody><tr><td>T</td><td>输入数据src0的数据类型。当前支持的数据类型为int8_t/uint8_t/int16_t/uint16_t/int32_t/uint32_t/float/int64_t/uint64_t。</td></tr><tr><td>U</td><td>输入数据src1的数据类型。当前支持的数据类型为int8_t/uint8_t/int16_t/uint16_t/int32_t/uint32_t/float/int64_t/uint64_t。预留类型，当前必须与T保持一致。</td></tr></tbody></table>

<table border="1"><caption>表2 接口参数说明</caption><thead><tr><th align="left">参数名</th><th align="left">输入/输出</th><th align="left">含义</th></tr></thead><tbody><tr><td>src0</td><td>输入</td><td>源操作数。参与比较的输入。</td></tr><tr><td>src1</td><td>输入</td><td>源操作数。参与比较的输入。</td></tr></tbody></table>

#### 约束说明
两个源操作数的数据类型必须相同。

#### 返回值说明
两个输入数据中的最小值。

#### 调用示例
```cpp
int64_t src0 = 1;
int64_t src1 = 2;

int64_t result = AscendC::Std::min(src0, src1);
// result: 1
```
