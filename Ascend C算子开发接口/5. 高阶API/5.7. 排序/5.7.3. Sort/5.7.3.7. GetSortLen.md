# GetSortLen

#### 功能说明
根据元素数量，获取Sort数据的大小（单位为字节）。

#### 函数原型
```cpp
template <typename T>
__aicore__ inline uint32_t GetSortLen(const uint32_t elemCount)
```

#### 参数说明
<table><caption><b>表1 </b>模板参数说明</caption><thead><tr><th>参数名</th><th>描述</th></tr></thead><tbody><tr><td>T</td><td>操作数的数据类型。<br>Atlas A3 训练系列产品/Atlas A3 推理系列产品，支持的数据类型为：half/float<br>Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件，支持的数据类型为：half/float<br>Atlas 推理系列产品AI Core，支持的数据类型为：half/float</td></tr></tbody></table>

<table><caption><b>表2 </b>接口参数列表</caption><thead><tr><th>参数名</th><th>输入/输出</th><th>描述</th></tr></thead><tbody><tr><td>elemCount</td><td>输入</td><td>输入元素个数。</td></tr></tbody></table>

#### 返回值说明
sort数据的大小（单位为字节）。

#### 约束说明
无

#### 调用示例
```cpp
AscendC::GetSortLen<half>(128);
```
