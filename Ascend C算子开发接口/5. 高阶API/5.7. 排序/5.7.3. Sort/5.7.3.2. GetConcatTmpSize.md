# GetConcatTmpSize

#### 功能说明
获取Concat接口所需的临时空间大小。

#### 函数原型
```cpp
inline uint32_t GetConcatTmpSize(const platform_ascendc::PlatformAscendC &ascendcPlatform, const uint32_t elemCount, const uint32_t dataTypeSize)
```

#### 参数说明
<table border="1" rules="all"><caption>表1 接口参数列表</caption><thead><tr><th>参数名</th><th>输入/输出</th><th>描述</th></tr></thead><tbody><tr><td>ascendcPlatform</td><td>输入</td><td>传入硬件平台的信息，PlatformAscendC定义请参见<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_1027.html">构造及析构函数</a>。</td></tr><tr><td>elemCount</td><td>输入</td><td>输入元素个数。</td></tr><tr><td>dataTypeSize</td><td>输入</td><td>输入数据大小（单位为字节）。</td></tr></tbody></table>

#### 返回值说明
Concat接口所需的临时空间大小。

#### 约束说明
无

#### 调用示例
```cpp
fe::PlatFormInfos platform_info;
auto plat = platform_ascendc::PlatformAscendC(&platform_info);
const uint32_t elemCount = 128;
AscendC::GetConcatTmpSize(plat, elemCount, 2);
```
