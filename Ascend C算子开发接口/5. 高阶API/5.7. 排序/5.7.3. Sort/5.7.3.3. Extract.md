# Extract

#### 产品支持情况
<table border="1" rules="all"><thead><tr><th align="left">产品</th><th align="center">是否支持</th></tr></thead><tbody><tr><td>Atlas A3 训练系列产品/Atlas A3 推理系列产品</td><td align="center">√</td></tr><tr><td>Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件</td><td align="center">√</td></tr><tr><td>Atlas 200I/500 A2 推理产品</td><td align="center">x</td></tr><tr><td>Atlas 推理系列产品AI Core</td><td align="center">√</td></tr><tr><td>Atlas 推理系列产品Vector Core</td><td align="center">x</td></tr><tr><td>Atlas 训练系列产品</td><td align="center">x</td></tr><tr><td>Atlas 200/300/500 推理产品</td><td align="center">x</td></tr></tbody></table>

#### 功能说明
处理Sort的结果数据，输出排序后的value和index。

#### 函数原型
```cpp
template <typename T>
__aicore__ inline void Extract(const LocalTensor<T> &dstValueLocal, const LocalTensor<uint32_t> &dstIndexLocal, const LocalTensor<T> &sortedLocal, const int32_t repeatTimes)
```
