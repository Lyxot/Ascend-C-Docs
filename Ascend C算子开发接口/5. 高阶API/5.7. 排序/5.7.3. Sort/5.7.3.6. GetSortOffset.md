# GetSortOffset

#### 功能说明
根据元素位置，获取Sort数据中的对应偏移量（单位为字节）。

#### 函数原型
```cpp
template <typename T>
__aicore__ inline uint32_t GetSortOffset(const uint32_t elemOffset)
```

sort数据中的对应偏移量。

#### 约束说明
无。
