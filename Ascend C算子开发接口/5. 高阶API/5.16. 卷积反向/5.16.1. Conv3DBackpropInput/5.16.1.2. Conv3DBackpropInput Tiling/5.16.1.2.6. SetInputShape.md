# SetInputShape

#### 功能说明
设置特征矩阵Input的形状：Batch、Channel、Depth、Height、Width。在构建Conv3DTranspose算子时，此接口无实际意义，请勿使用。

#### 函数原型
```cpp
bool SetInputShape(int64_t n, int64_t c, int64_t d, int64_t h, int64_t w)
```

#### 参数说明
<table>
<caption>表1 参数说明</caption>
<thead><tr><th>参数名</th><th>输入/输出</th><th>描述</th></tr></thead>
<tbody><tr><td>n</td><td>输入</td><td>输入Input的Batch值。</td></tr><tr><td>c</td><td>输入</td><td>输入Input的Channel值。</td></tr><tr><td>d</td><td>输入</td><td>输入Input的Depth值。</td></tr><tr><td>h</td><td>输入</td><td>输入Input的Height值。</td></tr><tr><td>w</td><td>输入</td><td>输入Input的Width值。</td></tr></tbody>
</table>

#### 返回值说明
true表示设置成功，false表示设置失败。

#### 约束说明
无

#### 调用示例
```cpp
auto ascendcPlatform = platform_ascendc::PlatformAscendCManager::GetInstance();
ConvBackpropApi::Conv3DBpInputTiling conv3DBpDxTiling(*ascendcPlatform);
conv3DBpDxTiling.SetInputShape(n, c, d, h, w);
```
