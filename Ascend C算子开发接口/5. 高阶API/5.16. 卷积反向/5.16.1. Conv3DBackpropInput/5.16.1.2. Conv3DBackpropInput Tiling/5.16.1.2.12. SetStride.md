# SetStride

#### 功能说明
设置Stride信息。

#### 函数原型
```cpp
void SetStride(int64_t strideD, int64_t strideH, int64_t strideW)
```

#### 参数说明
<table>
<caption>表1 参数说明</caption>
<thead>
<tr><th>参数名</th><th>输入/输出</th><th>描述</th></tr>
</thead>
<tbody>
<tr><td>strideD</td><td>输入</td><td>卷积正向过程中Depth方向Stride的大小。</td></tr>
<tr><td>strideH</td><td>输入</td><td>卷积正向过程中Height方向Stride的大小。</td></tr>
<tr><td>strideW</td><td>输入</td><td>卷积正向过程中Width方向Stride的大小。</td></tr>
</tbody>
</table>

#### 返回值说明
无

#### 约束说明
无

#### 调用示例
```cpp
auto ascendcPlatform = platform_ascendc::PlatformAscendCManager::GetInstance();
ConvBackpropApi::Conv3DBpInputTiling conv3DBpDxTiling(*ascendcPlatform);
conv3DBpDxTiling.SetStride(strideD, strideH, strideW);
```
