# SetGradOutputShape

#### 功能说明
设置GradOutput的形状：Batch、Channel、Depth、Height、Width。

#### 函数原型
```cpp
bool SetGradOutputShape(int64_t n, int64_t c, int64_t d, int64_t h, int64_t w)
```

#### 参数说明
<table cellpadding="4" cellspacing="0" frame="border" border="1" rules="all"><caption><b>表1 </b>参数说明</caption><thead><tr><th><p>参数名</p></th><th><p>输入/输出</p></th><th><p>描述</p></th></tr></thead><tbody><tr><td><p>n</p></td><td><p>输入</p></td><td><p>输入GradOuput的Batch值。</p></td></tr><tr><td><p>c</p></td><td><p>输入</p></td><td><p>输入GradOutput的Channel值。</p></td></tr><tr><td><p>d</p></td><td><p>输入</p></td><td><p>输入GradOutput的Depth值。</p></td></tr><tr><td><p>h</p></td><td><p>输入</p></td><td><p>输入GradOutput的Height值。</p></td></tr><tr><td><p>w</p></td><td><p>输入</p></td><td><p>输入GradOutput的Width值。</p></td></tr></tbody></table>

#### 返回值说明
true表示设置成功，false表示设置失败。

#### 约束说明
无

#### 调用示例
```cpp
auto ascendcPlatform = platform_ascendc::PlatformAscendCManager::GetInstance();
ConvBackpropApi::Conv3DBpInputTiling conv3DBpDxTiling(*ascendcPlatform);
conv3DBpDxTiling.SetGradOutputShape(n, c, d, h, w);
```
