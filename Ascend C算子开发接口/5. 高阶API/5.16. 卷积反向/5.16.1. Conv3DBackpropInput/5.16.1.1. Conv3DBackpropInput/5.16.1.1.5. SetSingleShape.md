#### 功能说明
设置Conv3dDBackpropInput在单核上计算的形状，单位为元素个数。

#### 函数原型
```cpp
__aicore__ inline void SetSingleShape(uint64_t singleShapeM, uint64_t singleShapeK, uint32_t singleShapeN)
```

#### 参数说明
<table border="1" rules="all" frame="border" cellpadding="4" cellspacing="0"><caption>表1 接口参数说明</caption><thead><tr><th align="left">参数名</th><th align="left">输入/输出</th><th align="left">描述</th></tr></thead><tbody><tr><td valign="top">singleShapeM</td><td valign="top">输入</td><td valign="top">单核上M的大小，单位为元素。</td></tr><tr><td valign="top">singleShapeK</td><td valign="top">输入</td><td valign="top">单核上K的大小，单位为元素。</td></tr><tr><td valign="top">singleShapeN</td><td valign="top">输入</td><td valign="top">单核上N的大小，单位为元素。</td></tr></tbody></table>

#### 返回值说明
无

#### 约束说明
无

```cpp
const Conv3DBackpropInputTilingData* tilingData;
```
