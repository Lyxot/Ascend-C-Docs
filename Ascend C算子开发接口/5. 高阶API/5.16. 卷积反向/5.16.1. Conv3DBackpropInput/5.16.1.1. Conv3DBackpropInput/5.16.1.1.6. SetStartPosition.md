#### 功能说明

设置单核上GradOutput载入数据的起始位置。

#### 函数原型

```cpp
__aicore__ inline void SetStartPosition(uint32_t curDinStartIdx, int32_t curHoStartIdx)
```

#### 参数说明

<table>
<thead><tr><th>参数名</th><th>输入/输出</th><th>描述</th></tr></thead>
<tbody>
<tr><td>curDinStartIdx</td><td>输入</td><td>当前核D方向起始位置。</td></tr>
<tr><td>curHoStartIdx</td><td>输入</td><td>当前核H方向起始位置。</td></tr>
</tbody>
</table>

#### 返回值说明

无

#### 约束说明

无

#### 调用示例

```cpp
gradInput_.SetStartPosition(dinStartIdx_, curHoStartIdx_); // 设置单核上GradOutput载入的起始位置
```
