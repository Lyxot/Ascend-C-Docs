# SetGradOutput

<table><thead><tr><th>产品</th><th>是否支持</th></tr></thead><tbody><tr><td><span><term>Atlas A3 训练系列产品/Atlas A3 推理系列产品</term></span></td><td><p>√</p></td></tr><tr><td><span><term>Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件</term></span></td><td><p>√</p></td></tr><tr><td><span><term>Atlas 200I/500 A2 推理产品</term></span></td><td><p>x</p></td></tr><tr><td><span><term>Atlas 推理系列产品</term>AI Core</span></td><td><p>x</p></td></tr><tr><td><span><term>Atlas 推理系列产品</term>Vector Core</span></td><td><p>x</p></td></tr><tr><td><span><term>Atlas 训练系列产品</term></span></td><td><p>x</p></td></tr><tr><td><span><term>Atlas 200/300/500 推理产品</term></span></td><td><p>x</p></td></tr></tbody></table>

#### 功能说明
设置卷积反向计算的输入矩阵GradOutput。

#### 函数原型
```cpp
__aicore__ inline void SetGradOutput(const AscendC::GlobalTensor<SrcT> &gradOutput)
```

#### 参数说明
<table><caption>表1 接口参数说明</caption><thead><tr><th>参数名</th><th>输入/输出</th><th>描述</th></tr></thead><tbody><tr><td>gradOutput</td><td>输入</td><td>GradOutput矩阵在Global Memory上的首地址。<span><span><span>类型为<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0007.html">GlobalTensor</a>。</span></span></span>SrcT表示GradOutput矩阵的数据类型，当前支持的数据类型为：half、bfloat16_t。</td></tr></tbody></table>

#### 返回值说明
无

#### 约束说明
无

#### 调用示例
```cpp
ConvBackpropApi::Conv3DBackpropInput<weightDxType, inputSizeDxType, gradOutputDxType, gradInputDxType> gradInput_;
GlobalTensor<gradOutputType> gradOutputGm_;
gradOutputGm_.SetGlobalBuffer((__gm__ gradOutputType *)gradOutput);
gradInput_.SetGradOutput(gradOutputGm_);
```
