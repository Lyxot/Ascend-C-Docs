# SetInputType

## 功能说明
设置特征矩阵Input的位置、数据格式、数据类型信息，这些信息必须与Kernel侧的设置保持一致。

## 函数原型
```cpp
void SetInputType(ConvCommonApi::TPosition pos, ConvCommonApi::ConvFormat format, ConvCommonApi::ConvDtype dtype)
```

## 参数说明
<table border="1" rules="all"><caption><b>表1 </b>参数说明</caption><thead><tr><th>参数名</th><th>输入/输出</th><th>描述</th></tr></thead><tbody><tr><td>pos</td><td>输入</td><td>Input在内存上的<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0004.html#ZH-CN_TOPIC_0000002370252365__table07372185712">位置</a>。当前仅支持TPosition::GM。</td></tr><tr><td>format</td><td>输入</td><td>Input的数据格式。当前仅支持ConvFormat::NDC1HWC0。</td></tr><tr><td>dtype</td><td>输入</td><td>Input的数据类型。当前仅支持ConvDtype::FLOAT16、ConvDtype::BF16。</td></tr></tbody></table>

## 返回值说明
无

## 约束说明
无

## 调用示例
```cpp
optiling::Conv3DBackpropFilterTilingData tilingData;
auto ascendcPlatform = platform_ascendc::PlatformAscendCManager::GetInstance();
ConvBackpropApi::Conv3dBpFilterTiling conv3dBpDwTiling(*ascendcPlatform);
conv3dBpDwTiling.SetInputType(ConvCommonApi::TPosition::GM,
                              ConvCommonApi::ConvFormat::NDC1HWC0,
                              ConvCommonApi::ConvDtype::FLOAT16);
```
