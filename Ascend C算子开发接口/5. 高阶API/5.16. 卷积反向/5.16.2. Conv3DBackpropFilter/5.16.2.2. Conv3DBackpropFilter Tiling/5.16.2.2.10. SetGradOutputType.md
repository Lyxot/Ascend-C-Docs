# SetGradOutputType

#### 功能说明
设置GradOutput的位置、数据格式、数据类型信息，这些信息必须与Kernel侧的设置保持一致。

#### 函数原型
```cpp
void SetGradOutputType(ConvCommonApi::TPosition pos, ConvCommonApi::ConvFormat format, ConvCommonApi::ConvDtype dtype)
```

#### 参数说明
<table cellpadding="4" cellspacing="0" frame="border" border="1" rules="all"><caption>表1 参数说明</caption><thead><tr><th align="left" valign="top"><p>参数名</p></th><th align="left" valign="top"><p>输入/输出</p></th><th align="left" valign="top"><p>描述</p></th></tr></thead><tbody><tr><td valign="top"><p>pos</p></td><td valign="top"><p>输入</p></td><td valign="top"><p>GradOutput在内存上的<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0004.html#ZH-CN_TOPIC_0000002370252365__table07372185712">位置</a>。当前仅支持TPosition::GM。</p></td></tr><tr><td valign="top"><p>format</p></td><td valign="top"><p>输入</p></td><td valign="top"><p>GradOutput的数据格式。当前仅支持ConvFormat:NDC1HWC0。</p></td></tr><tr><td valign="top"><p>dtype</p></td><td valign="top"><p>输入</p></td><td valign="top"><p>GradOutput的数据类型。当前仅支持ConvDtype::FLOAT16、ConvDtype::BF16。</p></td></tr></tbody></table>

#### 返回值说明
无

#### 约束说明
无

#### 调用示例
```cpp
optiling::Conv3DBackpropFilterTilingData tilingData;
auto ascendcPlatform = platform_ascendc::PlatformAscendCManager::GetInstance();
ConvBackpropApi::Conv3dBpFilterTiling conv3dBpDwTiling(*ascendcPlatform);
conv3dBpDwTiling.SetGradOutputType(ConvCommonApi::TPosition::GM,
                                   ConvCommonApi::ConvFormat::NDC1HWC0,
                                   ConvCommonApi::ConvDtype::FLOAT16);
```
