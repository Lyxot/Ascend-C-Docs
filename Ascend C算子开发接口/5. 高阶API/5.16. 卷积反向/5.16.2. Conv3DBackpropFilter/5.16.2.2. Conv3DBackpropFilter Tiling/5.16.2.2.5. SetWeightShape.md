# SetWeightShape

#### 功能说明
设置权重矩阵Weight的形状。

#### 函数原型
```cpp
void SetWeightShape(int64_t cout, int64_t cin, int64_t d, int64_t h, int64_t w)
```

#### 参数说明
<table>
<caption><b>表1 参数说明</b></caption>
<thead><tr><th>参数名</th><th>输入/输出</th><th>描述</th></tr></thead>
<tbody><tr><td>cout</td><td>输入</td><td>设置GradOutput的Channel值。</td></tr><tr><td>cin</td><td>输入</td><td>设置Input的Channel值。</td></tr><tr><td>d</td><td>输入</td><td>设置Weight的Depth值。</td></tr><tr><td>h</td><td>输入</td><td>设置Weight的Height值。</td></tr><tr><td>w</td><td>输入</td><td>设置Weight的Width值。</td></tr></tbody>
</table>

#### 返回值说明
无

#### 约束说明
无

#### 调用示例
```cpp
optiling::Conv3DBackpropFilterTilingData tilingData;
auto ascendcPlatform = platform_ascendc::PlatformAscendCManager::GetInstance();
ConvBackpropApi::Conv3dBpFilterTiling conv3dBpDwTiling(*ascendcPlatform);
conv3dBpDwTiling.SetWeightShape(cout, cin, d, h, w);
```
