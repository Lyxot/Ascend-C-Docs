# SetPadding

## 功能说明
设置Pad信息。

## 函数原型
```cpp
void SetPadding(int64_t padFront, int64_t padBack, int64_t padUp, int64_t padDown, int64_t padLeft, int64_t padRight)
```

## 参数说明
<table><caption><b>表1 </b>参数说明</caption><thead><tr><th>参数名</th><th>输入/输出</th><th>描述</th></tr></thead><tbody><tr><td>padFront</td><td>输入</td><td>卷积正向过程中Input Depth维度的前方向Padding大小。</td></tr><tr><td>padBack</td><td>输入</td><td>卷积正向过程中Input Depth维度的后方向Padding大小。</td></tr><tr><td>padUp</td><td>输入</td><td>卷积正向过程中Input Height维度的上方向Padding大小。</td></tr><tr><td>padDown</td><td>输入</td><td>卷积正向过程中Input Height维度的下方向Padding大小。</td></tr><tr><td>padLeft</td><td>输入</td><td>卷积正向过程中Input Width维度的左方向Padding大小。</td></tr><tr><td>padRight</td><td>输入</td><td>卷积正向过程中Input Width维度的右方向Padding大小。</td></tr></tbody></table>

## 返回值说明
无

## 约束说明
无

## 调用示例
```cpp
optiling::Conv3DBackpropFilterTilingData tilingData;
auto ascendcPlatform = platform_ascendc::PlatformAscendCManager::GetInstance();
ConvBackpropApi::Conv3dBpFilterTiling conv3dBpDwTiling(*ascendcPlatform);
conv3dBpDwTiling.SetPadding(padFront, padBack, padUp, padDown, padLeft, padRight);
```
