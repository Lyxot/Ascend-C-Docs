# GetTensorC

#### 产品支持情况

<table><thead><tr><th>产品</th><th>是否支持</th></tr></thead><tbody><tr><td>Atlas A3 训练系列产品/Atlas A3 推理系列产品</td><td>√</td></tr><tr><td>Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件</td><td>√</td></tr><tr><td>Atlas 200I/500 A2 推理产品</td><td>x</td></tr><tr><td>Atlas 推理系列产品AI Core</td><td>x</td></tr><tr><td>Atlas 推理系列产品Vector Core</td><td>x</td></tr><tr><td>Atlas 训练系列产品</td><td>x</td></tr><tr><td>Atlas 200/300/500 推理产品</td><td>x</td></tr></tbody></table>

#### 功能说明

在完成Iterate操作后调用本接口，获取结果矩阵块，完成数据从L0C到GM的搬运。此接口与[Iterate](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0925.html)接口配合使用，用于在Iterate执行迭代计算后，获取结果矩阵。

#### 函数原型

```cpp
template <bool sync = true>
__aicore__ inline void GetTensorC(const AscendC::GlobalTensor<DstT> &output, uint8_t enAtomic = 1, bool enSequentialWrite = false)
```

#### 参数说明

<table><caption>表1 模板参数说明</caption><thead><tr><th>参数名</th><th>描述</th></tr></thead><tbody><tr><td>sync</td><td>预留参数，用户无需感知。</td></tr></tbody></table>

<table><caption>表2 接口参数说明</caption><thead><tr><th>参数名</th><th>输入/输出</th><th>描述</th></tr></thead><tbody><tr><td>output</td><td>输入</td><td>将计算结果搬至Global Memory的GM地址。</td></tr><tr><td>enAtomic</td><td>输入</td><td>预留参数，用户无需感知。</td></tr><tr><td>enSequentialWrite</td><td>输入</td><td>预留参数，用户无需感知。</td></tr></tbody></table>

#### 返回值说明

无

#### 约束说明

GetTensorC接口必须在Iterate后进行调用，完成卷积反向实现，调用顺序如下。

```cpp
while (Iterate()) {   
    GetTensorC(); 
}
```

#### 调用示例

```cpp
while (gradWeight_.Iterate()) {
    gradWeight_.GetTensorC(gradWeightGm_[offsetC_]);
}
```
