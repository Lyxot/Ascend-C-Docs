# SetStartPosition

#### 产品支持情况
<table border="1"><thead><tr><th align="left">产品</th><th align="center">是否支持</th></tr></thead><tbody><tr><td>Atlas A3 训练系列产品/Atlas A3 推理系列产品</td><td align="center">√</td></tr><tr><td>Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件</td><td align="center">√</td></tr><tr><td>Atlas 200I/500 A2 推理产品</td><td align="center">x</td></tr><tr><td>Atlas 推理系列产品AI Core</td><td align="center">x</td></tr><tr><td>Atlas 推理系列产品Vector Core</td><td align="center">x</td></tr><tr><td>Atlas 训练系列产品</td><td align="center">x</td></tr><tr><td>Atlas 200/300/500 推理产品</td><td align="center">x</td></tr></tbody></table>

#### 功能说明
设置单核上GradOutput载入数据的起始位置。

#### 函数原型
```cpp
__aicore__ inline void SetStartPosition(uint32_t hoStartIdx)
```

#### 参数说明
<table border="1"><thead><tr><th align="left">参数名</th><th align="left">输入/输出</th><th align="left">描述</th></tr></thead><tbody><tr><td>hoStartIdx</td><td>输入</td><td>当前核GradOutput Height方向起始位置。</td></tr></tbody></table>

#### 返回值说明
无

#### 约束说明
无

#### 调用示例
```cpp
...
gradWeight_.SetSingleShape(singleShapeM, singleShapeN, singleShapeK);
gradWeight_.SetStartPosition(hoStartIdx); // 设置单核上GradOutput载入的起始位置
...
```
