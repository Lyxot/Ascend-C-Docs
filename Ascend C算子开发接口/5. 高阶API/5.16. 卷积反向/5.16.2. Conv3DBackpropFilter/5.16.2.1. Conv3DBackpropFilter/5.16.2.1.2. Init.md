# Init

#### 产品支持情况
<table><thead><tr><th>产品</th><th>是否支持</th></tr></thead><tbody><tr><td>Atlas A3 训练系列产品/Atlas A3 推理系列产品</td><td>√</td></tr><tr><td>Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件</td><td>√</td></tr><tr><td>Atlas 200I/500 A2 推理产品</td><td>x</td></tr><tr><td>Atlas 推理系列产品AI Core</td><td>x</td></tr><tr><td>Atlas 推理系列产品Vector Core</td><td>x</td></tr><tr><td>Atlas 训练系列产品</td><td>x</td></tr><tr><td>Atlas 200/300/500 推理产品</td><td>x</td></tr></tbody></table>

#### 功能说明
Init主要用于对Conv3DBackpropFilter对象中的Tiling数据进行初始化，根据Tiling参数进行资源划分，Tiling参数的具体介绍请参考[Conv3DBackpropFilter Tiling](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0904.html)。

#### 函数原型
```cpp
__aicore__ inline void Init(const TConv3DBpFilterTiling *__restrict tiling)
```

#### 参数说明
<table><caption>表1 接口参数说明</caption><thead><tr><th>参数名</th><th>输入/输出</th><th>描述</th></tr></thead><tbody><tr><td>tiling</td><td>输入</td><td>Conv3dBackpropFilter对象的Tiling参数，Conv3DBackpropFilterTilingData结构体定义请参见<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0907.html">TConv3DBpFilterTiling结构体</a>。Tiling参数可以通过Host侧<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0908.html">GetTiling</a>接口获取，并传递到Kernel侧使用。</td></tr></tbody></table>

#### 返回值说明
无

#### 约束说明
Init接口必须在Iterate、GetTensorC、End接口前调用，且只能调用一次Init接口，调用顺序如下。
```cpp
Init(...);
...
Iterate(...);
GetTensorC(...);
End();
```

#### 调用示例
```cpp
const Conv3DBackpropFilterTilingData* tilingData;
// ...初始化tilingData，创建Conv3DBackpropFilter对象，调用init接口
ConvBackpropApi::Conv3DBackpropFilter<inputType, weightSizeType, gradOutputType, gradWeightType> gradWeight_;
gradWeight_.Init(&(tilingData->dwTiling));
```
