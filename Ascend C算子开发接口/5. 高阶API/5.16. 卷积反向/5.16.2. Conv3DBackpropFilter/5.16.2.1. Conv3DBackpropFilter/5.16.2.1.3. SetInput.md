## 功能说明
设置特征矩阵Input。

## 函数原型
```cpp
__aicore__ inline void SetInput(const AscendC::GlobalTensor<SrcT> &input)
```

## 参数说明
表1 接口参数说明
<table><thead><tr><th>参数名</th><th>输入/输出</th><th>描述</th></tr></thead><tbody><tr><td>input</td><td>输入</td><td>Input在Global Memory上的首地址。类型为<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0007.html">GlobalTensor</a>。特征矩阵Input支持的数据类型SrcT为：half/bfloat16_t。</td></tr></tbody></table>

## 返回值说明
无

## 约束说明
无
