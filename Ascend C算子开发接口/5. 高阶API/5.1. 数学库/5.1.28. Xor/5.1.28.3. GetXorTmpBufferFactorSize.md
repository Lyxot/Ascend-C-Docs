<h1 class="topictitle1">GetXorTmpBufferFactorSize</h1>
<div><div class="section"><h4 class="sectiontitle">功能说明</h4><p>该接口用于获取maxLiveNodeCount和extraBuf，在固定空间大小的情况下，通过maxLiveNodeCount和extraBuf可以推算算子单次最大计算元素数量。maxLiveNodeCount表示临时空间是单次计算数据量所占空间的多少倍；extraBuf表示使用的额外临时空间大小。</p>
<p>推算示例如下：</p>
<ul><li>算子实现需要调用Xor接口，开发者为其预留currBuff大小的空间，利用GetXorTmpBufferFactorSize接口得到maxLiveNodeCount 、extraBuf输出值，可推导算子单次最大计算元素数量为：<p><a name="ZH-CN_TOPIC_0000002336174662__li98465267428"></a><a name="li98465267428"></a><strong>currentShapeSize = (currBuff - extraBuf) / maxLiveNodeCount / typeSize</strong></p>
</li><li>算子实现需要调用两个kernel侧API KernelIntf1、KernelIntf2，利用两个GetXxxTmpBufferFactorSize（其中Xxx为需要调用的两个高阶API）接口的两组输出值(maxLiveNodeCount 、extraBuf)以及当前现有的临时空间，推导单次最大计算元素数量currentShapeSize为：<p><a name="ZH-CN_TOPIC_0000002336174662__li8496123554212"></a><a name="li8496123554212"></a><strong>currentShapeSize1 = (currBuff - extraBuf1) / maxLiveNodeCount1 / typeSize</strong></p>
<p><strong>currentShapeSize2 = (currBuff - extraBuf2) / maxLiveNodeCount2 / typeSize</strong></p>
<p><strong>currentShapeSize = min(currentShapeSize1, currentShapeSize2)</strong></p>
</li></ul>
<p>注意上文中的currBuff表示接口计算可用的空间，需要去除用户输入输出等空间；另外，接口获取的maxLiveNodeCount值可能为0，计算时需要判断该值非0，避免除0错误。</p>
</div>
