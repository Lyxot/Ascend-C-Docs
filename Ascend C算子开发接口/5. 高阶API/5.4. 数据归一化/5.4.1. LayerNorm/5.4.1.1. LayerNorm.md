   <div class="section">
    <h4 class="sectiontitle">功能说明</h4>
    <p>根据接口输出的不同，本节介绍如下两种LayerNorm接口。</p>
    <ul>
     <li>输出归一化结果、均值和方差
      <p><a name="ZH-CN_TOPIC_0000002336173894__li334351794017"></a><a name="li334351794017"></a>在深层神经网络训练过程中，前面层训练参数的更新，会引起后面层输入数据分布的变化，导致权重更新不均衡及学习效率变慢。通过采用归一化策略，将网络层输入数据收敛到[0, 1]之间，可以规范网络层输入输出数据分布，加速训练参数收敛过程，使学习效率提升更加稳定。<strong>LayerNorm是许多归一化方法中的一种。</strong></p>
      <p>本接口实现了对shape大小为[B，S，H]输入数据的LayerNorm归一化，其计算公式如下，其中γ为缩放系数，β为平移系数，ε为防除零的权重系数：</p>
      <p><img class="mathml" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_formulaimage_0000002370173609.png"></p>
      <p>其中，如下两个参数分别代表输入在H轴的均值和方差。</p>
      <p><img class="mathml" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_formulaimage_0000002370253477.png"></p>
      <p></p></li>
    </ul>
    <ul>
     <li>输出归一化结果、均值和标准差的倒数
      <p><a name="ZH-CN_TOPIC_0000002336173894__li152275217406"></a><a name="li152275217406"></a>本接口实现了对shape为[A，R]输入数据的LayerNorm归一化，其计算公式如下，其中γ为缩放系数，β为平移系数，ε为防除零的权重系数：</p>
      <p><img class="mathml" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_formulaimage_0000002370253485.png"></p>
      <p>其中，如下三个参数分别代表输入在R轴的均值，方差和标准差的倒数。</p>
      <p><img class="mathml" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_formulaimage_0000002370253457.png"></p></li>
    </ul>
   </div>
   <div class="section">
    <h4 class="sectiontitle">实现原理</h4>
    <ul>
     <li>输出归一化结果、均值和方差
      <p><a name="ZH-CN_TOPIC_0000002336173894__li1552184441118"></a><a name="li1552184441118"></a>以float类型，ND格式，输入为inputX[B, S, H]，gamma[H]和beta[H]为例，描述LayerNorm高阶API内部算法框图，如下图所示。</p>
      <div class="fignone">
       <span class="figcap"><b>图1 </b>LayerNorm算法框图</span>
       <br><img class="imgResize" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002370253481.png" title="点击放大">
      </div>
      <p>计算过程分为如下几步，均在Vector上进行：</p>
      <ol>
       <li>计算均值：Muls计算x*1/m的值，再计算累加值ReduceSum，得到均值outputMean；</li>
       <li>计算方差：Sub计算出输入x与均值的差值，再用Mul进行平方计算，最后用Muls乘上1/m并计算累加值，得到方差outputVariance；</li>
       <li>处理gamma和beta：通过broadcast得到BSH维度的gamma和beta；</li>
       <li>计算输出：方差通过broadcast得到BSH维度的tensor，再依次经过Adds(outputVariance, eps), Ln, Muls, Exp，最后与(x-均值)相乘，得到的结果乘上gamma，加上beta，得到输出结果。</li>
      </ol></li>
    </ul>
    <ul>
     <li>输出归一化结果、均值和标准差的倒数
      <p><a name="ZH-CN_TOPIC_0000002336173894__li1738146191113"></a><a name="li1738146191113"></a>以float类型，ND格式，输入为inputX[A, R]，gamma[R] 和beta[R]为例，描述LayerNorm高阶API内部算法框架，如下图所示。</p>
      <div class="fignone">
       <span class="figcap"><b>图2 </b>LayerNorm-Rstd版本算法框图</span>
       <p><img class="imgResize" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002370253473.png" title="点击放大"></p>
       <p>计算过程分为如下几步，均在Vector上进行，整体按照以A轴为最外层循环进行计算：</p>
      </div>
      <ol>
       <li>计算均值：首先对x的每个元素乘以1/(2^k+m)，防止后续累加溢出。然后使用二分累加方式对数据进行求和：将数据拆分成一个整块和一个尾块，其中整块为2^k个元素，尾块为m个元素，将尾块数据叠加到整块数据。为方便描述，定义Vnum为参与单次计算的元素个数。对整块中，以Vnum长度为单位，奇偶位数据进行Vadd，得到一个Vnum长度的结果，对该结果做WholeReduceSum计算，得到输出均值mean；</li>
       <li>计算rstd：用Sub计算出输入x与均值的差值，再用Mul计算，计算该差值的平方，为防止溢出，按照同样的二分累加方式，计算出该平方结果的方差Variance；方差与防除零系数ε相加，通过Rsqrt计算，得到输出rstd；</li>
       <li>计算输出：用Sub计算出输入x与均值的差值，再与rstd相乘，得到的结果与gamma相乘，与beta相加，得到输出结果。</li>
      </ol></li>
    </ul>
   </div>

    <h4 class="sectiontitle">约束说明</h4>
    <ul>
     <li>操作数地址偏移对齐要求请参见<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0004.html">通用约束</a>。</li>
     <li>对于输出归一化结果、均值和方差的接口：
      <ul>
       <li>src和dst的Tensor空间可以复用。</li>
       <li>输入仅支持ND格式。</li>
       <li>输入数据不满足对齐要求时，开发者需要进行补齐，补齐的数据应设置为0，防止出现异常值从而影响网络计算。</li>
       <li>不支持对尾轴H轴的切分。</li>
      </ul></li>
    </ul>
    <ul>
     <li>对于输出归一化结果、均值和标准差的倒数的接口：
      <ul>
       <li>参数gamma和beta的数据类型精度不低于源操作数的数据类型精度。</li>
       <li>src和dst的Tensor空间不可以复用。</li>
       <li>输入仅支持ND格式。</li>
       <li>不支持对R轴进行切分。</li>
      </ul></li>
    </ul>
