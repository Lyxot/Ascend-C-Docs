<div class="section"><h4 class="sectiontitle">实现原理</h4><p>以float类型，ND格式，输入为inputDy[B, S, H], inputX[B, S, H], inputVariance[B, S], inputMean[B, S], inputGamma[H]为例，描述LayerNormGrad高阶API内部算法框图，如下图所示。</p>
<div class="fignone"><span class="figcap"><b>图1 </b>LayerNormGrad算法框图</span><br><img class="eddx" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002370174401.png"></div>
<p>计算过程分为如下几步，均在Vector上进行：</p>
<ol><li>ComputePdX1步骤：计算inputDy*inputGamma，结果存储至x1Tensor；</li><li>ComputePdX2步骤：inputMean先通过Brcb将shape扩充到[B, S, H]，再计算inputX-inputMean，结果存储至x2Tensor；</li><li>ComputePdVar步骤：实现公式np.sum(((-0.5) * x1Tensor * x2Tensor * np.power((inputVariance + EPSILON), (-1.5))))的计算，power方法的实现通过Ln、Exp、Muls三条基础API组合实现，结果存储至pdVarTensor；</li><li>ComputePdMean：实现公式np.sum(((-1.0) * x1Tensor * np.power((inputVariance + EPSILON), (-0.5)))) + pd_var * (1.0 / H) * np.sum(((-2.0) * (x2Tensor)))的计算，power方法通过Ln、Exp、Muls三条基础API组合实现，结果存储至pdMeanTensor。同时，利用中间计算结果，根据公式x2Tensor * np.power((inputVariance + EPSILON), (-1.5))，计算出resForGamma的结果；</li><li>ComputePdX步骤：实现公式x1Tensor * np.power((inputVariance + EPSILON), (-0.5)) + pd_var*(2.0 / H)*(x2Tensor) + pd_mean*(1.0 / H)的计算，结果存入outputPdX。</li></ol>
</div>
