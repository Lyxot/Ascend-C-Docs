# SetAlgConfig

## 功能说明
设置通信算法。

## 函数原型
```cpp
uint32_t SetAlgConfig(const std::string &algConfig)
```

## 参数说明
<table>
 <caption>表1 参数说明</caption>
 <thead>
  <tr><th>参数名</th><th>输入/输出</th><th>描述</th></tr>
 </thead>
 <tbody>
  <tr><td>algConfig</td><td>输入</td><td>通信算法配置。string类型，支持的最大长度为128字节。针对 Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件，该参数为预留字段，配置后不生效，默认仅支持FullMesh算法。FullMesh算法即NPU之间的全连接，任意两个NPU之间可以直接进行数据收发。详细的算法内容可参见<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/hccl/hcclug/hcclug_000006.html">集合通信算法</a>。针对 Atlas A3 训练系列产品/Atlas A3 推理系列产品，当前支持的取值为：<ul><li>"AllReduce=level0:doublering"：AllReduce通信任务。</li><li>"AllGather=level0:doublering"：AllGather通信任务。</li><li>"ReduceScatter=level0:doublering"：ReduceScatter通信任务。</li><li>"AlltoAll=level0:fullmesh;level1:pairwise"：AlltoAllV和AlltoAll通信任务。</li><li>"BatchWrite=level0:fullmesh"：BatchWrite通信任务。</li></ul></td></tr>
 </tbody>
</table>

## 返回值说明
- 0表示设置成功。
- 非0表示设置失败。

## 约束说明
无
