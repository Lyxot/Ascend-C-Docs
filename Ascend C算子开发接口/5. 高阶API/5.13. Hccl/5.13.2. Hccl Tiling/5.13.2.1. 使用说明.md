# 使用说明

> 本章节详述通信算子必需的TilingData结构体。本章节提供了三个版本的TilingData，建议使用[TilingData结构体](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_10048.html)，不推荐使用[v1版本TilingData（废弃）](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0888.html)和[v2版本TilingData（废弃）](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0889.html)。
> 对于[TilingData结构体](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_10048.html)，在定义通算融合算子的Tiling结构体时，[Mc2InitTiling](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_10048.html#ZH-CN_TOPIC_0000002336333658__table4835205712588)必须定义为算子Tiling结构体的第一个参数，[Mc2CcTiling](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_10048.html#ZH-CN_TOPIC_0000002336333658__table678914014562)对于在算子Tiling结构体中被定义的位置没有要求。

根据[使用标准C++语法定义TilingData](https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0064.html#ZH-CN_TOPIC_0000002370175109__section296113331481)的方式，Ascend C提供一组Hccl Tiling API，方便用户获取Hccl Kernel计算时所需的Tiling参数。您只需要传入通信的相关信息，调用API接口，即可获取通信相关的Tiling参数。

Hccl Tiling API获取Tiling参数的流程如下：

1. 创建一个[Mc2CcTilingConfig](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_10036.html)类对象。
  ```cpp
  const char *groupName = "testGroup";
  uint32_t opType = HCCL_CMD_REDUCE_SCATTER;
  std::string algConfig = "ReduceScatter=level0:fullmesh";
  uint32_t reduceType = HCCL_REDUCE_SUM;
  AscendC::Mc2CcTilingConfig mc2CcTilingConfig(groupName, opType, algConfig, reduceType);
  ```
2. 通过配置接口设置通信信息（可选）。
  ```cpp
  mc2CcTilingConfig.SetSkipLocalRankCopy(0);
  mc2CcTilingConfig.SetSkipBufferWindowCopy(1);
  ```

3. 调用[GetTiling](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_10037.html)接口，获取Tiling信息。
  ```cpp
  mc2CcTilingConfig.GetTiling(tiling->mc2InitTiling);
  mc2CcTilingConfig.GetTiling(tiling->reduceScatterTiling);
  ```
