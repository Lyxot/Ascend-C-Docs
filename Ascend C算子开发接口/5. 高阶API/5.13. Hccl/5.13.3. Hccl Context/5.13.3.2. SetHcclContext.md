#### 功能说明
设置通算融合算子每个通信域对应的context（消息区）地址。

#### 函数原型
```cpp
template <uint32_t index>
__aicore__ inline void SetHcclContext(__gm__ uint8_t* context)
```

#### 参数说明
表1 参数说明
<table border="1">
<thead><tr><th align="left">参数名</th><th align="left">描述</th></tr></thead>
<tbody>
<tr><td>index</td><td>模板参数，用来表示要设置的通信域ID，当前只支持2个通信域，index只能为0/1。</td></tr>
<tr><td>context</td><td>对应通信域的context（消息区）地址。</td></tr>
</tbody>
</table>

#### 返回值说明
无

#### 约束说明
当前最多只支持2个通信域。

#### 调用示例
```cpp
// 给GROUP_0设置消息区地址
AscendC::SetHcclContext<0>(contextGM);
```
