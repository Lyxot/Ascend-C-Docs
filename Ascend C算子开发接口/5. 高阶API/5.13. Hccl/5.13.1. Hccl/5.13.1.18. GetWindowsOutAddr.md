# GetWindowsOutAddr

#### 产品支持情况
<table border="1" rules="all" cellpadding="4" cellspacing="0"><thead><tr><th>产品</th><th>是否支持</th></tr></thead><tbody><tr><td>Atlas A3 训练系列产品/Atlas A3 推理系列产品</td><td>x</td></tr><tr><td>Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件</td><td>√</td></tr><tr><td>Atlas 200I/500 A2 推理产品</td><td>x</td></tr><tr><td>Atlas 推理系列产品AI Core</td><td>x</td></tr><tr><td>Atlas 推理系列产品Vector Core</td><td>x</td></tr><tr><td>Atlas 训练系列产品</td><td>x</td></tr><tr><td>Atlas 200/300/500 推理产品</td><td>x</td></tr></tbody></table>

#### 功能说明
获取卡间通信数据WindowsOut起始地址，可用来直接作为计算的输入输出地址，减少拷贝。该接口默认在所有核上工作，用户也可以在调用前通过[GetBlockIdx](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0185.html)指定其在某一个核上运行。

#### 函数原型
```cpp
__aicore__ inline GM_ADDR GetWindowsOutAddr(uint32_t rankId)
```

#### 参数说明
<table border="1" rules="all" cellpadding="4" cellspacing="0"><caption>表1 接口参数说明</caption><thead><tr><th>参数名</th><th>输入/输出</th><th>描述</th></tr></thead><tbody><tr><td>rankId</td><td>输入</td><td>待查询的卡的Id。</td></tr></tbody></table>

#### 返回值说明
返回对应卡的卡间通信数据WindowsOut起始地址。当rankId非法时，返回nullptr。

#### 约束说明
无
