#### 功能说明

用于设置Hccl客户端通信算法的Tiling地址。

#### 函数原型

```cpp
__aicore__ inline int32_t SetCcTiling(__gm__ void *ccOpTilingData)
```

#### 返回值说明

- HCCL_SUCCESS，表示成功。
- HCCL_FAILED，表示失败。

#### 约束说明

- 参数相同的同一种通信算法在调用Prepare接口前只需要调用一次本接口，否则需要多次调用本接口。请参考调用示例：<a href="#ZH-CN_TOPIC_0000002336333088__li1747632111399">•仅有一个通信算法</a>、<a href="#ZH-CN_TOPIC_0000002336333088__li71505119260">•一个通信域有多个通信算法</a>。
- 同一种通信算法只支持设置一个ccOpTilingData地址；对于同一种通信算法，重复调用本接口会覆盖该通信算法的ccOpTilingData地址。请参考调用示例：<a href="#ZH-CN_TOPIC_0000002336333088__li1163031215116">•一个通信域两个相同的算法</a>。
- 若调用本接口，必须与传initTiling地址的<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0871.html">Init</a>接口配合使用，且Init接口在本接口前被调用。
- 若调用本接口，必须使用标准C++语法定义TilingData结构体的开发方式，具体请参考<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0064.html#ZH-CN_TOPIC_0000002370175109__section296113331481">使用标准C++语法定义TilingData</a>。

#### 调用示例

1. <a name="ZH-CN_TOPIC_0000002336333088__li1747632111399"></a><a name="li1747632111399"></a>仅有一个通信算法

```cpp
// 传initTiling地址的调用方式
REGISTER_TILING_DEFAULT(AllGatherCustomTilingData); //AllGatherCustomTilingData为对应算子头文件定义的结构体
auto tiling = (__gm__ AllGatherCustomTilingData*)tilingGM;

Hccl hccl;
GM_ADDR contextGM = AscendC::GetHcclContext<0>();  // AscendC自定义算子kernel中，通过此方式获取Hccl context

__gm__ void *mc2InitTiling = (__gm__ void *)(&tiling->mc2InitTiling);
__gm__ void *mc2CcTiling = (__gm__ void *)(&((tiling->mc2CcTiling)));
hccl.Init(contextGM, mc2InitTiling);
auto ret = hccl.SetCcTiling(mc2CcTiling);
if (ret != HCCL_SUCCESS) {
  return;
}
// 调用Hccl的Prepare、Commit、Wait、Finalize接口
```

2. <a name="ZH-CN_TOPIC_0000002336333088__li71505119260"></a><a name="li71505119260"></a>一个通信域有多个通信算法

```cpp
// 传initTiling地址的调用方式
REGISTER_TILING_DEFAULT(AllGatherCustomTilingData); //AllGatherCustomTilingData为对应算子头文件定义的结构体
auto tiling = (__gm__ AllGatherCustomTilingData*)tilingGM;

Hccl hccl;
GM_ADDR contextGM = AscendC::GetHcclContext<0>();  // AscendC自定义算子kernel中，通过此方式获取Hccl context

__gm__ void *mc2InitTiling = (__gm__ void *)(&tiling->mc2InitTiling);
__gm__ void *allToAllTiling = (__gm__ void *)(&((tiling->allToAllCcTiling)));
__gm__ void *allGatherTiling = (__gm__ void *)(&((tiling->allGatherCcTiling)));
hccl.Init(contextGM, mc2InitTiling);
auto ret = hccl.SetCcTiling(allToAllTiling);
if (ret != HCCL_SUCCESS) {
  return;
}
ret = hccl.SetCcTiling(allGatherTiling);
if (ret != HCCL_SUCCESS) {
  return;
}
auto handleId = hccl.AllToAll<true>(sendBuf, recvBuf, dataCount, HcclDataType::HCCL_DATA_TYPE_FP16);
hccl.Wait(handleId);
handleId = hccl.AllGather<true>(sendBuf, recvBuf, sendCount, HcclDataType::HCCL_DATA_TYPE_FP16, strideCount);
hccl.Wait(handleId);
hccl.Finalize();
```

3. 多个通信域多个算法

```cpp
// 传initTiling地址的调用方式
REGISTER_TILING_DEFAULT(AlltoAllAllGatherCustomTilingData); //AlltoAllAllGatherCustomTilingData为对应算子头文件定义的结构体
auto tiling = (__gm__ AlltoAllAllGatherCustomTilingData*)tilingGM;

__gm__ void *mc2InitTiling = (__gm__ void *)(&(tiling1->mc2InitTiling));
__gm__ void *allToAllTiling = (__gm__ void *)(&(tiling1->allToAllTiling));
__gm__ void *allGatherTiling = (__gm__ void *)(&(tiling1->allGatherTiling));

Hccl hccl_alltoall;
Hccl hccl_allgather;
GM_ADDR context_0 = AscendC::GetHcclContext<0>();
GM_ADDR context_1 = AscendC::GetHcclContext<1>();

hccl_alltoall.Init(context_0, mc2InitTiling);
hccl_allgather.Init(context_1, mc2InitTiling);

auto ret = hccl_alltoall.SetCcTiling(allToAllTiling);
if (ret != HCCL_SUCCESS) {
  return;
}
ret = hccl_allgather.SetCcTiling(allGatherTiling);
if (ret != HCCL_SUCCESS) {
  return;
}

handleId = hccl_alltoall.AlltoAllV<true>(sendBuf, sendCounts, sDisplacements, dtype, recvBuf, recvCounts, rDisplacements, dtype);
hccl_allgather.InterHcclGroupSync(0, handleId);
auto allGatherHandleId = hccl_allgather.AllGather<true>(sendBuf, recvBuf, sendCount, HcclDataType::HCCL_DATA_TYPE_FP16, strideCount);
hccl_allgather.Wait(allGatherHandleId);
// 调用Finalize
```

  return;
