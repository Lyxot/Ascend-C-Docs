# SetMadType

#### 功能说明
设置是否使能HF32模式。**当前版本暂不支持。**

#### 函数原型
```cpp
int32_t SetMadType(MatrixMadType madType)
```

#### 参数说明
<table cellpadding="4" cellspacing="0" summary="" frame="border" border="1" rules="all"><caption>表1 参数说明</caption><thead align="left"><tr><th align="left" valign="top">参数名</th><th align="left" valign="top">输入/输出</th><th align="left" valign="top">描述</th></tr></thead><tbody><tr><td valign="top">madType</td><td valign="top">输入</td><td valign="top">设置Matmul模式。MatrixMadType类型，定义如下。<div><pre><code>enum class MatrixMadType : int32_t {
  NORMAL = 0,
  HF32 = 1,
};
</code></pre></div><ul><li>MatrixMadType::NORMAL：普通模式，即非HF32模式。</li><li>MatrixMadType::HF32：使能HF32模式。</li></ul></td></tr></tbody></table>

#### 返回值说明
-1表示设置失败； 0表示设置成功。

#### 约束说明
无
