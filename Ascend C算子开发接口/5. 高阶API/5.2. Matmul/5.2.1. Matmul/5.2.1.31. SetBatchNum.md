# SetBatchNum

### 功能说明
在不改变Tiling的情况下，重新设置多Batch计算的Batch数。

### 函数原型
```cpp
__aicore__ inline void SetBatchNum(int32_t batchA, int32_t batchB)
```

### 参数说明
<table>
<caption><b>表1 </b>参数说明</caption>
<thead><tr><th align="left">参数名</th><th align="left">输入/输出</th><th align="left">描述</th></tr></thead>
<tbody><tr><td>batchA</td><td>输入</td><td>设置的一次计算的A矩阵Batch数。</td></tr><tr><td>batchB</td><td>输入</td><td>设置的一次计算的B矩阵Batch数。</td></tr></tbody>
</table>

### 返回值说明
无

### 约束说明
模板参数[enableMixDualMaster](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0616.html#ZH-CN_TOPIC_0000002336332840__p9218181073719)（默认取值为false）设置为true，即使能MixDualMaster（双主模式）场景时，不支持使用该接口。

### 调用示例
```cpp
//  纯cube模式
mm1.SetTensorA(gm_a, isTransposeAIn);
mm1.SetTensorB(gm_b, isTransposeBIn);
if(tiling.isBias) {
    mm1.SetBias(gm_bias);
}
mm1.SetBatchNum(batchA, batchB);
// 多batch Matmul计算
mm1.IterateBatch(gm_c, false, 0, false);
```
