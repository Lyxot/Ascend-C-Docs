# SetWorkspace

#### 产品支持情况
<table><thead><tr><th>产品</th><th>是否支持</th></tr></thead><tbody><tr><td>Atlas A3 训练系列产品/Atlas A3 推理系列产品</td><td>√</td></tr><tr><td>Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件</td><td>√</td></tr><tr><td>Atlas 200I/500 A2 推理产品</td><td>x</td></tr><tr><td>Atlas 推理系列产品AI Core</td><td>x</td></tr><tr><td>Atlas 推理系列产品Vector Core</td><td>x</td></tr><tr><td>Atlas 训练系列产品</td><td>x</td></tr><tr><td>Atlas 200/300/500 推理产品</td><td>x</td></tr></tbody></table>

#### 功能说明
[异步场景](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0639.html#ZH-CN_TOPIC_0000002336173156__li17508136205415)时，需要使用一块临时空间来缓存Iterate计算结果，调用GetTensorC时会在该临时空间中获取C的矩阵分片。

#### 函数原型
建议用户使用GlobalTensor类型传入：

```cpp
template <class T> __aicore__ inline void SetWorkspace(GlobalTensor<T>& addr)
```

```cpp
template <class T> __aicore__ inline void SetWorkspace(__gm__ const T* addr, int size)
```

#### 参数说明
<table><thead><tr><th>参数名</th><th>输入/输出</th><th>描述</th></tr></thead><tbody><tr><td>addr</td><td>输入</td><td>用户传入的GM上的workspace空间，GlobalTensor类型。</td></tr><tr><td>addr</td><td>输入</td><td>用户传入的GM上的workspace空间，GM地址类型。</td></tr><tr><td>size</td><td>输入</td><td>传入GM地址时，需要配合传入元素个数。</td></tr></tbody></table>

#### 返回值说明
无

#### 约束说明
模板参数[enableMixDualMaster](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0616.html#ZH-CN_TOPIC_0000002336332840__p9218181073719)（默认取值为false）设置为true，即使能MixDualMaster（双主模式）场景时，不支持使用该接口。

#### 调用示例
```cpp
REGIST_MATMUL_OBJ(&pipe, GetSysWorkSpacePtr(), mm, &tiling);
mm.SetWorkspace(workspaceGM);    //设置异步时使用的临时空间
mm.SetTensorA(gm_a);
mm.SetTensorB(gm_b);
mm.SetBias(gm_bias);
mm.template Iterate<false>();
for (int i = 0; i < singleCoreM/baseM * singleCoreN/baseN; ++i) {
  mm.GetTensorC<false>(ub_c);
}
```
