# SetLocalWorkspace

#### 产品支持情况
<table><thead><tr><th>产品</th><th>是否支持</th></tr></thead><tbody><tr><td>Atlas A3 训练系列产品/Atlas A3 推理系列产品</td><td>x</td></tr><tr><td>Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件</td><td>x</td></tr><tr><td>Atlas 200I/500 A2 推理产品</td><td>x</td></tr><tr><td>Atlas 推理系列产品AI Core</td><td>√</td></tr><tr><td>Atlas 推理系列产品Vector Core</td><td>x</td></tr><tr><td>Atlas 训练系列产品</td><td>x</td></tr><tr><td>Atlas 200/300/500 推理产品</td><td>x</td></tr></tbody></table>

#### 功能说明
对于某些场景Matmul内部需要额外占用VECCALC空间，如果用户希望在算子中复用这个额外占用的VECCALC空间，则该空间需要用户预留，并申请好LocalTensor，将其起始物理地址传入给Matmul。具体需要申请的VECCALC临时空间大小由tiling接口[MatmulGetTmpBufSize](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0710.html)给出，满足以下几个条件之一就需要使用该接口传入UB临时空间：
- C矩阵Position为TPosition::GM；
- C矩阵CubeFormat为CubeFormat::ND；
- A矩阵或者B矩阵CubeFormat为CubeFormat::ND；
- 存在Bias且Bias的Position不是VECCALC。

请在[Iterate](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0638.html)或者[IterateAll](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0640.html)之前调用该接口。

获取到的UB临时空间大小以字节为单位。

#### 函数原型
```cpp
__aicore__ inline void SetLocalWorkspace(const LocalTensor<uint8_t>& tmpBuffer)
```

#### 参数说明
<table><thead><tr><th>参数名</th><th>输入/输出</th><th>描述</th></tr></thead><tbody><tr><td>tmpBuffer</td><td>输入</td><td>临时空间，由用户申请并管理，TPosition为VECCALC。</td></tr></tbody></table>

#### 返回值说明
无

#### 约束说明
模板参数[enableMixDualMaster](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0616.html#ZH-CN_TOPIC_0000002336332840__p9218181073719)（默认取值为false）设置为true，即使能MixDualMaster（双主模式）场景时，不支持使用该接口。

#### 调用示例
```cpp
REGIST_MATMUL_OBJ(&pipe, GetSysWorkSpacePtr(), mm, &tiling);
mm.SetLocalWorkspace(mmFormatUb);    //设置临时VECCALC空间
mm.SetTensorA(gm_a);
mm.SetTensorB(gm_b);
mm.SetBias(gm_bias);
mm.IterateAll(gm_c);
```
