#### 功能说明
获取Iterate接口异步计算的结果矩阵。该接口功能已被[GetTensorC](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0639.html)覆盖，建议直接使用GetTensorC异步接口。

#### 函数原型
```cpp
__aicore__ inline void AsyncGetTensorC(const LocalTensor<DstT>& c)
```

#### 返回值说明
无

#### 约束说明
模板参数[enableMixDualMaster](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0616.html#ZH-CN_TOPIC_0000002336332840__p9218181073719)（默认取值为false）设置为true，即使能MixDualMaster（双主模式）场景时，不支持使用该接口。
