#### 功能说明
在不改变Tiling的情况下，重新设置本次计算的singleCoreM/singleCoreN/singleCoreK，以元素为单位。

#### 函数原型
```cpp
__aicore__ inline void SetTail(int tailM = -1, int tailN = -1, int tailK = -1)
```

#### 参数说明
<table border="1" frame="border" rules="all"><thead><tr><th align="left" width="14.99%"><p>参数名</p></th><th align="left" width="12.02%"><p>输入/输出</p></th><th align="left" width="72.99%"><p>描述</p></th></tr></thead><tbody><tr><td valign="top" width="14.99%"><p>tailM</p></td><td valign="top" width="12.02%"><p>输入</p></td><td valign="top" width="72.99%"><p>重新设置的singleCoreM值</p></td></tr><tr><td valign="top" width="14.99%"><p>tailN</p></td><td valign="top" width="12.02%"><p>输入</p></td><td valign="top" width="72.99%"><p>重新设置的singleCoreN值</p></td></tr><tr><td valign="top" width="14.99%"><p>tailK</p></td><td valign="top" width="12.02%"><p>输入</p></td><td valign="top" width="72.99%"><p>重新设置的singleCoreK值</p></td></tr></tbody></table>

#### 返回值说明
无

#### 约束说明
无

#### 调用示例
```cpp
REGIST_MATMUL_OBJ(&pipe, GetSysWorkSpacePtr(), mm, &tiling);
mm.SetTensorA(gm_a);
mm.SetTensorB(gm_b);
mm.SetBias(gm_bias);
mm.SetTail(tailM, tailN, tailK);    // 如果是尾核，需要调整singleCoreM/singleCoreN/singleCoreK
mm.IterateAll(gm_c);
```
