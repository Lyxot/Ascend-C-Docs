#### 功能说明
等待IterateBatch异步接口返回，支持连续输出到Global Memory。

#### 函数原型
```cpp
__aicore__ inline void WaitIterateBatch()
```

#### 参数说明
<table>
<thead><tr><th align="left">参数名</th><th align="left">输入/输出</th><th align="left">描述</th></tr></thead>
<tbody>
<tr><td valign="top">无</td><td valign="top">无</td><td valign="top">NA</td></tr>
</tbody>
</table>

#### 返回值说明
无

#### 约束说明
- 配套[IterateBatch](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0642.html)异步接口使用。
- 仅支持连续输出至Global Memory。
- 模板参数[enableMixDualMaster](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0616.html#ZH-CN_TOPIC_0000002336332840__p9218181073719)（默认取值为false）设置为true，即使能MixDualMaster（双主模式）场景时，不支持使用该接口。

#### 调用示例
```cpp
AscendC::Matmul<aType, bType, cType, biasType> mm;
mm.SetTensorA(gm_a[offsetA]);
mm.SetTensorB(gm_b[offsetB]);
if (tiling.isBias) {
  mm.SetBias(gm_bias[offsetBias]);
}
mm.IterateBatch(gm_c[offsetC], batchA, batchB, false);
// do some others compute
mm.WaitIterateBatch(); // 等待IterateBatch完成
```
