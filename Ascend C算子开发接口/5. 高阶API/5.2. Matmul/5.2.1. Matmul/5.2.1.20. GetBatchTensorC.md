# GetBatchTensorC

#### 产品支持情况
<table border="1" rules="all"><thead><tr><th align="left">产品</th><th align="center">是否支持</th></tr></thead><tbody><tr><td align="left">Atlas A3 训练系列产品/Atlas A3 推理系列产品</td><td align="center">√</td></tr><tr><td align="left">Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件</td><td align="center">√</td></tr><tr><td align="left">Atlas 200I/500 A2 推理产品</td><td align="center">x</td></tr><tr><td align="left">Atlas 推理系列产品AI Core</td><td align="center">x</td></tr><tr><td align="left">Atlas 推理系列产品Vector Core</td><td align="center">x</td></tr><tr><td align="left">Atlas 训练系列产品</td><td align="center">x</td></tr><tr><td align="left">Atlas 200/300/500 推理产品</td><td align="center">x</td></tr></tbody></table>

#### 功能说明
调用一次GetBatchTensorC，会获取C矩阵片，该接口可以与[IterateNBatch](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0644.html)异步接口配合使用。用于在调用IterateNBatch迭代计算后，获取一片std::max(batchA, batchB) * singleCoreM * singleCoreN大小的矩阵分片。

#### 函数原型
```cpp
template <bool sync = true>
__aicore__ inline GlobalTensor<DstT> GetBatchTensorC(uint32_t batchA, uint32_t batchB, bool enSequentialWrite = false)
```

```cpp
template <bool sync = true>
__aicore__ inline void GetBatchTensorC(const LocalTensor<DstT>& c, uint32_t batchA, uint32_t batchB, bool enSequentialWrite = false)
```

#### 返回值说明
GlobalTensor<DstT>，返回计算的矩阵分片。

#### 约束说明
模板参数[enableMixDualMaster](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0616.html#ZH-CN_TOPIC_0000002336332840__p9218181073719)（默认取值为false）设置为true，即使能MixDualMaster（双主模式）场景时，不支持使用该接口。

#### 调用示例
```cpp
// 计算需要多Batch计算循环次数
int for_extent = tiling.ALayoutInfoB * tiling.ALayoutInfoN * g_lay / tiling.BatchNum;
mm1.SetTensorA(gm_a[0], isTransposeAIn);
mm1.SetTensorB(gm_b[0], isTransposeBIn);
if (tiling.isBias) {
  mm1.SetBias(gm_bias[0]);
}
// 多batch Matmul计算
mm1.template IterateNBatch<false>(for_extent, batchA, batchB, false);
...other compute
for (int i = 0; i < for_extent; ++i) {
  mm.GetBatchTensorC<false>(ubCmatrix);
  ...other compute
}
```
