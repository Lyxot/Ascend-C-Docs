    <h4 class="sectiontitle">功能说明</h4>
    <p>单次Matmul计算处理的shape比较小时，由于每次计算均涉及到内部的通信，可能会影响性能，该接口提供批量处理Matmul的功能，调用一次IterateBatch，可以计算出多个singleCoreM * singleCoreN大小的C矩阵。</p>
    <p>在使用该接口前，需要了解一些必备的数据排布格式：</p>
    <ul>
     <li><a name="ZH-CN_TOPIC_0000002370171685__li536045110115"></a><a name="li536045110115"></a><strong>通用数据格式（NORMAL）</strong>：BMNK的数据排布格式
      <p><a name="ZH-CN_TOPIC_0000002370171685__p553564441013"></a><a name="p553564441013"></a><img src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002370173241.png"></p></li>
     <li><strong>BSH/SBH：</strong>B：Batch，批处理的大小； S：sequence length，序列长度；H = N * D，其中，N为head的数量，D为head的大小。Layout格式如下图所示：
      <p><img class="eddx" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002336334886.png"></p>
      <p><img class="eddx" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002370173221.png"></p></li>
     <li><a name="ZH-CN_TOPIC_0000002370171685__li298041002213"></a><a name="li298041002213"></a><strong>BSNGD：</strong>为原始BSH shape做reshape后的shape，S和D为单Batch的矩阵乘的M轴（或N轴）和K轴，一个SD为一个batch的计算数据，Layout格式如下图所示：
      <p><img class="eddx" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002336175090.png"></p></li>
     <li><a name="ZH-CN_TOPIC_0000002370171685__li6785191319227"></a><a name="li6785191319227"></a><strong>SBNGD：</strong>为原始SBH shape做reshape后shape，S和D为的矩阵乘的M轴（或N轴）和K轴，一个SD为一个Batch的计算数据，Layout格式如下图所示：
      <p><img class="eddx" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002370253093.png"></p></li>
     <li><a name="ZH-CN_TOPIC_0000002370171685__li1922441712222"></a><a name="li1922441712222"></a><strong>BNGS1S2：</strong>一般为前两种Layout进行矩阵乘的输出，S1S2数据连续存放，一个S1S2为一个Batch的计算数据，Layout格式如下图所示：
      <p><img class="eddx" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002370173217.png"></p></li>
    </ul>
    <p>实例化Matmul时，需要通过MatmulType设置输入输出的Layout格式，当前支持4种Layout类型：BSNGD、SBNGD、BNGS1S2、NORMAL（BMNK的数据排布格式使用NORMAL表示）。</p>
    <p>对于BSNGD、SBNGD、BNGS1S2 Layout格式，调用该接口之前需要在host Tiling实现中使用<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0699.html">SetALayout</a>、<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0700.html">SetBLayout</a>、<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0701.html">SetCLayout</a>、<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0702.html">SetBatchNum</a>设置A/B/C的Layout轴信息和最大BatchNum数；对于NORMAL Layout格式则需使用<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0703.html">SetBatchInfoForNormal</a>设置A/B/C的M/N/K轴信息和A/B矩阵的BatchNum数。</p>
    <p>单个矩阵乘迭代顺序可通过tiling参数iterateOrder调整。</p>
    <p>更多矩阵编程batch场景的相关内容请参考<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0041.html">Batch Matmul基础功能</a>。</p>

         <p>获取C矩阵过程分为同步和异步两种模式：</p>
         <ul>
          <li><strong>同步：</strong>需要同步等待IterateBatch执行结束。</li>

        <td class="cellrowborder" valign="top" width="17.02%" headers="mcps1.3.4.2.2.3.1.1 ">
         <p>waitIterateBatch</p></td>
        <td class="cellrowborder" valign="top" width="82.98%" headers="mcps1.3.4.2.2.3.1.2 ">

    <h4 class="sectiontitle">约束说明</h4>
    <ul>
     <li>该接口只支持Norm模板，即BatchMatmul只支持Norm模板。</li>
     <li>对于BSNGD、SBNGD、BNGS1S2 Layout格式，输入A、B矩阵按分形对齐后的多Batch数据总和应小于<span>L1 Buffer</span>的大小；对于NORMAL Layout格式没有这种限制，但需通过MatmulConfig配置输入A、B矩阵多Batch数据大小与<span>L1 Buffer</span>的大小关系；</li>
     <li>对于BSNGD、SBNGD、BNGS1S2 Layout格式，称左矩阵、右矩阵的G轴分别为ALayoutInfoG、BLayoutInfoG，则ALayoutInfoG / batchA = BLayoutInfoG / batchB；对于NORMAL Layout格式，batchA 、batchB必须满足倍数关系。</li>
     <li>如果接口输出到<span>Unified Buffer</span>上，输出C矩阵大小BaseM*BaseN应小于分配的<span>Unified Buffer</span>内存大小。</li>
     <li>对于BSNGD、SBNGD Layout格式，输入输出只支持ND格式数据。对于BNGS1S2、NORMAL Layout格式， 输入支持ND/NZ格式数据。</li>
     <li>该接口不支持量化模式，即不支持SetQuantScalar、SetQuantVector接口。</li>
     <li>BSNGD场景，不支持一次计算多行SD，需要算子程序中循环计算。</li>
     <li><strong>异步模式</strong>不支持IterateBatch搬运到UB上。</li>
     <li>模板参数<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0616.html#ZH-CN_TOPIC_0000002336332840__p9218181073719">enableMixDualMaster</a>（默认取值为false）设置为true，即使能MixDualMaster（双主模式）场景时，不支持使用该接口。</li>
     <li><span><term>
        Atlas 推理系列产品
       </term>AI Core</span>上，只支持NORMAL Layout格式。</li>
     <li><span><term>
        Atlas 推理系列产品
       </term>AI Core</span>上，不支持A、B矩阵内存逻辑位置为TPosition::TSCM的输入。</li>
     <li><span><term>
        Atlas 推理系列产品
       </term>AI Core</span>上，Bias不支持复用，Bias的shape大小必须为Batch * N。</li>
     <li>使用该接口时，A矩阵、B矩阵不支持int4b_t类型的输入，即BatchMatmul不支持int4b_t类型的矩阵输入。</li>
    </ul>
