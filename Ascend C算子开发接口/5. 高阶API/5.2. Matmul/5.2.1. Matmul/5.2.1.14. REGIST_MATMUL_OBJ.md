# REGIST_MATMUL_OBJ

#### 功能说明
初始化Matmul对象。

#### 函数原型
```cpp
REGIST_MATMUL_OBJ(tpipe, workspace, ...)
```

#### 参数说明
<table border="1" cellpadding="4" cellspacing="0" frame="border" rules="all">
<caption>表1 参数说明</caption>
<thead>
<tr><th>参数名</th><th>输入/输出</th><th>描述</th></tr>
</thead>
<tbody>
<tr><td>tpipe</td><td>输入</td><td>Tpipe对象。</td></tr>
<tr><td>workspace</td><td>输入</td><td>系统workspace指针。</td></tr>
<tr><td>...</td><td>输入</td><td>可变参数，传入Matmul对象和与之对应的Tiling结构，要求Tiling结构的数据类型为<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0673.html#ZH-CN_TOPIC_0000002336174434__table1563162142915">TCubeTiling结构</a>。 Tiling参数可以通过Host侧<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0692.html">GetTiling</a>接口获取，并传递到kernel侧使用。</td></tr>
</tbody>
</table>

#### 返回值说明
无

#### 约束说明
- 在<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0008.html#ZH-CN_TOPIC_0000002336176974__section349312501823">分离架构</a>中，本接口必须在<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0110.html">InitBuffer</a>接口前调用。
- 在程序中，最多支持定义4个Matmul对象。
- 当代码中只有一个Matmul对象时，本接口可以不传入tiling参数，通过<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0630.html">Init</a>接口单独传入tiling参数。
- 当代码中有多个Matmul对象时，必须满足Matmul对象与其tiling参数一一对应，依次传入，具体方式请参考调用示例。

#### 调用示例
```cpp
Tpipe pipe;
// 推荐：初始化单个matmul对象，传入tiling参数
REGIST_MATMUL_OBJ(&pipe, GetSysWorkSpacePtr(), mm, &tiling);
// 推荐：初始化多个matmul对象，传入对应的tiling参数
REGIST_MATMUL_OBJ(&pipe, GetSysWorkSpacePtr(), mm1, mm1tiling, mm2, mm2tiling, mm3, mm3tiling, mm4, mm4tiling);
// 初始化单个matmul对象，未传入tiling参数。注意，该场景下需要使用Init接口单独传入tiling参数。这种方式将matmul对象的初始化和tiling的设置分离，比如，Tiling可变的场景，可通过这种方式多次对Tiling进行重新设置
REGIST_MATMUL_OBJ(&pipe, GetSysWorkSpacePtr(), mm);
mm.Init(&tiling);
```
