# GetSpecialMDLConfig

#### 产品支持情况

<table border="1" rules="all" cellpadding="4" cellspacing="0"><thead align="left"><tr><th align="left">产品</th><th align="center">是否支持</th></tr></thead><tbody><tr><td>Atlas A3 训练系列产品/Atlas A3 推理系列产品</td><td align="center">√</td></tr><tr><td>Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件</td><td align="center">√</td></tr><tr><td>Atlas 200I/500 A2 推理产品</td><td align="center">x</td></tr><tr><td>Atlas 推理系列产品AI Core</td><td align="center">x</td></tr><tr><td>Atlas 推理系列产品Vector Core</td><td align="center">x</td></tr><tr><td>Atlas 训练系列产品</td><td align="center">x</td></tr><tr><td>Atlas 200/300/500 推理产品</td><td align="center">x</td></tr></tbody></table>

#### 功能说明

用于配置SpecialMDL模板的参数，获取自定义SpecialMDL模板。SpecialMDL模板的介绍请参考[表 模板特性](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0616.html#ZH-CN_TOPIC_0000002336332840__table6981133810309)。

#### 函数原型

```cpp
__aicore__ constexpr MatmulConfig GetSpecialMDLConfig(const bool intrinsicsLimit = false, const bool batchLoop = false, const uint32_t doMTE2Preload = 0, const bool isVecND2NZ = false, bool isPerTensor = false, bool hasAntiQuantOffset = false)
```

#### 参数说明

本接口的所有参数用于设置[MatmulConfig结构体](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0616.html#ZH-CN_TOPIC_0000002336332840__table1761013213153)中的参数，其中互相对应的参数的功能作用相同。

<table border="1" rules="all" cellpadding="4" cellspacing="0"><caption><strong>表1 </strong>接口参数说明</caption><thead align="left"><tr><th align="left">参数名</th><th align="left">输入/输出</th><th align="left">描述</th></tr></thead><tbody><tr><td>intrinsicsLimit</td><td>输入</td><td>用于设置参数intrinsicsCheck。 当左矩阵或右矩阵在单核上内轴（即尾轴）大于等于65535（元素个数）时，是否使能循环执行数据从Global Memory到L1 Buffer的搬入。例如，左矩阵A[M, K]，单核上的内轴数据singleCoreK大于65535，配置该参数为true后，API内部通过循环执行数据的搬入。参数取值如下：<ul><li>false：当左矩阵或右矩阵在单核上内轴大于等于65535时，不使能循环执行数据的搬入（默认值）。</li><li>true：当左矩阵或右矩阵在单核上内轴大于等于65535时，使能循环执行数据的搬入。</li></ul></td></tr><tr><td>batchLoop</td><td>输入</td><td>用于设置参数isNBatch。 是否多Batch输入多Batch输出。仅对BatchMatmul有效。参数取值如下：<ul><li>false：不使能多Batch（默认值）。</li><li>true：使能多Batch。</li></ul></td></tr><tr><td>doMTE2Preload</td><td>输入</td><td>用于设置参数doMTE2Preload。 在MTE2流水间隙较大，且M/N数值较大时可通过该参数开启对应M/N方向的预加载功能，开启后能减小MTE2间隙，提升性能。预加载功能仅在MDL模板有效（不支持SpecialMDL模板）。参数取值如下：<ul><li>0：不开启（默认值）。</li><li>1：开启M方向preload。</li><li>2：开启N方向preload。</li></ul> 注意：开启M/N方向的预加载功能时需保证K全载且M/N方向开启<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0090.html">double buffer</a>；其中，M方向的K全载条件为：singleCoreK/baseK &lt;= stepKa；N方向的K全载条件为：singleCoreK/baseK &lt;= stepKb。 该参数的使用样例请参考<a href="https://gitee.com/ascend/ascendc-api-adv/tree/v1.6-8.2.RC1/examples/matrix/matmul_preload" target="_blank" rel="noopener noreferrer">M/N方向预加载Matmul算子样例</a>。</td></tr><tr><td>isVecND2NZ</td><td>输入</td><td>预留参数，保持默认值即可。</td></tr><tr><td>isPerTensor</td><td>输入</td><td>用于设置参数isPerTensor。 A矩阵half类型输入且B矩阵int8_t类型输入场景，使能B矩阵量化时是否为per tensor。<ul><li>true：per tensor量化。</li><li>false：per channel量化。</li></ul></td></tr><tr><td>hasAntiQuantOffset</td><td>输入</td><td>用于设置参数hasAntiQuantOffset。 A矩阵half类型输入且B矩阵int8_t类型输入场景，使能B矩阵量化时是否使用offset系数。</td></tr></tbody></table>

#### 返回值说明

[MatmulConfig结构体](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0616.html#ZH-CN_TOPIC_0000002336332840__table1761013213153)。

#### 约束说明

无

#### 调用示例

```cpp
constexpr MatmulConfig MM_CFG = GetSpecialMDLConfig();
AscendC::Matmul<A_TYPE, B_TYPE, C_TYPE, BIAS_TYPE, MM_CFG> mm;
REGIST_MATMUL_OBJ(&pipe, GetSysWorkSpacePtr(), mm, &tiling);
mm.SetTensorA(gm_a);
mm.SetTensorB(gm_b);
mm.SetBias(gm_bias);
mm.IterateAll(gm_c);
```
