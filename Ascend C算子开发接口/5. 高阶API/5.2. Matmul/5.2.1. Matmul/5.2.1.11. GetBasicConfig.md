#### 功能说明

用于配置BasicBlock模板的参数，获取自定义BasicBlock模板。BasicBlock模板的介绍请参考[表 模板特性](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0616.html#ZH-CN_TOPIC_0000002336332840__table6981133810309)。

使用该接口时可以优先考虑使用模板常量化。相比BasicBlock模板可以实现baseM/N/K常量化，模板常量化可以在此基础上实现singleCoreM/N/K、baseM/N/K的常量化，模板常量化的具体使用方式请参考[Matmul Tiling常量化](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0666.html#ZH-CN_TOPIC_0000002370252217__section618mcpsimp)。

#### 函数原型

```cpp
__aicore__ constexpr MatmulConfig GetBasicConfig(const uint32_t basicM, const uint32_t basicN, const uint32_t basicK, const bool intrinsicsLimit = false, const bool batchLoop = false, const BatchMode bmmMode = BatchMode::BATCH_LESS_THAN_L1)
```

#### 参数说明

本接口的所有参数用于设置[MatmulConfig结构体](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0616.html#ZH-CN_TOPIC_0000002336332840__table1761013213153)中的参数，其中互相对应的参数的功能作用相同。

#### 调用示例

BasicBlock模板的完整使用样例请参考[basic_block_matmul](https://gitee.com/ascend/ascendc-api-adv/tree/v1.6-8.2.RC1/examples/matrix/basic_block_matmul)。

```cpp
constexpr MatmulConfig MM_CFG = GetBasicConfig(128, 256, 64); // baseM, baseN, baseK
AscendC::Matmul<A_TYPE, B_TYPE, C_TYPE, BIAS_TYPE, MM_CFG> mm;
REGIST_MATMUL_OBJ(&pipe, GetSysWorkSpacePtr(), mm, &tiling);
mm.SetTensorA(gm_a);
mm.SetTensorB(gm_b);
mm.SetBias(gm_bias);
mm.IterateAll(gm_c);
```
