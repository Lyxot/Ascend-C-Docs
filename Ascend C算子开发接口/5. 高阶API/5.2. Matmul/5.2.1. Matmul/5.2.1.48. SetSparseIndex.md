# SetSparseIndex

#### 产品支持情况
<table border="1"><thead><tr><th>产品</th><th>是否支持</th></tr></thead><tbody><tr><td>Atlas A3 训练系列产品/Atlas A3 推理系列产品</td><td>√</td></tr><tr><td>Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件</td><td>√</td></tr><tr><td>Atlas 200I/500 A2 推理产品</td><td>x</td></tr><tr><td>Atlas 推理系列产品AI Core</td><td>x</td></tr><tr><td>Atlas 推理系列产品Vector Core</td><td>x</td></tr><tr><td>Atlas 训练系列产品</td><td>x</td></tr><tr><td>Atlas 200/300/500 推理产品</td><td>x</td></tr></tbody></table>

#### 功能说明
设置稀疏矩阵[稠密化过程](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0250.html#ZH-CN_TOPIC_0000002370172357__section19443175724215)生成的索引矩阵。

索引矩阵在稠密化中的作用请参考[MmadWithSparse](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0250.html#ZH-CN_TOPIC_0000002370172357__section618mcpsimp)。

#### 函数原型
```cpp
__aicore__ inline void SetSparseIndex(const GlobalTensor<uint8_t>& indexGlobal)
```

#### 参数说明
<table border="1"><caption><b>表1 </b>参数说明</caption><thead><tr><th>参数名</th><th>输入/输出</th><th>描述</th></tr></thead><tbody><tr><td>indexGlobal</td><td>输入</td><td>索引矩阵在Global Memory上的首地址，类型为GlobalTensor。索引矩阵的数据类型为int2，需要由用户拼成int8的数据类型，再传入本接口。索引矩阵的Format格式只支持NZ格式。</td></tr></tbody></table>

#### 返回值说明
无

#### 约束说明
- 索引矩阵的Format格式要求为NZ格式。
- 本接口仅支持在纯Cube模式（只有矩阵计算）且[MDL模板](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0616.html#ZH-CN_TOPIC_0000002336332840__li661233281512)的场景使用。

#### 调用示例
```cpp
#define ASCENDC_CUBE_ONLY // 使能纯Cube模式(只有矩阵计算)
REGIST_MATMUL_OBJ(&pipe, GetSysWorkSpacePtr(), mm, &tiling);
mm.SetTensorA(gm_a);
mm.SetTensorB(gm_b);
mm.SetSparseIndex(gm_index); //设置索引矩阵
mm.SetBias(gm_bias);  
mm.IterateAll(gm_c);
```
