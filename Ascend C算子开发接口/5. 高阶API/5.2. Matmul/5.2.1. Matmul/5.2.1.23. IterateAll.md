# IterateAll

#### 产品支持情况
<table>
<thead><tr><th>产品</th><th>是否支持</th></tr></thead>
<tbody><tr><td>Atlas A3 训练系列产品/Atlas A3 推理系列产品</td><td>√</td></tr><tr><td>Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件</td><td>√</td></tr><tr><td>Atlas 200I/500 A2 推理产品</td><td>√</td></tr><tr><td>Atlas 推理系列产品AI Core</td><td>√</td></tr><tr><td>Atlas 推理系列产品Vector Core</td><td>x</td></tr><tr><td>Atlas 训练系列产品</td><td>x</td></tr><tr><td>Atlas 200/300/500 推理产品</td><td>x</td></tr></tbody>
</table>

#### 功能说明
调用一次IterateAll，会计算出singleCoreM * singleCoreN大小的C矩阵。迭代顺序可通过tiling参数iterateOrder调整。

#### 函数原型
```cpp
template <bool sync = true> __aicore__ inline void IterateAll(const GlobalTensor<DstT>& gm, uint8_t enAtomic = 0, bool enSequentialWrite = false, bool waitIterateAll = false, bool fakeMsg = false)
```
```cpp
template <bool sync = true> __aicore__ inline void IterateAll(const LocalTensor<DstT>& ubCmatrix, uint8_t enAtomic = 0)
```

<ul>
<li>IBShare场景：该场景复用L1上相同的A矩阵或B矩阵数据，要求AIV分核调用IterateAll的次数必须匹配，此时需要调用IterateAll并设置fakeMsg为true，不执行真正的计算，仅用来保证IterateAll调用成对出现。默认值为false，表示执行真正的计算。</li>
<li>IntraBlockPartSum场景：用于分离架构上的Vector计算、Cube计算融合，使能多个AIV核的一次Matmul计算结果（baseM * baseN大小的矩阵分片）在<span>L0C Buffer</span>上累加。默认值为false，表示执行各AIV核的Matmul计算结果在<span>L0C Buffer</span>上累加。</li>
</ul></td></tr></tbody>
</table>

#### 返回值说明
无

#### 约束说明
传入的C矩阵地址空间大小需要保证不小于singleCoreM * singleCoreN。

#### 调用示例
IterateAll接口的调用示例如下，更多异步场景的算子样例请参考<a href="https://gitee.com/ascend/ascendc-api-adv/tree/v1.6-8.2.RC1/examples/matrix/matmul_async" target="_blank" rel="noopener noreferrer">异步场景Matmul矩阵乘法</a>。
```cpp
REGIST_MATMUL_OBJ(&pipe, GetSysWorkSpacePtr(), mm, &tiling);
mm.SetTensorA(gm_a);
mm.SetTensorB(gm_b);
mm.SetBias(gm_bias);
mm.IterateAll(gm_c);    // 计算
```
