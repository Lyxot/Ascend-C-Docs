# SetSingleShape

#### 产品支持情况
<table><thead><tr><th>产品</th><th>是否支持</th></tr></thead><tbody><tr><td>Atlas A3 训练系列产品/Atlas A3 推理系列产品</td><td>√</td></tr><tr><td>Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件</td><td>√</td></tr><tr><td>Atlas 200I/500 A2 推理产品</td><td>√</td></tr><tr><td>Atlas 推理系列产品AI Core</td><td>√</td></tr><tr><td>Atlas 推理系列产品Vector Core</td><td>x</td></tr><tr><td>Atlas 训练系列产品</td><td>x</td></tr><tr><td>Atlas 200/300/500 推理产品</td><td>x</td></tr></tbody></table>

#### 功能说明
设置Matmul单核计算的形状singleCoreM、singleCoreN、singleCoreK，单位为元素。用于运行时修改shape，比如复用Matmul对象来处理尾块。与SetTail接口功能一致，建议使用本接口。

#### 函数原型
```cpp
__aicore__ inline void SetSingleShape(int singleM, int singleN, int singleK)
```

#### 参数说明
<table><caption>表1 参数说明</caption><thead><tr><th>参数名</th><th>输入/输出</th><th>描述</th></tr></thead><tbody><tr><td>singleM</td><td>输入</td><td>设置的singleCoreM大小，单位为元素。</td></tr><tr><td>singleN</td><td>输入</td><td>设置的singleCoreN大小，单位为元素。</td></tr><tr><td>singleK</td><td>输入</td><td>设置的singleCoreK大小，单位为元素。</td></tr></tbody></table>

#### 返回值说明
无

#### 约束说明
无

#### 调用示例
```cpp
REGIST_MATMUL_OBJ(&pipe, GetSysWorkSpacePtr(), mm, &tiling);
mm.SetTensorA(gm_a);
mm.SetTensorB(gm_b);
mm.SetBias(gm_bias);
mm.SetSingleShape(tailM, tailN, tailK);    // 如果是尾核，需要调整singleCoreM/singleCoreN/singleCoreK
mm.IterateAll(gm_c);
```
