#### 功能说明
多个Matmul对象之间切换计算时，必须调用一次End函数，用于释放Matmul计算资源，防止多个Matmul对象的计算资源冲突。

#### 函数原型
```cpp
__aicore__ inline void End()
```

#### 参数说明
无

#### 返回值说明
无

#### 约束说明
无

#### 调用示例
```cpp
mm.IterateAll(gm_c);
mm.End();
```
