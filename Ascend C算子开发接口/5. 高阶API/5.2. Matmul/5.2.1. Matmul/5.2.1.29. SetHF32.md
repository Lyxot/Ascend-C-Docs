# SetHF32

#### 产品支持情况

<table cellpadding="4" cellspacing="0" border="1" frame="border" rules="all"><thead><tr><th>产品</th><th>是否支持</th></tr></thead><tbody><tr><td>Atlas A3 训练系列产品/Atlas A3 推理系列产品</td><td>√</td></tr><tr><td>Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件</td><td>√</td></tr><tr><td>Atlas 200I/500 A2 推理产品</td><td>x</td></tr><tr><td>Atlas 推理系列产品AI Core</td><td>x</td></tr><tr><td>Atlas 推理系列产品Vector Core</td><td>x</td></tr><tr><td>Atlas 训练系列产品</td><td>x</td></tr><tr><td>Atlas 200/300/500 推理产品</td><td>x</td></tr></tbody></table>

#### 功能说明

设置是否使能HF32（矩阵乘计算时可采用的数据类型）模式。使能后，在矩阵乘计算时，float32数据类型会转换为hf32数据类型，可提升计算性能，但同时也会带来精度损失。

#### 函数原型

```cpp
__aicore__ inline void SetHF32(bool enableHF32 = false, int32_t transMode = 0)
```

#### 参数说明

<table cellpadding="4" cellspacing="0" border="1" frame="border" rules="all"><thead><tr><th>参数名</th><th>输入/输出</th><th>描述</th></tr></thead><tbody><tr><td>enableHF32</td><td>输入</td><td>配置是否开启HF32模式，默认值false(不开启)。</td></tr><tr><td>transMode</td><td>输入</td><td>配置在开启HF32模式时，float转换为hf32时所采用的ROUND模式。默认值0。<p>0：就近舍入，距离相等时向偶数进位。</p><p>1：就近舍入，距离相等时向远离0方向进位。</p></td></tr></tbody></table>

#### 返回值说明

无

#### 约束说明

无

#### 调用示例

```cpp
REGIST_MATMUL_OBJ(&pipe, GetSysWorkSpacePtr(), mm, &tiling);    //  A/B/C/BIAS类型是float
mm.SetTensorA(gm_a);
mm.SetTensorB(gm_b);
mm.SetBias(gm_bias);
mm.SetHF32(true);
mm.IterateAll(gm_c);
```
