## 功能说明

按元素求差，再进行Relu计算（结果和0对比取较大值），并根据源操作数和目的操作数Tensor的数据类型进行精度转换。计算公式如下，其中dstType表示目的操作数的数据类型：

![](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_formulaimage_0000002336175374.png)

## 函数原型

1. tensor前n个数据计算
   ```cpp
   template <typename T1, typename T2>
   __aicore__ inline void SubReluCast(const LocalTensor<T1>& dstLocal, const LocalTensor<T2>& src0Local, const LocalTensor<T2>& src1Local, const uint32_t calCount)
   ```
2. tensor高维切分计算
   1. mask逐bit模式
      ```cpp
      template <typename T1, typename T2, bool isSetMask = true>
      __aicore__ inline void SubReluCast(const LocalTensor<T1>& dstLocal, const LocalTensor<T2>& src0Local, const LocalTensor<T2>& src1Local, uint64_t mask[], const uint8_t repeatTimes, const BinaryRepeatParams& repeatParams)
      ```
   2. mask连续模式
      ```cpp
      template <typename T1, typename T2, bool isSetMask = true>
      __aicore__ inline void SubReluCast(const LocalTensor<T1>& dstLocal, const LocalTensor<T2>& src0Local, const LocalTensor<T2>& src1Local, uint64_t mask, const uint8_t repeatTimes, const BinaryRepeatParams& repeatParams)
      ```

## 调用示例

本样例中只展示Compute流程中的部分代码。本样例的srcLocal为half类型，dstLocal为int8_t类型，计算mask时以half为准。如果您需要运行样例代码，请将该代码段拷贝并替换双目指令样例模板<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0052.html">更多样例</a>中的Compute函数即可。

1. tensor高维切分计算样例-mask连续模式
   ```cpp
   uint64_t mask = 256 / sizeof(half); // 128
   // repeatTimes = 4, 一次迭代计算128个数, 共计算512个数
   // dstBlkStride, src0BlkStride, src1BlkStride = 1, 单次迭代内数据连续读取和写入
   // dstRepStride = 4, src0RepStride, src1RepStride = 8, 相邻迭代间数据连续读取和写入
   AscendC::SubReluCast(dstLocal, src0Local, src1Local, mask, 4, { 1, 1, 1, 4, 8, 8 });
   ```
2. tensor高维切分计算样例-mask逐bit模式
   ```cpp
   uint64_t mask[2] = { UINT64_MAX, UINT64_MAX };
   // repeatTimes = 4, 一次迭代计算128个数, 共计算512个数
   // dstBlkStride, src0BlkStride, src1BlkStride = 1, 单次迭代内数据连续读取和写入
   // dstRepStride = 4, src0RepStride, src1RepStride = 8, 相邻迭代间数据连续读取和写入
   AscendC::SubReluCast(dstLocal, src0Local, src1Local, mask, 4, { 1, 1, 1, 4, 8, 8 });
   ```
3. tensor前n个数据计算样例
   ```cpp
   AscendC::SubReluCast(dstLocal, src0Local, src1Local, 512);
   ```

结果示例如下：
```
输入数据(src0Local): [1 2 3 ... 512]
输入数据(src1Local): [0 0.5 4 ... 513]
输出数据(dstLocal): [1 2 0 ... 0]
```
