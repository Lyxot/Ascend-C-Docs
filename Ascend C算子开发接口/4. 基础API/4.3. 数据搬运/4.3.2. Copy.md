         <ul>

    <h4 class="sectiontitle">约束说明</h4>
    <ul>
     <li>源操作数和目的操作数的起始地址需要保证32字节对齐。</li>
     <li>Copy和矢量计算API一样，支持和掩码操作API配合使用。但Counter模式配合高维切分计算API时，和<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0024.html">通用的Counter模式</a>有一定差异。具体差异如下：
      <ul>
       <li>通用的Counter模式：Mask代表<strong>整个矢量计算参与计算的元素个数，迭代次数不生效</strong>。</li>
       <li>Counter模式配合Copy高维切分计算API，Mask代表<strong>每次Repeat中处理的元素个数，迭代次数生效。</strong>示意图如下：
        <p><img class="eddx" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002370254433.png"></p></li>
      </ul></li>
    </ul>
