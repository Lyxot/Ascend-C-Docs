#### 功能说明

[DataCopy](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0105.html)（CO1->GM）过程中进行随路量化后，通过调用该接口设置Elementwise操作时LocalTensor的地址。

#### 函数原型

```cpp
template <typename T>
__aicore__ inline void SetFixPipeAddr(const LocalTensor<T> &eleWiseTensor, uint16_t c0ChStride)
```

#### 参数说明

<table>
<caption>表1 参数说明</caption>
<thead><tr><th>参数名称</th><th>输入/输出</th><th>含义</th></tr></thead>
<tbody>
<tr><td>eleWiseTensor</td><td>输入</td><td>L1 Buffer上的源操作数。类型为LocalTensor。支持的TPosition为A1/B1/C1。起始地址需要保证32字节对齐，仅支持half数据类型。</td></tr>
<tr><td>c0ChStride</td><td>输入</td><td>在L1 Buffer上的C0 channel stride，单位是C0_SIZE（32B）。eleWiseTensor沿N方向以C0为单位切分得到的数据块称为C0 channel，两块C0 channel的间隔称之为C0 channel stride。</td></tr>
</tbody>
</table>

#### 约束说明

无

#### 返回值

无
