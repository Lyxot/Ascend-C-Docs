#### 功能说明

[DataCopy](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0105.html)（CO1->GM、CO1->A1）过程中进行随路量化时，通过调用该接口设置量化流程中标量量化参数。

#### 函数原型

```cpp
__aicore__ inline void SetFixpipePreQuantFlag(uint64_t config)
```

</tbody>
</table>

#### 返回值

无
