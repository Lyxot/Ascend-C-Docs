<p>通过具体的示例对上述参数进行解析，示意图如下：</p>
<div class="fignone"><a name="ZH-CN_TOPIC_0000002370171673__fig12540183010309"></a><a name="fig12540183010309"></a><span class="figcap"><b>图1 </b>参数解析示意图</span><br><img class="eddx" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002382946957.png"></div>
<ul><li>dimValue为2，表示操作数有2维。</li><li>srcSliceInfo为 {{16, 70, 7, 3, 87},  {0, 2, 1, 1, 3}}<ul><li>{16, 70, 7, 3, 87}是针对单独一行， 即从一维的角度来配置，每个元素代表一个数：<p><a name="ZH-CN_TOPIC_0000002370171673__li109115490157"></a><a name="li109115490157"></a><strong>startIndex</strong> = 16，表示有效数据段从第16个数开始;</p>
<p><strong>endIndex</strong> = 70，表示有效数据段到第70个数结束；</p>
<p><strong>stride</strong> = 7，单位为元素个数，表示相邻的2个切片数据段间隔的元素个数，为7个0的间距；</p>
<p><strong>burstLen</strong> = 3，单位为32B，表示在这一个有效数据段中，一个切片数据段大小为3个datablock；</p>
<p><strong>shapeValue</strong> = 87，表示单独一行的长度，单位为元素个数，即 8 * 10 + 7 = 87个元素。</p>
