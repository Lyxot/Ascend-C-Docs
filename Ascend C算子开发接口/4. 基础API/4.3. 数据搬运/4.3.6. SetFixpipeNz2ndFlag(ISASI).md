# SetFixpipeNz2ndFlag(ISASI)

#### 产品支持情况
<table><thead><tr><th>产品</th><th>是否支持</th></tr></thead><tbody><tr><td>Atlas A3 训练系列产品/Atlas A3 推理系列产品</td><td>√</td></tr><tr><td>Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件</td><td>√</td></tr><tr><td>Atlas 200I/500 A2 推理产品</td><td>√</td></tr><tr><td>Atlas 推理系列产品AI Core</td><td>x</td></tr><tr><td>Atlas 推理系列产品Vector Core</td><td>x</td></tr><tr><td>Atlas 训练系列产品</td><td>x</td></tr><tr><td>Atlas 200/300/500 推理产品</td><td>x</td></tr></tbody></table>

#### 功能说明
[DataCopy](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0105.html)（CO1->GM、CO1->A1）过程中进行随路格式转换（NZ格式转换为ND格式）时，通过调用该接口设置格式转换的相关配置。

#### 函数原型
```cpp
__aicore__ inline void SetFixpipeNz2ndFlag(uint16_t ndNum, uint16_t srcNdStride, uint16_t dstNdStride)
```

#### 参数说明
<table><caption>表1 参数说明</caption><thead><tr><th>参数名称</th><th>输入/输出</th><th>含义</th></tr></thead><tbody><tr><td><strong>ndNum</strong></td><td>输入</td><td>nd的数量，类型是uint16_t，取值范围：ndNum∈[1, 65535]。</td></tr><tr><td><strong>srcNdStride</strong></td><td>输入</td><td><p>以分形大小为单位的源步长，源相邻nz矩阵的偏移（头与头）。</p><p>Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件，srcNdStride∈[1, 512]，单位：fractal_size 1024B。</p><p>Atlas A3 训练系列产品/Atlas A3 推理系列产品，srcNdStride∈[1, 512]，单位：fractal_size 1024B。</p><p>Atlas 200I/500 A2 推理产品，srcNdStride∈[1, 512]，单位：fractal_size 1024B。</p></td></tr><tr><td><strong>dstNdStride</strong></td><td>输入</td><td><p>目的相邻nd矩阵的偏移（头与头）。单位为元素。</p><p>Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件，dstNdStride∈[1, 65535]。</p><p>Atlas A3 训练系列产品/Atlas A3 推理系列产品，dstNdStride∈[1, 65535]。</p><p>Atlas 200I/500 A2 推理产品，dstNdStride∈[1, 65535]。</p></td></tr></tbody></table>

#### 约束说明
无

#### 返回值
无
