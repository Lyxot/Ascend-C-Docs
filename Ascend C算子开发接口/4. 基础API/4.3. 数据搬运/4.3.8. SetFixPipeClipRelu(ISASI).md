# SetFixPipeClipRelu(ISASI)

#### 产品支持情况
<table cellpadding="4" cellspacing="0" summary="" frame="border" border="1" rules="all"><thead><tr><th>产品</th><th>是否支持</th></tr></thead><tbody><tr><td>Atlas A3 训练系列产品/Atlas A3 推理系列产品</td><td>x</td></tr><tr><td>Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件</td><td>x</td></tr><tr><td>Atlas 200I/500 A2 推理产品</td><td>√</td></tr><tr><td>Atlas 推理系列产品AI Core</td><td>x</td></tr><tr><td>Atlas 推理系列产品Vector Core</td><td>x</td></tr><tr><td>Atlas 训练系列产品</td><td>x</td></tr><tr><td>Atlas 200/300/500 推理产品</td><td>x</td></tr></tbody></table>

#### 功能说明
[DataCopy](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0105.html)（CO1->GM）过程中进行随路量化后，通过调用该接口设置ClipRelu操作的最大值。

ClipRelu计算公式为min(clipReluMaxVal，srcData)，clipReluMaxVal为通过该接口设置的最大值，srcData为源数据。

#### 函数原型
```cpp
__aicore__ inline void SetFixPipeClipRelu(uint64_t config)
```

#### 参数说明
表1 参数说明
<table cellpadding="4" cellspacing="0" summary="" frame="border" border="1" rules="all"><thead><tr><th>参数名称</th><th>输入/输出</th><th>含义</th></tr></thead><tbody><tr><td>config</td><td>输入</td><td>clipReluMaxVal，ClipRelu操作中的最大值。clipReluMaxVal只占用0-15bit，必须大于0，不能为INF/NAN。</td></tr></tbody></table>

#### 约束说明
使能Relu的情况下，先进行Relu操作，之后再进行ClipRelu。

#### 返回值
无

#### 调用示例
完整示例可参考[完整示例](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0105.html#ZH-CN_TOPIC_0000002370171433__li152921471718)。

```cpp
uint64_t clipReluMaxVal = 0x3c00; // value 1, half类型转换成uint64_t类型
SetFixPipeClipRelu(clipReluMaxVal);
```
