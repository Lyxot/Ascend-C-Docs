# SetFixPipeConfig(ISASI)

#### 产品支持情况
<table><thead><tr><th>产品</th><th>是否支持</th></tr></thead><tbody><tr><td>Atlas A3 训练系列产品/Atlas A3 推理系列产品</td><td>√</td></tr><tr><td>Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件</td><td>√</td></tr><tr><td>Atlas 200I/500 A2 推理产品</td><td>√</td></tr><tr><td>Atlas 推理系列产品AI Core</td><td>x</td></tr><tr><td>Atlas 推理系列产品Vector Core</td><td>x</td></tr><tr><td>Atlas 训练系列产品</td><td>x</td></tr><tr><td>Atlas 200/300/500 推理产品</td><td>x</td></tr></tbody></table>

#### 功能说明
[DataCopy](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0105.html)（CO1->GM、CO1->A1）过程中进行随路量化时，通过调用该接口设置量化流程中tensor量化参数。

#### 函数原型
```cpp
template <typename T>
__aicore__ inline void SetFixPipeConfig(const LocalTensor<T> &reluPre, const LocalTensor<T> &quantPre, bool isUnitFlag = false)
template <typename T, bool setRelu = false>
__aicore__ inline void SetFixPipeConfig(const LocalTensor<T> &preTensor, bool isUnitFlag = false)
```

#### 参数说明
<table><caption><b>表1 </b>模板参数说明</caption><thead><tr><th>参数名</th><th>描述</th></tr></thead><tbody><tr><td>T</td><td>操作数的数据类型。</td></tr><tr><td>setRelu</td><td>针对设置一个tensor的情况，当setRelu为true时，设置reluPreTensor；反之设置quantPreTensor。当前仅支持设置为false。</td></tr></tbody></table>

<table><caption><b>表2 </b>参数说明</caption><thead><tr><th>参数名称</th><th>输入/输出</th><th>含义</th></tr></thead><tbody><tr><td>reluPre</td><td>输入</td><td>源操作数，relu tensor，类型为LocalTensor，支持的TPosition为C2PIPE2GM。预留参数，暂未启用，为后续的功能扩展做保留，传入一个空LocalTensor即可。</td></tr><tr><td>quantPre</td><td>输入</td><td>源操作数，quant tensor，量化操作时参与计算的tensor，类型为LocalTensor，支持的TPosition为C2PIPE2GM。</td></tr><tr><td>isUnitFlag</td><td>输入</td><td>UnitFlag配置项，类型为bool。预留参数，暂未启用，为后续的功能扩展做保留，保持默认值false即可。</td></tr><tr><td>preTensor</td><td>输入</td><td>支持设置一个Tensor，通过开关控制是relu Tensor还是quantTensor，支持的TPosition为C2PIPE2GM。当前仅支持传入quantTensor。</td></tr></tbody></table>

#### 约束说明
无

无
