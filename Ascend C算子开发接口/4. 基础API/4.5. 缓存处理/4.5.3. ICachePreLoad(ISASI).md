# ICachePreLoad(ISASI)

#### 产品支持情况
<table cellpadding="4" cellspacing="0" frame="border" border="1" rules="all"><thead><tr><th><p><span>产品</span></p></th><th><p>是否支持</p></th></tr></thead><tbody><tr><td><p><span><term>Atlas A3 训练系列产品/Atlas A3 推理系列产品</term></span></p></td><td><p>√</p></td></tr><tr><td><p><span><term>Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件</term></span></p></td><td><p>√</p></td></tr><tr><td><p><span><term>Atlas 200I/500 A2 推理产品</term></span></p></td><td><p>x</p></td></tr><tr><td><p><span><term>Atlas 推理系列产品</term>AI Core</span></p></td><td><p>√</p></td></tr><tr><td><p><span><term>Atlas 推理系列产品</term>Vector Core</span></p></td><td><p>x</p></td></tr><tr><td><p><span><term>Atlas 训练系列产品</term></span></p></td><td><p>x</p></td></tr><tr><td><p><span><term>Atlas 200/300/500 推理产品</term></span></p></td><td><p>x</p></td></tr></tbody></table>

#### 功能说明
从指令所在DDR地址预加载指令到ICache中。

#### 函数原型
```cpp
__aicore__ inline void ICachePreLoad(const int64_t preFetchLen)
```

#### 参数说明
<table cellpadding="4" cellspacing="0" frame="border" border="1" rules="all"><caption><b>表1 </b>参数说明</caption><thead><tr><th><p>参数名</p></th><th><p>输入/输出</p></th><th><p>描述</p></th></tr></thead><tbody><tr><td><p><strong>preFetchLen</strong></p></td><td><p>输入</p></td><td><p>预取长度。</p><p>针对<span><term>Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件</term></span>：preFetchLen参数单位为2K Byte, 取值应小于ICache的大小/2K。AIC和AIV的ICache大小分别为32KB和16KB。</p><p>针对<span><term>Atlas A3 训练系列产品/Atlas A3 推理系列产品</term></span>：preFetchLen参数单位为2K Byte, 取值应小于ICache的大小/2K。AIC和AIV的ICache大小分别为32KB和16KB。</p><p>针对<span><term>Atlas 推理系列产品</term>AI Core</span>：传入该参数无效，预取长度均为128Byte。</p></td></tr></tbody></table>

#### 返回值
无

#### 约束说明
无

#### 调用示例
```cpp
int64_t preFetchLen = 2;
AscendC::ICachePreLoad(preFetchLen);
```
