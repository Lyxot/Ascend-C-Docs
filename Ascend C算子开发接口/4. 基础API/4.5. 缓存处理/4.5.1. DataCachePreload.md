#### 功能说明
从源地址所在的特定GM地址预加载数据到data cache中。

#### 函数原型
```cpp
template <typename T>
__aicore__ inline void DataCachePreload(const GlobalTensor<uint64_t> &srcTensor, const T cacheOffset)
```

#### 参数说明
<table>
<caption>表1 参数说明</caption>
<thead>
<tr><th>参数名</th><th>输入/输出</th><th>描述</th></tr>
</thead>
<tbody>
<tr><td>srcTensor</td><td>输入</td><td>源操作数，类型为GlobalTensor。支持的数据类型为：uint64_t。</td></tr>
<tr><td>cacheOffset</td><td>输入</td><td>在源操作数上偏移cacheOffset大小开始加载数据，单位为byte，支持的数据类型为：int16_t/int64_t。</td></tr>
</tbody>
</table>

#### 返回值
无

#### 约束说明
频繁调用此接口可能导致保留站拥塞，这种情况下，此指令将被视为NOP指令，阻塞Scalar流水。因此不建议频繁调用该接口。

#### 调用示例
```cpp
AscendC::GlobalTensor<uint64_t> srcGlobal;
int64_t cacheOffset = 0;
AscendC::DataCachePreload(srcGlobal, cacheOffset);
```
