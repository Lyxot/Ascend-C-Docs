#### 功能说明
获取一个uint64_t类型数字的二进制表示中从最低有效位开始的第一个0或1出现的位置，如果没找到则返回-1。

#### 函数原型
```cpp
template <int countValue>
__aicore__ inline int64_t ScalarGetSFFValue(uint64_t valueIn)
```

#### 参数说明
<table border="1" cellpadding="4" cellspacing="0" frame="border" rules="all"><caption><b>表1 </b>模板参数说明</caption><thead><tr><th>参数名</th><th>描述</th></tr></thead><tbody><tr><td>countValue</td><td>指定要查找的值，0表示查找第一个0的位置，1表示查找第一个1的位置，数据类型是int，只能输入0或1。</td></tr></tbody></table>

<table border="1" cellpadding="4" cellspacing="0" frame="border" rules="all"><caption><b>表2 </b>参数说明</caption><thead><tr><th>参数名</th><th>输入/输出</th><th>描述</th></tr></thead><tbody><tr><td>valueIn</td><td>输入</td><td>输入数据，数据类型是uint64_t。</td></tr></tbody></table>

#### 返回值
int64_t类型的数，valueIn中第一个0或1出现的位置。

#### 约束说明
无。

#### 调用示例
```cpp
uint64_t valueIn = 28;
// 输出数据(oneCount): 2
int64_t oneCount = AscendC::ScalarGetSFFValue<1>(valueIn);
```
