#### 功能说明
计算一个uint64_t类型数字前导0的个数（二进制从最高位到第一个1一共有多少个0）。

#### 函数原型
```cpp
__aicore__ inline int64_t ScalarCountLeadingZero(uint64_t valueIn)
```

#### 参数说明
<table>
<caption>表1 参数说明</caption>
<thead><tr><th>参数名</th><th>输入/输出</th><th>描述</th></tr></thead>
<tbody><tr><td>valueIn</td><td>输入</td><td>被统计的二进制数字。</td></tr></tbody>
</table>

#### 返回值
返回valueIn的前导0的个数。

#### 约束说明
无

#### 调用示例
```cpp
uint64_t valueIn = 0x0fffffffffffffff;
// 输出数据(ans): 4
int64_t ans = AscendC::ScalarCountLeadingZero(valueIn);
```
