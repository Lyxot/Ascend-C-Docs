# ScalarGetCountOfValue

#### 产品支持情况
<table border="1"><thead><tr><th align="left">产品</th><th align="center">是否支持</th></tr></thead><tbody><tr><td>Atlas A3 训练系列产品/Atlas A3 推理系列产品</td><td align="center">√</td></tr><tr><td>Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件</td><td align="center">√</td></tr><tr><td>Atlas 200I/500 A2 推理产品</td><td align="center">x</td></tr><tr><td>Atlas 推理系列产品AI Core</td><td align="center">√</td></tr><tr><td>Atlas 推理系列产品Vector Core</td><td align="center">x</td></tr><tr><td>Atlas 训练系列产品</td><td align="center">x</td></tr><tr><td>Atlas 200/300/500 推理产品</td><td align="center">x</td></tr></tbody></table>

#### 功能说明
获取一个uint64_t类型数字的二进制中0或者1的个数。

#### 函数原型
```cpp
template <int countValue>
__aicore__ inline int64_t ScalarGetCountOfValue(uint64_t valueIn)
```

#### 参数说明
<table border="1"><caption>表1 模板参数说明</caption><thead><tr><th align="left">参数名</th><th align="left">描述</th></tr></thead><tbody><tr><td>countValue</td><td>指定统计0还是统计1的个数。只能输入0或1。</td></tr></tbody></table>

<table border="1"><caption>表2 参数说明</caption><thead><tr><th align="left">参数名</th><th align="left">输入/输出</th><th align="left">描述</th></tr></thead><tbody><tr><td>valueIn</td><td>输入</td><td>被统计的二进制数字。</td></tr></tbody></table>

#### 返回值
valueIn中0或者1的个数。

#### 约束说明
无

#### 调用示例
```cpp
uint64_t valueIn = 0xffff;
// 输出数据(oneCount): 16
int64_t oneCount = AscendC::ScalarGetCountOfValue<1>(valueIn);
```
