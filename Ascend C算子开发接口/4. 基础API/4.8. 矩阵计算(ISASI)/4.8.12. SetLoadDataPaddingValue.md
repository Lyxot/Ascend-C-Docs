# SetLoadDataPaddingValue

#### 产品支持情况
<table cellpadding="4" cellspacing="0" frame="border" border="1" rules="all"><thead align="left"><tr><th align="left">产品</th><th align="center">是否支持</th></tr></thead><tbody><tr><td>Atlas A3 训练系列产品/Atlas A3 推理系列产品</td><td align="center">√</td></tr><tr><td>Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件</td><td align="center">√</td></tr><tr><td>Atlas 200I/500 A2 推理产品</td><td align="center">√</td></tr><tr><td>Atlas 推理系列产品AI Core</td><td align="center">√</td></tr><tr><td>Atlas 推理系列产品Vector Core</td><td align="center">x</td></tr><tr><td>Atlas 训练系列产品</td><td align="center">x</td></tr><tr><td>Atlas 200/300/500 推理产品</td><td align="center">x</td></tr></tbody></table>

#### 功能说明
用于调用[Load3Dv1接口](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0238.html#ZH-CN_TOPIC_0000002336173244__li1135744819417)/[Load3Dv2接口](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0238.html#ZH-CN_TOPIC_0000002336173244__li83241850104315)时设置Pad填充的数值。Load3Dv1/Load3Dv2的模板参数isSetPadding设置为true时，用户需要通过本接口设置Pad填充的数值，设置为false时，本接口设置的填充值不生效。

#### 函数原型
```cpp
template <typename T>
__aicore__ inline void SetLoadDataPaddingValue(const T padValue)
```
