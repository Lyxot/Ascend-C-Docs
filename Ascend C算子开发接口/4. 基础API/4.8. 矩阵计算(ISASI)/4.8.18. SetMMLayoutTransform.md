## 功能说明
设置Mmad计算时优先通过M/N中的哪个方向。

## 函数原型
```cpp
__aicore__ inline void SetMMLayoutTransform(bool mmLayoutMode)
```

## 参数说明
<table border="1" cellpadding="4" cellspacing="0"><caption>表1 参数说明</caption><thead><tr><th align="left">参数名</th><th align="left">输入/输出</th><th align="left">描述</th></tr></thead><tbody><tr><td>mmLayoutMode</td><td>输入</td><td>控制Mmad 优先通过M/N的哪个方向，bool型，支持如下两种取值：<ul><li>true：代表CUBE将首先通过N方向，然后通过M方向产生结果。</li><li>false：代表CUBE将首先通过M方向，然后通过N方向生成结果。</li></ul></td></tr></tbody></table>

## 返回值
无

## 约束说明
无

## 调用示例
```cpp
bool mmLayoutMode = true;
AscendC::SetMMLayoutTransform(mmLayoutMode);
```
