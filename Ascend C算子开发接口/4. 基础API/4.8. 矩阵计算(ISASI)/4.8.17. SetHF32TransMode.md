#### 功能说明
设置HF32模式取整的具体方式，需要先使用[SetHF32Mode](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0258.html)开启HF32取整模式。

#### 函数原型
```cpp
__aicore__ inline void SetHF32TransMode(bool hf32TransMode)
```

#### 参数说明
表1 参数说明
<table>
<thead>
<tr><th>参数名</th><th>输入/输出</th><th>描述</th></tr>
</thead>
<tbody>
<tr><td>hf32TransMode</td><td>输入</td><td>Mmad HF32取整模式控制入参，bool类型。支持如下两种取值：
<ul>
<li>true：则FP32将以向零靠近的方式四舍五入为HF32。</li>
<li>false：则FP32将以最接近偶数的方式四舍五入为HF32。</li>
</ul>
</td></tr>
</tbody>
</table>

#### 返回值
无

#### 约束说明
无

#### 调用示例
```cpp
bool hf32TransMode = true;
AscendC::SetHF32TransMode(hf32TransMode);
```
