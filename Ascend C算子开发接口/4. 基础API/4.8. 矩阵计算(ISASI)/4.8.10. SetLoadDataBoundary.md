# SetLoadDataBoundary

## 功能说明
设置[Load3D](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0238.html)时A1/B1边界值。  
如果Load3D指令在处理源操作数时，源操作数在A1/B1上的地址超出设置的边界，则会从A1/B1起始地址开始读取数据。

## 函数原型
```Cpp
__aicore__ inline void SetLoadDataBoundary(uint32_t boundaryValue)
```

<caption>表1 参数说明</caption>
<thead><tr><th>参数名称</th><th>输入/输出</th><th>含义</th></tr></thead>
<tbody><tr><td>boundaryValue</td><td>输入</td><td>边界值。Load3Dv1指令：单位是32字节。Load3Dv2指令：单位是字节。</td></tr></tbody>
</table>

## 约束说明
- 用于Load3Dv1时，boundaryValue的最小值是16（单位：32字节）；用于Load3Dv2时，boundaryValue的最小值是1024（单位：字节）。
- 如果使用SetLoadDataBoundary接口设置了边界值，配合Load3D指令使用时，Load3D指令的A1/B1初始地址要在设置的边界内。
- 如果boundaryValue设置为0，则表示无边界，可使用整个A1/B1。
- 操作数地址偏移对齐要求请参见[通用约束](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0004.html)。
