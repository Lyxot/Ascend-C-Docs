   <div class="section">
    <h4 class="sectiontitle">功能说明</h4>
    <p>设置图片预处理（AIPP，AI core pre-process）相关参数。和<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0241.html">LoadImageToLocal</a>接口配合使用。设置后，调用<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0241.html">LoadImageToLocal</a>接口可在搬运过程中完成图像预处理操作：包括数据填充，通道交换，单行读取、数据类型转换、通道填充、色域转换。调用SetAippFunctions接口时需传入源图片在Global Memory上的矩阵、源图片的图片格式。</p>
    <ul>
     <li><strong>数据填充</strong>：在图片HW方向上padding。分为如下几种模式：
      <ul>
       <li>模式0：常量填充模式，padding区域各位置填充为常数，支持设置每个通道填充的常数。该模式下仅支持左右padding，不支持上下padding。
        <div class="fignone">
         <span class="figcap"><b>图1 </b>常量填充模式（图片中间的绿色区域表示原始数据，其他为padding数据）</span>
         <br><img src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002336334866.png">
        </div></li>
       <li>模式1：行列填充模式，padding区域各位置填充行/列上最邻近源图片位置的数据。
        <div class="fignone">
         <span class="figcap"><b>图2 </b>行列填充模式（图片中间的绿色区域表示原始数据，其他为padding数据）</span>
         <br><img src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002370253053.png" title="点击放大" class="imgResize">
        </div></li>
       <li>模式2：块填充模式，按照padding的宽高，从源图片拷贝数据块进行padding区域填充。
        <div class="fignone">
         <span class="figcap"><b>图3 </b>块填充模式（图片中间的绿色区域表示原始数据，其他为padding数据）</span>
         <br><img src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002370253065.png">
        </div></li>
       <li>模式3：镜像块填充模式，按照padding的宽高，从源图片拷贝数据块的镜像进行padding区域填充。
        <div class="fignone">
         <span class="figcap"><b>图4 </b>镜像块填充模式（图片中间的绿色区域表示原始数据，其他为padding数据）</span>
         <br><img src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002370253061.png">
        </div></li>
      </ul></li>
    </ul>
    <ul>
     <li><strong>通道交换</strong>：将图片通道进行交换。
      <p>对于RGB888格式，支持交换R和B通道。</p>
      <p>对于YUV420SP格式，支持交换U和V通道。</p>
      <p>对于XRGB8888格式，支持X通道后移（XRGB-&gt;RGBX）、支持交换R和B通道。</p>
      <p>例：对于XRGB格式的数据，芯片在处理的时候会默认丢弃掉第四个通道的数据留下XRG。因此如果要保留RGB通道的数据，对于XRGB输入的需要后移X通道，将输入的通道转换为RGBX即可。</p></li>
    </ul>
    <ul>
     <li><strong>单行读取</strong>：源图片中仅读取一行。
      <div class="note">
       <img src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/public_sys-resources/note_3.0-zh-cn.png"><span class="notetitle"> </span>
       <div class="notebody">
        <p>调用数据搬运接口时，开启单行读取后设置的目的图片高度参数无效，如<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0241.html">LoadImageToLocal</a>接口的loadImageToLocalParams.verSize。</p>
       </div>
      </div></li>
    </ul>
    <ul>
     <li><strong>数据类型转换</strong>：转换像素的数据类型，支持uint8转换为int8或fp16。

        <p>转换后的数据类型是由模板参数U配置，U为uint8时数据类型转换功能不生效。</p>
        <p>调用数据搬运接口时，目的Tensor的数据类型需要与本接口输出数据类型保持一致，如<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0241.html">LoadImageToLocal</a>的dstLocal参数的数据类型。</p>
       </div>
      </div></li>
    </ul>
    <ul>
     <li><strong>通道填充</strong>：在图片通道方向上padding。默认为模式0。
      <p>模式0：将通道padding至32Bytes。即输出数据类型为uint8/int8时，padding至32通道；输出数据类型为fp16时，padding至16通道。</p>
      <p>模式1：将通道padding至4通道。</p></li>
    </ul>
    <ul>
     <li><strong>色域转换</strong>：RGB格式转换为YUV格式，或YUV模式转换为RGB格式。

    </ul>
