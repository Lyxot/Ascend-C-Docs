#### 功能说明

用于获取算子kernel入口函数传入的Tiling信息，并填入注册的TilingData结构体中，此函数会以宏展开的方式进行编译。对应的算子host实现中需要定义TilingData结构体，实现并注册计算TilingData的Tiling函数，具体请参考[Host侧tiling实现](https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0064.html)。如果用户通过[TilingData结构注册](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_1006.html)注册了多个TilingData结构体，使用该接口返回默认注册的结构体。

#### 函数原型

```cpp
GET_TILING_DATA(tiling_data, tiling_arg)
```

#### 参数说明

<table border="1" cellpadding="4" cellspacing="0">
<tr><th>参数</th><th>输入/输出</th><th>说明</th></tr>
<tr><td>tiling_data</td><td>输出</td><td>返回默认TilingData结构体变量。</td></tr>
<tr><td>tiling_arg</td><td>输入</td><td>此参数为算子入口函数处传入的Tiling参数。</td></tr>
</table>

#### 约束说明

- 本函数需在算子kernel代码处使用，并且传入的tiling_data参数不需要声明类型。
- 暂不支持kernel直调工程。

#### 调用示例

```cpp
extern "C" __global__ __aicore__ void add_custom(__gm__ uint8_t *x, __gm__ uint8_t *y, __gm__ uint8_t *z, __gm__ uint8_t *tiling)
{
    GET_TILING_DATA(tilingData, tiling);
    KernelAdd op;
    op.Init(x, y, z, tilingData.blkDim, tilingData.totalSize, tilingData.splitTile);
    op.Process();
}
```
