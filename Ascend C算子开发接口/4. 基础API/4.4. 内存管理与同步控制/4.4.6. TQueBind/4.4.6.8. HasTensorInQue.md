#### 功能说明

查询Que中目前是否已有入队的Tensor。

#### 函数原型

```cpp
__aicore__ inline bool HasTensorInQue()
```

#### 参数说明

无

#### 约束说明

该接口不支持[Tesnsor原地操作](https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_00020.html)，即TQue的depth设置为0的场景。

#### 返回值

- true - 表示Queue中存在已入队的Tensor
- false - 表示Queue为完全空闲

#### 调用示例

```cpp
// 根据VacantInQue判断当前que中是否有已入队的Tensor，当前que的深度为4，无内存Enque动作，返回为false
AscendC::TPipe pipe;
AscendC::TQueBind<AscendC::TPosition::VECOUT, AscendC::TPosition::GM, 4> que;
int num = 4;
int len = 1024;
pipe.InitBuffer(que, num, len);
bool ret = que.HasTensorInQue();
```
