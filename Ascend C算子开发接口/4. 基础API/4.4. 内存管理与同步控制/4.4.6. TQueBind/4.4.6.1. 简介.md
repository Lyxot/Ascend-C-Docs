# 简介

TQueBind绑定源逻辑位置和目的逻辑位置，根据源位置和目的位置，来确定内存分配的位置、插入对应的同步事件，帮助开发者解决内存分配和管理、同步等问题。Tque是TQueBind的简化模式。通常情况下开发者使用TQue进行编程，TQueBind对外提供一些特殊数据通路的内存管理和同步控制，涉及这些通路时可以直接使用TQueBind。

如下图的数据通路示意图所示，红色线条和蓝色线条的通路可通过TQueBind定义表达，蓝色线条的通路可通过TQue进行简化表达。

#### 模板参数

```cpp
template <TPosition src, TPosition dst, int32_t depth, auto mask = 0> class TQueBind {...};
```

<table>
<caption>表2 模板参数说明</caption>
<thead><tr><th>参数名</th><th>描述</th></tr></thead>
<tbody>
<tr><td>src</td><td>源逻辑位置，支持的TPosition可以为VECIN、VECOUT、A1、A2、B1、B2、CO1、CO2。关于TPosition的具体介绍请参考<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0174.html">TPosition</a>。支持的src和dst组合请参考<a href="#ZH-CN_TOPIC_0000002370171789__table171821134125613">表1</a>。</td></tr>
<tr><td>dst</td><td>目的逻辑位置，TPosition可以为VECIN、VECOUT、A1、A2、B1、B2、CO1、CO2。</td></tr>
<tr><td>depth</td><td>TQue的深度，一般不超过4。</td></tr>
<tr><td>mask</td><td>如果用户在某一个Que上，数据搬运的时候需要做转换，可以设置为0或1。一般不需要用户配置，默认为0。设置为0，代表数据格式从ND转换为NZ，目前仅支持TPosition为A1或B1。</td></tr>
</tbody>
</table>
