# 构造函数

#### 功能说明
创建TBufPool对象时，初始化数据成员。

#### 函数原型
```cpp
template <TPosition pos, uint32_t bufIDSize = 4>
__aicore__ inline TBufPool();
```

#### 参数说明
<table>
<caption>表1 模板参数说明</caption>
<thead><tr><th>参数名</th><th>说明</th></tr></thead>
<tbody><tr><td>pos</td><td>TBufPool逻辑位置，可以为VECIN、VECOUT、VECCALC、A1、B1、C1。关于TPosition的具体介绍请参考<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0174.html">TPosition</a>。</td></tr><tr><td>bufIDSize</td><td>TBufPool可分配Buffer数量，默认为4，不超过16。对于非共享模式的资源分配，在本TBufPool上再次申请TBufPool时，申请的bufIDSize不能超过原TBufPool剩余可用的Buffer数量；对于共享模式的资源分配，在本TBufPool上再次申请TBufPool时，申请的bufIDSize不能超过原TBufPool设置的Buffer数量。</td></tr></tbody>
</table>

无。
