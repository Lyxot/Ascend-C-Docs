# Reset

#### 产品支持情况
<table><thead><tr><th>产品</th><th>是否支持</th></tr></thead><tbody><tr><td>Atlas A3 训练系列产品/Atlas A3 推理系列产品</td><td>√</td></tr><tr><td>Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件</td><td>√</td></tr><tr><td>Atlas 200I/500 A2 推理产品</td><td>x</td></tr><tr><td>Atlas 推理系列产品 AI Core</td><td>√</td></tr><tr><td>Atlas 推理系列产品 Vector Core</td><td>x</td></tr><tr><td>Atlas 训练系列产品</td><td>√</td></tr><tr><td>Atlas 200/300/500 推理产品</td><td>x</td></tr></tbody></table>

#### 功能说明
完成自定义TbufPool资源的释放与eventId等变量的复位对消。

#### 函数原型
```cpp
__aicore__ inline void Reset()
```

#### 约束说明
切换自定义TBufPool资源池时调用该接口，调用后对应资源池及资源池分配的Buffer不能继续使用。

#### 返回值
无
