# DataSyncBarrier(ISASI)

#### 产品支持情况
<table><thead><tr><th>产品</th><th>是否支持</th></tr></thead><tbody><tr><td>Atlas A3 训练系列产品/Atlas A3 推理系列产品</td><td>x</td></tr><tr><td>Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件</td><td>√</td></tr><tr><td>Atlas 200I/500 A2 推理产品</td><td>√</td></tr><tr><td>Atlas 推理系列产品AI Core</td><td>x</td></tr><tr><td>Atlas 推理系列产品Vector Core</td><td>x</td></tr><tr><td>Atlas 训练系列产品</td><td>x</td></tr><tr><td>Atlas 200/300/500 推理产品</td><td>x</td></tr></tbody></table>

#### 功能说明
用于阻塞后续的指令执行，直到所有之前的内存访问指令（需要等待的内存位置可通过参数控制）执行结束。

#### 函数原型
```cpp
template <MemDsbT arg0>
__aicore__ inline void DataSyncBarrier()
```

#### 参数说明
表1 模板参数说明

<table><thead><tr><th>参数名</th><th>描述</th></tr></thead><tbody><tr><td>arg0</td><td>模板参数，表示需要等待的内存位置，类型为MemDsbT，可取值为：<ul><li>ALL，等待所有内存访问指令。</li><li>DDR，等待GM访问指令。</li><li>UB，等待UB访问指令。</li><li>SEQ，预留参数，暂未启用，为后续的功能扩展做保留。</li></ul></td></tr></tbody></table>

#### 返回值
无

#### 约束说明
无

#### 调用示例
```cpp
AscendC::Mmad(...);
AscendC::DataSyncBarrier<MemDsbT::ALL>();
AscendC::Fixpipe(...);
```
