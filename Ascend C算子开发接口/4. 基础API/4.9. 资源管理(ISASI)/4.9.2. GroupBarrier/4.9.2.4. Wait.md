# Wait

#### 产品支持情况

<table><thead><tr><th>产品</th><th>是否支持</th></tr></thead><tbody><tr><td>Atlas A3 训练系列产品/Atlas A3 推理系列产品</td><td>x</td></tr><tr><td>Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件</td><td>√</td></tr><tr><td>Atlas 200I/500 A2 推理产品</td><td>x</td></tr><tr><td>Atlas 推理系列产品AI Core</td><td>x</td></tr><tr><td>Atlas 推理系列产品Vector Core</td><td>x</td></tr><tr><td>Atlas 训练系列产品</td><td>x</td></tr><tr><td>Atlas 200/300/500 推理产品</td><td>x</td></tr></tbody></table>

#### 功能说明

阻塞该AIV需要等待Arrive组全部完成任务，再开始执行任务。

#### 函数原型

```cpp
__aicore__ inline void Wait(uint32_t waitIndex)
```

#### 参数说明

<table><caption><b>表1 </b>接口参数说明</caption><thead><tr><th>参数</th><th>输入/输出</th><th>说明</th></tr></thead><tbody><tr><td>waitIndex</td><td>输入</td><td>该AIV在Wait组的序号。范围为[0, waitSize - 1]。</td></tr></tbody></table>

#### 返回值

无。

#### 约束说明

该接口支持在循环中使用，但是受限于多核间通信效率要求，循环最大次数不超过1,048,575次。

#### 调用示例

```cpp
if (id >= 0 && id < ARRIVE_NUM) {
  //各种Vector计算逻辑，用户自行实现
  barA.Arrive(id);
} else if(id >= ARRIVE_NUM && id < ARRIVE_NUM + WAIT_NUM){
  barA.Wait(id - ARRIVE_NUM);                            // Wait组的6个AIV中的AIV需要等待Arrive组AIV做完任务
  // 各种Vector计算逻辑，用户自行实现
}
```
