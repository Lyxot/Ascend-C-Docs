# FreeMessage

## 产品支持情况
<table border="1" rules="all"><thead><tr><th>产品</th><th>是否支持</th></tr></thead><tbody><tr><td>Atlas A3 训练系列产品/Atlas A3 推理系列产品</td><td>x</td></tr><tr><td>Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件</td><td>√</td></tr><tr><td>Atlas 200I/500 A2 推理产品</td><td>x</td></tr><tr><td>Atlas 推理系列产品AI Core</td><td>x</td></tr><tr><td>Atlas 推理系列产品Vector Core</td><td>x</td></tr><tr><td>Atlas 训练系列产品</td><td>x</td></tr><tr><td>Atlas 200/300/500 推理产品</td><td>x</td></tr></tbody></table>

## 功能说明
在自定义的回调函数逻辑中，完成消息处理后，调用该接口，刷新消息状态为FREE；或者待消息状态为指定状态waitState时，刷新消息状态为FREE。消息状态的介绍可以参考[表2](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0290.html#ZH-CN_TOPIC_0000002370251213__table77221554135216)中的参数msgState。

## 函数原型
```Cpp
__aicore__ inline uint16_t FreeMessage(__gm__ CubeMsgType *msg);
__aicore__ inline uint16_t FreeMessage(__gm__ CubeMsgType *msg, CubeMsgState waitState);
```

## 参数说明
<table border="1" rules="all"><caption>表1 接口参数说明</caption><thead><tr><th>参数</th><th>输入/输出</th><th>说明</th></tr></thead><tbody><tr><td>msg</td><td>输入</td><td>该CubeResGroupHandle中的消息空间地址。</td></tr><tr><td>waitState</td><td>输入</td><td>需要等待的msgState。</td></tr></tbody></table>

## 返回值
当前消息空间与该消息队列队首空间的地址偏移。

## 约束说明
指定的消息状态waitState不能为QUIT和FREE。

## 调用示例
```Cpp
template <int32_t funcId>
__aicore__ inline static typename IsEqual<funcId, 1>::Type CubeGroupCallBack(
    MatmulApiCfg &mm, __gm__ CubeMsgBody *rcvMsg, CubeResGroupHandle<CubeMsgBody> &handle)
{
    // Cube核上计算逻辑，此处用户自行实现，在一切计算完毕后需要调用FreeMessage，代表rcvMsg已处理完。
    auto tmpId = handle.FreeMessage(rcvMsg);
};
```
