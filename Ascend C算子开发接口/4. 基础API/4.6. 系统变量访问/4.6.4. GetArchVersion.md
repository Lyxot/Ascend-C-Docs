# GetArchVersion

#### 产品支持情况
<table>
<thead><tr><th>产品</th><th>是否支持</th></tr></thead>
<tbody><tr><td>Atlas A3 训练系列产品/Atlas A3 推理系列产品</td><td>√</td></tr><tr><td>Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件</td><td>√</td></tr><tr><td>Atlas 200I/500 A2 推理产品</td><td>x</td></tr><tr><td>Atlas 推理系列产品AI Core</td><td>√</td></tr><tr><td>Atlas 推理系列产品Vector Core</td><td>x</td></tr><tr><td>Atlas 训练系列产品</td><td>x</td></tr><tr><td>Atlas 200/300/500 推理产品</td><td>x</td></tr></tbody>
</table>

#### 功能说明
获取当前AI处理器架构版本号。

#### 函数原型
```cpp
__aicore__ inline void GetArchVersion(uint32_t& coreVersion)
```

#### 参数说明
<table>
<thead><tr><th>参数名</th><th>输入/输出</th><th>描述</th></tr></thead>
<tbody><tr><td>coreVersion</td><td>输出</td><td>AI处理器架构版本<br>数据类型：uint32_t</td></tr></tbody>
</table>

#### 返回值
无

#### 约束说明
在调用GetArchVersion接口前，需先定义coreVersion，调用GetArchVersion接口后coreVersion会变成相对应架构版本号的值。  
由于硬件约束，在查看转换后的AI处理器架构版本号时需要将其打印成十六进制的数或者自行转换成十六进制的数。

#### 调用示例
如下样例通过调用GetArchVersion接口获取AI处理器架构版本号。
```cpp
    uint32_t coreVersion = 0; //定义AI处理器版本
    AscendC::GetArchVersion(coreVersion);
    AscendC::PRINTF("core version is %x", coreVersion); //需用%x将其打印成十六进制的数
```
