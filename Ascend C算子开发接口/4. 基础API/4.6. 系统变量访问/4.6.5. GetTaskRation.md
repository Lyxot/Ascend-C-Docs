# GetTaskRation

#### 产品支持情况
<table border="1"><thead><tr><th align="left">产品</th><th align="center">是否支持</th></tr></thead><tbody><tr><td>Atlas A3 训练系列产品/Atlas A3 推理系列产品</td><td align="center">√</td></tr><tr><td>Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件</td><td align="center">√</td></tr><tr><td>Atlas 200I/500 A2 推理产品</td><td align="center">x</td></tr><tr><td>Atlas 推理系列产品AI Core</td><td align="center">√</td></tr><tr><td>Atlas 推理系列产品Vector Core</td><td align="center">x</td></tr><tr><td>Atlas 训练系列产品</td><td align="center">x</td></tr><tr><td>Atlas 200/300/500 推理产品</td><td align="center">x</td></tr></tbody></table>

#### 功能说明
适用于Cube/Vector分离架构，用来获取Cube/Vector的配比。

#### 函数原型
```cpp
__aicore__ inline int64_t GetTaskRation()
```

#### 参数说明
无

#### 返回值
Cube/Vector的配比：
- 针对分离架构，该接口返回算子执行时block（逻辑概念）内的Cube/Vector核数量。融合算子的1个block内通常有1个Cube+2个Vector，该接口在Cube上会返回block内Cube核数(通常为1)，在Vector上会返回Vector核数(通常为2)。对于纯Vector/纯Cube算子，1个block内只有1个Vector核/Core核，此时该接口固定返回1；
- 针对耦合架构，固定返回1。

#### 约束说明
无

#### 调用示例
```cpp
    uint64_t ratio = AscendC::GetTaskRation();
    // 在分离架构融合算子场景，可以查看Cube/Vector的配比
    AscendC::PRINTF("task ratio is %u", ratio);
```
