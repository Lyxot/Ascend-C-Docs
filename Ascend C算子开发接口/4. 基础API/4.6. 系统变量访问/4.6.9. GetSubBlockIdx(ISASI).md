## 功能说明
获取AI Core上Vector核的ID。

## 函数原型
```cpp
__aicore__ inline int64_t GetSubBlockIdx()
```

## 参数说明
无

## 返回值
返回int64_t类型的Vector核ID。

## 约束说明
无

## 调用示例
```cpp
int64_t subBlockID = AscendC::GetSubBlockIdx();
```
