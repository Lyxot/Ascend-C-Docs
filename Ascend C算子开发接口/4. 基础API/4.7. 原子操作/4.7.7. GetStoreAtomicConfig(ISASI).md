# GetStoreAtomicConfig(ISASI)

#### 产品支持情况

<table border="1" cellpadding="4" cellspacing="0" rules="all"><thead><tr><th>产品</th><th>是否支持</th></tr></thead><tbody><tr><td>Atlas A3 训练系列产品/Atlas A3 推理系列产品</td><td>√</td></tr><tr><td>Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件</td><td>√</td></tr><tr><td>Atlas 200I/500 A2 推理产品</td><td>√</td></tr><tr><td>Atlas 推理系列产品AI Core</td><td>x</td></tr><tr><td>Atlas 推理系列产品Vector Core</td><td>x</td></tr><tr><td>Atlas 训练系列产品</td><td>x</td></tr><tr><td>Atlas 200/300/500 推理产品</td><td>x</td></tr></tbody></table>

#### 功能说明

获取原子操作使能位与原子操作类型的值，详细说明见[表1](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0286.html#ZH-CN_TOPIC_0000002336173152__zh-cn_topic_0235751031_table33761356)。

#### 函数原型

```cpp
__aicore__ inline void GetStoreAtomicConfig(uint16_t &atomicType, uint16_t &atomicOp)
```

#### 参数说明

表1 参数说明

<table border="1" cellpadding="4" cellspacing="0" rules="all"><thead><tr><th>参数名</th><th>输入/输出</th><th>描述</th></tr></thead><tbody><tr><td>atomicType</td><td>输出</td><td>原子操作使能位。0：无原子操作1：使能原子操作，进行原子操作的数据类型为float2：使能原子操作，进行原子操作的数据类型为half3：使能原子操作，进行原子操作的数据类型为int16_t4：使能原子操作，进行原子操作的数据类型为int32_t5：使能原子操作，进行原子操作的数据类型为int8_t6：使能原子操作，进行原子操作的数据类型为bfloat16_t</td></tr><tr><td>atomicOp</td><td>输出</td><td>原子操作类型。0：求和操作</td></tr></tbody></table>

#### 返回值

无

#### 约束说明

此接口需要与[SetStoreAtomicConfig(ISASI)](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0286.html)配合使用，用以获取原子操作使能位与原子操作类型的值。

#### 调用示例

```cpp
AscendC::SetStoreAtomicConfig<AscendC::AtomicDtype::ATOMIC_F16, AscendC::AtomicOp::ATOMIC_SUM>();
uint16_t type = 0;       // 原子操作使能位
uint16_t op = 0;         // 原子操作类型
AscendC::GetStoreAtomicConfig(type, op);
```
