#### 功能说明
获取LocalTensor所在的TPosition逻辑位置，支持TPosition为VECIN、VECOUT、VECCALC、A1、A2、B1、B2、CO1、CO2。

#### 函数原型
```cpp
__aicore__ inline int32_t GetPosition() const
```

#### 参数说明
无

#### 返回值
LocalTensor所在的[TPosition](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0174.html)逻辑位置。
