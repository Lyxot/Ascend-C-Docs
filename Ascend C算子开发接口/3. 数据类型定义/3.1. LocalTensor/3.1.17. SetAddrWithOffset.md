# SetAddrWithOffset

#### 产品支持情况
<table><thead><tr><th>产品</th><th>是否支持</th></tr></thead><tbody><tr><td>Atlas A3 训练系列产品/Atlas A3 推理系列产品</td><td>√</td></tr><tr><td>Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件</td><td>√</td></tr><tr><td>Atlas 200I/500 A2 推理产品</td><td>√</td></tr><tr><td><term>Atlas 推理系列产品</term>AI Core</td><td>√</td></tr><tr><td><term>Atlas 推理系列产品</term>Vector Core</td><td>√</td></tr><tr><td>Atlas 训练系列产品</td><td>√</td></tr><tr><td>Atlas 200/300/500 推理产品</td><td>x</td></tr></tbody></table>

#### 功能说明
设置带有偏移的Tensor地址。用于快速获取定义一个Tensor，同时指定新Tensor相对于旧Tensor首地址的偏移。偏移的长度为旧Tensor的元素个数。

#### 函数原型
```cpp
template <typename T1>
__aicore__ inline void SetAddrWithOffset(LocalTensor<T1> &src, uint32_t offset)
```

#### 参数说明
<table><caption><b>表1 </b>参数说明</caption><thead><tr><th>参数名</th><th>输入/输出</th><th>描述</th></tr></thead><tbody><tr><td>src</td><td>输入</td><td>基础地址的Tensor，将该Tensor的地址作为基础地址，设置偏移后的Tensor地址。</td></tr><tr><td>offset</td><td>输入</td><td>偏移的长度，单位为元素。</td></tr></tbody></table>

#### 返回值
无
