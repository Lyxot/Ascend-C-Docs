#### 功能说明

设置LocalTensor中的某个值。

**该接口仅在LocalTensor的TPosition为VECIN/VECCALC/VECOUT时支持。**

#### 函数原型

```cpp
template <typename T1> __aicore__ inline __inout_pipe__(S)
void SetValue(const uint32_t index, const T1 value) const
```

#### 参数说明

<caption><b>表1 </b>参数说明</caption>

<tbody>
<tr><td>index</td><td>输入</td><td>LocalTensor索引，单位为元素。</td></tr>
<tr><td>value</td><td>输入</td><td>待设置的数值。</td></tr>
</tbody>

#### 返回值

无

#### 约束说明

不要大量使用SetValue对LocalTensor进行赋值，会使性能下降。若需要大批量赋值，请根据实际场景选择[数据填充基础API接口](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0087.html)或[数据填充高阶API接口](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0848.html)，以及在需要生成递增数列的场景，选择[ArithProgression](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0856.html)。
