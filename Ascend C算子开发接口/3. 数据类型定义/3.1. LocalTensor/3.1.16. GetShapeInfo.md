#### 功能说明
获取LocalTensor的Shape信息。注意：Shape信息没有默认值，只有通过[SetShapeInfo](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_00114.html)设置过Shape信息后，才可以调用该接口获取正确的Shape信息。

#### 函数原型
```cpp
__aicore__ inline ShapeInfo GetShapeInfo() const
```

#### 参数说明
无

#### 返回值
LocalTensor的Shape信息，[ShapeInfo](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0008.html)结构体类型。
