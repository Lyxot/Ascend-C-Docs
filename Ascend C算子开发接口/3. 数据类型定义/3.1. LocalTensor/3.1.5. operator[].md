#### 功能说明
获取距原LocalTensor起始地址偏移量为offset的新LocalTensor，注意offset不能超过原有LocalTensor的size大小。

#### 函数原型
```cpp
__aicore__ inline LocalTensor operator[](const uint32_t offset) const
```

</table>

#### 返回值
返回距原LocalTensor起始地址偏移量为offset的新LocalTensor。
