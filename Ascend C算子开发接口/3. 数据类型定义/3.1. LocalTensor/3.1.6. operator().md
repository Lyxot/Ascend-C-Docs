#### 功能说明
获取本LocalTensor的第offset个变量的引用。用于左值，相当于[SetValue](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_00102.html)接口，用于右值，相当于[GetValue](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_00103.html)接口。

#### 函数原型
```cpp
__aicore__ inline __inout_pipe__(S) __ubuf__ PrimType& operator()(const uint32_t offset) const
```

#### 参数说明
<table cellpadding="4" cellspacing="0" summary="" frame="border" border="1" rules="all"><caption><b>表1 </b>参数说明</caption><thead><tr><th>参数名</th><th>输入/输出</th><th>描述</th></tr></thead><tbody><tr><td>offset</td><td>输入</td><td>LocalTensor下标索引。</td></tr></tbody></table>

#### 返回值
返回指定索引位置的元素的PrimType类型引用。  
PrimType定义如下：

```cpp
// PrimT用于从T中提取基础数据类型：T传入基础数据类型，直接返回数据类型；T传入为TensorTrait类型时萃取TensorTrait中的LiteType基础数据类型
using PrimType = PrimT<T>;
```
