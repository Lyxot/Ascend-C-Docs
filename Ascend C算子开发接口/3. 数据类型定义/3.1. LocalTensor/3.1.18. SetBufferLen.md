#### 功能说明
设置Buffer长度。当用户调用operator[]函数创建新LocalTensor时，建议调用该接口设置新LocalTensor长度，便于编译器对内存及同步进行自动优化。

#### 函数原型
```cpp
__aicore__ inline void SetBufferLen(uint32_t dataLen)
```
