#### 功能说明
将当前Tensor重解释为用户指定的新类型，转换后的Tensor与原Tensor地址及内容完全相同，Tensor的大小（字节数）保持不变。

#### 函数原型
```cpp
template <typename CAST_T>
__aicore__ inline LocalTensor<CAST_T> ReinterpretCast() const
```

#### 返回值
重解释转换后的Tensor。
