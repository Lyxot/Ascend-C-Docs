#### 功能说明
将传入的数据打包成Stride数据结构。

#### 函数原型
```cpp
template <typename... Ts>
__aicore__ inline constexpr Stride<Ts...> MakeStride(const Ts&... t)
```

#### 参数说明
<table>
<thead><tr><th align="left">参数名</th><th align="left">输入/输出</th><th align="left">描述</th></tr></thead>
<tbody>
<tr><td align="left">Ts...</td><td align="left">输入</td><td align="left">表示输入类型的形参包，使用方法和约束说明同<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_10107.html">Std::tuple</a>。</td></tr>

#### 返回值说明
Stride结构类型（<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_10107.html">Std::tuple</a>类型的别名），用于定义各维度在内存中的步长，即同维度相邻元素在内存中的间隔，与Shape的维度信息一一对应。定义如下：
```cpp
template <typename... Strides>
using Stride = Std::tuple<Strides...>;
```

同<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_10107.html">Std::tuple</a>。
