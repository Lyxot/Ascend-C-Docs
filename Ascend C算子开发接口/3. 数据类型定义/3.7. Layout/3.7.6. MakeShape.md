#### 功能说明
将传入的数据打包成Shape数据结构。

#### 函数原型
```cpp
template <typename... Ts>
__aicore__ inline constexpr Shape<Ts...> MakeShape(const Ts&... t)
```

#### 参数说明
<table><thead><tr><th>参数名</th><th>输入/输出</th><th>描述</th></tr></thead><tbody><tr><td>Ts...</td><td>输入</td><td>表示输入类型的形参包，使用方法和约束说明同<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_10107.html">Std::tuple</a>。</td></tr></tbody></table>

#### 返回值说明
Shape结构类型（[Std::tuple](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_10107.html)类型的别名），用于定义数据的逻辑形状，例如二维矩阵的行数和列数或多维张量的各维度大小。定义如下:
```cpp
template <typename... Shapes>
using Shape = Std::tuple<Shapes...>;
```

#### 约束说明
同[Std::tuple](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_10107.html)。
