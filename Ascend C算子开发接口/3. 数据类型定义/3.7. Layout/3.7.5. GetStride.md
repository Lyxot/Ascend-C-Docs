# GetStride

### 产品支持情况
<table border="1"><thead><tr><th>产品</th><th>是否支持</th></tr></thead><tbody><tr><td>Atlas A3 训练系列产品/Atlas A3 推理系列产品</td><td>√</td></tr><tr><td>Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件</td><td>√</td></tr><tr><td>Atlas 200I/500 A2 推理产品</td><td>x</td></tr><tr><td>Atlas 推理系列产品AI Core</td><td>x</td></tr><tr><td>Atlas 推理系列产品Vector Core</td><td>x</td></tr><tr><td>Atlas 训练系列产品</td><td>x</td></tr><tr><td>Atlas 200/300/500 推理产品</td><td>x</td></tr></tbody></table>

### 功能说明
返回描述内存访问步长的Stride对象，与Shape的维度信息一一对应。

### 函数原型
```cpp
__aicore__ inline constexpr decltype(auto) GetStride() {}
__aicore__ inline constexpr decltype(auto) GetStride() const {}
```

### 参数说明
无

### 返回值说明
描述内存访问步长的Stride对象，Stride结构类型（[Std::tuple](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_10107.html)类型的别名），定义如下：
```cpp
template <typename... Strides>
using Stride = Std::tuple<Strides...>;
```

### 约束说明
无

### 调用示例
```cpp
// 初始化Layout数据结构，获取对应数值
AscendC::Shape<int,int,int> shape = AscendC::MakeShape(10, 20, 30);
AscendC::Stride<int,int,int> stride = AscendC::MakeStride(1, 100, 200);

auto layoutMake = AscendC::MakeLayout(shape, stride);
AscendC::Layout<AscendC::Shape<int,int,int>, AscendC::Stride<int,int,int>> layoutInit(shape, stride);

int value = AscendC::Std::get<0>(layoutInit.GetStride());  // value = 1
value = AscendC::Std::get<1>(layoutInit.GetStride());      // value = 100
value = AscendC::Std::get<2>(layoutInit.GetStride());      // value = 200
```
