## 功能说明
根据输入的Shape和Stride对象，实例化Layout对象。

## 函数原型
```cpp
__aicore__ inline constexpr Layout(const ShapeType& shape = {}, const StrideType& stride = {}) : Std::tuple<ShapeType, StrideType>(shape, stride)
```

## 参数说明
<table border="1" cellpadding="4" cellspacing="0" frame="border" rules="all"><thead><tr><th align="left">参数名</th><th align="left">输入/输出</th><th align="left">描述</th></tr></thead><tbody><tr><td>shape</td><td>输入</td><td><a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_10107.html">Std::tuple</a>结构类型，用于定义数据的逻辑形状，例如二维矩阵的行数和列数或多维张量的各维度大小。</td></tr><tr><td>stride</td><td>输入</td><td><a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_10107.html">Std::tuple</a>结构类型，用于定义各维度在内存中的步长，即同维度相邻元素在内存中的间隔，间隔的单位为元素，与Shape的维度信息一一对应。</td></tr></tbody></table>

## 返回值说明
无

## 约束说明
构造Layout对象时传入的Shape和Stride结构，需是<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_10107.html">Std::tuple</a>结构类型，且满足Std::tuple结构类型的使用约束。

## 调用示例
```cpp
AscendC::Shape<int, int, int> shape = AscendC::MakeShape(10, 20, 30);
AscendC::Stride<int, int, int> stride = AscendC::MakeStride(1, 100, 200);

AscendC::Layout<AscendC::Shape<int, int, int>, AscendC::Stride<int, int, int>> layoutInit(shape, stride);
```
