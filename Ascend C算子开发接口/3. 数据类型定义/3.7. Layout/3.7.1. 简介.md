<h1 class="topictitle1">简介</h1>
<div><p>Layout&lt;Shape, Stride&gt;数据结构是描述多维张量内存布局的基础模板类，通过编译时的形状（Shape）和步长（Stride）信息，实现逻辑坐标空间到一维内存地址空间的映射，为复杂张量操作和硬件优化提供基础支持。借助模板元编程技术，该类在编译时完成计算和代码生成，从而降低运行时开销。</p>
<p>Layout包含两个核心组成部分：</p>
<ul><li>Shape：定义数据的逻辑形状，例如二维矩阵的行数和列数或多维张量的各维度大小。</li><li>Stride：定义各维度在内存中的步长，即同维度相邻元素在内存中的间隔，间隔的单位为元素，与Shape的维度信息一一对应。</li></ul>
<p>例如，一个二维矩阵的Shape为(4, 2)，Stride为(1, 4)，表示：</p>
<ul><li>矩阵有4行、2列。</li><li>列方向上的步长为1，即每行中相邻元素在内存中的间隔为1个元素；行方向上的步长为4，即相邻行的起始地址间隔为4个元素。</li></ul>
