# operator[]

#### 功能说明
根据输入的offset偏移返回新的GlobalTensor。

#### 函数原型
```cpp
__aicore__ inline GlobalTensor operator[](const uint64_t offset) const
```

#### 参数说明
<table>
  <caption><b>表1</b>参数说明</caption>
  <thead><tr><th>参数名</th><th>输入/输出</th><th>描述</th></tr></thead>
  <tbody><tr><td>offset</td><td>输入</td><td>偏移offset个元素。</td></tr></tbody>
</table>

#### 返回值
指定偏移量的GlobalTensor。
