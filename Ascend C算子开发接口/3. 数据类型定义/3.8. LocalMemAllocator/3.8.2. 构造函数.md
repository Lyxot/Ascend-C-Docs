#### 功能说明
LocalMemAllocator构造函数。

#### 函数原型
```cpp
__aicore__ inline LocalMemAllocator<hard>()
```

#### 参数说明
<table cellpadding="4" cellspacing="0" border="1" rules="all" frame="border"><caption>表1 模板参数说明</caption><thead><tr><th>参数名</th><th>描述</th></tr></thead><tbody><tr><td>hard</td><td>用于表示数据的物理位置，Hardware枚举类型，定义如下，合法位置为：UB、L1、L0A、L0B、L0C、BIAS、FIXBUF。物理位置的具体说明可参考<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0010.html">存储单元</a>。<br>
```cpp
enum class Hardware : uint8_t {
GM,     // Global Memory
UB,     // Unified Buffer
L1,     // L1 Buffer
L0A,    // L0A Buffer
L0B,    // L0B Buffer
L0C,    // L0C Buffer
BIAS,   // BiasTable Buffer
FIXBUF, // Fixpipe Buffer
MAX };
```</td></tr></tbody></table>

#### 返回值说明
无

#### 约束说明
同一个物理位置的LocalMemAllocator对象，在算子生命周期内只能存在1个。
