# 工具概述

#### 工具概述

完成算子分析&原型定义后，可使用msOpGen工具生成自定义算子工程，并进行编译部署，具体流程请参考[图1](#fig1120319585112)。

> 注意：在TBE及AI CPU算子开发场景中，msOpGen工具的使用详情请参考[基于msOpGen工具创建算子工程](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/devaids/optool/atlasopdev_10_0024.html)及[算子编译部署](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/devaids/optool/atlasopdev_10_0087.html)。

具有如下功能：
- 基于算子原型定义输出算子工程。
- 基于性能仿真环境生成的dump数据文件输出算子仿真流水图文件。

#### 命令汇总

执行如下命令，参数说明请参见[表2](#zh-cn_topic_0000001740005677_table20825174505717)。

> 注意：用户按照输入的配置参数生成算子模板后，建议在运行前确认算子工程代码的安全性。

```
msopgen gen -i {*.json} -f {framework type} -c {Compute Resource} -lan cpp -out {Output Path}
```

<caption><b>表2 </b>创建算子工程参数说明</caption>
<thead><tr><th>参数名称</th><th>参数描述</th><th>是否必选</th></tr></thead>
<tbody>
<tr><td>gen</td><td>用于生成算子开发交付件。</td><td>是</td></tr>
<tr><td>-i，--input</td><td>算子原型定义文件（<b>.json</b>）路径，可配置为绝对路径或者相对路径。工具执行用户需要有此路径的可读权限。</td><td>是</td></tr>
<tr><td>-f，--framework</td><td>框架类型。<ul><li>默认为TensorFlow框架，默认值：tf或者tensorflow</li><li>Caffe框架，参数值：caffe<blockquote>说明：自定义Ascend C算子不支持Caffe框架。</blockquote></li><li>PyTorch框架，参数值：pytorch</li><li>MindSpore框架，参数值：ms或mindspore</li><li>ONNX框架，参数值：onnx</li></ul><blockquote>说明：<ul><li>所有参数值大小写不敏感。</li><li>TBE&TIK不支持单算子API调用，默认生成TensorFlow框架。</li><li>Ascend C算子工程支持TensorFlow框架、PyTorch框架和单算子API调用，默认生成TensorFlow框架。</li><li>当用户使用-f aclnn时，生成Ascend C简易算子工程，否则保持原功能特性生成。</li></ul></blockquote></td><td>否</td></tr>
<tr><td>-lan，--language</td><td>算子编码语言。<ul><li>cpp：基于Ascend C编程框架，使用C/C++编程语言进行开发。</li><li>py：基于DSL和TIK算子编程框架，使用Python编程语言进行开发。</li></ul>默认值：py。<blockquote>说明：<b>cpp</b>仅适用于Ascend C算子开发场景。</blockquote></td><td>否</td></tr>
<tr><td>-c，--compute_unit</td><td><ul><li>算子使用的计算资源。配置格式为：ai_core-{soc version}，ai_core与{soc version}之间用中划线“-”连接。请根据实际昇腾AI处理器版本进行选择。</li></ul><blockquote>说明：<p>AI处理器的型号{soc_version}请通过如下方式获取：</p><ul><li>非Atlas A3 训练系列产品/Atlas A3 推理系列产品：在安装昇腾AI处理器的服务器执行<b>npu-smi info</b>命令进行查询，获取<b>Chip Name</b>信息。实际配置值为AscendChip Name，例如<b>Chip Name</b>取值为xxxyy，实际配置值为Ascendxxxyy。当Ascendxxxyy为代码样例的路径时，需要配置ascendxxxyy。</li><li>Atlas A3 训练系列产品/Atlas A3 推理系列产品：在安装昇腾AI处理器的服务器执行<b>npu-smi info -t board -i </b>id<b> -c </b>chip_id命令进行查询，获取<b>Chip Name</b>和<b>NPU Name</b>信息，实际配置值为Chip Name_NPU Name。例如<b>Chip Name</b>取值为Ascendxxx，<b>NPU Name</b>取值为1234，实际配置值为Ascendxxx_1234。当Ascendxxx_1234为代码样例的路径时，需要配置ascendxxx_1234。<p>其中：</p><ul><li>id：设备id，通过<b>npu-smi info -l</b>命令查出的NPU ID即为设备id。</li><li>chip_id：芯片id，通过<b>npu-smi info -m</b>命令查出的Chip ID即为芯片id。</li></ul></li></ul><p>基于同系列的AI处理器型号创建的算子工程，其基础功能（基于该工程进行算子开发、编译和部署）通用。</p></blockquote><ul><li>针对AI CPU算子，请配置为：aicpu。<blockquote>说明：在Atlas A3 训练系列产品/Atlas A3 推理系列产品场景下，请勿在编译时使用以下编译选项，否则会导致机器异常。<ul><li>-march=armv8-a+lse</li><li>-march=armv8.1-a</li><li>-march=armv8.2-a</li><li>-march=armv8.3-a</li></ul></blockquote></li></ul></td><td>是</td></tr>
<tr><td>-out，--output</td><td>生成文件所在路径，可配置为绝对路径或者相对路径，并且工具执行用户具有可读写权限。若不配置，则默认生成在执行命令的当前路径。<blockquote>说明：若用户指定的输出目录中存在与模板工程重名的文件，输出目录中的文件将会被模板工程的文件覆盖。</blockquote></td><td>否</td></tr>
<tr><td>-m，--mode</td><td>生成交付件模式。<ul><li>0：创建新的算子工程，若指定的路径下已存在算子工程，则会报错退出。</li><li>1：在已有的算子工程中追加算子。</li></ul>默认值：0。</td><td>否</td></tr>
<tr><td>-op，--operator</td><td>配置算子的类型，如：Conv2DTik。若不配置此参数，当算子原型定义文件中存在多个算子时，工具会提示用户选择算子。</td><td>否</td></tr>
<tr><td>-h，--help</td><td>输出帮助信息。</td><td>否</td></tr>
</tbody>
