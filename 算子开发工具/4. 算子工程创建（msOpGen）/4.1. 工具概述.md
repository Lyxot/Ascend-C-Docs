  <h1 class="topictitle1">工具概述</h1>
  <div>
   <div class="section">
    <h4 class="sectiontitle">工具概述</h4>
    <p>完成算子分析&amp;原型定义后，可使用msOpGen工具生成自定义算子工程，并进行编译部署，具体流程请参考<a href="#ZH-CN_TOPIC_0000002336189102__fig1120319585112">图1</a>。</p>
    <div class="note">
     <img src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/devaids/optool/public_sys-resources/note_3.0-zh-cn.png"><span class="notetitle"> </span>
     <div class="notebody">
      <p>在TBE及AI CPU算子开发场景中，msOpGen工具的使用详情请参考<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/devaids/optool/atlasopdev_10_0024.html">基于msOpGen工具创建算子工程</a>及<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/devaids/optool/atlasopdev_10_0087.html">算子编译部署</a>。</p>
     </div>
    </div>
    <p>具有如下功能：</p>
    <ul>
     <li>基于算子原型定义输出算子工程。</li>
     <li>基于性能仿真环境生成的dump数据文件输出算子仿真流水图文件。</li>
    </ul>
   </div>
   <div class="fignone">
    <a name="ZH-CN_TOPIC_0000002336189102__fig1120319585112"></a><a name="fig1120319585112"></a><span class="figcap"><b>图1 </b>msOpGen工具使用流程介绍</span>

    <h4 class="sectiontitle">命令汇总</h4>
    <div class="p">
     执行如下命令，参数说明请参见<a href="#ZH-CN_TOPIC_0000002336189102__zh-cn_topic_0000001740005677_table20825174505717">表2</a>。
     <div class="note">
      <img src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/devaids/optool/public_sys-resources/note_3.0-zh-cn.png"><span class="notetitle"> </span>
      <div class="notebody">
       <p>用户按照输入的配置参数生成算子模板后，建议在运行前确认算子工程代码的安全性。</p>
      </div>
     </div>
    </div>
    <pre class="code_wrap">msopgen gen -i <em>{*.json}</em> -f <em>{framework type} </em>-c <em>{Compute Resource}</em> -lan cpp -out <em>{Output Path}</em></pre>

        <p>框架类型。</p>
        <ul>
         <li>默认为TensorFlow框架，默认值：tf或者tensorflow</li>

          <div class="note">

         <li>PyTorch框架，参数值：pytorch</li>
         <li>MindSpore框架，参数值：ms或mindspore</li>
         <li>ONNX框架，参数值：onnx</li>
        </ul>
        <div class="note">
         <span class="notetitle"> 说明： </span>
         <div class="notebody">
          <ul>
           <li>所有参数值大小写不敏感。</li>
           <li>TBE&amp;TIK不支持单算子API调用，默认生成TensorFlow框架。</li>
           <li>Ascend C算子工程支持TensorFlow框架、PyTorch框架和单算子API调用，默认生成TensorFlow框架。</li>
           <li>当用户使用-f aclnn时，生成Ascend C简易算子工程，否则保持原功能特性生成。</li>
          </ul>
         </div>
        </div></td>

         <li>py：基于DSL和TIK算子编程框架，使用Python编程语言进行开发。</li>
        </ul>
        <p>默认值：py。</p>
        <div class="note">
         <span class="notetitle"> 说明： </span>
         <div class="notebody">
          <p><strong>cpp</strong>仅适用于Ascend C算子开发场景。</p>
         </div>

        <p>-c，--compute_unit</p></td>
       <td class="cellrowborder" valign="top" width="66.95%" headers="mcps1.3.5.2.4.1.2 ">
        <ul>
         <li>算子使用的计算资源。
          <p><a name="ZH-CN_TOPIC_0000002336189102__zh-cn_topic_0000001740005677_li214854416414"></a><a name="zh-cn_topic_0000001740005677_li214854416414"></a>配置格式为：ai_core-<em>{soc version}</em>，ai_core与<em>{soc version}</em>之间用中划线“-”连接。</p>
          <p>请根据实际<span>昇腾AI处理器</span>版本进行选择。</p></li>
        </ul>
        <div class="note">
         <span class="notetitle"> 说明： </span>
         <div class="notebody">
          <p>AI处理器的型号<span><em>&lt;soc_version&gt;</em></span>请通过如下方式获取：</p>
          <ul>
           <li>非<span><term>
              Atlas A3 训练系列产品/Atlas A3 推理系列产品
             </term></span>：在安装<span>昇腾AI处理器</span>的服务器执行<strong>npu-smi info</strong>命令进行查询，获取<strong>Chip Name</strong>信息。实际配置值为AscendChip Name，例如<strong>Chip Name</strong>取值为<em>xxxyy</em>，实际配置值为Ascend<em>xxxyy</em>。当Ascendxxxyy为代码样例的路径时，需要配置ascend<em>xxxyy</em>。</li>
           <li><span><term>
              Atlas A3 训练系列产品/Atlas A3 推理系列产品
             </term></span>：在安装<span>昇腾AI处理器</span>的服务器执行<strong>npu-smi info -t board -i </strong><em>id</em><strong> -c </strong><em>chip_id</em>命令进行查询，获取<strong>Chip Name</strong>和<strong>NPU Name</strong>信息，实际配置值为Chip Name_NPU Name。例如<strong>Chip Name</strong>取值为Ascend<em>xxx</em>，<strong>NPU Name</strong>取值为1234，实际配置值为Ascend<em>xxx</em><em>_</em>1234。当Ascend<em>xxx</em><em>_</em>1234为代码样例的路径时，需要配置ascend<em>xxx</em><em>_</em>1234。
            <p>其中：</p>
            <ul>
             <li>id：设备id，通过<strong>npu-smi info -l</strong>命令查出的NPU ID即为设备id。</li>
             <li>chip_id：芯片id，通过<strong>npu-smi info -m</strong>命令查出的Chip ID即为芯片id。</li>
            </ul></li>
          </ul>
          <p>基于同系列的AI处理器型号创建的算子工程，其基础功能（基于该工程进行算子开发、编译和部署）通用。</p>
         </div>
        </div>
        <ul>
         <li>针对AI CPU算子，请配置为：aicpu。
          <div class="note">
           <span class="notetitle"> 说明： </span>
           <div class="notebody">
            <p>在<span><term>
               Atlas A3 训练系列产品/Atlas A3 推理系列产品
              </term></span>场景下，请勿在编译时使用以下编译选项，否则会导致机器异常。</p>
            <ul>
             <li>-march=armv8-a+lse</li>
             <li>-march=armv8.1-a</li>
             <li>-march=armv8.2-a</li>
             <li>-march=armv8.3-a</li>
            </ul>
           </div>
          </div></li>
        </ul></td>
       <td class="cellrowborder" valign="top" width="13.83%" headers="mcps1.3.5.2.4.1.3 ">
        <p>是</p></td>
      </tr>

       <td class="cellrowborder" valign="top" width="19.220000000000002%" headers="mcps1.3.5.2.4.1.1 ">
        <p>-out，--output</p></td>
       <td class="cellrowborder" valign="top" width="66.95%" headers="mcps1.3.5.2.4.1.2 ">
        <p>生成文件所在路径，可配置为绝对路径或者相对路径，并且工具执行用户具有可读写权限。</p>
        <p>若不配置，则默认生成在执行命令的当前路径。</p>
        <div class="note">
         <span class="notetitle"> 说明： </span>
         <div class="notebody">
          <p>若用户指定的输出目录中存在与模板工程重名的文件，输出目录中的文件将会被模板工程的文件覆盖。</p>
         </div>
        </div></td>
       <td class="cellrowborder" valign="top" width="13.83%" headers="mcps1.3.5.2.4.1.3 ">
        <p>否</p></td>
      </tr>
      <tr>
       <td class="cellrowborder" valign="top" width="19.220000000000002%" headers="mcps1.3.5.2.4.1.1 ">
        <p>-m，--mode</p></td>
       <td class="cellrowborder" valign="top" width="66.95%" headers="mcps1.3.5.2.4.1.2 ">
        <p>生成交付件模式。</p>
        <ul>
         <li>0：创建新的算子工程，若指定的路径下已存在算子工程，则会报错退出。</li>
         <li>1：在已有的算子工程中追加算子。</li>
        </ul>
        <p>默认值：0。</p></td>
       <td class="cellrowborder" valign="top" width="13.83%" headers="mcps1.3.5.2.4.1.3 ">
        <p>否</p></td>
      </tr>

       <td class="cellrowborder" valign="top" width="19.220000000000002%" headers="mcps1.3.5.2.4.1.1 ">

       <td class="cellrowborder" valign="top" width="66.95%" headers="mcps1.3.5.2.4.1.2 ">
        <p>配置算子的类型，如：Conv2DTik。</p>
        <p>若不配置此参数，当算子原型定义文件中存在多个算子时，工具会提示用户选择算子。</p></td>
       <td class="cellrowborder" valign="top" width="13.83%" headers="mcps1.3.5.2.4.1.3 ">
        <p>否</p></td>
      </tr>
      <tr>
