# mstxMemRegionsUnregister

#### 函数原型
**void mstxMemRegionsUnregister(mstxDomainHandle_t domain, mstxMemRegionsUnregisterBatch_t const *desc)**

#### 功能说明
注销内存池二次分配。

<tr><td>domain</td><td>输入</td><td>为globalDomain或<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/devaids/optool/atlasopdev_16_0144.html">mstxDomainCreateA</a>返回的句柄。<br/>数据类型：const char *。</td></tr>
<tr><td>desc</td><td>输入</td><td>输入的描述信息必须是某一次<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/devaids/optool/atlasopdev_16_0145.html">mstxMemHeapRegister</a>的输入描述信息，否则工具将打屏提示错误。<pre><code>typedef enum mstxMemRegionRefType {

typedef struct mstxMemRegionsUnregisterBatch_t {

#### 返回值
无

#### 调用示例
```c
mstxMemRegionsUnregisterBatch_t refsDesc = {}
refsDesc.refCount = 1;
refsDesc.refArray = regionRef;
mstxMemRegionsUnregister(globalDomain, &refsDesc);                   // 注销二次分配
```
