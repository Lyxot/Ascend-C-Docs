<h1 class="topictitle1">msDebug工具在docker中执行"run"命令运行程序后，提示“'A' packet returned an error: 8”</h1>
<div><div class="section"><h4 class="sectiontitle">现象描述</h4><p>在docker中，msDebug工具在执行"run"命令运行程序后，出现以下报错。</p>
<pre class="code_wrap">(msdebug) run
'A' packet returned an error: 8
(msdebug)
...</pre>
</div>
<div class="section"><h4 class="sectiontitle">原因分析</h4><p>出现该错误，可能与“地址空间布局随机化”有关。</p>
</div>
<div class="section"><h4 class="sectiontitle">解决措施</h4><p>需输入并执行下列命令来规避此问题。</p>
<pre class="code_wrap">...
(msdebug) settings set target.disable-aslr false
...</pre>
</div>
