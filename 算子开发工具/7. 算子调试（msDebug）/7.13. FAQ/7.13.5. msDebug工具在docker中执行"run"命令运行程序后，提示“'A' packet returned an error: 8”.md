<h1 class="topictitle1">msDebug工具在docker中执行"run"命令运行程序后，提示“'A' packet returned an error: 8”</h1>
<div id="body0000002065749256"><div class="section" id="ZH-CN_TOPIC_0000002370266993__section167618581163"><h4 class="sectiontitle">现象描述</h4><p id="ZH-CN_TOPIC_0000002370266993__p299212125113">在docker中，msDebug工具在执行"run"命令运行程序后，出现以下报错。</p>
<pre class="code_wrap" id="ZH-CN_TOPIC_0000002370266993__screen125171343185017">(msdebug) run
'A' packet returned an error: 8
(msdebug)
...</pre>
</div>
<div class="section" id="ZH-CN_TOPIC_0000002370266993__section35471290"><h4 class="sectiontitle">原因分析</h4><p id="ZH-CN_TOPIC_0000002370266993__zh-cn_topic_0000001194191386_p250116411213">出现该错误，可能与“地址空间布局随机化”有关。</p>
</div>
<div class="section" id="ZH-CN_TOPIC_0000002370266993__section063999476"><h4 class="sectiontitle">解决措施</h4><p id="ZH-CN_TOPIC_0000002370266993__p13369151510520">需输入并执行下列命令来规避此问题。</p>
<pre class="code_wrap" id="ZH-CN_TOPIC_0000002370266993__screen1487015591168">...
(msdebug) settings set target.disable-aslr false
...</pre>
