<h1 class="topictitle1">msDebug工具打印Tensor变量功能不可用，提示“unavailable”或“memory read failed”</h1>
<div id="body8662426"><div class="section" id="ZH-CN_TOPIC_0000002370266945__zh-cn_topic_0000001850621940_section3972144895218"><h4 class="sectiontitle">现象描述</h4><p id="ZH-CN_TOPIC_0000002370266945__zh-cn_topic_0000001850621940_p19264162713539">提示“unavailable”或“Failed to dereference pointer from xxx for DW_OP_deref: memory read failed for xxx”。</p>
</div>
<div class="section" id="ZH-CN_TOPIC_0000002370266945__section35471290"><h4 class="sectiontitle">原因分析</h4><p id="ZH-CN_TOPIC_0000002370266945__zh-cn_topic_0000001194191386_p250116411213">单步调试功能不支持Tensor按值传递的写法。</p>
</div>
<div class="section" id="ZH-CN_TOPIC_0000002370266945__zh-cn_topic_0000001850621940_section954135714522"><h4 class="sectiontitle">解决措施</h4><p id="ZH-CN_TOPIC_0000002370266945__zh-cn_topic_0000001850621940_p201039501104">当打印对象a为Tensor类型且以值传递作为函数入参时会出现该问题。</p>
<pre class="screen" id="ZH-CN_TOPIC_0000002370266945__zh-cn_topic_0000001850621940_screen612482561918">void Foo(const LocalTensor&lt;float&gt; <strong id="ZH-CN_TOPIC_0000002370266945__zh-cn_topic_0000001850621940_b208531914113313">a</strong>); // 该写法变量a打印失败</pre>
<p id="ZH-CN_TOPIC_0000002370266945__zh-cn_topic_0000001850621940_p6331913102117">若需打印该变量，可修改代码使对象a以引用传递作为函数入参，修复该问题。</p>
<pre class="screen" id="ZH-CN_TOPIC_0000002370266945__zh-cn_topic_0000001850621940_screen1653924913365">void Foo(const LocalTensor&lt;float&gt; <strong id="ZH-CN_TOPIC_0000002370266945__zh-cn_topic_0000001850621940_b1966302615331">&amp;</strong><strong id="ZH-CN_TOPIC_0000002370266945__zh-cn_topic_0000001850621940_b10666142643317">a</strong>); // 该写法变量a可正常打印</pre>
</div>
