<h1 class="topictitle1">msDebug工具打印Tensor变量功能不可用，提示“unavailable”或“memory read failed”</h1>
<div><div class="section"><h4 class="sectiontitle">现象描述</h4><p>提示“unavailable”或“Failed to dereference pointer from xxx for DW_OP_deref: memory read failed for xxx”。</p>
</div>
<div class="section"><h4 class="sectiontitle">原因分析</h4><p>单步调试功能不支持Tensor按值传递的写法。</p>
</div>
<div class="section"><h4 class="sectiontitle">解决措施</h4><p>当打印对象a为Tensor类型且以值传递作为函数入参时会出现该问题。</p>
<pre class="screen">void Foo(const LocalTensor&lt;float&gt; <strong>a</strong>); // 该写法变量a打印失败</pre>
<p>若需打印该变量，可修改代码使对象a以引用传递作为函数入参，修复该问题。</p>
<pre class="screen">void Foo(const LocalTensor&lt;float&gt; <strong>&amp;</strong><strong>a</strong>); // 该写法变量a可正常打印</pre>
</div>
