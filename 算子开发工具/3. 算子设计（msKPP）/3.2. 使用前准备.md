# 使用前准备

- 请参考[环境准备](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/devaids/optool/atlasopdev_16_0003.html)，完成相关环境变量的配置。然后，可直接使用msKPP工具的[性能建模](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/devaids/optool/atlasopdev_16_0151.html)功能。
  > 注意：
  > - 在任意目录下实现算子的DSL语言方案（Domain-Specific Language，领域特定语言），实现中包括如下注意事项：
  >   - 实现模拟DSL算子前，需要导入Tensor、Chip以及算子实现所必要的指令（统一以小写命名）。
  >   - 以with语句开启算子实现代码的入口，`enable_trace`和`enable_metrics`两个接口可使能trace打点图和指令统计功能，具体请参见[极限性能分析](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/devaids/optool/atlasopdev_16_0011.html)章节的main.py。
  >   - 详细指令接口说明请参考[对外接口使用说明](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/devaids/optool/atlasopdev_16_0015.html)。
  > - 如果需要指令占比饼图（instruction_cycle_consumption.html），则需要安装生成饼图所依赖的Python三方库plotly。
  >
  > ```
  > pip3 install plotly
  > ```

- 若要使用[自动调优](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/devaids/optool/atlasopdev_16_0153.html)功能，需要下载[Link](https://gitee.com/ascend/ascendc-operator-templates)中的Ascend C模板库。
