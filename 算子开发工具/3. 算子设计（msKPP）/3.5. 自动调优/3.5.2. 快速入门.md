# 快速入门

本章节以单算子00_basic_matmul为例，帮助用户快速上手msKPP工具的Kernel级自动调优功能。

## 操作步骤

1. 执行以下命令，下载[Link](https://gitee.com/ascend/catlass/tree/catlass-v1-stable/)中的Ascend C模板库。
   
   ```
   git clone https://gitee.com/ascend/catlass.git -b catlass-v1-stable
   ```

2. 进入模板库中的00_basic_matmul样例代码目录。
   
   ```
   cd catlass/examples/00_basic_matmul
   ```

3. 修改basic_matmul.cpp文件，在L1TileShape、L0TileShape变量声明的行末尾添加注释 （// tunable）。
   
   ```
   // basic_matmul.cpp
   ...
   51 using L1TileShape = GemmShape<128, 256, 256>; // tunable
   52 using L0TileShape = GemmShape<128, 256, 64>; // tunable
   ...
   ```

4. 将附录中Python脚本文件[basic_matmul_autotune.py](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/devaids/optool/atlasopdev_16_0157.html)与编译脚本文件[jit_build.sh](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/devaids/optool/atlasopdev_16_0164.html)保存至00_basic_matmul目录中。
