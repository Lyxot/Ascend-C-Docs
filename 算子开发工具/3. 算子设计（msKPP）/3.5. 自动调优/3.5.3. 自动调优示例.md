</p></li><li>参考附录，在examples/00_basic_matmul目录中创建Python脚本文件<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/devaids/optool/atlasopdev_16_0157.html">basic_matmul_autotune.py</a>与编译脚本文件<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/devaids/optool/atlasopdev_16_0164.html">jit_build.sh</a>。<p><p>按照如下要求，定义算子Kernel函数的Python接口：在Python脚本中定义basic_matmul函数，其入参需与C++代码中的Kernel函数保持一致。</p>
<pre class="screen"># basic_matmul_autotune.py
import mskpp

def get_kernel():
    kernel_file = "./basic_matmul.cpp"
    kernel_name = "BasicMatmul"
    build_script = "./jit_build.sh" # kernel compile script
    config = mskpp.KernelInvokeConfig(kernel_file, kernel_name)
    gen_file = mskpp.Launcher(config).code_gen()
    kernel = mskpp.compile(build_script=build_script, launch_src_file=gen_file)
    return kernel

def basic_matmul(problem_shape, a, layout_a, b, layout_b, c, layout_c):
    # This function's input arguments must exactly match the kernel function.
    kernel = get_kernel()
    blockdim = 20 # use the correct aic number that matches your hardware
    return kernel[blockdim](problem_shape, a, layout_a, b, layout_b, c, layout_c, device_id=1) # invoke the kernel</pre>
</p></li><li>参考如下代码实现，构造Kernel入参，实现basic_matmul函数的正常运行。<p><ul><li>若算子Kernel函数入参是GM_ADDR，则构造入参需使用numpy.array类型。</li><li>若算子Kernel函数入参是C++结构体对象，则需依靠ctypes.Structure在Python中构建一个相同的结构体。</li></ul>
<pre class="screen"># basic_matmul_autotune.py
import numpy as np
from ctypes import Structure, c_uint32, c_int32, c_int64
class GemmCoord(Structure):
    _fields_ = [("m", c_uint32),
                ("n", c_uint32),
                ("k", c_uint32)]
    def __init__(self, m, n, k):
        super().__init__()
        self.m = (c_uint32)(m)
        self.n = (c_uint32)(n)
        self.k = (c_uint32)(k)
    @staticmethod
    def get_namespace():
        return "Catlass::"
class RowMajor(Structure):
    _fields_ = [("shape", c_int32 * 2),
                ("stride", c_int64 * 2)]
    def __init__(self, rows : int = 0, cols : int = 0, ldm : int = None):
        super().__init__()
        self.shape = (c_int32 * 2)(rows, cols)
        if ldm is None:
            self.stride = (c_int64 * 2)(cols, 1)
        else:
            self.stride = (c_int64 * 2)((c_int64)(ldm), 1)
    @staticmethod
    def get_namespace():
        return "Catlass::layout::"
if __name__ == "__main__":
    m = 256
    n = 512
    k = 1024
    problem_shape = GemmCoord(m, n, k)
    layout_a = RowMajor(m, k)
    layout_b = RowMajor(k, n)
    layout_c = RowMajor(m, n)
    a = np.random.randint(1, 2, [m, k]).astype(np.half)
    b = np.random.randint(1, 2, [k, n]).astype(np.half)
    c = np.zeros([m, n]).astype(np.half)
    basic_matmul(problem_shape, a, layout_a, b, layout_b, c, layout_c)
    # check if the output tensor c is consistent with the golden data
    golden = np.matmul(a, b)
    is_equal = np.array_equal(c, golden)
    result = "success" if is_equal else "failed"
    print("compare {}.".format(result))</pre>

</p></li><li>通过<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/devaids/optool/atlasopdev_16_0163.html">autotune</a>接口的configs入参定义参数搜索空间，每一类参数组合会替换算子Kernel代码中被标记的代码行，然后进行编译、运行并完成Kernel性能采集。搜索空间定义示例可参考如下所示。<p><div class="note"><img src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/devaids/optool/public_sys-resources/note_3.0-zh-cn.png"><span class="notetitle"> </span><div class="notebody"><ul><li>参数替换需合理，不能造成编译或运行错误。</li><li>参数替换原则如下（以configs中的第一行为例）：<ol type="a"><li>先替换// tunable: L0Shape方式标记的参数，将标记代码行（MatmulShape&lt;128, 256, 64&gt;）整行替换为configs中的value字符串（MatmulShape&lt;128, 256, 64&gt;）。</li><li>再替换// tunable方式标记的代码行，将"="号后的MatmulShape&lt;128, 256, 256&gt;替换为configs中value字符串MatmulShape&lt;64, 64, 64&gt;。<ul><li>不同作用域中，可能会有两个同名的变量被声明。若两个变量均符合匹配规则时，仅第一个变量会被修改。</li><li>若其中一个config未匹配成功，该config对应的任务会停止并报错。但其他匹配成功的config将会成功进行参数替换。</li></ul>
