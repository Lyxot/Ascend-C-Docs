# code_gen

## 功能说明
根据输入的模板库Kernel信息，生成Kernel下发代码。

## 函数原型
```
gen_file = mskpp.Launcher(config).code_gen()
```

## 参数说明
<table><thead><tr><th>参数名</th><th>输入/输出</th><th>说明</th></tr></thead><tbody><tr><td>gen_file</td><td>输入</td><td>指定生成Kernel侧下发代码的文件路径。数据类型：str。可选参数，默认值为_gen_launch.cpp。</td></tr></tbody></table>

## 返回值说明
生成代码的文件路径。

## 调用示例
```
config = mskpp.KernelInvokeConfig(kernel_file, kernel_name)
gen_file = mskpp.Launcher(config).code_gen()
```
