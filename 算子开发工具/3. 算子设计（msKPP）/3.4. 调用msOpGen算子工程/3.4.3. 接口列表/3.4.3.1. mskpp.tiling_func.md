<h1 class="topictitle1">mskpp.tiling_func</h1>
<div><div class="section"><h4 class="sectiontitle">功能说明</h4><p>调用用户的tiling函数。目前仅该接口的部分参数支持输入list[tensor]，调用<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/devaids/optool/atlasopdev_16_0186.html">mskpp.get_kernel_from_binary</a>返回的CompiledKernel不支持传入list[tensor]。</p>
<div class="note"><img src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/devaids/optool/public_sys-resources/note_3.0-zh-cn.png"><span class="notetitle"> </span><div class="notebody"><p>调用tiling_func函数时，会在当前目录生成_mskpp_gen_tiling.cpp和_mskpp_gen_tiling.so文件，该文件仅用于开发问题定位，用户无需关注。</p>
</div></div>
</div>
<div class="section"><h4 class="sectiontitle">函数原型</h4><pre class="screen">def tiling_func(op_type: str, inputs: list, outputs: list, lib_path: str,
                inputs_info: list = None, outputs_info: list = None, attr=None, soc_version: str = None) -&gt; TilingOutput</pre>
</div>
