  <h1 class="topictitle1">算子特性建模</h1>
  <div>
   <p>msKPP支持tensor拆分使用、debug模式和pipe信息的理论值与msprof实测值比对的功能，也支持对算子特性进行建模（搬运通路建模、随路转换建模和cache命中率建模），用户需根据实际需求进行选择，完成后可实现<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/devaids/optool/atlasopdev_16_0010.html">算子计算搬运规格分析</a>、<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/devaids/optool/atlasopdev_16_0011.html">极限性能分析</a>以及<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/devaids/optool/atlasopdev_16_0012.html">算子tiling初步设计</a>。</p>
   <div class="note">
    <img src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/devaids/optool/public_sys-resources/note_3.0-zh-cn.png"><span class="notetitle"> </span>
    <div class="notebody">
     <p>文档中的Ascend<em>xxxyy</em>需替换为实际使用的处理器类型。</p>
    </div>
   </div>
   <ul>
    <li>支持搬运通路建模（<span><term>
       Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件
      </term></span>）
     <div class="p">
      在<span><term>
        Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件
       </term></span>中，新增了L1到fixpipe buffer(FP)的通路以及L1到Bias table(BT)的通路。前者用于L0C_TO_OUT随路转换时存储量化转换的scale参数，后者用于存储一维的bias数据。在本工具中对该搬运通路建模只需按照GM-&gt;L1-&gt;FP/BT的顺序即可。

<span class="normal">8</span>
<span class="normal">9</span></pre>

           <td class="code">

    <li>支持随路转换建模
     <p><a name="ZH-CN_TOPIC_0000002336189066__zh-cn_topic_0000001692046854_li1944344115404"></a><a name="zh-cn_topic_0000001692046854_li1944344115404"></a>在<span>昇腾AI处理器</span>的CUBE单元中，进行计算的数据格式需要是特殊的私有NZ格式。而通常在GM上的数据都是ND格式，因此在进行Cube运算时，需要将数据格式进行转换。在<span><term>
        Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件
       </term></span>中，GM到CUBE相关的存储单元的搬运通路已具备ND转NZ的随路转换能力。</p>
     <p>在msKPP工具中，若GM-L1且用户定义GM的tensor是ND，L1的tensor是NZ，或L0C-GM且用户定义L0C上的tensor是NZ，GM的tensor是ND，则开启随路转换，调取相关实测数据。</p>

<span class="normal">5</span></pre>

          <td class="code">
           <div>
