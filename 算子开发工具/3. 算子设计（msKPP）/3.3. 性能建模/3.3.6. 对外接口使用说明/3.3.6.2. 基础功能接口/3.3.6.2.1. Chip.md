# Chip

#### 功能说明
处理器抽象，在with语句中实例化并用来明确针对某一昇腾AI处理器类型进行建模。

#### 接口原型
```python
class Chip(name, debug_mode=False)
```

#### 参数说明
<table>
<thead><tr><th>参数名</th><th>输入类型</th><th>说明</th></tr></thead>
<tbody><tr><td>name</td><td>string</td><td>处理器名称。<p>目前大部分数据基于Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件采集，使用npu-smi info可以查看当前设备昇腾AI处理器类型。</p></td></tr><tr><td>debug_mode</td><td>bool</td><td>是否启用调试模式，默认为False。<ul><li>True：启用</li><li>False：不启用</li></ul><p><strong>说明：</strong> 开启debug模式后可查看未正确运行的指令，但不会生成任何输出件。</p></td></tr></tbody>
</table>

#### 成员
<table>
<thead><tr><th>成员名称</th><th>描述</th></tr></thead>
<tbody><tr><td>chip.enable_trace()</td><td>使能算子模拟流水图的功能，生成流水图文件trace.json。</td></tr><tr><td>chip.enable_metrics()</td><td>使能单指令及分PIPE的流水信息，生成指令统计（Instruction_statistic.csv）、搬运流水统计（Pipe_statistic.csv）文件和指令占比饼图（instruction_cycle_consumption.html）。</td></tr><tr><td>chip.set_cache_hit_ratio(config)</td><td>用于使能手动调整L2Cache命中率，其中config = {"cache_hit_ratio": 0.6}，具体介绍请参见<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/devaids/optool/atlasopdev_16_0009.html#ZH-CN_TOPIC_0000002336189066__zh-cn_topic_0000001692046854_li173978547417">支持cache命中率建模</a>。</td></tr><tr><td>chip.set_prof_summary_path("xxx/PipeUtilization.csv")</td><td>其中PipeUtilization.csv为msprof的结果示例，用于使能PIPE信息的理论值与msprof实测值比对。具体介绍请参见<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/devaids/optool/atlasopdev_16_0009.html#ZH-CN_TOPIC_0000002336189066__zh-cn_topic_0000001692046854_li47891488449">支持PIPE信息的理论值与msprof实测值比对</a>。</td></tr><tr><td>chip.disable_instr_log()</td><td>使能后，抑制指令任务添加和调度结束后的日志打印。</td></tr></tbody>
</table>

#### 约束说明
需在with语句下将该类初始化。

#### 使用示例
```python
from mskpp import Chip
# 如何查看当前设备昇腾处理器类型请参见以下说明
with Chip("Ascendxxxyy") as chip:    # Ascendxxxyy需替换为实际使用的处理器类型
    chip.enable_trace()   # 调用该函数即可使能算子模拟流水图的功能，生成流水图文件
    chip.enable_metrics()  # 调用该函数即可使能单指令及分PIPE的流水信息，生成搬运流水统计、指令信息统计和指令占比饼图
```

> 非Atlas A3 训练系列产品/Atlas A3 推理系列产品：在安装昇腾AI处理器的服务器执行npu-smi info命令进行查询，获取Chip Name信息。实际配置值为AscendChip Name，例如Chip Name取值为xxxyy，实际配置值为Ascendxxxyy。当Ascendxxxyy为代码样例的路径时，需要配置为ascendxxxyy。
