# Tensor

#### 功能说明
片上Tensor的抽象，可指定Tensor的内存位置、数据类型、大小及排布格式作为指令的数据依赖标识。

#### 接口原型
```python
class Tensor(mem_type, dtype=None, size=None, format=None, is_inited=False)
```

#### 约束说明
需通过创建一个shape为[1]且is_inited=True的Tensor进行标量创建。
