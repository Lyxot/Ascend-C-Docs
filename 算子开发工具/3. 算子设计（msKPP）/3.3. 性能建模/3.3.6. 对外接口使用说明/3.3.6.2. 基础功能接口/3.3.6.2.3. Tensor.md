  <h1 class="topictitle1">Tensor</h1>
  <div>
   <div class="section">
    <h4 class="sectiontitle">功能说明</h4>
    <p>片上Tensor的抽象，可指定Tensor的内存位置、数据类型、大小及排布格式作为指令的数据依赖标识。</p>
