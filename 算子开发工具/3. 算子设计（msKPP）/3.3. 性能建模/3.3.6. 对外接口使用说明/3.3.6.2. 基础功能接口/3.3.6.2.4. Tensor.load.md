<h1 class="topictitle1">Tensor.load</h1>
<div><div class="section"><h4 class="sectiontitle">功能说明</h4><p>所有的数据搬运指令在msKPP工具下都抽象为load方法，用户只需关心<span>昇腾AI处理器</span>中合理的搬运通路，无需考虑搬运指令中复杂的stride概念。</p>
</div>
