<h1 class="topictitle1">wait_flag</h1>
<div><div class="section"><h4 class="sectiontitle">功能说明</h4><p>用于确保核内各PIPE间不同指令的同步，pipe_dst等待pipe_src完成调度之后解除阻塞状态。</p>
</div>

<div class="section"><h4 class="sectiontitle">约束说明</h4><ul><li>在同一核内set_flag与wait_flag个数需匹配。</li><li>同核内不应出现重复的set_flag指令。</li><li>同一核内，当set_flag和wait_flag内的pipe_src和pipe_dst相同时，event_id也应保持唯一。</li></ul>
</div>
