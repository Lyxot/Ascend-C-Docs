# set_flag

### 功能说明
用于确保核内各PIPE间不同指令的同步，pipe_src先完成调度后，pipe_dst将解除阻塞状态。设置set_flag和[wait_flag](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/devaids/optool/atlasopdevapi_16_00074.html)之后，[指令流水图](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/devaids/optool/atlasopdev_16_0011.html#ZH-CN_TOPIC_0000002336348870__zh-cn_topic_0000001740005673_section695114214019)将会更贴合用户的调用预期。

### 接口原型
```python
set_flag(pipe_src, pipe_dst, event_id)
```

### 参数说明
<table border="1">
<thead><tr><th>参数名</th><th>输入/输出</th><th>说明</th></tr></thead>
<tbody>
<tr><td>pipe_src</td><td>输入</td><td>源PIPE，在pipe_src调度后设置event_id。取值范围为"PIPE-MTE1"、"PIPE-MTE2"、"PIPE-MTE3"、"PIPE-FIX"、"PIPE-M"、"PIPE-V"、"PIPE-S"。数据类型：string。必选参数。</td></tr>
<tr><td>pipe_dst</td><td>输入</td><td>目的PIPE，在pipe_src调度之后，pipe_dst将会解除阻塞状态。取值范围为"PIPE-MTE1"、"PIPE-MTE2"、"PIPE-MTE3"、"PIPE-FIX"、"PIPE-M"、"PIPE-V"、"PIPE-S"。数据类型：string。必选参数。</td></tr>
<tr><td>event_id</td><td>输入</td><td>同步指令之间依赖的唯一值。取值范围[0, 65535]。数据类型：int。必选参数。</td></tr>
</tbody>
</table>

### 约束说明
- 在同一核内set_flag与wait_flag个数需匹配。
- 同核内不应出现重复的set_flag指令。
- 同一核内，当set_flag和wait_flag内的pipe_src和pipe_dst相同时，event_id也应保持唯一。

### 使用示例
```python
from mskpp import Tensor, Chip, set_flag, wait_flag
with Chip("Ascendxxyy") as chip:
    gm_weight = Tensor("GM", "FP16", [128, 256], format="ND")
    l1_weight = Tensor("L1", "FP16", [128, 256], format="ND")
    for conv_idx in range(4):  # L0A数据加载前，GM分批加载到L1上
        gm_weight_part = gm_weight[:, 64]
        l1_weight_part = l1_weight[:, 64]
        l1_weight_part.load(gm_weight_part)
        if conv_idx == 3:
            set_flag("PIPE-MTE2", "PIPE-MTE1", 1)  # 当完成MTE2，才可以执行MTE1
    x = Tensor("L0A")   # L0A
    # 正在执行MTE2操作， MTE1操作需要等待MTE2完成才能执行。
    l1_weight.set_valid()  # 手动使能L1
    wait_flag("PIPE-MTE2", "PIPE-MTE1", 1)
    x.load(l1_weight)
```
