<h1 class="topictitle1">vmla</h1>
<div id="body0000001836974177"><div class="section" id="ZH-CN_TOPIC_0000002336353322__zh-cn_topic_0000001741276825_section0459164813338"><h4 class="sectiontitle">功能说明</h4><p id="ZH-CN_TOPIC_0000002336353322__zh-cn_topic_0000001741276825_p5252816288">vmla指令抽象。</p>
<p id="ZH-CN_TOPIC_0000002336353322__zh-cn_topic_0000001741276825_p11211843646">z = x * y + z， x、y按元素相乘，相乘的结果与z按元素相加，可以通过if_mix将输出的数据类型格式指定为FP32。</p>
<p id="ZH-CN_TOPIC_0000002336353322__p758205822917">目前支持：</p>
<p id="ZH-CN_TOPIC_0000002336353322__p1254483743015">type = f16，f16 = f16 * f16 + f16。</p>
<p id="ZH-CN_TOPIC_0000002336353322__p195451637163018">type = f32，f32 = f32 * f32 + f32。</p>
<p id="ZH-CN_TOPIC_0000002336353322__p1954543723013">if_mix = True时，f32 = f16 * f16 + f32。其中x、y向量使用64个元素的f16数据用于计算，源向量仅使用低4个block，4个高block被忽略。z是64个元素的包含8个block的f32数据，同时作为目标向量和第三个源向量。</p>
</div>
