# vrsqrt

#### 功能说明
vrsqrt指令抽象。  
浮点数的倒数平方根。

#### 接口原型
```python
class vrsqrt(x, y)
```

#### 参数说明
<table cellpadding="4" cellspacing="0" frame="border" border="1" rules="all"><thead><tr><th>参数名</th><th>输入/输出</th><th>数据类型</th><th>说明</th></tr></thead><tbody><tr><td>x</td><td>输入</td><td>Tensor变量</td><td>输入x向量Tensor。支持float16、float32。</td></tr><tr><td>y</td><td>输出</td><td>Tensor变量</td><td>输出向量Tensor。支持float16、float32。</td></tr></tbody></table>

#### 使用示例
```python
from mskpp import vrsqrt, Tensor
ub_x, ub_y = Tensor("UB"), Tensor("UB")
gm_x, gm_y = Tensor("GM"), Tensor("GM")
ub_x.load(gm_x)
ub_y.load(gm_y)
out = vrsqrt(ub_x, ub_y)()
```
