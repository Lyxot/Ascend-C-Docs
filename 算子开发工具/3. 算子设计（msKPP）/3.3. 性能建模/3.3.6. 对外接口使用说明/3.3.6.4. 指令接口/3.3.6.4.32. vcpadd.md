# vcpadd

#### 功能说明
vcpadd指令抽象。  
计算输入的x向量的n和n+1的和，n为偶数下标，将结果写回y。reduce_num控制了输出的type。

#### 接口原型
```python
class vcpadd(x, y, reduce_num)
```

#### 参数说明
<table border="1">
<thead><tr><th>参数名</th><th>输入/输出</th><th>数据类型</th><th>说明</th></tr></thead>
<tbody><tr><td>x</td><td>输入</td><td>Tensor变量</td><td>输入x向量Tensor。支持fp16、fp32。</td></tr><tr><td>y</td><td>输出</td><td>Tensor变量</td><td>输出y向量Tensor。支持fp16、fp32。</td></tr><tr><td>reduce_num</td><td>输入</td><td>int</td><td>shape指定的缩减倍数。</td></tr></tbody>
</table>

#### 使用示例
```python
from mskpp import vcpadd, Tensor
ub_x, ub_y = Tensor("UB"), Tensor("UB")
gm_x, gm_y = Tensor("GM"), Tensor("GM")
ub_x.load(gm_x)
ub_y.load(gm_y)
out = vcpadd(ub_x, ub_y, reduce_num)()
```
