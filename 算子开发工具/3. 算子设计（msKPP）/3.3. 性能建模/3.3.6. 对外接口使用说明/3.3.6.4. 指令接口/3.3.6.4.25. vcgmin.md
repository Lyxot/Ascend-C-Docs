# vcgmin

## 功能说明
vcgmin指令抽象

计算每个block的最小元素，共计8个block，不支持混合地址。

## 接口原型
```python
class vcgmin(x, y, reduce_num)
```

## 约束说明
reduce_num不能为0。

## 使用示例
```python
from mskpp import vcgmin, Tensor
ub_x, ub_y = Tensor("UB"), Tensor("UB")
gm_x = Tensor("GM")
reduce_num = 16
ub_x.load(gm_x)
out = vcgmin(ub_x, ub_y, reduce_num)()
```
