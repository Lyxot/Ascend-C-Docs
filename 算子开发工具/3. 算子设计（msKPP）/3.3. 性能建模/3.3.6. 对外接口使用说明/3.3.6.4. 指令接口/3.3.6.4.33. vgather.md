# vgather

#### 功能说明
给定输入的张量和一个地址偏移张量，vgather指令根据偏移地址将输入张量按元素收集到结果张量中。

#### 接口原型
```python
class vgather(x, y)
```

#### 参数说明
<table><thead><tr><th>参数名</th><th>输入/输出</th><th>数据类型</th><th>说明</th></tr></thead><tbody><tr><td>x</td><td>输入</td><td>Tensor变量</td><td>输入x向量Tensor。支持UINT16、UINT32。</td></tr><tr><td>y</td><td>输出</td><td>Tensor变量</td><td>输出y向量Tensor。支持UINT16、UINT32。</td></tr></tbody></table>

#### 使用示例
```python
from mskpp import vgather, Tensor
ub_x, ub_y = Tensor("UB"), Tensor("UB")
gm_x, gm_y = Tensor("GM"), Tensor("GM")
ub_x.load(gm_x)
ub_y.load(gm_y)
out = vgather(ub_x, ub_y)()
```
