# vaddrelu

#### 功能说明
vaddrelu指令抽象。  
z = vaddrelu(x, y)，x、y按元素相加后再计算relu值。

#### 接口原型
```python
class vaddrelu(x, y, z)
```

#### 参数说明
<table>
<thead><tr><th>参数名</th><th>输入/输出</th><th>数据类型</th><th>说明</th></tr></thead>
<tbody><tr><td>x</td><td>输入</td><td>Tensor变量</td><td>输入x向量Tensor。支持FP16、FP32、INT16。</td></tr>
<tr><td>y</td><td>输入</td><td>Tensor变量</td><td>输入y向量Tensor。支持FP16、FP32、INT16。</td></tr>
<tr><td>z</td><td>输出</td><td>Tensor变量</td><td>输出向量Tensor。支持FP16、FP32、INT16。</td></tr></tbody>
</table>

#### 使用示例
```python
from mskpp import vaddrelu, Tensor
ub_x, ub_y, ub_z = Tensor("UB"), Tensor("UB"), Tensor("UB")
gm_x, gm_y = Tensor("GM"), Tensor("GM")
ub_x.load(gm_x)
ub_y.load(gm_y)
out = vaddrelu(ub_x, ub_y, ub_z)()
```
