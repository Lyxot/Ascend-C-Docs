# vshr

## 功能说明
vshr指令抽象。  
根据输入类型进行逻辑左移或算术左移。

## 接口原型
```python
class vshr(x, y)
```

## 参数说明
<table cellpadding="4" cellspacing="0" frame="border" border="1" rules="all"><thead><tr><th><p>参数名</p></th><th><p>输入/输出</p></th><th><p>数据类型</p></th><th><p>说明</p></th></tr></thead><tbody><tr><td><p>x</p></td><td><p>输入</p></td><td><p>Tensor变量</p></td><td><p>输入x向量Tensor。支持UINT16、UINT32、INT16、INT32。</p></td></tr><tr><td><p>y</p></td><td><p>输出</p></td><td><p>Tensor变量</p></td><td><p>输出y向量Tensor。支持UINT16、UINT32、INT16、INT32。</p></td></tr></tbody></table>

## 使用示例
```python
from mskpp import vshr, Tensor
gm_x, gm_y = Tensor("GM"), Tensor("GM")
ub_x.load(gm_x)
ub_y.load(gm_y)
out = vshr(ub_x, ub_y)()
```
