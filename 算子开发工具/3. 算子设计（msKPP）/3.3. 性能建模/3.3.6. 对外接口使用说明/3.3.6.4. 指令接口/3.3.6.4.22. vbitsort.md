<h1 class="topictitle1">vbitsort</h1>
<div><div class="section"><h4 class="sectiontitle">功能说明</h4><p>vbitsort指令抽象。</p>
<p>根据x输入进行排序，并在排序后给出元素原始的index数据，因此输出向量Tensor的shape会是x数据的两倍。</p>
