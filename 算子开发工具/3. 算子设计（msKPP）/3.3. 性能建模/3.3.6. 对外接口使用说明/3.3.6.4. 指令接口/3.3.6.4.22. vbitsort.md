# vbitsort

#### 功能说明
vbitsort指令抽象。

根据x输入进行排序，并在排序后给出元素原始的index数据，因此输出向量Tensor的shape会是x数据的两倍。

#### 接口原型
```python
class vbitsort(x, y, z)
```

#### 参数说明
<table cellpadding="4" cellspacing="0" frame="border" border="1" rules="all"><thead><tr><th>参数名</th><th>输入/输出</th><th>数据类型</th><th>说明</th></tr></thead><tbody><tr><td>x</td><td>输入</td><td>Tensor变量</td><td>输入向量Tensor。支持FP16、FP32。</td></tr><tr><td>y</td><td>输入</td><td>Tensor变量</td><td>输入向量Tensor。支持UINT32。</td></tr><tr><td>z</td><td>输出</td><td>Tensor变量</td><td>输出向量Tensor。支持FP16、FP32。</td></tr></tbody></table>

#### 使用示例
```python
from mskpp import vbitsort, Tensor
ub_x, ub_y, ub_z = Tensor("UB"), Tensor("UB"), Tensor("UB")
gm_x, gm_y = Tensor("GM"), Tensor("GM")
ub_x.load(gm_x)
ub_y.load(gm_y)
out = vbitsort(ub_x, ub_y, ub_z)()
```
