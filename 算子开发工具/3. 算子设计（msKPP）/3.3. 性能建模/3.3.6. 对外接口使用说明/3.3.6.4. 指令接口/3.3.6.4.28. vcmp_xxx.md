<div id="body0000001836814185"><div class="section" id="ZH-CN_TOPIC_0000002336193566__zh-cn_topic_0000001741276825_section0459164813338"><h4 class="sectiontitle">功能说明</h4><p id="ZH-CN_TOPIC_0000002336193566__zh-cn_topic_0000001741276825_p5252816288">vcmp_[eq|ge|gt|le|lt|ne]指令抽象，该六条指令性能一致。</p>
<p id="ZH-CN_TOPIC_0000002336193566__zh-cn_topic_0000001741276825_p11211843646">vcmp_eq: z = (x == y)， x、y按元素比较相等得到z。</p>
<p id="ZH-CN_TOPIC_0000002336193566__p19350849135914">vcmp_ge: z = (x &gt;= y)， x、y按元素比较大于或等于得到z。</p>
<p id="ZH-CN_TOPIC_0000002336193566__p16505155515598">vcmp_gt: z = (x &gt; y)， x、y按元素比较大于得到z。</p>
<p id="ZH-CN_TOPIC_0000002336193566__p104882021406">vcmp_le: z = (x &lt;= y)， x、y按元素比较小于或等于得到z。</p>
<p id="ZH-CN_TOPIC_0000002336193566__p144888217016">vcmp_lt: z = (x &lt; y)， x、y按元素比较小于得到z。</p>
<p id="ZH-CN_TOPIC_0000002336193566__p19488121402">vcmp_ne: z = (x != y)， x、y按元素比较不等得到z。</p>
