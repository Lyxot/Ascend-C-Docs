# vor

#### 功能说明
vor指令抽象。  
vor指令对输入向量按位取或，每个向量为8*256bits。

#### 接口原型
```python
class vor(x, y, z)
```

#### 参数说明
<table border="1" rules="all"><thead><tr><th>参数名</th><th>输入/输出</th><th>数据类型</th><th>说明</th></tr></thead><tbody><tr><td>x</td><td>输入</td><td>Tensor变量</td><td>输入x向量Tensor，支持INT16、 UINT16。</td></tr><tr><td>y</td><td>输入</td><td>Tensor变量</td><td>输入y向量Tensor，支持INT16、UINT16。</td></tr><tr><td>z</td><td>输出</td><td>Tensor变量</td><td>输出z向量Tensor，支持INT16、UINT16。</td></tr></tbody></table>

#### 使用示例
```python
from mskpp import vor, Tensor
ub_x, ub_y, ub_z = Tensor("UB"), Tensor("UB"), Tensor("UB")
gm_x, gm_y = Tensor("GM"), Tensor("GM")
ub_x.load(gm_x)
ub_y.load(gm_y)
out = vor(ub_x, ub_y, ub_z)()
```

#### 约束说明
该指令仅支持普通掩码模式和计数器模式。
