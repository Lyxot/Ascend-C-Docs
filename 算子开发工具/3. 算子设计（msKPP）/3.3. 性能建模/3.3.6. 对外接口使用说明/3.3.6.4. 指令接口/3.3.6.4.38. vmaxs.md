vmaxs

### 功能说明
vmaxs指令抽象。  
对向量中的每个元素和标量进行比较，返回较大者。

### 接口原型
```python
class vmaxs(x, y, z)
```

### 使用示例
```python
from mskpp import vmaxs, Tensor
ub_x, ub_z = Tensor("UB"), Tensor("UB")
gm_x = Tensor("GM")
ub_x.load(gm_x)
out = vmaxs(ub_x, 5, ub_z)()
```
