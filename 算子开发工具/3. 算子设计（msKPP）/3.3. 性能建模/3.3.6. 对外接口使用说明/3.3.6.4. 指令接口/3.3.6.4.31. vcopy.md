# vcopy

#### 功能说明
vcopy指令抽象  
将源地址的Tensor拷贝到目标地址。

#### 接口原型
```python
class vcopy(x, y)
```

#### 使用示例
```python
from mskpp import vcopy, Tensor
ub_x, ub_y = Tensor("UB"), Tensor("UB")
gm_x = Tensor("GM")
ub_x.load(gm_x)
out = vcopy(ub_x, ub_y)()
```
