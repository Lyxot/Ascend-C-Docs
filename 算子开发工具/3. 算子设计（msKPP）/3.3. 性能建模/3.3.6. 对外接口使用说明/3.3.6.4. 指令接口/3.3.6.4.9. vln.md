# vln

#### 功能说明
vln指令抽象。

y = vln(x)，x、y按元素取对数。

#### 接口原型
```python
class vln(x, y)
```

#### 参数说明
<table>
<thead><tr><th align="left"><p>参数名</p></th><th align="left"><p>输入/输出</p></th><th align="left"><p>数据类型</p></th><th align="left"><p>说明</p></th></tr></thead>
<tbody><tr><td><p>x</p></td><td><p>输入</p></td><td><p>Tensor变量</p></td><td><p>输入x向量Tensor。支持FP16、FP32。</p></td></tr><tr><td><p>y</p></td><td><p>输出</p></td><td><p>Tensor变量</p></td><td><p>输出y向量Tensor。支持FP16、FP32。</p></td></tr></tbody>
</table>

#### 使用示例
```python
from mskpp import vln, Tensor
ub_x = Tensor("UB")
gm_x = Tensor("GM")
ub_x.load(gm_x)
ub_y = Tensor("UB")
out = vln(ub_x, ub_y)()
```
