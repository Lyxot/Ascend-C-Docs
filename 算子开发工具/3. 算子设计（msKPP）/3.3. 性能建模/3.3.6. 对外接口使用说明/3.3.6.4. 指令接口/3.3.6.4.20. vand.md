# vand

## 功能说明

vand指令抽象。

vand(x, y, z)，x、y按元素取与，得到z值。

## 接口原型

```python
class vand(x, y, z)
```

## 参数说明

<table>
  <thead>
    <tr><th>参数名</th><th>输入/输出</th><th>数据类型</th><th>说明</th></tr>
  </thead>
  <tbody>
    <tr><td>x</td><td>输入</td><td>Tensor变量</td><td>输入x向量Tensor。支持INT16、UINT16。</td></tr>
    <tr><td>y</td><td>输入</td><td>Tensor变量</td><td>输入y向量Tensor。支持INT16、UINT16。</td></tr>
    <tr><td>z</td><td>输出</td><td>Tensor变量</td><td>输出向量Tensor。支持INT16、UINT16。</td></tr>
  </tbody>
</table>

## 使用示例

```python
from mskpp import vand, Tensor
ub_x, ub_y, ub_z = Tensor("UB"), Tensor("UB"), Tensor("UB")
gm_x, gm_y = Tensor("GM"), Tensor("GM")
ub_x.load(gm_x)
ub_y.load(gm_y)
out = vand(ub_x, ub_y, ub_z)()
```
