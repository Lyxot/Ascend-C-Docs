# vmadd

#### 功能说明
vmadd指令抽象。  
z = x * z + y。对两个向量中的每个元素执行乘法和加法。

#### 接口原型
```python
class vmadd(x, y, z)
```

#### 使用示例
```python
from mskpp import vmadd, Tensor
ub_x, ub_y, ub_z = Tensor("UB"), Tensor("UB"), Tensor("UB")
gm_x, gm_y = Tensor("GM"), Tensor("GM")
ub_x.load(gm_x)
ub_y.load(gm_y)
out = vmadd(ub_x, ub_y, ub_z)()
```
