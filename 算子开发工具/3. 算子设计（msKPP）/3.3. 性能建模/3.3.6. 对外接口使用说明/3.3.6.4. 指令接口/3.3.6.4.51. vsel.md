# vsel

#### 功能说明
vsel指令抽象。  
通常与vcmp合用，根据获得的cmp_mask来选取x，y中对应位置的某个元素。

#### 接口原型
```python
class vsel(x, y, z)
```

#### 参数说明
<table cellpadding="4" cellspacing="0" border="1" rules="all"><thead><tr><th>参数名</th><th>输入/输出</th><th>数据类型</th><th>说明</th></tr></thead><tbody><tr><td>x</td><td>输入</td><td>Tensor变量</td><td>输入x向量Tensor。支持FP16、FP32、INT16、INT32。</td></tr><tr><td>y</td><td>输入</td><td>Tensor变量</td><td>输入y向量Tensor。支持FP16、FP32、INT16、INT32。</td></tr><tr><td>z</td><td>输出</td><td>Tensor变量</td><td>输出向量Tensor。支持FP16、FP32、INT16、INT32。</td></tr></tbody></table>

#### 使用示例
```python
from mskpp import vsel, Tensor
ub_x, ub_y, ub_z = Tensor("UB"), Tensor("UB"), Tensor("UB")
gm_x, gm_y = Tensor("GM"), Tensor("GM")
ub_x.load(gm_x)
ub_y.load(gm_y)
out = vsel(ub_x, ub_y, ub_z)()
```
