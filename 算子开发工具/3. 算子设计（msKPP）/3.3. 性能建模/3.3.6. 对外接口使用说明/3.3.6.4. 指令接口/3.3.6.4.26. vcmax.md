# vcmax

#### 功能说明
vcmax指令抽象。  
计算输入的vector中的元素最大值。

#### 接口原型
```python
class vcmax(x, y, reduce_num)
```

#### 参数说明
<table>
<thead><tr><th><p>参数名</p></th><th><p>输入/输出</p></th><th><p>数据类型</p></th><th><p>说明</p></th></tr></thead>
<tbody><tr><td><p>x</p></td><td><p>输入</p></td><td><p>Tensor变量</p></td><td><p>输入x向量Tensor，支持FP16、FP32。</p></td></tr>
<tr><td><p>y</p></td><td><p>输出</p></td><td><p>Tensor变量</p></td><td><p>输出y向量Tensor，支持FP16、FP32。</p></td></tr>
<tr><td><p>reduce_num</p></td><td><p>输入</p></td><td><p>int</p></td><td><p>指定最后一维reduce到多少倍，实测性能数据reduce对性能无影响。</p></td></tr></tbody>
</table>

#### 约束说明
reduce_num不能为0。

#### 使用示例
```python
from mskpp import vcmax, Tensor
ub_x, ub_y = Tensor("UB"), Tensor("UB")
gm_x = Tensor("GM")
reduce_num = 16
ub_x.load(gm_x)
out = vcmax(ub_x, ub_y, reduce_num)()
```
