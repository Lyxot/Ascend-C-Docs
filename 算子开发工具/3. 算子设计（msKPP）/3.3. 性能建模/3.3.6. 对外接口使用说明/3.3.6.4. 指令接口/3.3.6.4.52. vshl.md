# vshl

#### 功能说明
vshl指令抽象。

根据输入类型进行逻辑左移或算术左移。

#### 接口原型
```python
class vshl(x, y)
```

#### 参数说明
<table><thead><tr><th>参数名</th><th>输入/输出</th><th>数据类型</th><th>说明</th></tr></thead><tbody><tr><td>x</td><td>输入</td><td>Tensor变量</td><td>输入x向量Tensor。支持UINT16、UINT32、INT16、INT32。</td></tr><tr><td>y</td><td>输出</td><td>Tensor变量</td><td>输出y向量Tensor。支持UINT16、UINT32、INT16、INT32。</td></tr></tbody></table>

#### 使用示例
```python
from mskpp import vshl, Tensor
ub_x, ub_z = Tensor("UB"), Tensor("UB")
gm_x = Tensor("GM")
ub_x.load(gm_x)
out = vshl(ub_x, ub_z)()
```
