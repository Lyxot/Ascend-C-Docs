# vabs

## 功能说明
vabs指令抽象。
y = vabs(x)， x、y按元素取绝对值。

## 接口原型
```python
class vabs(x, y)
```

## 参数说明
<table><thead><tr><th>参数名</th><th>输入/输出</th><th>数据类型</th><th>说明</th></tr></thead><tbody><tr><td>x</td><td>输入</td><td>Tensor变量</td><td>输入x向量Tensor。支持FP16、FP32。</td></tr><tr><td>y</td><td>输出</td><td>Tensor变量</td><td>输出y向量Tensor。支持FP16、FP32。</td></tr></tbody></table>

## 使用示例
```python
from mskpp import vabs, Tensor
ub_x, ub_y = Tensor("UB"), Tensor("UB")
gm_x = Tensor("GM")
ub_x.load(gm_x)
out = vabs(ub_x, ub_y)()
```
