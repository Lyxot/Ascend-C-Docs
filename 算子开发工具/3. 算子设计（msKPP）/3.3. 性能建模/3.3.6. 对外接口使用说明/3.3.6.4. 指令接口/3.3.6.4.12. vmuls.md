# vmuls

## 功能说明
vmuls指令抽象。

z = vmuls(x, y)，vmuls求值向量x与标量y的乘积。

## 接口原型
```python
class vmuls(x, y, z)
```

## 参数说明
<table>
<thead><tr><th>参数名</th><th>输入/输出</th><th>数据类型</th><th>说明</th></tr></thead>
<tbody><tr><td>x</td><td>输入</td><td>Tensor变量</td><td>输入向量Tensor。支持FP16、FP32、INT16、INT32。</td></tr><tr><td>y</td><td>输入</td><td>Python标量</td><td>输入标量，程序不对该参数做任何处理。</td></tr><tr><td>z</td><td>输出</td><td>Tensor变量</td><td>输出向量Tensor。支持FP16、FP32、INT16、INT32。</td></tr></tbody>
</table>

## 使用示例
```python
from mskpp import vmuls, Tensor
ub_x, ub_z = Tensor("UB"), Tensor("UB")
gm_x = Tensor("GM")
ub_x.load(gm_x)
out = vmuls(ub_x, 5, ub_z)()  //5为y标量的值
```
