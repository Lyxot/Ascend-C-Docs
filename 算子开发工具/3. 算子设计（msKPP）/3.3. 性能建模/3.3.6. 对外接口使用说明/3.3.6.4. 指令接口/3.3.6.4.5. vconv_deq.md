# vconv_deq

#### 功能说明
vconv_deq指令抽象。  
y = vconv_deq(x, dtype)，vconv_deq表示对输入数据进行量化操作的向量计算。  
目前支持转换类型包括：FP16->INT8、INT32>FP16。

#### 接口原型
```python
class vconv_deq(x, y, dtype)
```

#### 参数说明
<table><thead><tr><th>参数名</th><th>输入/输出</th><th>数据类型</th><th>说明</th></tr></thead><tbody><tr><td>x</td><td>输入</td><td>Tensor变量</td><td>输入x向量Tensor。</td></tr><tr><td>y</td><td>输出</td><td>Tensor变量</td><td>输出y向量Tensor。</td></tr><tr><td>dtype</td><td>输入</td><td>字符串</td><td>表示目标Tensor的数据类型。</td></tr></tbody></table>

#### 使用示例
```python
from mskpp import vconv_deq, Tensor
ub_x, ub_y = Tensor("UB", "FP16"), Tensor("UB")
gm_x = Tensor("GM")
ub_x.load(gm_x)
out = vconv_deq(ub_x, ub_y, "FP32")()
```
