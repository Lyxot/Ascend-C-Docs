<h1 class="topictitle1">vbrcb</h1>
<div><div class="section"><h4 class="sectiontitle">功能说明</h4><p>vbrcb指令抽象。</p>
<p>根据指令的stride将Tensor进行扩维，由于目前msKPP工具的指令体系里并没有stride的概念，需要用户填写如何扩维倍数，并保持输入输出Tensor的shape维度一致。</p>
</div>
