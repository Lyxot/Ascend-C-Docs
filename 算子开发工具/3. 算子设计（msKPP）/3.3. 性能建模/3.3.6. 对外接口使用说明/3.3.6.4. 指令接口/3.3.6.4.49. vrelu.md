# vrelu

## 功能说明
vrelu指令抽象。  
每个元素的relu操作，按照元素小于0的取0，大于等于0的取本身。

## 接口原型
```python
class vrelu(x, y)
```

## 参数说明
<table><thead><tr><th>参数名</th><th>输入/输出</th><th>数据类型</th><th>说明</th></tr></thead><tbody><tr><td>x</td><td>输入</td><td>Tensor变量</td><td>输入x向量Tensor。支持float16、float32、int32。</td></tr><tr><td>y</td><td>输出</td><td>Tensor变量</td><td>输出向量Tensor。支持float16、float32、int32。</td></tr></tbody></table>

## 使用示例
```python
from mskpp import vrelu, Tensor
ub_x, ub_y = Tensor("UB"), Tensor("UB")
gm_x, gm_y = Tensor("GM"), Tensor("GM")
ub_x.load(gm_x)
ub_y.load(gm_y)
out = vrelu(ub_x, ub_y)()
```
