<p>对于流水线耗时最长，明显是搬运性能瓶颈的PIPE，通常有如下优化思路：</p>
<ul><li>若搬运数据量较大时，尽可能一次搬运较多的数据，充分利用搬运带宽。</li><li>尽可能保证性能瓶颈的PIPE在流水上一直在工作。</li></ul>
