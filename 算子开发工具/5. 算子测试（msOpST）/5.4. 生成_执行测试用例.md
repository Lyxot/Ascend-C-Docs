  <h1 class="topictitle1">生成/执行测试用例</h1>
  <div>
   <p>指导用户根据算子测试用例定义文件生成ST测试数据及测试用例执行代码，在硬件环境上执行算子测试用例。</p>
   <div class="section">
    <h4 class="sectiontitle">开发环境与运行环境合设场景</h4>
    <ol>
     <li>ST测试用例执行时，会使用AscendCL接口加载单算子模型文件并执行，所以需要配置AscendCL应用编译所需其他环境变量，如下所示。
      <p></p>
      <pre class="code_wrap">export DDK_PATH=<span>${INSTALL_DIR}</span>
export NPU_HOST_LIB=<span>${INSTALL_DIR}</span>/<em>{arch-os}</em>/devlib</pre>
      <div class="note">
       <img src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/devaids/optool/public_sys-resources/note_3.0-zh-cn.png"><span class="notetitle"> </span>
       <div class="notebody">
        <ul>
         <li><span>${INSTALL_DIR}请替换为CANN软件安装后文件存储路径。若安装的Ascend-cann-toolkit软件包，以root安装举例，则安装后文件存储路径为：/usr/local/Ascend/ascend-toolkit/latest。</span></li>
         <li><em>{arch-os}中</em><em>arch</em>表示操作系统架构，<em>os</em>表示操作系统。</li>
        </ul>
       </div>
      </div>
      <p></p></li>
     <li>执行如下命令生成/执行测试用例，具体参数介绍请参见<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/devaids/optool/atlasopdev_16_0029.html#ZH-CN_TOPIC_0000002336189038__zh-cn_topic_0000001821790281_table1735410430919">表2</a>。
      <p></p>
      <pre class="code_wrap">msopst run -i<em> {**.json}</em>  -soc<em>{soc version}</em>  -out <em>{output path}</em> -c<em> {case name}</em> -d<em> {device id}</em> -conf<em> {msopst.ini path}</em> -err_thr "[threshold1,threshold2]"</pre>
      <ul>
       <li>msopst.ini文件的路径为：<span>${INSTALL_DIR}</span>/python/site-packages/bin/。</li>
       <li>msopst.ini文件参数说明如下表所示。

         <div class="notebody">
          <p>msopst.ini文件默认使用FP16精度模式，如需使用其他精度模式需手动修改<a href="#ZH-CN_TOPIC_0000002336348910__zh-cn_topic_0000001821790281_table17358154319919">表1</a>中atc_singleop_advance_option的--precision_mode参数。</p>
         </div>

       <li><strong>命令行执行示例：</strong>
        <ul>
         <li>不启用msOpST工具的高级功能，执行如下命令生成ST测试用例并执行。
          <pre class="code_wrap">msopst run -i <em>xx</em>/<em>AddCustom</em>_case_<em>timestamp</em>.json -soc<em>{soc version}</em> -out ./output</pre></li>
         <li>启动msOpST工具的高级功能，仅生成ST测试用例，用户修改ST测试用例后，再执行ST测试用例。
          <ol type="a">
           <li>执行命令，编辑msopst.ini文件
            <pre class="code_wrap">vim <span>${INSTALL_DIR}</span>/python/site-packages/bin/msopst.ini</pre>
            <p>将msOpST工具的运行模式修改为模式2，按照<a href="#ZH-CN_TOPIC_0000002336348910__zh-cn_topic_0000001821790281_table1836016436913">表2</a>修改<span class="parmname">“only_gen_without_run”</span>和<span class="parmname">“only_run_without_gen”</span>参数的取值。只生成ST测试代码，不运行ST测试代码。</p></li>
           <li>执行如下命令生成ST测试源码。
            <pre class="code_wrap">msopst run -i <em>xx</em>/<em>AddCustom</em>_case_<em>timestamp</em>.json -soc<em>{soc version}</em> -out ./output -conf <em>xx/</em>msopst.ini</pre>
            <p>-conf参数请修改为msopst.ini配置文件的实际路径。</p>
            <p>ST测试用例生成后，用户可根据需要自行修改ST测试用例代码。</p></li>
           <li>修改msopst.ini文件，修改运行模式为仅执行ST测试用例。
            <p><a name="ZH-CN_TOPIC_0000002336348910__zh-cn_topic_0000001821790281_li836112432093"></a><a name="zh-cn_topic_0000001821790281_li836112432093"></a>执行命令，编辑msopst.ini文件</p>
            <pre class="code_wrap">vim <span>${INSTALL_DIR}</span>/python/site-packages/bin/msopst.ini</pre>
            <p>将msOpST工具的运行模式修改为模式3，按照<a href="#ZH-CN_TOPIC_0000002336348910__zh-cn_topic_0000001821790281_table1836016436913">表2</a>修改<span class="parmname">“only_gen_without_run”</span>和<span class="parmname">“only_run_without_gen”</span>参数的取值。不生成ST测试代码，只运行ST测试代码。</p></li>
           <li>执行如下命令运行已修改的ST测试源码。
            <pre class="screen">msopst run -i <em>xx</em>/<em>AddCustom</em>_case_<em>timestamp</em>.json -soc<em>{soc version}</em> -out ./output -conf <em>xx/</em>msopst.ini</pre></li>
          </ol>

    <h4 class="sectiontitle">开发环境与运行环境分设场景</h4>
    <ol>
     <li>根据运行环境的架构在开发环境上搭建环境。
      <p></p>
      <ol type="a">
       <li>ST测试用例执行时，会使用AscendCL接口加载单算子模型文件并执行，需要在开发环境上根据运行环境的架构配置AscendCL应用编译所需其他环境变量。
        <ul>
         <li>当开发环境和运行环境架构相同时，环境变量如下所示。
          <pre class="code_wrap">export DDK_PATH=<span>${INSTALL_DIR}</span>
export NPU_HOST_LIB=<span>${INSTALL_DIR}</span>/<em>{arch-os}</em>/devlib</pre></li>
         <li>当开发环境和运行环境架构不同时，环境变量如下所示。
          <pre class="code_wrap">export DDK_PATH=<span>${INSTALL_DIR}</span>/<em>{arch-os}</em>
export NPU_HOST_LIB=<span>${INSTALL_DIR}</span>/<em>{arch-os}</em>/devlib</pre></li>
        </ul>
        <div class="note">
         <img src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/devaids/optool/public_sys-resources/note_3.0-zh-cn.png"><span class="notetitle"> </span>
         <div class="notebody">
          <ul>
           <li><span>${INSTALL_DIR}请替换为CANN软件安装后文件存储路径。若安装的Ascend-cann-toolkit软件包，以root安装举例，则安装后文件存储路径为：/usr/local/Ascend/ascend-toolkit/latest。</span></li>
           <li><em>{arch-os}中</em><em>arch</em>表示操作系统架构（需根据运行环境的架构选择），<em>os</em>表示操作系统（需根据运行环境的操作系统选择）。</li>
          </ul>
         </div>
        </div></li>
      </ol>
      <p></p></li>
     <li>在开发环境启动msOpST工具的高级功能，仅生成ST测试用例。
      <p></p>
      <ol type="a">
       <li>执行命令，编辑msopst.ini文件。
        <pre class="code_wrap">vim <span>${INSTALL_DIR}</span>/python/site-packages/bin/msopst.ini</pre></li>
       <li>将msOpST工具的运行模式修改为模式2，按照<a href="#ZH-CN_TOPIC_0000002336348910__zh-cn_topic_0000001821790281_table1836016436913">表2</a>修改<span class="parmname">“only_gen_without_run”</span>和<span class="parmname">“only_run_without_gen”</span>参数的取值。只生成ST测试代码，不运行ST测试代码。</li>
       <li>若开发环境和运行环境架构不同，按照<a href="#ZH-CN_TOPIC_0000002336348910__zh-cn_topic_0000001821790281_table17358154319919">表1</a>修改<span class="parmname">“HOST_ARCH”</span>和<span class="parmname">“TOOL_CHAIN”</span>参数的取值。</li>
       <li>执行如下命令生成ST测试源码。
        <pre class="code_wrap">msopst run -i<em> xx/AddCustom_case_timestamp.json</em> -soc<em>{soc version}</em> -out <em>{output path}</em> -conf <em>xx/</em>msopst.ini</pre>
        <p>-conf参数请修改为msopst.ini配置文件的实际路径。</p>
        <p>ST测试用例生成后，用户可根据需要自行修改ST测试用例代码。</p></li>
       <li>执行完成后，将在<em>{output path}</em>下生成ST测试用例，并使用g++编译器生成可执行文件main。同时，屏幕打印信息中展示此次一共运行几个用例，测试用例运行的情况，并生成报表st_report.json，保存在屏显信息中“The st report saved in”所示路径下，报表具体信息请参见<a href="#ZH-CN_TOPIC_0000002336348910__zh-cn_topic_0000001821790281_table1236818431294">表3</a>。</li>
      </ol>
      <p></p></li>
     <li>执行测试用例。
      <p></p>
      <ol type="a">
       <li>将开发环境的算子工程目录的run目录下的out文件夹拷贝至运行环境任一目录，例如上传到<span>${INSTALL_DIR}</span>/Ascend_project/run_add/目录下。</li>
       <li>在运行环境中执行out文件夹下的可执行文件。
        <div class="p">
         <a name="ZH-CN_TOPIC_0000002336348910__zh-cn_topic_0000001821790281_li14500317144313"></a><a name="zh-cn_topic_0000001821790281_li14500317144313"></a>进入out文件夹所在目录，执行如下命令：
         <pre class="code_wrap">chmod +x main
./main</pre>
        </div></li>
      </ol>
      <p></p></li>
     <li>查看运行结果。
      <p></p>
      <p>执行完成后，屏显信息显示此次用例运行的情况，如<a href="#ZH-CN_TOPIC_0000002336348910__zh-cn_topic_0000001821790281_fig204517552811">图2</a>所示。</p>
