# 生成测试用例定义文件

指导用户使用msOpST工具生成算子测试用例定义文件（*.json），作为算子ST测试用例的输入。

1. 获取并编辑待测试Host侧算子的实现文件（.cpp文件）。  
  msOpST工具根据待测Host侧算子的实现文件生成算子ST测试用例定义文件，在算子工程文件中Host侧算子的实现文件路径如下所示。  
  可以单击[Link](https://gitee.com/ascend/samples/tree/v1.5-8.2.RC1/operator/ascendc/0_introduction/1_add_frameworklaunch/AddCustom)获取文档中对应的Host侧算子实现文件add_custom.cpp进行参考。  
  > 注意：此样例工程不支持Atlas A3 训练系列产品。  
  ```text
  ├── framework/tf_plugin        // 算子插件实现文件目录，单算子模型文件的生成不依赖算子适配插件，无需关注
  ├── op_host                    // Host侧实现文件
  │   ├── add_custom_tiling.h    // 算子tiling定义文件
  │   ├── add_custom.cpp         // 算子原型注册、shape推导、信息库、tiling实现等内容文件
  │   ├── CMakeLists.txt
  ├── op_kernel                  // Kernel侧实现文件
  │   ├── CMakeLists.txt
  │   ├── add_custom.cpp         // 算子代码实现文件
  ```
2. 执行如下命令生成算子测试用例定义文件，详细参数说明请参见[表1](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/devaids/optool/atlasopdev_16_0029.html#ZH-CN_TOPIC_0000002336189038__zh-cn_topic_0000001775029424_table15856145565413)。  
  ```bash
  msopst create -i {operator.cpp file} -out {output path} -m {pb file} -q
  ```
  > 注意：示例如下：  
  > 以AddCustom算子为例，执行如下命令:  
  > ```bash
  > msopst create -i Op_implementation/add_custom.cpp -out ./output
  > ```  
  > 请将Op_implementation更换为Host侧算子的实现文件所在路径。  
  > 命令执行成功后，会在当前路径的output目录下生成算子测试用例定义文件：AddCustom_case_timestamp.json。
3. 创建算子ST测试用例定义文件“AddCustom_case.json”。该文件的模板如下，您可以基于如下模板进行修改，“*.json”文件支持的全量字段说明参见[表1](#表1-算子测试用例定义json文件)。不同场景下的测试用例定义文件的样例可参见[测试用例定义文件](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/devaids/optool/atlasopdev_16_0036.html)。  
  ```json
  [
      {
          "case_name": "Test_OpType_001",
          "op": "OpType",
          "input_desc": [
              {
                  "format": [],
                  "type": [],
                  "shape": [],
                  "data_distribute": [
                      "uniform"
                  ],
                  "value_range": [
                      [
                          0.1,
                          1.0
                      ]
                  ]
              }
          ],
          "output_desc": [
              {
                  "format": [],
                  "type": [],
                  "shape": []
              }
          ]
      }
  ]
  ```
