  <h1 class="topictitle1">基于msOpGen工具创建算子工程</h1>
  <div id="body0000002295873658">
   <div class="section" id="ZH-CN_TOPIC_0000002336189082__section135911857313">
    <h4 class="sectiontitle">功能描述</h4>
    <p id="ZH-CN_TOPIC_0000002336189082__p8060118">CANN开发套件包中提供了自定义算子工程生成工具msOpGen，可基于算子原型定义输出算子开发相关交付件，包括算子代码实现文件、算子适配插件、算子原型定义、算子信息库定义以及工程编译配置文件。</p>
    <div class="notice" id="ZH-CN_TOPIC_0000002336189082__note2559125934114">
     <span class="noticetitle"><img src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/devaids/optool/public_sys-resources/notice_3.0-zh-cn.png"> </span>
     <div class="noticebody">
      <p id="ZH-CN_TOPIC_0000002336189082__p1148082075019">若开发者需要自定义多个AI CPU算子，需要在同一算子工程中进行实现，并将所有自定义算子在同一工程中同时进行编译，将所有AI CPU自定义算子的实现文件编译成一个动态库文件。</p>
     </div>
    </div>
   </div>
   <div class="section" id="ZH-CN_TOPIC_0000002336189082__section2874153621014">
    <h4 class="sectiontitle">使用前提</h4>
    <ul id="ZH-CN_TOPIC_0000002336189082__ul1575204681017">
     <li id="ZH-CN_TOPIC_0000002336189082__li5943194313259">
      <p id="ZH-CN_TOPIC_0000002336189082__p1730174313411"><a name="ZH-CN_TOPIC_0000002336189082__li5943194313259"></a><a name="li5943194313259"></a>CANN组合包提供进程级环境变量设置脚本，供用户在进程中引用，以自动完成环境变量设置。执行命令参考如下，以下示例均为root或非root用户默认安装路径，请以实际安装路径为准。</p>
      <pre class="screen" id="ZH-CN_TOPIC_0000002336189082__screen164418463419"># 以root用户安装toolkit包后配置环境变量
source /usr/local/Ascend/ascend-toolkit/set_env.sh 
# 以非root用户安装toolkit包后配置环境变量
source ${HOME}/Ascend/ascend-toolkit/set_env.sh </pre></li>
     <li id="ZH-CN_TOPIC_0000002336189082__li1463402714179">安装依赖：
      <div class="p" id="ZH-CN_TOPIC_0000002336189082__p1773351810290">
       <a name="ZH-CN_TOPIC_0000002336189082__li1463402714179"></a><a name="li1463402714179"></a>如下命令如果使用非root用户安装，需要在安装命令后加上<strong id="ZH-CN_TOPIC_0000002336189082__zh-cn_topic_0000001126740895_b14364102145317">--user。</strong>
       <pre class="screen" id="ZH-CN_TOPIC_0000002336189082__screen20661143621819">pip3 install xlrd==1.2.0</pre>
      </div></li>
    </ul>
   </div>
   <div class="section" id="ZH-CN_TOPIC_0000002336189082__section5149182711616">
    <h4 class="sectiontitle">使用方法</h4>
    <ol id="ZH-CN_TOPIC_0000002336189082__ol8711163018227">
     <li id="ZH-CN_TOPIC_0000002336189082__li197119305222"><span>确认需要的输入文件。</span>
      <p></p>
      <div class="p" id="ZH-CN_TOPIC_0000002336189082__p115212442369">
       自定义算子工程生成工具支持输入三种类型的原型定义文件创建算子工程，分别为：
       <ul id="ZH-CN_TOPIC_0000002336189082__ul1884311451334">
        <li id="ZH-CN_TOPIC_0000002336189082__li1949916552368">适配<span id="ZH-CN_TOPIC_0000002336189082__ph19712310269">昇腾AI处理器</span>算子IR定义文件（.json）</li>
        <li id="ZH-CN_TOPIC_0000002336189082__li15499175513369"><span id="ZH-CN_TOPIC_0000002336189082__ph945113392513">TensorFlow</span>的原型定义文件（.txt）
         <p id="ZH-CN_TOPIC_0000002336189082__p1250331184711">TensorFlow的原型定义文件可用于生成TensorFlow、Caffe、PyTorch框架的算子工程。</p></li>
        <li id="ZH-CN_TOPIC_0000002336189082__li14499355113613">适配<span id="ZH-CN_TOPIC_0000002336189082__ph396238162815">昇腾AI处理器</span>算子IR定义文件（.xlsx）</li>
       </ul>
      </div>
      <p></p></li>
     <li id="ZH-CN_TOPIC_0000002336189082__li874114104315"><span>请用户选择一种文件完成输入文件的准备工作。</span>

      <p id="ZH-CN_TOPIC_0000002336189082__p772517895612">示例：</p>
      <p id="ZH-CN_TOPIC_0000002336189082__p144421126270">使用IR_json.json模板作为输入创建原始框架为TensorFlow的算子工程。</p>
      <ol type="a" id="ZH-CN_TOPIC_0000002336189082__ol149562181112">
       <li id="ZH-CN_TOPIC_0000002336189082__li8952215114">创建算子工程。
        <div class="p" id="ZH-CN_TOPIC_0000002336189082__p158674014185">
         <a name="ZH-CN_TOPIC_0000002336189082__li8952215114"></a><a name="li8952215114"></a>TBE算子执行如下命令：
         <pre class="screen" id="ZH-CN_TOPIC_0000002336189082__screen15978151812185">msopgen gen -i <em id="ZH-CN_TOPIC_0000002336189082__i15661043185010">json_path/</em>IR_json.json -f tf -c ai_core-<em id="ZH-CN_TOPIC_0000002336189082__i167917430299">{Soc Version}</em> -out <em id="ZH-CN_TOPIC_0000002336189082__i11718135925112">./output_data</em></pre>
        </div>
        <div class="p" id="ZH-CN_TOPIC_0000002336189082__p1193594284415">
         AI CPU算子执行如下命令：
         <pre class="screen" id="ZH-CN_TOPIC_0000002336189082__zh-cn_topic_0261351675_screen15978151812185">msopgen gen -i <em id="ZH-CN_TOPIC_0000002336189082__zh-cn_topic_0261351675_i15661043185010">json_path/</em>IR_json.json -f tf -c aicpu -out <em id="ZH-CN_TOPIC_0000002336189082__zh-cn_topic_0261351675_i11718135925112">./output_data</em></pre>

         <li id="ZH-CN_TOPIC_0000002336189082__li137081341573">-i参数请修改为IR_json.json文件的实际路径。例如："<span id="ZH-CN_TOPIC_0000002336189082__ph10562197165916">${INSTALL_DIR}</span>/python/site-packages/op_gen/json_template/IR_json.json"。</li>
         <li id="ZH-CN_TOPIC_0000002336189082__li22721183190">TBE算子工程的-c参数中{Soc Version}为<span id="ZH-CN_TOPIC_0000002336189082__ph2065683517556">昇腾AI处理器</span>的型号。</li>
        </ul></li>
       <li id="ZH-CN_TOPIC_0000002336189082__li1741104211710">选择算子（可选）：
        <ul id="ZH-CN_TOPIC_0000002336189082__ul41938557540">
         <li id="ZH-CN_TOPIC_0000002336189082__li182251234551">若输入IR_json.json文件只有一个算子原型定义或使用-op参数指定算子类型请跳过此步骤。</li>
         <li id="ZH-CN_TOPIC_0000002336189082__li185898132437">若输入IR_json.json文件中包含多个原型定义，且没有使用-op参数指定算子类型工具会提示输入选择的算子序号，选择算子。
          <p id="ZH-CN_TOPIC_0000002336189082__p20512227131111"><a name="ZH-CN_TOPIC_0000002336189082__li185898132437"></a><a name="li185898132437"></a>工具会提示输入选择的算子序号，输入：1。</p>
          <pre class="screen" id="ZH-CN_TOPIC_0000002336189082__screen18624318161313">There is more than one operator in the .json file:

Input the number of the op: 1</pre>
