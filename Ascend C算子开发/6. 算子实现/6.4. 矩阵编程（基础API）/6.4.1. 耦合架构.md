    <h4 class="sectiontitle">编程范式</h4>
    <p>Cube编程范式把算子的实现流程分为5个基本任务：CopyIn，Split，Compute，Aggregate，CopyOut。CopyIn负责搬入操作，Split负责数据切分操作，Compute负责矩阵指令计算操作，Aggregate负责数据汇聚操作，CopyOut负责搬出操作。</p>
    <div class="fignone">
     <span class="figcap"><b>图1 </b>矩阵编程基本任务设计</span>
     <br><img class="eddx" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/figure/zh-cn_image_0000002370175173.png">
    </div>
    <p>具体任务之间的交互流程和流程图如下。</p>
    <ol>
     <li>Stage1：CopyIn任务。
      <p></p>
      <ol type="a">
       <li>使用<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0101.html">DataCopy</a>接口将GlobalTensor数据拷贝到LocalTensor。</li>
       <li>使用<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0140.html">EnQue</a>将LocalTensor放入A1/B1的Queue中。</li>
      </ol>
      <p></p></li>
     <li>Stage2：Split任务。
      <p></p>
      <ol type="a">
       <li>使用<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0141.html">DeQue</a>从A1/B1中取出LocalTensor。</li>
       <li>使用<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0238.html">17.1.1.5.8.2 LoadData</a>接口将LocalTensor从A1/B1中搬运到A2/B2。</li>
       <li>使用<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0140.html">EnQue</a>将计算结果LocalTensor放入到A2/B2的Queue中。</li>
      </ol>
      <p></p></li>
     <li>Stage3：Compute任务。
      <p></p>
      <ol type="a">
       <li>使用<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0141.html">DeQue</a>从A2/B2中取出LocalTensor。</li>
       <li>使用<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0249.html">Mmad</a>接口完成矩阵计算。</li>
       <li>使用<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0140.html">EnQue</a>将计算结果LocalTensor放入到CO1的Queue中。</li>
      </ol>
      <p></p></li>
     <li>Stage4：Aggregate任务。
      <p></p>
      <ol type="a">
       <li>使用<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0141.html">DeQue</a>从CO1中取出LocalTensor。</li>
       <li>使用<span>Ascend C</span>接口拷贝结果矩阵到CO2。</li>
       <li>使用<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0140.html">EnQue</a>将计算结果LocalTensor放入到CO2的Queue中。</li>
      </ol>
      <p></p></li>
     <li>Stage5：CopyOut任务。
      <p></p>
      <ol type="a">
       <li>使用<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0141.html">DeQue</a>接口从CO2的Queue中取出LocalTensor。</li>
       <li>使用<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0101.html">DataCopy</a>接口将LocalTensor拷贝到GlobalTensor上。</li>
      </ol>
      <p></p></li>
    </ol>

    <h4 class="sectiontitle">算子分析</h4>
    <p>在开发算子代码之前需要分析算子的数学表达式、输入、输出以及计算逻辑的实现，明确需要调用的<span>Ascend C</span>接口。</p>
    <ol>
     <li>明确算子的数学表达式及计算逻辑。
      <p></p>
      <div class="p">
       Matmul算子完成矩阵乘操作，其数学表达式如下，形状为[m, k]的矩阵a和形状为[k, n]的矩阵b相乘，得到形状为[m, n]的矩阵c。为了方便，令m=k=n=32。
       <pre class="screen">c = a * b</pre>
      </div>
      <p>注意需要处理的数据过大时，需要对数据进行切分并分块搬运到A2、B2，分别计算后再进行汇聚。下文的计算逻辑为了展示Split和Aggregate阶段的样例，请您根据实际需要处理的数据大小决定是否需要切分和汇聚。</p>
      <div class="p">
       计算逻辑如下：
       <ol type="a">
        <li>分别搬运输入数据矩阵a、b至Local Memory A1、B1。</li>
        <li>将a矩阵从A1搬运至A2。为实现部分并行，将b矩阵切分为part1和part2，形状均为[k, n / 2]，切分后再分块搬运至B2。</li>
        <li>a矩阵和b矩阵part1、part2分别做矩阵乘运算，获得矩阵c的part1和part2，形状均为[m, n / 2]。计算结果在CO1存储。</li>
        <li>将矩阵c的part1和part2分别拷贝到CO2进行合并。</li>
        <li>将合并后的输出数据从CO2搬出。</li>
       </ol>
      </div>
      <p></p></li>
     <li>明确输入和输出。
      <p></p>
      <ul>
       <li>Matmul算子有两个输入：a与b，输出为c。</li>
       <li>本样例中算子输入支持的数据类型为half（float16），算子输出的数据类型为float32。</li>
       <li>矩阵a、b、c的形状均为[32, 32]。</li>
       <li>算子输入输出支持的数据格式为：ND。</li>
      </ul>
      <p></p></li>
     <li>确定核函数名称和参数。
      <p></p>
      <ul>
       <li>您可以自定义核函数名称，本样例中核函数命名为matmul_custom。</li>
       <li>根据对算子输入输出的分析，确定核函数有3个参数a，b，c；a，b为输入在Global Memory上的内存地址，c为输出在Global Memory上的内存地址。</li>
      </ul>
      <p></p></li>
     <li>约束分析。
      <p></p>
      <p>由于硬件架构对矩阵乘计算的输入输出有格式约束，需要在算子实现中增加格式转换的流程。</p>
      <ul>
       <li>搬运矩阵a、b至A1、B1时，将ND格式的矩阵a、b转换为NZ格式。</li>
       <li>从A1搬运矩阵a至A2时，将NZ格式的a矩阵转换为ZZ格式；从B1搬运矩阵b到B2时将NZ格式的b矩阵转换为ZN格式。</li>
       <li>将计算结果从CO2搬出时，将NZ格式的c矩阵转换为ND格式。</li>
       <li>数据排布格式的相关介绍详见<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0099.html">数据排布格式</a>。</li>
      </ul>
      <p></p></li>
     <li>确定算子实现所需接口。
      <p></p>
      <ul>
       <li>实现外部存储和内部存储间的数据搬运，查看<span>Ascend C</span> API参考中的数据搬移接口，具体参考<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0101.html">DataCopy</a>。</li>
       <li>实现矩阵数据格式转换，查看<span>Ascend C</span> API参考中的数据转换接口，具体参考<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0238.html">LoadData</a>。</li>
       <li>矩阵计算过程涉及矩阵乘法，查看<span>Ascend C</span> API参考中的矩阵计算接口，具体参考<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0249.html">Mmad</a>。</li>
       <li>计算中使用到的Tensor数据结构，使用Queue队列进行管理，会使用到<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0140.html">EnQue</a>、<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0141.html">DeQue</a>等接口。</li>
      </ul>
      <p></p></li>
    </ol>

          <li>dstStride使用默认值0，目的矩阵两个分形连续存储。</li>
          <li>ifTranspose设置为true，每块分形搬运前为Z格式，搬运后需要为N格式，需要使能转置。</li>

         每次循环移动一个分形，搬运m*16个数。DataCopy参数说明如下：
         <ul>
          <li>blockCount设置为m，共搬运m次。</li>
          <li>blockLen设置为2，DataCopy指令一次搬运2个block，每个block16个数。</li>
          <li>srcStride设置为0，每两次搬运间没有间隙。</li>
          <li>dstStride设置为(nBlocks - 1) * 2，每两次搬运间隔2个block。</li>
          <li>每次循环迭代，目的矩阵偏移16，源矩阵偏移m*16。</li>
         </ul>
        </div>
        <p>格式转换示意图如下，第一次循环搬运蓝色部分数据，第二次循环搬运绿色部分数据。</p>
