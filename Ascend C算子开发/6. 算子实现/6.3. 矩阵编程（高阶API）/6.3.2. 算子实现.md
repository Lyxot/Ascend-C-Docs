    <h4 class="sectiontitle">实现流程</h4>
    <p>上文介绍了Matmul矩阵乘的数据切分方案和数据流。<span>Ascend C</span>提供一组Matmul高阶API，封装了这些常用的切分和数据搬运、计算的算法逻辑，方便用户快速实现Matmul矩阵乘法的运算操作。开发者在host侧通过调用API自动获取Tiling参数，该参数传递到kernel侧后，在初始化操作时传入，通过几个简单的API即可完成矩阵乘操作。完整样例请参考<span><a href="https://gitee.com/ascend/samples/tree/v1.5-8.2.RC1/operator/ascendc/0_introduction/10_matmul_frameworklaunch/MatmulCustomSingleCore" target="_blank" rel="noopener noreferrer">LINK</a></span>。</p>

    <h4 class="sectiontitle">设置Shape信息</h4>
    <p>在实现Host Tiling时可以设置Shape信息，用于Tiling计算；kernel侧运行时也可以修改部分Shape信息，用于尾块设置、Matmul复用（多个Matmul计算复用一个Matmul对象）等场景。本节对涉及到的Shape概念进行介绍，并给出host侧和kernel侧设置Tiling信息的指导。</p>
    <ul>
     <li>orgShape：M、N、K</li>
     <li>singleCoreShape：singleCoreM、singleCoreN、singleCoreK</li>
     <li>singleShape：singleM、singleN、singleK</li>
     <li>baseShape：baseM、baseN、baseK</li>
    </ul>
    <p>通过<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0037.html#ZH-CN_TOPIC_0000002370175001__section68451031218">数据分块（Tiling）</a>的介绍我们已经了解了orgShape(M、N、K)，singleCoreShape(singleCoreM、singleCoreN、singleCoreK)，baseShape(baseM、baseN、baseK)的概念，如下图所示：</p>
    <p><img class="eddx" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/figure/zh-cn_image_0000002336177446.png"></p>
    <p>除此之外，单核的Matmul Tiling时，实际参与Matmul计算的shape可以是原始shape中的一部分，singleM, singleN, singleK用于表达实际参与Matmul计算的shape，如下图所示。在单核的情况下，singleM, singleN, singleK会透传给singleCoreM, singleCoreN, singleCoreK。</p>
    <p><img src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/figure/zh-cn_image_0000002336177438.png"></p>
    <ul>
     <li>Kernel运行时设置
      <ul>
       <li><a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0647.html">SetTail</a>、<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0652.html">SetSingleShape</a>都是运行时修改singleCoreM、singleCoreN、singleCoreK，处理尾块时使用SetTail，Matmul复用（多个Matmul计算复用一个Matmul对象）的场景可以使用SetSingleShape重新设置。</li>
       <li><a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0651.html">SetOrgShape</a>是运行时修改M、N、K，Matmul复用的场景可以使用SetOrgShape重新设置。</li>
      </ul></li>
     <li>单核Tiling时设置
      <ul>
       <li><a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0680.html">SetOrgShape</a>（必选）：设置M、N、K</li>
       <li><a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0679.html">SetShape</a>（非必选）： 设置singleM、singleN、singleK，等同于设置singleCoreM、singleCoreN、singleCoreK</li>
       <li><a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0681.html">SetFixSplit</a>（非必选）：设置baseM、baseN、baseK</li>
      </ul></li>
     <li>多核Tiling时设置
      <ul>
       <li><a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0680.html">SetOrgShape</a>（必选）：设置M、N、K</li>
       <li><a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0679.html">SetShape</a>（非必选）： 设置singleM、singleN、singleK</li>
       <li><a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0681.html">SetFixSplit</a>（非必选）：设置baseM、baseN、baseK</li>
      </ul>
      <ul>
       <li><a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0678.html">SetSingleShape</a>(非必选)： 设置singleCoreM、singleCoreN、singleCoreK</li>
       <li><a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0694.html">SetSingleRange</a>(非必选) ：设置singleCoreM、singleCoreN、singleCoreK的范围</li>
      </ul></li>
    </ul>
