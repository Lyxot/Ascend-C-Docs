  <h1 class="topictitle1">矩阵向量乘</h1>
  <div>
   <div class="section">
    <h4 class="sectiontitle">功能介绍</h4>
    <p>矩阵向量乘（General Matrix-Vector multiplication），即GEMV，是指Matmul计算中M=1，形状为(1, K)的左矩阵A与形状为(K, N)的右矩阵B进行矩阵乘运算的场景。Matmul支持在Tiling侧与Kernel侧通过配置A矩阵的数据格式为<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0099.html#ZH-CN_TOPIC_0000002370174973__li51557161818">VECTOR</a>来开启GEMV模式，从而高效处理M=1的计算场景。若在M=1时未开启GEMV模式，Matmul计算则将M方向作为非对齐场景进行处理。GEMV模式相较于非对齐处理方式，搬运数据量更少，性能更好。</p>
    <p>以M=1，K=256，N=32，左右矩阵数据类型为half的Matmul为具体示例，说明GEMV模式的Matmul API内部处理过程。</p>
    <ul>
     <li>GEMV模式
      <div class="p">
       <a name="ZH-CN_TOPIC_0000002336176842__li64811914133216"></a><a name="li64811914133216"></a>将A矩阵从A1搬运到A2时，1*256的向量被当作16*16的矩阵进行处理，调用<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0238.html">LoadData</a>接口一次完成16*16分形大小的矩阵搬运。B矩阵的搬运以及矩阵乘计算跟基础场景相同，如下图所示。
       <div class="fignone">
        <span class="figcap"><b>图1 </b>GEMV模式M=1的矩阵乘计算示意图</span>
        <br><img class="eddx" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/figure/zh-cn_image_0000002370255017.png">
       </div>
      </div></li>
     <li>非GEMV模式
      <div class="p">
       <a name="ZH-CN_TOPIC_0000002336176842__li947019305324"></a><a name="li947019305324"></a>将A矩阵从A1搬运到A2时，1*256的向量被当作非对齐矩阵数据进行处理，将M方向对齐到32字节后进行搬运。调用<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0238.html">LoadData</a>接口每次搬运16*16分形大小的矩阵，一共搬运K/16=16次，导致搬运数据量增加，性能相较于GEMV模式差，如下图所示。
       <div class="fignone">
        <span class="figcap"><b>图2 </b>非GEMV模式M=1的矩阵乘计算示意图</span>
        <br><img class="eddx" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/figure/zh-cn_image_0000002370255009.png">
       </div>
      </div></li>
    </ul>
   </div>
   <div class="section">
    <h4 class="sectiontitle">使用场景</h4>
    <p>形状为(1, K)的A矩阵（M=1，K&gt;1）做矩阵乘计算，即输入A矩阵的数据是向量数据。</p>
   </div>
   <div class="section">
    <h4 class="sectiontitle">约束说明</h4>
    <ul>
     <li>在Matmul计算中，若要开启GEMV模式，A矩阵的原始输入形状M必须等于1。</li>
    </ul>
    <ul>
     <li>GEMV场景下，左矩阵A不支持转置。</li>
    </ul>
   </div>
