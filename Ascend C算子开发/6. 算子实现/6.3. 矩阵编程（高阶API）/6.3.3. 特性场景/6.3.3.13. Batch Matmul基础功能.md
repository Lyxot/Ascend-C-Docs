  <h1 class="topictitle1">Batch Matmul基础功能</h1>
  <div>
   <div class="section">
    <h4 class="sectiontitle">功能介绍</h4>
    <p>Batch Matmul是指批量处理Matmul计算的场景。该场景对外提供了<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0642.html">IterateBatch</a>的调用接口，调用一次IterateBatch，可以计算出多个singleCoreM * singleCoreN大小的C矩阵。</p>
    <p>Matmul单次计算的过程需要搬入和搬出数据，当进行多次Matmul计算且单次Matmul计算的输入shape较小时，搬运开销在整体耗时中占比较大。通过IterateBatch接口批量处理Matmul，可以有效提升带宽利用率。</p>
    <p>Batch Matmul当前支持4种Layout类型：<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0642.html#ZH-CN_TOPIC_0000002370171685__li298041002213">BSNGD</a>、<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0642.html#ZH-CN_TOPIC_0000002370171685__li6785191319227">SBNGD</a>、<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0642.html#ZH-CN_TOPIC_0000002370171685__li1922441712222">BNGS1S2</a>、<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0642.html#ZH-CN_TOPIC_0000002370171685__p553564441013">NORMAL</a>（BMNK的数据排布格式），相关数据排布格式请参考<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0642.html">IterateBatch</a>。</p>
   </div>
   <p>下图为NORMAL数据排布格式的Batch Matmul计算。整个Matmul计算一共包含4个矩阵乘操作：mat_a1*mat_b1、mat_a2*mat_b2、mat_a3*mat_b3、mat_a4*mat_b4，需要单核上计算四个singleCoreM *singleCoreN。在该场景下，如果shape较小，可以将其视为Batch Matmul场景进行批量处理，以提升性能。一次IterateBatch可同时计算出mat_c1 = mat_a1 * mat_b1、mat_c2 = mat_a2 * mat_b2、mat_c3 = mat_a3 * mat_b3、mat_c4 = mat_a4 * mat_b4。</p>

   <div class="section">
    <h4 class="sectiontitle">使用场景</h4>
    <p>Matmul计算需要计算出多个singleCoreM * singleCoreN大小的C矩阵，且单次Matmul计算处理的shape较小。</p>
   </div>
   <div class="section">
    <h4 class="sectiontitle">约束说明</h4>
    <ul>
     <li>只支持<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0616.html">Norm模板</a>。</li>
     <li>对于BSNGD、SBNGD、BNGS1S2 Layout格式，输入A、B矩阵按分形对齐后的多Batch数据总和应小于L1 Buffer的大小；对于NORMAL Layout格式没有这种限制，但需通过<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0616.html#ZH-CN_TOPIC_0000002336332840__table1761013213153">MatmulConfig</a>配置<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0616.html#ZH-CN_TOPIC_0000002336332840__p7593533192910">batchMode</a>参数，即输入A、B矩阵多Batch数据大小与L1 Buffer的大小关系；</li>
     <li>对于BSNGD、SBNGD、BNGS1S2 Layout格式，称左矩阵、右矩阵的G轴分别为ALayoutInfoG、BLayoutInfoG，则ALayoutInfoG / batchA = BLayoutInfoG / batchB；对于NORMAL Layout格式，batchA 、batchB必须满足倍数关系。</li>
     <li>如果接口输出到Unified Buffer上，输出C矩阵大小BaseM*BaseN应小于分配的Unified Buffer内存大小。</li>
     <li>对于BSNGD、SBNGD Layout格式，输入输出只支持ND格式数据。对于BNGS1S2、NORMAL Layout格式， 输入支持ND/NZ格式数据。</li>
     <li>Batch Matmul不支持量化/反量化模式，即不支持<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0649.html">SetQuantScalar</a>、<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0650.html">SetQuantVector</a>接口。</li>
     <li>BSNGD场景，不支持一次计算多行SD，需要算子程序中循环计算。</li>
     <li><strong>异步模式</strong>不支持IterateBatch搬运到Unified Buffer上。</li>
     <li>模板参数<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0616.html#ZH-CN_TOPIC_0000002336332840__p9218181073719">enableMixDualMaster</a>（默认取值为false）设置为true，即使能MixDualMaster（双主模式）场景时，不支持Batch Matmul。</li>
     <li>在batch场景，A矩阵、B矩阵支持half/float/bfloat16_t/int8_t数据类型，不支持int4b_t数据类型。</li>
    </ul>
   </div>
