  <h1 class="topictitle1">多核非对齐切分</h1>
  <div>
   <div class="section">
    <h4 class="sectiontitle">功能介绍</h4>
    <p>多核场景，对矩阵进行切分时，若M、N、K无法整除singleCoreM 、singleCoreN、 singleCoreK时，就会出现尾块，即多核非对齐场景。如下图矩阵A、B的最后一行和最后一列的矩阵块：</p>
    <p><img class="imgResize" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/figure/zh-cn_image_0000002370255373.png" title="点击放大"></p>
    <p>此时，C矩阵中的R矩阵块，依然是通过A1*B1+A2*B2+A3*B3+A4*B4累加得到的，处理A1*B1、A2*B2、A3*B3、A4*B4等尾块时，需在kernel侧设置尾块大小，在不改变原有tiling的情况下，调用<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0647.html">SetTail</a>接口重新设置本次计算的singleCoreM/singleCoreN/singleCoreK，在处理尾块的时候按照设置的值也就是tailM/tailN/tailK进行搬运和计算。</p>
   </div>
   <div class="section">
    <h4 class="sectiontitle">使用场景</h4>
    <p>多核处理Matmul矩阵计算，存在尾块的场景。</p>
   </div>
   <div class="section">
    <h4 class="sectiontitle">约束说明</h4>
    <p>处理尾块调用的SetTail接口，需要在Iterate/IterateAll之前调用。</p>
   </div>
