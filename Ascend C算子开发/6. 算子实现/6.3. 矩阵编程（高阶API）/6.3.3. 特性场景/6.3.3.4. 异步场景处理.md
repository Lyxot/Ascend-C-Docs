  <h1 class="topictitle1">异步场景处理</h1>
  <div>
   <div class="section">
    <h4 class="sectiontitle">功能介绍</h4>
    <p>Matmul的<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0638.html">Iterate</a>和<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0640.html">IterateAll</a>接口在MIX场景（包含矩阵计算和矢量计算）下提供了同步和异步两种模式，纯Cube场景（只有矩阵计算）下，只支持同步模式。</p>
    <p>同步模式指的是程序执行时，需要等待某个操作完成后才能继续执行下一步操作。 异步模式指的是程序执行时，不需要等待某个操作完成就可以继续执行下一步操作。</p>
    <ul>
     <li>Iterate&amp;GetTensorC的同步和异步 
      <ul>
       <li>同步：执行完一次Iterate迭代计算后，执行<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0639.html">GetTensorC</a>搬运矩阵C分片，搬运完成后，才能进行下一次计算。如下图所示，C矩阵中，矩阵块1搬走后，才能计算矩阵块2，矩阵块2搬运完成后，才能计算矩阵块3。 
        <p><img class="imgResize" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/figure/zh-cn_image_0000002370254969.png" title="点击放大"></p>

        </div></li>
       <li>异步：通过设置Iterate接口的模板参数开启异步模式。调用Iterate后，无需立即调用GetTensorC同步等待矩阵C分块搬运完成，可以先执行其它操作，待需要获取结果时再调用GetTensorC。异步模式可以减少同步等待，提高并行度，开发者对计算性能要求较高时，可以选用该方式。异步场景时，需要使用一块临时空间来缓存Iterate计算结果，否则会覆盖计算结果，调用GetTensorC时会在该临时空间中获取C的矩阵分片。临时空间通过<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0654.html">SetWorkspace</a>接口进行设置。SetWorkspace接口需要在Iterate接口之前调用。

   <div class="section">
    <h4 class="sectiontitle">使用场景</h4>
    <ul>
     <li>Iterate&amp;GetTensorC的同步：MIX场景（包含矩阵计算和矢量计算）、纯Cube场景（只有矩阵计算）。</li>
     <li>Iterate&amp;GetTensorC的异步：仅MIX场景（包含矩阵计算和矢量计算）。</li>
     <li>IterateAll的同步：MIX场景（包含矩阵计算和矢量计算）、纯Cube场景（只有矩阵计算）。</li>
     <li>IterateAll的异步：仅MIX场景（包含矩阵计算和矢量计算）。</li>
    </ul>
   </div>
   <div class="section">
    <h4 class="sectiontitle">约束说明</h4>
    <ul>
     <li>Iterate&amp;GetTensorC的异步场景： 
      <ul>
       <li>传入的C矩阵地址空间大小需要保证不小于baseM * baseN。</li>
       <li>SetWorkspace接口需要在Iterate接口之前调用。</li>
       <li>支持只输出到VECIN、只输出到Global Memory，同时输出到Global Memory和VECIN三种输出方式。</li>
       <li>取出C矩阵到VECIN时，数据格式仅支持NZ；取出C矩阵到GM时，数据格式支持ND或NZ。</li>
      </ul></li>
     <li>IterateAll的异步场景： 
      <ul>
       <li>传入的C矩阵地址空间大小需要保证不小于singleCoreM * singleCoreN。</li>
       <li>仅支持连续输出至Global Memory。</li>
      </ul></li>
    </ul>
   </div>
