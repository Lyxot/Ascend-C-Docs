  <h1 class="topictitle1">AIC和AIV独立运行机制</h1>
  <div>
   <div class="section">
    <h4 class="sectiontitle">功能介绍</h4>
    <p>AIC和AIV独立运行机制，又称双主模式。在<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0008.html#ZH-CN_TOPIC_0000002336176974__section349312501823">分离架构</a>下，区别于MIX模式（包含矩阵计算和矢量计算）通过消息机制驱动AIC运行，双主模式为AIC和AIV独立运行代码，不依赖消息驱动，使能双主模式能够提高Matmul计算性能。默认情况下，双主模式不使能，需要通过<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0616.html#ZH-CN_TOPIC_0000002336332840__table1761013213153">MatmulConfig</a>中的enableMixDualMaster参数开启。</p>
   </div>
   <div class="section">
    <h4 class="sectiontitle">使用场景</h4>
    <p>算子中的矩阵计算和矢量计算相关代码独立运行，不依赖消息驱动时，可以开启双主模式，以提高Matmul计算性能。</p>
   </div>
   <div class="section">
    <h4 class="sectiontitle">约束说明</h4>
    <ul>
     <li>该功能仅支持<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0616.html">Norm模板</a>和<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0616.html">MDL模板</a>。</li>
     <li>算子核函数的类型为MIX，同时AIC核数 : AIV核数为1:1。</li>
     <li>算子核函数的类型为MIX，同时AIC核数 : AIV核数为1:2，且A矩阵和B矩阵同时使能<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0614.html#ZH-CN_TOPIC_0000002370251917__table1188045714378">IBSHARE</a>参数。</li>
    </ul>
    <ul>
     <li>同一算子中所有Matmul对象的该参数取值必须保持一致。</li>
     <li>A、B、Bias矩阵只支持从Global Memory输入。</li>
     <li>获取矩阵计算结果只支持调用<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0640.html">IterateAll</a>接口输出到<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0007.html">GlobalTensor</a>，即计算结果放置于Global Memory的地址，不能调用<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0639.html">GetTensorC</a>等接口获取结果。</li>
    </ul>
   </div>
