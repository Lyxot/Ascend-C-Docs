<h1 class="topictitle1">算子包部署</h1>
<div><p>算子包部署指执行自定义算子包的安装，算子工程的编译结果会自动部署到算子包安装目录下。</p>
<div class="section"><h4 class="sectiontitle">算子包部署</h4><ol><li>自定义算子包安装部署。<p><p>在自定义算子包所在路径下，执行如下命令，安装自定义算子包。</p>
<p><strong>./custom_opp_</strong><em>&lt;target os&gt;</em><strong><em>_</em></strong><em>&lt;target architecture&gt;</em><strong>.run</strong> <strong>--install-path</strong><em><strong>=</strong>&lt;path&gt;</em></p>
<p>--install-path为可选参数，用于指定自定义算子包的安装目录。支持指定绝对路径，运行用户需要对指定的安装路径有可读写权限。</p>
<div class="p">下文描述中的<em>&lt;vendor_name&gt;</em>为算子工程编译时CMakePresets.json配置文件中字段“vendor_name”的取值，默认为“customize”。<ul><li>默认安装场景，不配置--install-path参数，安装成功后会将编译生成的自定义算子相关文件部署到<span>${INSTALL_DIR}</span>/opp/vendors/<em>&lt;vendor_name&gt;</em>目录。<span>${INSTALL_DIR}请替换为CANN软件安装后文件存储路径。例如，若安装的Ascend-cann-toolkit软件包，安装后文件存储路径示例为：$HOME/Ascend/ascend-toolkit/latest。</span><div class="note"><img src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/public_sys-resources/note_3.0-zh-cn.png"><span class="notetitle"> </span><div class="notebody"><p>自定义算子包默认安装路径<span>${INSTALL_DIR}</span>/opp/vendors的目录权限与CANN软件包安装用户和安装配置有关。如果因权限不足导致自定义算子包安装失败，可使用<em>--install-path</em>参数并配置环境变量ASCEND_CUSTOM_OPP_PATH来指定安装目录（参考<a href="#ZH-CN_TOPIC_0000002370175005__li1652971821912">指定目录安装</a>）或者联系CANN软件包的安装用户修改vendors目录权限来解决。详细的案例请参考<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_00003.html">调用算子时出现无法打开config.ini的报错</a>和<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_00004.html">算子包部署时出现权限不足报错</a>。</p>
</div></div>
</li><li><a name="ZH-CN_TOPIC_0000002370175005__li1652971821912"></a><a name="li1652971821912"></a>指定目录安装场景，配置--install-path参数，安装成功后会将编译生成的自定义算子相关文件部署到&lt;<em>path</em>&gt;/vendors/<em>&lt;vendor_name&gt;</em>目录，并在<em>&lt;</em><em>path</em><em>&gt;</em>/vendors/<em>&lt;vendor_name&gt;/</em><em>bin</em>目录下新增set_env.bash，写入当前自定义算子包相关的环境变量。<div class="notice"><span class="noticetitle"><img src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/public_sys-resources/notice_3.0-zh-cn.png"> </span><div class="noticebody"><p>如果部署算子包时通过配置--install-path参数指定了算子包的安装目录，则在使用自定义算子前，需要执行<strong>source <em>&lt;</em><em>path</em><em>&gt;</em>/vendors/<em>&lt;vendor_name&gt;/</em></strong><em><strong>bin/set_env.bash</strong></em>命令，<strong>set_env.bash</strong>脚本中将自定义算子包的安装路径追加到环境变量ASCEND_CUSTOM_OPP_PATH中，使自定义算子在当前环境中生效。</p>
</div></div>
</li></ul>
</div>
<p>命令执行成功后，自定义算子包中的相关文件将部署至当前环境中。</p>
</p></li><li>以默认安装场景为例，可查看部署后的目录结构，如下所示：<p><pre class="screen">├── opp    //算子库目录
│   ├── vendors     //自定义算子所在目录
│       ├── config.ini
│       └── <strong><em>vendor_name1</em></strong>   // 存储对应厂商部署的自定义算子，此名字为编译自定义算子安装包时配置的vendor_name，若未配置，默认值为customize
│           ├── framework     //自定义算子插件库
│           ├── op_api
│           │   ├── include
│           │   │  └── aclnn_<em>xx</em>.h      //算子调用API声明文件
│           │   └── lib
│           │       └── libcust_opapi.so
│           ├── op_impl
│           │   └── ai_core
│           │       └── tbe
│           │           ├── config
│           │           │   └── <em>${soc_version}</em>     //<span>昇腾AI处理器</span>类型
│           │           │       └── aic-<em>${soc_version}</em>-ops-info.json     //自定义算子信息库文件
│           │           ├── <em>vendor_name1</em>_impl    //自定义算子实现代码文件
│           │           │   └── dynamic
│           │           │       ├── <em>xx</em>.cpp
│           │           │       └── <em>xx</em>.py
│           │           ├── kernel     //自定义算子二进制文件
│           │           │   └── <em>${soc_version}</em>     //<span>昇腾AI处理器</span>类型
│           │           │   └── config
│           │           └── op_tiling
│           │               ├── lib
│           │               └── liboptiling.so 
│           └── op_proto     //自定义算子原型库所在目录
│                ├── inc
│                │   └── op_proto.h
│                └── lib
│       ├── <strong><em>vendor_name2</em></strong>   // 存储厂商<em>vendor_name2</em>部署的自定义算子</pre>
</p></li><li>配置自定义算子优先级。<p><div class="p">多算子包共存的情况下，若不同的算子包目录下存在相同OpType的自定义算子，则以优先级高的算子包目录下的算子为准。下面介绍如何配置算子包优先级：<ul><li>默认安装场景<p><a name="ZH-CN_TOPIC_0000002370175005__li156991057143519"></a><a name="li156991057143519"></a>当“opp/vendors”目录下存在多个厂商的自定义算子时，您可通过配置“opp/vendors”目录下的“config.ini”文件，配置自定义算子包的优先级。</p>
<p>“config.ini”文件的配置示例如下：</p>
<pre class="screen"><strong>load_priority=</strong><em>vendor_name</em>1,<em>vendor_name</em>2,<em>vendor_name</em>3</pre>
<ul><li>“load_priority”：优先级配置序列的关键字，不允许修改。</li><li>“<em>vendor_name</em>1,<em>vendor_name</em>2,<em>vendor_name</em>3”：自定义算子厂商的优先级序列，按照优先级从高到低的顺序进行排列。</li></ul>
</li><li>指定目录安装场景<p><a name="ZH-CN_TOPIC_0000002370175005__li10326944153612"></a><a name="li10326944153612"></a>指定目录安装场景下，如果需要多个自定义算子包同时生效，分别执行各算子包安装路径下的<strong>s</strong><strong>et_env.bash</strong>脚本即可。每次脚本执行都会将当前算子包的安装路径追加到ASCEND_CUSTOM_OPP_PATH环境变量的最前面。因此可以按照脚本执行顺序确定优先级：脚本执行顺序越靠后，算子包优先级越高。</p>
<p>比如先执行<strong>source <em>&lt;</em><em>path</em><em>&gt;/</em><em>vendor_name1/</em></strong><em><strong>bin/set_env.bash</strong></em>，后执行<strong>source <em>&lt;</em><em>path</em><em>&gt;/</em><em>vendor_name2/</em></strong><em><strong>bin/set_env.bash</strong></em>，vendor_name2算子包的优先级高于vendor_name1。ASCEND_CUSTOM_OPP_PATH示例如下：</p>
<pre class="screen">ASCEND_CUSTOM_OPP_PATH=&lt;<em>path</em>&gt;/<em>vendor_name2</em>:&lt;<em>path</em>&gt;/<em>vendor_name1</em>：</pre>
</li><li>指定目录安装场景下安装的算子包优先级高于默认方式安装的算子包。</li></ul>
</div>
</p></li></ol>
</div>
<div class="section"><h4 class="sectiontitle">多平台算子包部署</h4><p>支持安装多平台的自定义算子包，安装时同样支持默认路径和自定义路径安装。</p>
<p>以默认路径安装为例，在aarch64平台上分别安装aarch64平台和x86_64平台算子包，安装成功后可查看目录结构兼容两种平台类型，如下所示：</p>
<pre class="screen">├── opp    //算子库目录
│   ├── vendors     //自定义算子所在目录
│       ├── config.ini
│       └── vendor_name1   // 存储对应厂商部署的自定义算子，此名字为编译自定义算子安装包时配置的vendor_name，若未配置，默认值为customize
│           ├── framework     //自定义算子插件库
│           ├── op_impl
│           │   └── ai_core
│           │       └── tbe
│           │           ├── config
│           │           │   └── <em>${soc_version}</em> 
│           │           │       └── aic-<em>${soc_version}</em>-ops-info.json     //自定义算子信息库文件
│           │           ├── <em>vendor_name1</em>_impl    //自定义算子实现代码文件
│           │           │   └── dynamic
│           │           │       ├── <em>xx</em>.cpp
│           │           │       └── <em>xx</em>.py
│           │           ├── kernel     //自定义算子二进制文件
│           │           │   └── <em>${soc_version}</em>     
│           │           │   └── config
│           │           └── op_tiling
│           │               ├── lib
│           │               │   └──linux
│           │               │       ├──<strong>aarch64</strong>
│           │               │       │   └──libcust_opmaster_rt2.0.so
│           │               │       └──<strong>x86_64</strong>
│           │               │            └──libcust_opmaster_rt2.0.so
│           │               └── <strong>liboptiling.so</strong>  -&gt; lib/linux/aarch64/libcust_opmaster_rt2.0.so
│           └── op_proto     //自定义算子原型库所在目录
│               ├── inc
│               │   └── op_proto.h
│               └── lib
│                    └──linux
│                         ├──<strong>aarch64</strong>
│                         │   └──libcust_opsproto_rt2.0.so
│                         └──<strong>x86_64</strong>
│                              └──libcust_opsproto_rt2.0.so
│       ├── vendor_name2   // 存储厂商<em>vendor_name2</em>部署的自定义算子</pre>
