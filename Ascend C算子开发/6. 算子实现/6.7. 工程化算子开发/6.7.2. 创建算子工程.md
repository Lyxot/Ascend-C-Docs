  <h1 class="topictitle1">创建算子工程</h1>
  <div>
   <p>CANN开发套件包中提供了自定义算子工程生成工具msOpGen，可基于算子原型定义输出算子工程：包括<strong>算子host侧代码实现文件</strong>、<strong>算子kernel侧实现文件</strong>以及<strong>工程编译配置文件等</strong>。</p>
   <div class="note">
    <img src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/public_sys-resources/note_3.0-zh-cn.png"><span class="notetitle"> </span>
    <div class="notebody">
     <p>使用msOpGen工具创建算子工程之前，需要参考<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0002.html">环境准备</a>章节安装驱动固件和CANN软件包，完成开发环境和运行环境的准备。</p>
    </div>
   </div>
   <p>使用msOpGen工具创建算子开发工程的步骤如下：</p>
   <ol>
    <li>编写算子的原型定义json文件，用于生成算子开发工程。json文件的配置参数详细说明请参考<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/devaids/optool/atlasopdev_16_0021.html#ZH-CN_TOPIC_0000002370267097__zh-cn_topic_0000001740005677_table8534182020116">表1</a>。
     <p></p>
     <div class="p">
      例如，AddCustom算子的json文件命名为add_custom.json，文件内容如下：
      <pre class="screen">[
    {
        "op": "AddCustom",
        "input_desc": [
            {
                "name": "x",
                "param_type": "required",
                "format": [
                    "ND",
                    "ND",
                    "ND"
                ],
                "type": [
                    "float16",
                    "float",
                    "int32"
                ]
            },
            {
                "name": "y",
                "param_type": "required",
                "format": [
                    "ND",
                    "ND",
                    "ND"
                ],
                "type": [
                    "float16",
                    "float",
                    "int32"
                ]
            }
        ],
        "output_desc": [
            {
                "name": "z",
                "param_type": "required",
                "format": [
                    "ND",
                    "ND",
                    "ND"
                ],
                "type": [
                    "float16",
                    "float",
                    "int32"
                ]
            }
        ]
    }
]</pre>
     </div>
     <div class="p">
      例如，ReduceMaxCustom算子（包含属性）的json文件命名为reduce_max_custom.json，文件内容如下：
      <pre class="screen">[
    {
        "op": "ReduceMaxCustom",
         "input_desc": [
            {
                "name": "x",
                "param_type": "required",
                "format": ["ND"],
                "type": ["float16"]
            }
        ],
        "output_desc": [
            {
                "name": "y",
                "param_type": "required",
                "format": ["ND"],
                "type": ["float16"]
            },
            {
                "name": "idx",
                "param_type": "required",
                "format": ["ND"],
                "type": ["int32"]
            }
        ],
        "attr": [                                                                   
            {
                "name": "reduceDim",
                "param_type": "required",
                "type": "int"
            },
            {
                "name": "isKeepDim",
                "param_type": "optional",
                "type": "int",
                "default_value": 1
            }
        ]
    }
]</pre>
     </div>
     <p></p></li>
    <li>使用msOpGen工具生成算子的开发工程。以生成AddCustom的算子工程为例，下文仅针对关键参数进行解释，详细参数说明请参见<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/devaids/optool/atlasopdev_16_0017.html">算子工程创建（msOpGen）</a>。
     <p></p>
     <pre class="screen"><strong><span>${INSTALL_DIR}</span></strong>/python/site-packages/bin/msopgen gen -i<strong> </strong>$HOME/sample/add_custom.json -c ai_core-<strong><span><em>&lt;soc_version&gt;</em></span> </strong>-lan cpp -out $HOME/sample/AddCustom</pre>
     <ul>
      <li><strong><span>${INSTALL_DIR}</span></strong>为CANN软件安装后文件存储路径，请根据实际环境进行替换。</li>
      <li>-i：指定算子原型定义文件<em>add_custom</em>.json所在路径，请根据实际情况修改。</li>
      <li>-c：ai_core-<span><em>&lt;soc_version&gt;</em></span>代表算子在AI Core上执行，<span><em>&lt;soc_version&gt;</em></span>为<span>昇腾AI处理器</span>的型号。
       <div class="note">
        <img src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/public_sys-resources/note_3.0-zh-cn.png"><span class="notetitle"> </span>
        <div class="notebody">
         <p>AI处理器的型号<span><em>&lt;soc_version&gt;</em></span>请通过如下方式获取：</p>
         <ul>
          <li>非<span><term>
             Atlas A3 训练系列产品/Atlas A3 推理系列产品
            </term></span>：在安装<span>昇腾AI处理器</span>的服务器执行<strong>npu-smi info</strong>命令进行查询，获取<strong>Name</strong>信息。实际配置值为AscendName，例如<strong>Name</strong>取值为<em>xxxyy</em>，实际配置值为Ascend<em>xxxyy</em>。</li>
          <li><span><term>
             Atlas A3 训练系列产品/Atlas A3 推理系列产品
            </term></span>：在安装<span>昇腾AI处理器</span>的服务器执行<strong>npu-smi info -t board -i </strong><em>id</em><strong> -c </strong><em>chip_id</em>命令进行查询，获取<strong>Chip Name</strong>和<strong>NPU Name</strong>信息，实际配置值为Chip Name_NPU Name。例如<strong>Chip Name</strong>取值为Ascend<em>xxx</em>，<strong>NPU Name</strong>取值为1234，实际配置值为Ascend<em>xxx</em><em>_</em>1234。
           <p>其中：</p>
           <ul>
            <li>id：设备id，通过<strong>npu-smi info -l</strong>命令查出的NPU ID即为设备id。</li>
            <li>chip_id：芯片id，通过<strong>npu-smi info -m</strong>命令查出的Chip ID即为芯片id。</li>
           </ul></li>
         </ul>
         <p>基于同系列的AI处理器型号创建的算子工程，其基础功能（基于该工程进行算子开发、编译和部署）通用。</p>
        </div>
       </div></li>
      <li>-lan： 参数cpp代表算子基于Ascend C编程框架，使用C/C++编程语言开发。</li>
      <li>-out：生成文件所在路径，可配置为绝对路径或者相对路径，并且工具执行用户对路径具有可读写权限。若不配置，则默认生成在执行命令的当前路径。</li>
     </ul>
     <p></p></li>
    <li>命令执行完后，会在-out指定目录或者默认路径下生成算子工程目录，工程中包含算子实现的模板文件，编译脚本等，以AddCustom算子为例，目录结构如下所示：
     <p></p>
     <pre class="screen">AddCustom
├── build.sh         // 编译入口脚本
├── cmake            // 算子工程编译所需脚本及公共编译文件存放目录
├── CMakeLists.txt    // 算子工程的CMakeLists.txt
├── <strong>CMakePresets.json</strong>    // 编译配置项
├── framework        // AI框架适配时，算子插件实现文件目录
├── op_host                      // host侧实现文件
│   ├── <strong>add_custom_tiling.h</strong><strong>    // 算子tiling定义文件</strong>
│   ├── <strong>add_custom.cpp</strong><strong>         // 算子原型注册、shape推导、信息库、tiling实现等内容文件</strong>
│   ├── CMakeLists.txt
├── op_kernel                   // kernel侧实现文件
│   ├── CMakeLists.txt   
│   ├── <strong>add_custom.cpp</strong><strong>        // 算子代码实现文件</strong> 
└── scripts                     // 自定义算子工程打包相关脚本所在目录</pre>
     <div class="note">
      <img src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/public_sys-resources/note_3.0-zh-cn.png"><span class="notetitle"> </span>
      <div class="notebody">
       <ul>
        <li>上述目录结构中的粗体文件为后续算子开发过程中需要修改的文件，其他文件无需修改。</li>
        <li>kernel侧实现依赖的所有文件需全部放置在op_kernel目录下，不遵循该约束会导致<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0068.html#ZH-CN_TOPIC_0000002336336606__li139988411333">源码发布</a>场景在线编译失败。因为在后续的算子源码发布时，只会打包发布op_kernel目录下的文件。</li>
       </ul>
      </div>
     </div>
     <p></p></li>
   </ol>
   <p>工程目录中的op_kernel和op_host包含了算子的核心实现文件。op_kernel下存放<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0063.html">kernel侧算子实现</a>。op_host下存放host侧代码实现，包括<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0062.html">算子原型定义</a>、<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0064.html">host侧tiling实现</a>。其中kernel侧算子实现和host侧tiling实现在<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0030.html">算子实现</a>章节已经介绍了其核心的实现方法，在该章节会侧重于介绍接入CANN框架后的编程模式和API的使用。工程目录中的CMakePresets.json，用于开发者完成工程编译相关配置，之后即可进行编译部署。</p>
  </div>
