  <h1 class="topictitle1">单算子API调用</h1>
  <div>
   <p>单算子API调用方式，是指直接调用单算子API接口，基于C语言的API执行算子。算子工程创建完成后，基于工程代码框架完成算子原型定义、kernel侧算子实现、host侧tiling实现，通过工程编译脚本完成算子的编译部署，之后再进行单算子API的调用。</p>
   <div class="section">
    <h4 class="sectiontitle">基本原理</h4>
    <p>完成自定义算子编译后，会自动生成单算子API，可以直接在应用程序中调用。</p>
    <p>单算子API的形式一般定义为“两段式接口”，形如：</p>

    <ul>
     <li>参考<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0060.html">创建算子工程</a>完成自定义算子工程的创建或者参考<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0101.html">简易自定义算子工程</a>完成简易自定义算子工程的创建。</li>
     <li>参考<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0063.html">Kernel侧算子实现</a>完成kernel侧实现的相关准备，参考<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0064.html">Host侧tiling实现</a>、<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0062.html">算子原型定义</a>完成host侧实现相关准备。</li>
     <li>对于自定义算子工程，参考<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0068.html">算子工程编译</a>、<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0069.html">算子包部署</a>完成算子的编译部署，编译部署时需要开启算子的二进制编译功能：修改算子工程中的编译配置项文件CMakePresets.json，将ENABLE_BINARY_PACKAGE设置为True。编译部署时可将算子的二进制部署到当前环境，便于后续算子的调用。
      <pre class="screen">"ENABLE_BINARY_PACKAGE": {
                    "type": "BOOL",
                    <strong>"value": "True"</strong>
                },</pre>
      <p>算子编译部署后，会在算子包安装目录下的op_api目录生成单算子调用的头文件aclnn_<em>xx</em>.h和动态库libcust_opapi.so。</p>
      <div class="p">
       以默认安装场景为例，单算子调用的头文件.h和动态库libcust_opapi.so所在的目录结构，如下所示：
       <pre class="screen">├── opp    //算子库目录
│   ├── vendors     //自定义算子所在目录
│       ├── config.ini
│       └── <strong><em>vendor_name1</em></strong>   // 存储对应厂商部署的自定义算子，此名字为编译自定义算子安装包时配置的vendor_name，若未配置，默认值为customize
│           ├── op_api
│           │   ├── include
│           │   │  └── aclnn_<em>xx</em>.h
│           │   └── lib
│           │       └── libcust_opapi.so
...</pre>
      </div></li>
     <li>对于简易自定义算子开发工程，参考<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0101.html">简易自定义算子工程</a>完成算子的编译。编译完成后会在如下路径生成单算子调用的头文件aclnn_<em>xx</em>.h和动态库libcust_opapi.so。其中CMAKE_INSTALL_PREFIX为开发者在cmake文件中配置的编译产物存放路径。
      <ul>
       <li>动态库路径：${CMAKE_INSTALL_PREFIX}/op_api/lib/libcust_opapi.so</li>
       <li>头文件路径：${CMAKE_INSTALL_PREFIX}/op_api/include</li>
      </ul></li>
    </ul>
   </div>
