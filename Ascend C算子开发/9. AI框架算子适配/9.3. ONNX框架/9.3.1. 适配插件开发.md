  <h1 class="topictitle1">适配插件开发</h1>
  <div>
   <div class="note">
    <img src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/public_sys-resources/note_3.0-zh-cn.png"><span class="notetitle"> </span>
    <div class="notebody">
     <p>针对<span><term>
        Atlas A3 训练系列产品/Atlas A3 推理系列产品
       </term></span>，暂不支持<span>ONNX</span>框架算子调用。</p>
    </div>
   </div>
   <p>您可以参考本章节进行算子适配插件的开发，将ONNX框架的算子映射成适配<span>昇腾AI处理器</span>的算子（下文简称<span>CANN</span>算子），从而完成从<span>ONNX</span>框架调用Ascend C自定义算子的过程。</p>
   <p>完成<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0088.html#ZH-CN_TOPIC_0000002336176898__li123241091016">算子工程创建</a>后，会在算子工程目录下生成framework/onnx_plugin目录，用于存放ONNX框架适配插件实现文件。以自定义CANN算子LeakyReluCustom为例，算子工程目录如下：</p>
   <pre class="screen">LeakyReluCustom
├── build.sh             // 编译入口脚本
├── cmake 
├── CMakeLists.txt       // 算子工程的CMakeLists.txt
├── CMakePresets.json    // 编译配置项
├── framework            // 框架适配插件实现文件目录
│   ├── <strong>onnx_plugin</strong><strong>    </strong> //  ONNX框架适配插件实现文件目录
│   │   ├── CMakeLists.txt<strong>    </strong>
│   │   ├── <strong>leaky_relu_custom_plugin.cc</strong> // ONNX框架适配插件实现文件   <strong> </strong>
│   ├── CMakeLists.txt
├── op_host                      // host侧实现文件
├── op_kernel                    // kernel侧实现文件
└── scripts                      // 自定义算子工程打包相关脚本所在目录</pre>

   <ol>
    <li>包含所需头文件。
     <p></p>
     <ul>
      <li>register.h，存储在<span>CANN软件安装后文件存储路径</span>的“include/register/”目录下，包含该头文件，可使用算子注册相关类，调用算子注册相关的接口。</li>
      <li>operator.h（可选），存储在<span>CANN软件安装后文件存储路径</span>的“include/graph/”目录下，包含该头文件，可以使用Operator类相关接口，获取算子输入输出及属性等算子信息。</li>
      <li>json.hpp，用于进行<span>ONNX</span>数据定义的解析，将String类型的算子参数定义转换为json格式。若样例工程中未提供“json.hpp”文件，用户可以自行下载，并将“json.hpp”放在工程可以找到的任意路径下，然后包含此头文件即可，下载路径可参见<a href="https://github.com/nlohmann/json/blob/develop/include/nlohmann/json.hpp" target="_blank" rel="noopener noreferrer">json.hpp</a>。</li>
     </ul>
     <p></p></li>
    <li>使用REGISTER_CUSTOM_OP宏，完成<span>CANN算子和ONNX框架的算子映射关系注册。使用方法如下：</span>
     <p></p>
     <ul>
      <li>REGISTER_CUSTOM_OP：注册自定义算子，<em>OpType</em>为算子类型名称，需要与<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0062.html">算子原型注册</a>中的<em>OpType</em>保持一致。</li>
      <li><a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/basicdataapi/atlasopapi_07_00387.html">FrameworkType</a>：ONNX代表原始框架为<span>ONNX</span>。</li>
      <li><a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/basicdataapi/atlasopapi_07_00388.html">OriginOpType</a>：算子在原始框架中的类型。例如自定义算子<em>OpTypeA</em>，对应ONNX算子库版本opset_version=11，应传入“ai.onnx::11::<em>OpTypeA</em>”，当前支持的ONNX版本范围为9~15。</li>
      <li><a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/basicdataapi/atlasopapi_07_00390.html">ParseParamsByOperatorFn</a>(<em>ParseParamByOpFunc</em>)：用来注册解析算子参数实现映射关系的回调函数，需要用户自定义实现<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/basicdataapi/atlasopapi_07_00390.html#ZH-CN_TOPIC_0000002370164661__zh-cn_topic_0000001264911314_section288217313810">回调函数ParseParamByOpFunc</a>。具体实现方式参考<a href="#ZH-CN_TOPIC_0000002336176894__li213610403113">3</a>。</li>
      <li>ImplyType：指定算子的实现方式。Ascend C算子实现类型设置为TVM。</li>
     </ul>
     <p></p></li>

      <li><em>ParseParamByOpFunc</em>：函数名称，用户自定义。</li>
      <li>op_src：<span>ONNX</span>框架定义的Operator类对象，包含<span>ONNX</span>模型中自定义的算子属性信息，定义来源于<span>ONNX</span>框架的原始模型文件。</li>
      <li>op_dest：<span>CANN</span>算子数据结构，保存算子信息，Operator类的详细描述请参见<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/basicdataapi/atlasopapi_07_00336.html">Operator类</a>。</li>
     </ul>
     <p>开发者需要在回调函数中实现属性的解析和映射，具体实现方式如下：</p>
