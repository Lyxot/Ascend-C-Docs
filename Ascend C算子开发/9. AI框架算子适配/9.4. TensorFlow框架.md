  <h1 class="topictitle1">TensorFlow框架</h1>
  <div>
   <p>本章节介绍TensorFlow框架算子适配的流程，用于将TensorFlow框架的算子映射成CANN算子（开发者基于CANN框架自定义开发的算子），从而完成从<span>TensorFlow</span>框架调用到<span>CANN</span>算子的过程。同时给出TensorFlow框架侧算子调用的示例，便于开发者了解完整流程。</p>
   <p>下图展示了完整的开发流程，具体步骤如下：</p>
   <p><img class="imgResize" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/figure/zh-cn_image_0000002336336918.png" title="点击放大"></p>
   <ol>
    <li>环境准备。
     <p></p>
     <ol type="a">
      <li>CANN软件安装请参考<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0002.html">环境准备</a>。</li>
      <li><a name="ZH-CN_TOPIC_0000002336176898__li123241091016"></a><a name="li123241091016"></a><a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0060.html">创建算子工程</a>。使用msOpGen工具创建算子开发工程。TensorFlow框架算子适配场景下，需要通过framework参数指定具体的框架为tf或者tensorflow，工具会自动生成框架适配代码。以自定义CANN算子AddCustom为例，使用msOpGen工具创建算子开发工程的具体命令如下： 
       <pre class="screen"><strong><span>${INSTALL_DIR}</span></strong>/python/site-packages/bin/msopgen gen -i<strong> </strong>$HOME/sample/add_custom.json -f tf -c ai_core-<strong><span><em>&lt;soc_version&gt;</em></span> </strong>-lan cpp -out $HOME/sample/AddCustom</pre></li>
     </ol>
     <p></p></li>
    <li>算子实现。
     <p></p>
     <ul>
      <li><a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0062.html">算子原型定义</a>。通过原型定义来描述算子输入输出、属性等信息以及算子在AI处理器上相关实现信息，并关联tiling实现等函数。</li>
      <li>Kernel侧算子实现和host侧tiling实现请参考<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0030.html">算子实现</a>；工程化算子开发，支持开发者调用Tiling API基于CANN提供的编程框架进行tiling开发，kernel侧也提供对应的接口方便开发者获取tiling参数，具体内容请参考<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0063.html">Kernel侧算子实现</a>和<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0064.html">Host侧tiling实现</a>，由此而带来的额外约束也在上述章节说明。</li>
     </ul>
     <p></p></li>
    <li><a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0078.html">算子入图（GE图）开发</a>。算子入图场景下，需要提供shape推导等算子入图适配函数的实现。</li>
    <li>TensorFlow框架适配插件开发。详细说明见<a href="#ZH-CN_TOPIC_0000002336176898__section1820291291414">适配插件开发</a>。</li>
    <li>编译部署。通过工程编译脚本完成算子的编译部署，分为<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_00011.html">算子包编译</a>和<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_00012.html">算子动态库编译</a>两种方式。</li>
    <li>TensorFlow框架算子调用。详细说明见<a href="#ZH-CN_TOPIC_0000002336176898__section6342138121512">TensorFlow原生算子映射到CANN算子</a>和<a href="#ZH-CN_TOPIC_0000002336176898__section18276103563719">TensorFlow自定义算子开发并映射到CANN算子</a>。完整样例请参考<span><a href="https://gitee.com/ascend/samples/tree/master/operator/ascendc/0_introduction/1_add_frameworklaunch/TensorflowInvocation" target="_blank" rel="noopener noreferrer">LINK</a>。</span></li>
   </ol>

    <pre class="screen">AddCustom
├── build.sh             // 编译入口脚本
├── cmake 
├── CMakeLists.txt       // 算子工程的CMakeLists.txt
├── CMakePresets.json    // 编译配置项
├── framework            // 框架适配插件实现文件目录
│   ├── <strong>tf_plugin</strong><strong>    </strong> //  TensorFlow框架适配插件实现文件目录
│   │   ├── CMakeLists.txt<strong>    </strong>
│   │   ├── <strong>tensorflow_add_custom_plugin.cc</strong>  // TensorFlow框架适配插件实现文件   <strong> </strong>
│   ├── CMakeLists.txt
├── op_host                      // host侧实现文件
├── op_kernel                    // kernel侧实现文件
└── scripts                      // 自定义算子工程打包相关脚本所在目录</pre>

     <ul>
      <li>包含插件实现函数相关的头文件。 
       <p><a name="ZH-CN_TOPIC_0000002336176898__zh-cn_topic_0000001568063020_zh-cn_topic_0000001264917334_zh-cn_topic_0228422378_li18784154463917"></a><a name="zh-cn_topic_0000001568063020_zh-cn_topic_0000001264917334_zh-cn_topic_0228422378_li18784154463917"></a>register.h存储在<span>CANN软件安装后文件存储路径</span>的“include/register/”目录下，包含该头文件，可使用算子注册相关类，调用算子注册相关的接口。</p></li>
      <li>REGISTER_CUSTOM_OP：注册自定义算子，传入算子的<em>OpType</em>，需要与算子原型注册中的<em>OpType</em>保持一致。 
       <ul>
        <li><a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/basicdataapi/atlasopapi_07_00387.html">FrameworkType</a>：TENSORFLOW代表原始框架为<span>TensorFlow</span>。</li>
        <li><a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/basicdataapi/atlasopapi_07_00388.html">OriginOpType</a>：算子在原始框架中的类型。对于TensorFlow自定义算子，还需要完成<a href="#ZH-CN_TOPIC_0000002336176898__li312982016383">TensorFlow自定义算子的开发</a>，这里的OriginOpType与REGISTER_OP注册算子名相同，对于TensorFlow原生算子， 即为原生算子名。</li>
        <li><a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/basicdataapi/atlasopapi_07_00390.html">ParseParamsByOperatorFn</a>：用来注册解析算子参数实现映射关系的回调函数，需要用户自定义实现<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/basicdataapi/atlasopapi_07_00390.html#ZH-CN_TOPIC_0000002370164661__zh-cn_topic_0000001264911314_section288217313810">回调函数ParseParamByOpFunc</a>。原始<span>TensorFlow</span>算子中参数与<span>CANN</span>算子中参数一一对应时，可直接使用自动映射回调函数<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/basicdataapi/atlasopapi_07_00409.html">AutoMappingByOpFn</a>自动实现映射。</li>
        <li><a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/basicdataapi/atlasopapi_07_00394.html">ParseOpToGraphFn</a>：当TensorFlow算子与CANN算子原型定义不一致（比如CANN算子原型定义原型中有可选输入，但TensorFlow原型定义中不支持可选输入，没有可选输入）的情况时，用来注册调整算子原型映射关系的回调函数。</li>
       </ul></li>
     </ul>

    <h4 class="sectiontitle">可选输入算子映射关系开发</h4>
    <p>TensorFlow的原型定义中不支持可选输入，对于包含可选输入的算子，其从TensorFlow到CANN的映射关系，不满足简单的一对一映射，需要在插件适配代码中，将输入转换为可选输入，调整原型的映射关系。下文以CANN算子库中的FlashAttentionScore算子为例，介绍针对此类算子的框架适配插件如何开发。</p>
    <ol>
     <li>适配插件开发
      <p></p>
      <div class="p">
       和上文中介绍的简单的一对一映射不同，进行插件适配开发时，需要调用<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/basicdataapi/atlasopapi_07_00394.html">ParseOpToGraphFn</a>注册回调函数，回调函数中用于调整算子原型映射关系。此时： 
       <ul>
        <li>通过ParseParamsByOperatorFn注册回调函数，回调函数中将TensorFlow原生算子映射到一个IR和TensorFlow一致的中间算子(调用AutoMappingByOpFn完成属性映射)。</li>
        <li>通过ParseOpToGraphFn注册回调函数，调整算子原型映射关系，将中间算子最终映射到CANN算子库中的算子，这里映射到Graph图的概念是指一个算子构成的单算子图。</li>
       </ul>
      </div>
