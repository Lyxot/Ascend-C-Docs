  <h1 class="topictitle1">简易自定义算子工程</h1>
  <div>
   <p>本章节介绍的简易自定义算子工程，是上文中介绍的自定义算子工程的简化版，对算子的编译、打包、部署过程进行简化，便于开发者将该工程集成到自己的算子工程。</p>
   <p>基于简易自定义算子工程进行算子开发的完整样例请参考<span><a href="https://gitee.com/ascend/samples/tree/master/operator/ascendc/0_introduction/2_add_frameworklaunchlite" target="_blank" rel="noopener noreferrer">简易自定义算子工程</a></span>。</p>
   <div class="note">
    <img src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/public_sys-resources/note_3.0-zh-cn.png"><span class="notetitle"> </span>
    <div class="notebody">
     <ul>
      <li>使用该工程，支持在如下平台进行自定义算子开发：
       <ul>
        <li><span>Atlas A2训练系列产品/Atlas 800I A2推理产品</span></li>
        <li><span>Atlas 推理系列产品</span></li>
       </ul></li>
      <li>使用本工程开发的算子，只支持通过单算子API执行（aclnn）方式进行调用。</li>
      <li>本工程暂不支持算子的交叉编译功能。</li>
     </ul>
    </div>
   </div>
   <p>基于简易自定义算子工程的算子开发流程图如下：</p>
   <p><img class="eddx" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/figure/zh-cn_image_0000002370175585.png"></p>
   <div class="section">
    <h4 class="sectiontitle">创建算子工程</h4>
    <p>和<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0060.html">创建算子工程</a>类似，简易自定义算子工程通过msOpGen生成，基于算子原型定义输出算子工程，包括<strong>算子host侧代码实现文件</strong>、<strong>算子kernel侧实现文件</strong>以及<strong>工程编译配置文件等</strong>。主要差异点在于：创建简易算子工程需要通过<strong>-f</strong>参数配置framework框架为aclnn。</p>
    <div class="note">
     <img src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/public_sys-resources/note_3.0-zh-cn.png"><span class="notetitle"> </span>
     <div class="notebody">
      <p>使用msOpGen工具创建算子工程之前，需要参考<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0002.html">环境准备</a>章节安装驱动固件和CANN软件包，完成开发环境和运行环境的准备。</p>
     </div>
    </div>
    <p>使用msOpGen工具创建简易算子开发工程的步骤如下：</p>
    <ol>
     <li>编写算子的原型定义json文件，用于生成算子开发工程。
      <p></p>
      <div class="p">
       例如，AddCustom算子的json文件命名为add_custom.json，文件内容如下：
       <pre class="screen">[
    {
        "op": "AddCustom",
        "input_desc": [
            {
                "name": "x",
                "param_type": "required",
                "format": [
                    "ND",
                    "ND",
                    "ND"
                ],
                "type": [
                    "fp16",
                    "float",
                    "int32"
                ]
            },
            {
                "name": "y",
                "param_type": "required",
                "format": [
                    "ND",
                    "ND",
                    "ND"
                ],
                "type": [
                    "fp16",
                    "float",
                    "int32"
                ]
            }
        ],
        "output_desc": [
            {
                "name": "z",
                "param_type": "required",
                "format": [
                    "ND",
                    "ND",
                    "ND"
                ],
                "type": [
                    "fp16",
                    "float",
                    "int32"
                ]
            }
        ]
    }
]</pre>
      </div>
      <p></p></li>
     <li>使用msOpGen工具生成算子的开发工程。以生成AddCustom的算子工程为例，下文仅针对关键参数进行解释，详细参数说明请参见<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/devaids/optool/atlasopdev_16_0017.html">msOpGen工具</a>。
      <p></p>
      <pre class="screen"><strong><span>${INSTALL_DIR}</span></strong>/python/site-packages/bin/msopgen gen -i<strong> </strong>$HOME/sample/add_custom.json -c ai_core-<strong><span><em>&lt;soc_version&gt;</em></span> </strong>-lan cpp -out $HOME/sample/AddCustom <strong>-f aclnn</strong></pre>
      <ul>
       <li><strong><span>${INSTALL_DIR}</span></strong>为CANN软件安装后文件存储路径，请根据实际环境进行替换。</li>
       <li>-i：指定算子原型定义文件<em>add_custom</em>.json所在路径，请根据实际情况修改。</li>
       <li>-c：ai_core-<span><em>&lt;soc_version&gt;</em></span>代表算子在AI Core上执行，<span><em>&lt;soc_version&gt;</em></span>为<span>昇腾AI处理器</span>的型号。
        <div class="note">
         <img src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/public_sys-resources/note_3.0-zh-cn.png"><span class="notetitle"> </span>
         <div class="notebody">
          <p>AI处理器的型号<span><em>&lt;soc_version&gt;</em></span>请通过如下方式获取：</p>
          <ul>
           <li>非<span><term>
              Atlas A3 训练系列产品/Atlas A3 推理系列产品
             </term></span>：在安装<span>昇腾AI处理器</span>的服务器执行<strong>npu-smi info</strong>命令进行查询，获取<strong>Name</strong>信息。实际配置值为AscendName，例如<strong>Name</strong>取值为<em>xxxyy</em>，实际配置值为Ascend<em>xxxyy</em>。</li>
           <li><span><term>
              Atlas A3 训练系列产品/Atlas A3 推理系列产品
             </term></span>：在安装<span>昇腾AI处理器</span>的服务器执行<strong>npu-smi info -t board -i </strong><em>id</em><strong> -c </strong><em>chip_id</em>命令进行查询，获取<strong>Chip Name</strong>和<strong>NPU Name</strong>信息，实际配置值为Chip Name_NPU Name。例如<strong>Chip Name</strong>取值为Ascend<em>xxx</em>，<strong>NPU Name</strong>取值为1234，实际配置值为Ascend<em>xxx</em><em>_</em>1234。
            <p>其中：</p>
            <ul>
             <li>id：设备id，通过<strong>npu-smi info -l</strong>命令查出的NPU ID即为设备id。</li>
             <li>chip_id：芯片id，通过<strong>npu-smi info -m</strong>命令查出的Chip ID即为芯片id。</li>
            </ul></li>
          </ul>
          <p>基于同系列的AI处理器型号创建的算子工程，其基础功能（基于该工程进行算子开发、编译和部署）通用。</p>
         </div>
        </div></li>
       <li>-lan：参数cpp代表算子基于Ascend C编程框架，使用C/C++编程语言开发。</li>
       <li>-out：生成文件所在路径，可配置为绝对路径或者相对路径，并且工具执行用户对路径具有可读写权限。若不配置，则默认生成在执行命令的当前路径。</li>
       <li>-f：表示框架类型，aclnn表示生成简易工程。</li>
      </ul>
      <p></p></li>
     <li>命令执行完后，会在-out指定目录或者默认路径下生成算子工程目录，工程中包含算子实现的模板文件，编译脚本等，以AddCustom算子为例，目录结构如下所示：
      <p></p>
      <pre class="screen">AddCustom
├── build.sh                        // 编译入口脚本
├── cmake 
│   ├── <strong>config.cmake</strong>              <strong>// 编译配置项</strong>
│   ├── func.cmake
│   ├── intf.cmake
│   └── util                       // 算子工程编译所需脚本及公共编译文件存放目录
├── CMakeLists.txt                  // 算子工程的CMakeLists.txt
├── op_host                         // host侧实现文件
│   ├── <strong>add_custom_tiling.h</strong><strong>     // 算子tiling定义文件</strong>
│   ├── <strong>add_custom.cpp</strong><strong>          // 算子原型注册、tiling实现等内容文件</strong>
│   ├── CMakeLists.txt
├── op_kernel                       // kernel侧实现文件
│   ├── CMakeLists.txt   
│   ├── <strong>add_custom.cpp</strong><strong>          // 算子代码实现文件</strong> </pre>
      <div class="note">
       <img src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/public_sys-resources/note_3.0-zh-cn.png"><span class="notetitle"> </span>
       <div class="notebody">
        <p>上述目录结构中的粗体文件为后续算子开发过程中需要修改的文件，其他文件无需修改。</p>
       </div>
      </div>
      <p></p></li>
    </ol>
   </div>

    <h4 class="sectiontitle">算子编译</h4>
    <p>算子kernel侧和host侧实现开发完成后，需要对算子进行编译，生成算子静态库；自动生成aclnn调用实现代码和头文件，链接算子静态库生成aclnn动态库，以支持后续的单算子API执行方式（aclnn）的算子调用。编译过程如下：</p>
    <ul>
     <li>根据host侧算子实现文件自动生成aclnn接口aclnn_*.h和aclnn实现文件aclnn_.cpp。</li>
     <li>编译Tiling实现和算子原型定义生成Tiling动态库liboptiling.so（libcust_opmaster_rt2.0）。</li>
     <li>编译kernel侧算子实现文件，并加载Tiling动态库，生成kernel静态库libkernels.a。</li>
     <li>编译aclnn实现文件，并链接kernel静态库libkernels.a生成单算子API调用的动态库libcust_opapi.so。</li>
    </ul>
    <p>上述编译过程示意图如下：</p>
