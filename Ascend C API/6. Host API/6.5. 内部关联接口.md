<h1 class="topictitle1">内部关联接口</h1>
<div id="body8662426"><p id="ZH-CN_TOPIC_0000002336174590__zh-cn_topic_0000002043789866_p1191154110105">在进行算子原型注册、Tiling实现、shape推导过程中，使用到的外部开放接口中会调用到一些辅助数据结构和接口，称之为<strong id="ZH-CN_TOPIC_0000002336174590__zh-cn_topic_0000002043789866_b231172151810">内部关联接口</strong>。开发者不会直接调用内部关联接口，此处仅作简单介绍。</p>
