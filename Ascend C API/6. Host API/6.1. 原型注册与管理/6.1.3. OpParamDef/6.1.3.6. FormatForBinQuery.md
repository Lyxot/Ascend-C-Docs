  <h1 class="topictitle1">FormatForBinQuery</h1>
  <div id="body0000002084619088">
   <div class="section" id="ZH-CN_TOPIC_0000002370252261__zh-cn_topic_0000001549188228_zh-cn_topic_0000001526275046_zh-cn_topic_0000001525424352_section36583473819">
    <h4 class="sectiontitle">功能说明</h4>
    <p id="ZH-CN_TOPIC_0000002370252261__p144831244173614">设置Input/Output用于运行时算子二进制查找的数据格式，和<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0961.html">Format</a>/<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0962.html">FormatList</a>的数量一致，且一一对应。</p>
    <p id="ZH-CN_TOPIC_0000002370252261__p126637563522">算子编译过程中，会根据数据格式生成多个.o，并通过这些数据格式在运行时索引算子二进制。某些算子支持多种数据格式，且对数据格式不敏感，这时可以使用该接口，将多种数据格式映射到同一个算子二进制，多个数据格式可以复用一个.o，从而减少二进制文件的生成。</p>
    <p id="ZH-CN_TOPIC_0000002370252261__p196661925011">例如，如果一个算子的输入支持多种数据格式（ge::FORMAT_NC和ge::FORMAT_ND），并且使用ge::FORMAT_NC输入时可以复用ge::FORMAT_ND的二进制文件而不影响最终结果，那么可以采用如下配置：</p>
    <div class="codecoloring" codetype="Cpp" id="ZH-CN_TOPIC_0000002370252261__screen101195311014">
     <div class="highlight">
      <table class="highlighttable">
       <tbody>

<span class="normal">2</span>
<span class="normal">3</span>
<span class="normal">4</span>
<span class="normal">5</span></pre>
          </div></td>
         <td class="code">
          <div>
           <pre><span></span><span class="k">this</span><span class="o">-&gt;</span><span class="n">Input</span><span class="p">(</span><span class="s">"x"</span><span class="p">)</span>
<span class="w">            </span><span class="p">.</span><span class="n">ParamType</span><span class="p">(</span><span class="n">REQUIRED</span><span class="p">)</span>

    <p id="ZH-CN_TOPIC_0000002370252261__p17894204624010">这样，只需生成一个目标文件（.o），就能实现对多种数据格式的支持。</p>

    <h4 class="sectiontitle">约束说明</h4>
    <ul id="ZH-CN_TOPIC_0000002370252261__ul12890113718241">
     <li id="ZH-CN_TOPIC_0000002370252261__li14891637182414">FormatForBinQuery的参数个数需要和当前算子参数的Format或者FormatList的参数个数保持一致。</li>
     <li id="ZH-CN_TOPIC_0000002370252261__li489143722419">不支持与<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0967.html">Scalar</a>/<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0968.html">ScalarList</a>同时使用。</li>
     <li id="ZH-CN_TOPIC_0000002370252261__li789103713249">不支持与<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0964.html">ValueDepend</a>同时使用。</li>
     <li id="ZH-CN_TOPIC_0000002370252261__li16783173413012">设置FormatForBinQuery后，会用FormatForBinQuery的数据格式替换当前Input/Output的数据格式，并检查新组合在替换前是否存在。如果存在，则指向对应的二进制，如果不存在，该参数失效，按照原来的数据格式生成。具体请参考<a href="#ZH-CN_TOPIC_0000002370252261__li26512368417">示例一</a>。</li>
    </ul>
   </div>
