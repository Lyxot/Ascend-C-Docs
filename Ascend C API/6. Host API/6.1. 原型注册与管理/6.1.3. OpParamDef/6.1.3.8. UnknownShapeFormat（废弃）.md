  <h1 class="topictitle1">UnknownShapeFormat（废弃）</h1>
  <div id="body8662426">
   <div class="section" id="ZH-CN_TOPIC_0000002336333706__zh-cn_topic_0000001549347680_zh-cn_topic_0000001576875005_zh-cn_topic_0000001525424352_section36583473819">
    <h4 class="sectiontitle">功能说明</h4>
    <div class="notice" id="ZH-CN_TOPIC_0000002336333706__zh-cn_topic_0000001549347680_note969319162711">
     <span class="noticetitle"><img src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/public_sys-resources/notice_3.0-zh-cn.png"> </span>
     <div class="noticebody">
      <ul id="ZH-CN_TOPIC_0000002336333706__zh-cn_topic_0000001549347680_ul168812641016">
       <li id="ZH-CN_TOPIC_0000002336333706__zh-cn_topic_0000001549347680_li18885264109">该接口废弃，并将在后续版本移除，请不要使用该接口。无需针对动态/静态shape单独设置format，统一使用<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0961.html">Format</a>接口来设置即可。</li>
       <li id="ZH-CN_TOPIC_0000002336333706__zh-cn_topic_0000001549347680_li3687327101020">如果开发者使用了该接口，并开启-Werror -Wall编译选项开启所有警告当做错误处理，会有编译报错。此时可以通过添加-Wno-deprecated编译选项来消除，但是存在后续接口在版本中移除后编译报错的风险，建议不要使用该接口，统一使用<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0961.html">Format</a>接口来设置。
        <p id="ZH-CN_TOPIC_0000002336333706__zh-cn_topic_0000001549347680_p824917495260">编译选项加在自定义算子工程目录下op_host/CMakeLists.txt中的cust_optiling、cust_opproto编译target上，样例如下：</p>
        <pre class="screen" id="ZH-CN_TOPIC_0000002336333706__zh-cn_topic_0000001549347680_screen1228519222719">target_compile_options(cust_optiling PRIVATE
        -Wno-deprecated
)</pre></li>
      </ul>
     </div>
    </div>
    <p id="ZH-CN_TOPIC_0000002336333706__zh-cn_topic_0000001549347680_zh-cn_topic_0000001576875005_zh-cn_topic_0000001525424352_p10448657201310">未知Shape情况下的Format的默认值。</p>
