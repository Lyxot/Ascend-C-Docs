  <h1 class="topictitle1">原型注册接口（OP_ADD）</h1>
  <div id="body8662426">
   <div class="section" id="ZH-CN_TOPIC_0000002370171857__zh-cn_topic_0000001600307121_zh-cn_topic_0000001576870453_zh-cn_topic_0000001525424352_section36583473819">
    <h4 class="sectiontitle">功能说明</h4>
    <p id="ZH-CN_TOPIC_0000002370171857__zh-cn_topic_0000001600307121_zh-cn_topic_0000001576870453_zh-cn_topic_0000001525424352_p10448657201310">注册算子的原型定义，从而确保算子能够被框架正确识别、编译和执行<strong id="ZH-CN_TOPIC_0000002370171857__zh-cn_topic_0000001600307121_zh-cn_topic_0000001576870453_b126537433259"></strong>。</p>
    <p id="ZH-CN_TOPIC_0000002370171857__p1979518107315">算子原型主要描述了算子的输入输出、属性等信息以及算子在AI处理器上相关实现信息，并关联<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0064.html">tiling实现</a>等函数。算子原型通过自定义的算子类来承载，该算子类继承自<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0946.html">OpDef类</a>。完成算子的原型定义等操作后，需要调用<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0945.html">OP_ADD</a>接口，传入算子类型（自定义算子类的类名），进行算子原型注册。详细内容请参考<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0062.html">算子原型定义</a>。</p>
