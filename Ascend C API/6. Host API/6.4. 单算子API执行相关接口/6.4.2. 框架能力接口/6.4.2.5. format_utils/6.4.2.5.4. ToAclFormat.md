   <div class="section" id="ZH-CN_TOPIC_0000002370251197__zh-cn_topic_0000001949516813_zh-cn_topic_0000001647821269_section36583473819">
    <h4 class="sectiontitle">功能说明</h4>
    <p id="ZH-CN_TOPIC_0000002370251197__zh-cn_topic_0000001949516813_p11444123612618">将op::Format转为对应的aclFormat。</p>
    <ul id="ZH-CN_TOPIC_0000002370251197__ul085193241615">
     <li id="ZH-CN_TOPIC_0000002370251197__zh-cn_topic_0000002078653714_li6246392177">aclFormat：AscendCL（Ascend Computing Language）框架对外提供的数据格式，具体定义参见<span id="ZH-CN_TOPIC_0000002370251197__zh-cn_topic_0000002078653714_ph6585134814192">“<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/appdevgapi/aclcppdevg_03_1348.html">aclFormat</a>”</span>。</li>
     <li id="ZH-CN_TOPIC_0000002370251197__zh-cn_topic_0000002078653714_li285132161611">op::Format：算子框架内部定义的数据格式，本质使用的是GE定义的<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/basicdataapi/atlasopapi_07_00515.html">ge::Format</a>。</li>
    </ul>
