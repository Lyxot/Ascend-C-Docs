  <h1 class="topictitle1">GetViewShape</h1>
  <div id="body8662426">
   <div class="section" id="ZH-CN_TOPIC_0000002370171397__zh-cn_topic_0000001948643461_zh-cn_topic_0000001647821269_section36583473819">
    <h4 class="sectiontitle">功能说明</h4>
    <p id="ZH-CN_TOPIC_0000002370171397__zh-cn_topic_0000001948643461_p1354465292714">获取aclTensor的ViewShape。ViewShape表示aclTensor的逻辑shape。</p>
    <p id="ZH-CN_TOPIC_0000002370171397__zh-cn_topic_0000001948643461_p494662342613">假设一个aclTensor的StorageShape和ViewShape如下：</p>
    <ul id="ZH-CN_TOPIC_0000002370171397__zh-cn_topic_0000001948643461_ul172011271263">
     <li id="ZH-CN_TOPIC_0000002370171397__zh-cn_topic_0000001948643461_li492812992614">StorageShape为[10, 20]：表示该aclTensor在内存上是按照[10, 20]排布的。</li>
     <li id="ZH-CN_TOPIC_0000002370171397__zh-cn_topic_0000001948643461_li22072792610">ViewShape为[2, 5, 20]：在算子使用时，表示该aclTensor可被视为一块[2, 5, 20]的数据使用。</li>
    </ul>
   </div>
