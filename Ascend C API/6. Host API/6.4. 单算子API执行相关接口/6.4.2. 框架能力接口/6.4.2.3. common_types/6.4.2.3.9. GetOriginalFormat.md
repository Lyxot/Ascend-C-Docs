    <h4 class="sectiontitle">功能说明</h4>
    <p id="ZH-CN_TOPIC_0000002336333044__zh-cn_topic_0000001919484494_p16365143710201">获取aclTensor的OriginFormat。</p>
    <p id="ZH-CN_TOPIC_0000002336333044__zh-cn_topic_0000001919484494_zh-cn_topic_0000001647821269_p1490231814403">OriginFormat一般表示aclTensor在经历transdata节点前（如果存在该节点）的原始Format信息。</p>
