   <div class="section" id="ZH-CN_TOPIC_0000002336334134__zh-cn_topic_0000001920960152_zh-cn_topic_0000001647821269_section36583473819">
    <h4 class="sectiontitle">功能说明</h4>
    <p id="ZH-CN_TOPIC_0000002336334134__zh-cn_topic_0000001920960152_p1953321712423">将aclDataType转换为对应的op::DataType。</p>
    <ul id="ZH-CN_TOPIC_0000002336334134__ul085193241615">
     <li id="ZH-CN_TOPIC_0000002336334134__li6246392177">aclDataType：AscendCL（Ascend Computing Language）框架对外提供的数据类型，具体定义参见<span id="ZH-CN_TOPIC_0000002336334134__ph1922620529165">“<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/appdevgapi/aclcppdevg_03_1346.html">aclDataType</a>”</span>。</li>
     <li id="ZH-CN_TOPIC_0000002336334134__li285132161611">op::DataType：算子框架内部定义的数据类型，本质使用的是GE定义的<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/basicdataapi/atlasopapi_07_00514.html">ge::DataType</a>。</li>
    </ul>
