    <h4 class="sectiontitle">返回值说明</h4>
    <p id="ZH-CN_TOPIC_0000002370171313__zh-cn_topic_0000001920624064_p74693430173">若reshape转换成功，则返回带有目标shape信息的aclTensor给调用者；若失败，则返回nullptr。</p>
   </div>
   <div class="section" id="ZH-CN_TOPIC_0000002370171313__zh-cn_topic_0000001920624064_zh-cn_topic_0000001647821269_section19165124931511">
    <h4 class="sectiontitle">约束说明</h4>
    <ul id="ZH-CN_TOPIC_0000002370171313__zh-cn_topic_0000001920624064_ul565713563115">
     <li id="ZH-CN_TOPIC_0000002370171313__zh-cn_topic_0000001920624064_li9657175621113">reshape转换成功的前提是x的ShapeSize需要和第二个参数shape的ShapeSize相等，所谓的ShapeSize举例如下：A的shape=(1, 3, 256, 256)， 则A的ShapeSize=1*3*256*256。</li>
     <li id="ZH-CN_TOPIC_0000002370171313__zh-cn_topic_0000001920624064_li1420820567126">当前不支持转换成空tensor，所谓的空tensor即shape中包含0。</li>
    </ul>
