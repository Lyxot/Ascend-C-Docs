<div class="section" id="ZH-CN_TOPIC_0000002336174538__zh-cn_topic_0000001920783760_zh-cn_topic_0000001647821269_section36583473819"><h4 class="sectiontitle">功能说明</h4><p id="ZH-CN_TOPIC_0000002336174538__zh-cn_topic_0000001920783760_p1694105214011">该函数不改变tensor数据的值，而是对tensor进行转置操作。</p>
<p id="ZH-CN_TOPIC_0000002336174538__zh-cn_topic_0000001920783760_p49554401714">通过transpose算子，可以改变tensor在不同维度上的排列顺序，实现对tensor的维度重排。</p>
<p id="ZH-CN_TOPIC_0000002336174538__zh-cn_topic_0000001920783760_p11164155810599">具体的是将用户传入的输入tensor x的shape按指定维度的排列顺序perm进行转置并输出。</p>
