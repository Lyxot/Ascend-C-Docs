  <h1 class="topictitle1">单算子API执行相关接口列表</h1>
  <div id="body8662426">
   <div class="section" id="ZH-CN_TOPIC_0000002370171629__section870245616319">
    <h4 class="sectiontitle">整体说明</h4>
    <p id="ZH-CN_TOPIC_0000002370171629__p126519919205">无论是基于Ascend C自定义的算子还是CANN提供的内置算子，都可以通过<strong id="ZH-CN_TOPIC_0000002370171629__b365112910204">aclnn前缀API</strong>（简称aclnn接口）形式调用算子，这种方式称为“<strong id="ZH-CN_TOPIC_0000002370171629__b3651391206">单算子API执行</strong>”。该方法简单且灵活，更便于用户进行AI业务开发与应用。</p>
    <div class="note" id="ZH-CN_TOPIC_0000002370171629__note527882814433">
     <img src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/public_sys-resources/note_3.0-zh-cn.png"><span class="notetitle"> </span>
     <div class="notebody">
      <ul id="ZH-CN_TOPIC_0000002370171629__ul151153815435">
       <li id="ZH-CN_TOPIC_0000002370171629__li1193824312">aclnn前缀API：简称aclnn接口，属于<a href="#ZH-CN_TOPIC_0000002370171629__zh-cn_topic_0000001917744184_li572474119382">Level2层接口</a>，本质是一类C语言API，调用算子时无需提供IR（Intermediate Representation）定义。</li>
       <li id="ZH-CN_TOPIC_0000002370171629__li389484654313">内置算子：CANN的算子加速库（Ascend Operator Library，简称AOL），包含一系列高性能算子和aclnn接口，用户可直接使用，无需自定义，详细介绍请参考<span id="ZH-CN_TOPIC_0000002370171629__ph8894124604319">《<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/apiref/aolapi/operatorlist_00001.html" target="_blank" rel="noopener noreferrer">AOL算子加速库接口参考</a>》</span>。</li>
       <li id="ZH-CN_TOPIC_0000002370171629__li10569737171011">“<strong id="ZH-CN_TOPIC_0000002370171629__b236839132717">单算子API执行</strong>”是一种单算子调用方式，其调用流程和其他调用方式介绍请参考<span id="ZH-CN_TOPIC_0000002370171629__ph14590526191120">“<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/appdevg/acldevg/aclcppdevg_000017.html">单算子调用流程</a>”</span>。</li>
      </ul>
     </div>
    </div>
    <p id="ZH-CN_TOPIC_0000002370171629__p782773584815">为实现API形式直调算子，本章提供了单算子API执行依赖的底层框架接口和基础核函数接口（即<a href="#ZH-CN_TOPIC_0000002370171629__zh-cn_topic_0000001917744184_li1543255153717">Level0层接口</a>），详细阐述了接口的原型、功能、参数说明、约束与限制、调用示例等，指导开发者快速掌握接口含义和使用方法。</p>
    <ul id="ZH-CN_TOPIC_0000002370171629__ul714511223498">
     <li id="ZH-CN_TOPIC_0000002370171629__li171458220490">框架能力接口：提供实现aclnn前缀接口相关的基础能力接口，比如算子执行器（opExecutor）处理、数据类型/格式/shape等操作，具体如<a href="#ZH-CN_TOPIC_0000002370171629__table2070319561334">表1</a>所示；此外还包括常用类和宏，具体参见<a href="#ZH-CN_TOPIC_0000002370171629__table370875616310">表2</a>、<a href="#ZH-CN_TOPIC_0000002370171629__table2712056035">表3</a>。</li>
     <li id="ZH-CN_TOPIC_0000002370171629__li582813362495">基础核函数接口：提供实现aclnn前缀接口的基础核函数接口，比如Tensor数据类型转换、shape重构等，具体如<a href="#ZH-CN_TOPIC_0000002370171629__table177150561835">表4</a>所示。</li>
    </ul>
    <p id="ZH-CN_TOPIC_0000002370171629__p553272072210">使用上述接口时，注意请根据实际情况include依赖的头文件，头文件路径为<span id="ZH-CN_TOPIC_0000002370171629__ph370014309235">${INSTALL_DIR}</span>/include目录，其中<span id="ZH-CN_TOPIC_0000002370171629__ph27035569315">${INSTALL_DIR}请替换为CANN软件安装后文件存储路径。若安装的Ascend-cann-toolkit软件包，以root安装举例，则安装后文件存储路径为：/usr/local/Ascend/ascend-toolkit/latest。</span></p>
    <p id="ZH-CN_TOPIC_0000002370171629__p66162912117">为更好指导开发者应用本章接口，<strong id="ZH-CN_TOPIC_0000002370171629__b4377938448">端到端的接口调用示例</strong>可参考Gitee <strong id="ZH-CN_TOPIC_0000002370171629__b12801231145912">cann-ops-adv仓</strong>，该仓开放了融合算子实现的源代码，单击<a href="https://gitee.com/ascend/cann-ops-adv" target="_blank" rel="noopener noreferrer">Link</a>访问“/src/transformer/${OpType}/ophost/”获取不同算子源码，${OpType}表示算子类型。如果您需要对算子Host侧API实现进行<strong id="ZH-CN_TOPIC_0000002370171629__b976411775811">定制化修改</strong>，建议先熟悉本章接口。</p>
