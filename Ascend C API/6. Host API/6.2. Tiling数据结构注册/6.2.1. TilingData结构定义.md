<div id="body8662426"><div class="section" id="ZH-CN_TOPIC_0000002336173802__zh-cn_topic_0000001576606633_section212607105720"><h4 class="sectiontitle">功能说明</h4><p id="ZH-CN_TOPIC_0000002336173802__zh-cn_topic_0000001576606633_p0824144014589">定义一个TilingData的类，添加所需的成员变量（TilingData字段），用于保存所需TilingData参数。完成该TilingData类的定义后，该类通过继承TilingDef类（用来存放、处理用户自定义Tiling结构体成员变量的基类）提供以下接口：</p>
