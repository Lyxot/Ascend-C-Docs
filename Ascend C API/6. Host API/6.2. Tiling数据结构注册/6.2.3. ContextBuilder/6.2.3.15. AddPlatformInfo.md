  <h1 class="topictitle1">AddPlatformInfo</h1>
  <div id="body0000002333452901">
   <div class="section" id="ZH-CN_TOPIC_0000002370251077__zh-cn_topic_0000001867409741_zh-cn_topic_0000001389787297_section36583473819">
    <h4 class="sectiontitle">功能说明</h4>
    <p id="ZH-CN_TOPIC_0000002370251077__p188432020507">设置硬件平台信息便于用户在算子Tiling函数调测中使用。支持以下两种设置方式：</p>
    <ul id="ZH-CN_TOPIC_0000002370251077__ul4116133735012">
     <li id="ZH-CN_TOPIC_0000002370251077__li1111615374503"><strong id="ZH-CN_TOPIC_0000002370251077__b158841920105011">自动获取当前硬件平台信息</strong>：传入空指针，自动获取当前硬件信息并添加到ContextBuilder类中。</li>
     <li id="ZH-CN_TOPIC_0000002370251077__li12116163711503"><strong id="ZH-CN_TOPIC_0000002370251077__b288419207502">指定硬件平台信息</strong>：传入具体的<span id="ZH-CN_TOPIC_0000002370251077__ph61141655195019">昇腾AI处理器</span>型号，添加对应硬件信息至ContextBuilder类中。</li>
    </ul>
    <p id="ZH-CN_TOPIC_0000002370251077__p188841920145017">若设置失败，会打印报错信息。关于日志配置和查看，请参考<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/maintenref/envvar/envref_07_0118.html">日志</a>。</p>
   </div>
