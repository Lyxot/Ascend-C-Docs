    <h4 class="sectiontitle">功能说明</h4>
    <p id="ZH-CN_TOPIC_0000002370171885__p911mcpsimp">给定一个连续的输入张量和一个目的地址偏移张量，Scatter指令根据偏移地址生成新的结果张量后将输入张量分散到结果张量中。</p>
    <p id="ZH-CN_TOPIC_0000002370171885__p865295702911">将源操作数src中的元素按照指定的位置（由dst_offset和base_addr共同作用）分散到目的操作数dst中。</p>

    <h4 class="sectiontitle">约束说明</h4>
    <ul id="ZH-CN_TOPIC_0000002370171885__ul1121114715127">
     <li id="ZH-CN_TOPIC_0000002370171885__li124011313290">操作数地址偏移对齐要求请参见<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0004.html">通用约束</a>。</li>
     <li id="ZH-CN_TOPIC_0000002370171885__li19856145613575">为了节省地址空间，开发者可以定义一个Tensor，供源操作数与目的操作数同时使用（即地址重叠），相关约束如下
      <ul id="ZH-CN_TOPIC_0000002370171885__ul7856756145719">
       <li id="ZH-CN_TOPIC_0000002370171885__li1085695675720">对于单次repeat（repeatTimes=1），支持源操作数与目的操作数之间要求100%完全重叠，不支持部分重叠。</li>
       <li id="ZH-CN_TOPIC_0000002370171885__li2856556135718">对于多次repeat（repeatTimes&gt;1），不支持源操作数与目的操作数在迭代间存在依赖。例如当第N次迭代的目的操作数是第N+1次的源操作数时，不支持地址重叠</li>
      </ul></li>
     <li id="ZH-CN_TOPIC_0000002370171885__li7516439185510">dstOffsetLocal中的偏移地址不能有相同值，如果存在2个或者多个偏移重复的情况，行为是不可预期的。</li>
    </ul>
