    <h4 class="sectiontitle">功能说明</h4>
    <p id="ZH-CN_TOPIC_0000002336173654__p68801917161513">按元素执行Leaky ReLU（Leaky Rectified Linear Unit）操作，计算公式如下，其中PAR表示矢量计算单元一个迭代能够处理的元素个数：</p>
    <p id="ZH-CN_TOPIC_0000002336173654__p103996104179"><span><img class="mathml" id="ZH-CN_TOPIC_0000002336173654__image94451056171711" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_formulaimage_0000002370173349.png"></span></p>
    <p id="ZH-CN_TOPIC_0000002336173654__p2444144412105">Leaky ReLU带泄露线性整流函数是一种人工神经网络中常用的激活函数，其数学表达式为：</p>
    <p id="ZH-CN_TOPIC_0000002336173654__p531331221616"><span><img class="mathml" id="ZH-CN_TOPIC_0000002336173654__image3478122818311" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_formulaimage_0000002336335010.png"></span></p>
    <p id="ZH-CN_TOPIC_0000002336173654__p1816116953015">和ReLU的区别是：ReLU是将所有的负值都设为零，而Leaky ReLU是给所有负值赋予一个斜率。下图表示了Relu和Leaky ReLU的区别：</p>

    <h4 class="sectiontitle">约束说明</h4>
    <ul id="ZH-CN_TOPIC_0000002336173654__ul1761mcpsimp">
     <li id="ZH-CN_TOPIC_0000002336173654__li1776mcpsimp">使用tensor高维切分计算接口时，节省地址空间，开发者可以定义一个Tensor，供源操作数与目的操作数同时使用（即地址重叠），相关约束如下： 
      <ul id="ZH-CN_TOPIC_0000002336173654__ul1777mcpsimp">
       <li id="ZH-CN_TOPIC_0000002336173654__li1778mcpsimp">对于单次repeat（repeatTimes=1），且源操作数与目的操作数之间要求100%完全重叠，不支持部分重叠。</li>
       <li id="ZH-CN_TOPIC_0000002336173654__li1781mcpsimp">对于多次repeat（repeatTimes&gt;1），操作数与目的操作数之间存在依赖的情况下，即第N次迭代的目的操作数是第N+1次的源操作数，不支持地址重叠。</li>
      </ul></li>
    </ul>
    <ul id="ZH-CN_TOPIC_0000002336173654__ul195491551216">
     <li id="ZH-CN_TOPIC_0000002336173654__li16168139112915">操作数地址偏移对齐要求请参见<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0004.html">通用约束</a>。</li>
