    <h4 class="sectiontitle">功能说明</h4>
    <p id="ZH-CN_TOPIC_0000002370172429__p1676331375210">对源操作数中的每个元素进行右移操作，右移的位数由输入参数scalarValue决定。根据源操作数的数据类型，右移操作分为以下两种情况：</p>
    <ul id="ZH-CN_TOPIC_0000002370172429__ul4430195119521">
     <li id="ZH-CN_TOPIC_0000002370172429__li84301051105218">数据类型为无符号类型：执行逻辑右移。逻辑右移会将二进制数整体向右移动指定的位数，最低位被丢弃，最高位用0填充。例如，二进制数1010101010101010（uint16_t类型）逻辑右移1位后，结果为0101010101010101。</li>
     <li id="ZH-CN_TOPIC_0000002370172429__li10430551105220">数据类型为有符号类型：执行算术右移。算术右移会将二进制数整体向右移动指定的位数，最低位被丢弃，最高位复制符号位。例如，二进制数1010101010101010（int16_t 类型）算术右移1位后，结果为1101010101010101；算术右移3位后，结果为1111010101010101。</li>
    </ul>

    <h4 class="sectiontitle">约束说明</h4>
    <ul id="ZH-CN_TOPIC_0000002370172429__ul1761mcpsimp">
     <li id="ZH-CN_TOPIC_0000002370172429__li1776mcpsimp">使用tensor高维切分计算接口时，节省地址空间，开发者可以定义一个Tensor，供源操作数与目的操作数同时使用（即地址重叠），相关约束如下：
      <ul id="ZH-CN_TOPIC_0000002370172429__ul1777mcpsimp">
       <li id="ZH-CN_TOPIC_0000002370172429__li1778mcpsimp">对于单次repeat（repeatTimes=1），且源操作数与目的操作数之间要求100%完全重叠，不支持部分重叠。</li>
       <li id="ZH-CN_TOPIC_0000002370172429__li1781mcpsimp">对于多次repeat（repeatTimes&gt;1），操作数与目的操作数之间存在依赖的情况下，即第N次迭代的目的操作数是第N+1次的源操作数，不支持地址重叠。</li>
      </ul></li>
    </ul>
    <ul id="ZH-CN_TOPIC_0000002370172429__ul195491551216">
     <li id="ZH-CN_TOPIC_0000002370172429__li16168139112915">操作数地址偏移对齐要求请参见<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0004.html">通用约束</a>。</li>
    </ul>
