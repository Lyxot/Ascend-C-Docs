         <p id="ZH-CN_TOPIC_0000002336174150__p2554141321313">mask/mask[]</p></td>
        <td class="cellrowborder" valign="top" width="6.7299999999999995%" headers="mcps1.3.4.3.2.4.1.2 ">
         <p id="ZH-CN_TOPIC_0000002336174150__p10535746191515">输入</p></td>
        <td class="cellrowborder" valign="top" width="78.75999999999999%" headers="mcps1.3.4.3.2.4.1.3 ">
         <p id="ZH-CN_TOPIC_0000002336174150__zh-cn_topic_0000002370171669_p0554313181312"><span id="ZH-CN_TOPIC_0000002336174150__zh-cn_topic_0000002370171669_ph793119540147"><a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0022.html#ZH-CN_TOPIC_0000002370254921__zh-cn_topic_0000002267504656_zh-cn_topic_0000001764162593_section4252658182">mask</a>用于控制每次迭代内参与计算的元素。</span></p>
         <ul id="ZH-CN_TOPIC_0000002336174150__zh-cn_topic_0000002370171669_ul1255411133132">
          <li id="ZH-CN_TOPIC_0000002336174150__zh-cn_topic_0000002370171669_li855401313131">逐bit模式：可以按位控制哪些元素参与计算，bit位的值为1表示参与计算，0表示不参与。
           <p id="ZH-CN_TOPIC_0000002336174150__zh-cn_topic_0000002370171669_p121114581013"><a name="ZH-CN_TOPIC_0000002336174150__zh-cn_topic_0000002370171669_li855401313131"></a><a name="zh-cn_topic_0000002370171669_li855401313131"></a>mask为数组形式，数组长度和数组元素的取值范围和操作数的数据类型有关。当操作数为16位时，数组长度为2，mask[0]、mask[1]∈[0, 2<sup id="ZH-CN_TOPIC_0000002336174150__zh-cn_topic_0000002370171669_sup1411059101">64</sup>-1]并且不同时为0；当操作数为32位时，数组长度为1，mask[0]∈(0, 2<sup id="ZH-CN_TOPIC_0000002336174150__zh-cn_topic_0000002370171669_sup1711155161017">64</sup>-1]；当操作数为64位时，数组长度为1，mask[0]∈(0, 2<sup id="ZH-CN_TOPIC_0000002336174150__zh-cn_topic_0000002370171669_sup181195111019">32</sup>-1]。</p>
           <p id="ZH-CN_TOPIC_0000002336174150__zh-cn_topic_0000002370171669_p711354105">例如，mask=[8, 0]，8=0b1000，表示仅第4个元素参与计算。</p></li>
         </ul>
         <ul id="ZH-CN_TOPIC_0000002336174150__zh-cn_topic_0000002370171669_ul18554121313135">
          <li id="ZH-CN_TOPIC_0000002336174150__zh-cn_topic_0000002370171669_li1655411331318">连续模式：表示前面连续的多少个元素参与计算。取值范围和操作数的数据类型有关，数据类型不同，每次迭代内能够处理的元素个数最大值不同。当操作数为16位时，mask∈[1, 128]；当操作数为32位时，mask∈[1, 64]；当操作数为64位时，mask∈[1, 32]。</li>

    <h4 class="sectiontitle">约束说明</h4>
    <ul id="ZH-CN_TOPIC_0000002336174150__ul1761mcpsimp">
     <li id="ZH-CN_TOPIC_0000002336174150__li1776mcpsimp">使用tensor高维切分计算接口时，节省地址空间，开发者可以定义一个Tensor，供源操作数与目的操作数同时使用（即地址重叠），相关约束如下：
      <ul id="ZH-CN_TOPIC_0000002336174150__ul1777mcpsimp">
       <li id="ZH-CN_TOPIC_0000002336174150__li1778mcpsimp">对于单次repeat（repeatTimes=1），且源操作数与目的操作数之间要求100%完全重叠，不支持部分重叠。</li>
       <li id="ZH-CN_TOPIC_0000002336174150__li1781mcpsimp">对于多次repeat（repeatTimes&gt;1），操作数与目的操作数之间存在依赖的情况下，即第N次迭代的目的操作数是第N+1次的源操作数，不支持地址重叠。</li>
      </ul></li>
    </ul>
    <ul id="ZH-CN_TOPIC_0000002336174150__ul195491551216">
     <li id="ZH-CN_TOPIC_0000002336174150__li2578121915268">操作数地址偏移对齐要求请参见<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0004.html">通用约束</a>。</li>
    </ul>
