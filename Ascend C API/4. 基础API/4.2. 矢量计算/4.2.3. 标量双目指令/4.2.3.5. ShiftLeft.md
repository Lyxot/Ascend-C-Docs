    <h4 class="sectiontitle">功能说明</h4>
    <p id="ZH-CN_TOPIC_0000002370172265__p1676331375210">对源操作数中的每个元素进行左移操作，左移的位数由输入参数scalarValue决定。根据源操作数的数据类型，左移操作分为以下两种情况：</p>
    <ul id="ZH-CN_TOPIC_0000002370172265__ul4430195119521">
     <li id="ZH-CN_TOPIC_0000002370172265__li84301051105218">数据类型为无符号类型：执行逻辑左移。逻辑左移会将二进制数整体向左移动指定的位数，最高位被丢弃，最低位用0填充。例如，二进制数1010101010101010（uint16_t 类型）逻辑左移1位后，结果为0101010101010100。</li>
     <li id="ZH-CN_TOPIC_0000002370172265__li10430551105220">数据类型为有符号类型：执行算术左移。算术左移会将二进制数整体向左移动指定的位数，次高位被丢弃，最低位用0填充。例如，二进制数1010101010101010（int16_t 类型）算术左移1位后，结果为1101010101010100；算术左移3位后，结果为1101010101010000。</li>
    </ul>

          <li id="ZH-CN_TOPIC_0000002370172265__zh-cn_topic_0000002370171669_li855401313131">逐bit模式：可以按位控制哪些元素参与计算，bit位的值为1表示参与计算，0表示不参与。
           <p id="ZH-CN_TOPIC_0000002370172265__zh-cn_topic_0000002370171669_p121114581013"><a name="ZH-CN_TOPIC_0000002370172265__zh-cn_topic_0000002370171669_li855401313131"></a><a name="zh-cn_topic_0000002370171669_li855401313131"></a>mask为数组形式，数组长度和数组元素的取值范围和操作数的数据类型有关。当操作数为16位时，数组长度为2，mask[0]、mask[1]∈[0, 2<sup id="ZH-CN_TOPIC_0000002370172265__zh-cn_topic_0000002370171669_sup1411059101">64</sup>-1]并且不同时为0；当操作数为32位时，数组长度为1，mask[0]∈(0, 2<sup id="ZH-CN_TOPIC_0000002370172265__zh-cn_topic_0000002370171669_sup1711155161017">64</sup>-1]；当操作数为64位时，数组长度为1，mask[0]∈(0, 2<sup id="ZH-CN_TOPIC_0000002370172265__zh-cn_topic_0000002370171669_sup181195111019">32</sup>-1]。</p>

    <h4 class="sectiontitle">约束说明</h4>
    <ul id="ZH-CN_TOPIC_0000002370172265__ul1761mcpsimp">
     <li id="ZH-CN_TOPIC_0000002370172265__li1776mcpsimp">使用tensor高维切分计算接口时，节省地址空间，开发者可以定义一个Tensor，供源操作数与目的操作数同时使用（即地址重叠），相关约束如下：
      <ul id="ZH-CN_TOPIC_0000002370172265__ul1777mcpsimp">
       <li id="ZH-CN_TOPIC_0000002370172265__li1778mcpsimp">对于单次repeat（repeatTimes=1），且源操作数与目的操作数之间要求100%完全重叠，不支持部分重叠。</li>
       <li id="ZH-CN_TOPIC_0000002370172265__li1781mcpsimp">对于多次repeat（repeatTimes&gt;1），操作数与目的操作数之间存在依赖的情况下，即第N次迭代的目的操作数是第N+1次的源操作数，不支持地址重叠。</li>
      </ul></li>
    </ul>
    <ul id="ZH-CN_TOPIC_0000002370172265__ul195491551216">
     <li id="ZH-CN_TOPIC_0000002370172265__li98424482918">操作数地址偏移对齐要求请参见<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0004.html">通用约束</a>。</li>
    </ul>
