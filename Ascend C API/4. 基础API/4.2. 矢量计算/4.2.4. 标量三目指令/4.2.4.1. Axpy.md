   <div class="section" id="ZH-CN_TOPIC_0000002370172297__section633mcpsimp">
    <h4 class="sectiontitle">约束说明</h4>
    <ul id="ZH-CN_TOPIC_0000002370172297__ul144961427164811">
     <li id="ZH-CN_TOPIC_0000002370172297__li1232317672315">为了节省地址空间，开发者可以定义一个Tensor，供源操作数与目的操作数同时使用（即地址重叠），约束如下：
      <ul id="ZH-CN_TOPIC_0000002370172297__ul131846544227">
       <li id="ZH-CN_TOPIC_0000002370172297__li996272494817">对于单次repeat，且源操作数与目的操作数之间要求100%完全重叠，不支持部分重叠。</li>
       <li id="ZH-CN_TOPIC_0000002370172297__li1418415410228">对于多次repeat（repeatTimes&gt;1），若源操作数与目的操作数之间存在依赖，即第N次迭代的目的操作数是第N+1次的源操作数，这种情况是不支持地址重叠的。</li>
      </ul></li>
    </ul>
    <ul class="subitemlist" id="ZH-CN_TOPIC_0000002370172297__ul15129509">
     <li id="ZH-CN_TOPIC_0000002370172297__li1392613885710">使用tensor高维切分计算接口时，srcLocal和scalar的数据类型为half、dstLocal的数据类型为float的情况下，一个迭代处理的源操作数元素个数需要和目的操作数保持一致，所以每次迭代选取前4个datablock参与计算。设置<span id="ZH-CN_TOPIC_0000002370172297__ph13946527113916">Repeat Stride</span>参数和mask参数以及地址重叠时，需要考虑该限制。</li>
    </ul>
