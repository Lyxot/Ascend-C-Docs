    <h4 class="sectiontitle">功能说明</h4>
    <p id="ZH-CN_TOPIC_0000002370251097__p177959415503">逐元素比较一个tensor中的元素和另一个Scalar的大小，如果比较后的结果为真，则输出结果的对应比特位为1，否则为0。</p>
    <p id="ZH-CN_TOPIC_0000002370251097__p2568164215512">支持多种比较模式：</p>
    <ul id="ZH-CN_TOPIC_0000002370251097__ul14429497516">
     <li id="ZH-CN_TOPIC_0000002370251097__li44424498514">LT：小于（less than）</li>
     <li id="ZH-CN_TOPIC_0000002370251097__li529315419511">GT：大于（greater than）</li>
    </ul>
    <ul id="ZH-CN_TOPIC_0000002370251097__ul147379458500">
     <li id="ZH-CN_TOPIC_0000002370251097__li14324287514">GE：大于或等于（greater than or equal to）</li>
     <li id="ZH-CN_TOPIC_0000002370251097__li3297153812518">EQ：等于（equal to）</li>
     <li id="ZH-CN_TOPIC_0000002370251097__li19737134519504">NE：不等于（not equal to）</li>
     <li id="ZH-CN_TOPIC_0000002370251097__li13738164555011">LE：小于或等于（less than or equal to）</li>
    </ul>
