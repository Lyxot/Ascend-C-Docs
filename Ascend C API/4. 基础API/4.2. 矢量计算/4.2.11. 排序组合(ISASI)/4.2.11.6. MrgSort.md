<div class="section" id="ZH-CN_TOPIC_0000002370251493__section618mcpsimp"><h4 class="sectiontitle">功能说明</h4><p id="ZH-CN_TOPIC_0000002370251493__p10462291478">将已经排好序的最多4条队列，合并排列成1条队列，结果按照score域由大到小排序。</p>
