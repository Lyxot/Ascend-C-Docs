    <h4 class="sectiontitle">功能说明</h4>
    <p id="ZH-CN_TOPIC_0000002336174578__p1312023415718">对输入做量化并进行精度转换。不同的数据类型，转换公式不同。</p>
    <ul id="ZH-CN_TOPIC_0000002336174578__ul154899239582">
     <li id="ZH-CN_TOPIC_0000002336174578__li10489323105819"><span id="ZH-CN_TOPIC_0000002336174578__ph464016551376">在输入类型为int16_t的情况下，</span>对int16_t类型的输入做量化并进行精度转换，得到int8_t/uint8_t类型的数据。使用该接口前需要调用<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0099.html">SetDeqScale</a>设置scale、offset、signMode等量化参数。
      <p id="ZH-CN_TOPIC_0000002336174578__p13228152311373">通过模板参数isVecDeq控制是否选择向量量化模式。</p>
      <ul id="ZH-CN_TOPIC_0000002336174578__ul785121262817">
       <li id="ZH-CN_TOPIC_0000002336174578__li138361320162916">当isVecDeq=false时，根据SetDeqScale设置的scale、offset、signMode，对输入做量化并进行精度转换。计算公式如下：
        <p id="ZH-CN_TOPIC_0000002336174578__p166637958"><a name="ZH-CN_TOPIC_0000002336174578__li138361320162916"></a><a name="li138361320162916"></a><span><img class="mathml" id="ZH-CN_TOPIC_0000002336174578__image67429612248" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_formulaimage_0000002336176470.png"></span></p></li>
      </ul>
      <ul id="ZH-CN_TOPIC_0000002336174578__ul94541234163019">
       <li id="ZH-CN_TOPIC_0000002336174578__li1945416341307">当isVecDeq=true时，根据SetDeqScale设置的一段128B的UB上的16组量化参数scale<sub id="ZH-CN_TOPIC_0000002336174578__sub414892413511">0</sub>-scale<sub id="ZH-CN_TOPIC_0000002336174578__sub21484241958">15</sub>、offset<sub id="ZH-CN_TOPIC_0000002336174578__sub1014811247516">0</sub>-offset<sub id="ZH-CN_TOPIC_0000002336174578__sub6148224655">15</sub>、signMode<sub id="ZH-CN_TOPIC_0000002336174578__sub5148132415511">0</sub>-signMode<sub id="ZH-CN_TOPIC_0000002336174578__sub111489246516">15</sub>，以循环的方式对输入做量化并进行精度转换。计算公式如下：
        <p id="ZH-CN_TOPIC_0000002336174578__p1514892416513"><span><img class="mathml" id="ZH-CN_TOPIC_0000002336174578__image14307101218244" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_formulaimage_0000002336336246.png"></span></p></li>
      </ul></li>
     <li id="ZH-CN_TOPIC_0000002336174578__li159541429105814">在输入类型为int32_t的情况下，对int32_t类型的输入做量化并进行精度转换，得到half类型的数据。使用该接口前需要调用<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0099.html">SetDeqScale</a>设置scale参数。
