    <h4 class="sectiontitle">功能说明</h4>
    <p class="msonormal" id="ZH-CN_TOPIC_0000002336173718__p1170511253416">功能分为水平迭代和垂直迭代。每个水平迭代顺序地从src0Offset读取8个偏移值，表示src0的偏移，每个偏移值指向src0的一个<span id="ZH-CN_TOPIC_0000002336173718__ph1642151741316">DataBlock</span>的起始地址，如果repeatMode=false，从src1中取一个值，与src0中8个<span id="ZH-CN_TOPIC_0000002336173718__ph1491619210139">DataBlock</span>中每个值进行乘操作；如果repeatMode=true，从src1中取8个值，按顺序与src0中8个<span id="ZH-CN_TOPIC_0000002336173718__ph17668174813123">DataBlock</span>中的值进行乘操作，最后当前迭代的dst结果与前一个dst结果按<span id="ZH-CN_TOPIC_0000002336173718__ph123261523127">DataBlock</span>进行累加，存入目的地址，在同一个水平迭代内dst地址不变。然后进行垂直迭代，垂直迭代的dst起始地址为上一轮垂直迭代的dst起始地址加上vROffset，本轮垂直迭代占用dst空间为dst起始地址之后的8个<span id="ZH-CN_TOPIC_0000002336173718__ph480117544125">DataBlock</span>，每轮垂直迭代进行hRepeat次水平迭代。</p>
    <p id="ZH-CN_TOPIC_0000002336173718__p1089316872514"><span><img class="eddx" id="ZH-CN_TOPIC_0000002336173718__image2284171375710" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002370253253.png"></span></p>
