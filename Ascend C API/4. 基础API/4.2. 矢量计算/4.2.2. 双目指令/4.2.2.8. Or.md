    <h4 class="sectiontitle">约束说明</h4>
    <ul id="ZH-CN_TOPIC_0000002370171945__ul1761mcpsimp">
     <li id="ZH-CN_TOPIC_0000002370171945__li1776mcpsimp">使用tensor高维切分计算接口时，节省地址空间，开发者可以定义一个Tensor，供源操作数与目的操作数同时使用（即地址重叠），相关约束如下：
      <ul id="ZH-CN_TOPIC_0000002370171945__ul1201559192814">
       <li id="ZH-CN_TOPIC_0000002370171945__li129655772817">单次迭代内，要求源操作数和目的操作数之间100%重叠，不支持部分重叠。</li>
       <li id="ZH-CN_TOPIC_0000002370171945__li199847102919">多次迭代间，第N次目的操作数是第N+1次源操作数的情况下，是不支持地址重叠的，因为第N+1次依赖第N次的结果。</li>
      </ul></li>
    </ul>
    <ul id="ZH-CN_TOPIC_0000002370171945__ul191871049165113">
     <li id="ZH-CN_TOPIC_0000002370171945__li5579012733">使用整个tensor参与计算符号重载时，运算量为目的LocalTensor的总长度。</li>
    </ul>
    <ul id="ZH-CN_TOPIC_0000002370171945__ul195491551216">
     <li id="ZH-CN_TOPIC_0000002370171945__li124011313290">操作数地址偏移对齐要求请参见<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0004.html">通用约束</a>。</li>
     <li id="ZH-CN_TOPIC_0000002370171945__li751511512122">特别的，针对uint32_t/int32_t类型的Or操作，支持通过ReinterpretCast的方式来实现：使用Local Tensor的ReinterpretCast转换成uint16_t/int16_t后再调用Or进行计算。直接传入uint32_t/int32_t类型的数据，在不同版本型号上表现会有所差异，考虑到算子在各个版本中的兼容性，不建议使用这种直接传入的方式：
