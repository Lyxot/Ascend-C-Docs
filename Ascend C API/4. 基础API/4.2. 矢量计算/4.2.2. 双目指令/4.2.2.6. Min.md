    <h4 class="sectiontitle">约束说明</h4>
    <ul id="ZH-CN_TOPIC_0000002370252597__ul1761mcpsimp">
     <li id="ZH-CN_TOPIC_0000002370252597__li1776mcpsimp">使用tensor高维切分计算接口时，节省地址空间，开发者可以定义一个Tensor，供源操作数与目的操作数同时使用（即地址重叠），相关约束如下：
      <ul id="ZH-CN_TOPIC_0000002370252597__ul1777mcpsimp">
       <li id="ZH-CN_TOPIC_0000002370252597__li1778mcpsimp">对于单次repeat（repeatTimes=1），且源操作数与目的操作数之间要求100%完全重叠，不支持部分重叠。</li>
       <li id="ZH-CN_TOPIC_0000002370252597__li1781mcpsimp">对于多次repeat（repeatTimes&gt;1），操作数与目的操作数之间存在依赖的情况下，即第N次迭代的目的操作数是第N+1次的源操作数，不支持地址重叠。以下情况是支持地址重叠的：当数据类型为half，int32_t，float时，支持目的操作数与第二个源操作数重叠；src1RepStride或者dstRepStride为0；src0与src1之间不能有任何的地址重叠。</li>
      </ul></li>
    </ul>
    <ul id="ZH-CN_TOPIC_0000002370252597__ul195491551216">
     <li id="ZH-CN_TOPIC_0000002370252597__li124011313290">操作数地址偏移对齐要求请参见<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0004.html">通用约束</a>。</li>
    </ul>
