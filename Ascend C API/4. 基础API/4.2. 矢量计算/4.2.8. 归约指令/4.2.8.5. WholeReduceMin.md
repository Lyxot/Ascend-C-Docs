    <h4 class="sectiontitle">约束说明</h4>
    <ul id="ZH-CN_TOPIC_0000002336174418__ul144961427164811">
     <li id="ZH-CN_TOPIC_0000002336174418__li17843193715482">srcLocal和dstLocal地址对齐要求请见 ：<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0004.html">通用约束</a>。</li>
     <li id="ZH-CN_TOPIC_0000002336174418__li1776mcpsimp">为节省地址空间，开发者可以定义一个Tensor，供源操作数与目的操作数同时使用（即地址重叠），相关约束如下：
      <ul id="ZH-CN_TOPIC_0000002336174418__ul1777mcpsimp">
       <li id="ZH-CN_TOPIC_0000002336174418__li1778mcpsimp">对于单次repeat（repeatTimes=1），且源操作数与目的操作数之间要求100%完全重叠，不支持部分重叠。</li>
       <li id="ZH-CN_TOPIC_0000002336174418__li1781mcpsimp">对于多次repeat（repeatTimes&gt;1），操作数与目的操作数之间存在依赖的情况下，即第N次迭代的目的操作数是第N+1次的源操作数，不支持地址重叠。</li>
      </ul></li>
     <li id="ZH-CN_TOPIC_0000002336174418__li15409185923920">dstLocal结果存储顺序由order决定，默认为最值，最值索引。返回结果中索引index数据按照dstLocal的数据类型进行存储，比如dstLocal使用half类型时，index按照half类型进行存储，读取时需要使用reinterpret_cast方法转换到整数类型。若输入数据类型是half，需要使用reinterpret_cast&lt;uint16_t*&gt;，若输入是float，需要使用reinterpret_cast&lt;uint32_t*&gt;。比如<a href="#ZH-CN_TOPIC_0000002336174418__section642mcpsimp">调用示例</a>中，前两个计算结果为[9.980e-01 5.364e-06]，5.364e-06需要使用reinterpret_cast方法转换得到索引值90。</li>
     <li id="ZH-CN_TOPIC_0000002336174418__li62301276515">针对不同场景合理使用归约指令可以带来性能提升，相关介绍请参考<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/opdevg/ascendcbestP/atlas_ascendc_best_practices_10_0031.html">针对不同场景合理使用归约指令</a>，具体样例请参考<span id="ZH-CN_TOPIC_0000002336174418__ph75302464319"><a href="https://gitee.com/ascend/samples/tree/v1.5-8.2.RC1/operator/ascendc/0_introduction/14_reduce_frameworklaunch/ReduceCustom" target="_blank" rel="noopener noreferrer">ReduceCustom</a></span>。</li>
    </ul>
