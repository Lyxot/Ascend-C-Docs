    <h4 class="sectiontitle">约束说明</h4>
    <ul id="ZH-CN_TOPIC_0000002370251185__ul17809351949">
     <li id="ZH-CN_TOPIC_0000002370251185__li38161226123420">为了节省地址空间，开发者可以定义一个Tensor，供srcLocal、dstLocal、workLocal同时使用（即地址重叠），地址重叠的约束条件如下：
      <ul id="ZH-CN_TOPIC_0000002370251185__ul139621524134813">
       <li id="ZH-CN_TOPIC_0000002370251185__li147013402420">若源操作数与目的操作数之间存在依赖，即第N次迭代的目的操作数是第N+1次的源操作数，这种情况不支持地址重叠。</li>
       <li id="ZH-CN_TOPIC_0000002370251185__li81438426511">需要使用workLocal的情况下，dstLocal与workLocal地址重叠时（通常情况下dstLocal比workLocal所需的空间要小），workLocal必须满足最小所需空间要求，否则不支持地址重叠。</li>
       <li id="ZH-CN_TOPIC_0000002370251185__li6349437102115">各操作数地址如重叠则要求100%完全重叠，不支持部分重叠。</li>
      </ul></li>
    </ul>

     <li id="ZH-CN_TOPIC_0000002370251185__li43154581748">dstLocal结果存储顺序为最小值，最小值索引，若不需要索引，只会存储最小值。返回结果中索引index数据是按照dstLocal的数据类型进行存储的，比如dstLocal使用half类型时，index按照half类型进行存储，如果按照half格式进行读取，index的值是不对的，因此index的读取需要使用reinterpret_cast方法转换到整数类型。若输入数据类型是half，需要使用reinterpret_cast&lt;uint16_t*&gt;，若输入是float，需要使用reinterpret_cast&lt;uint32_t*&gt;。比如<a href="#ZH-CN_TOPIC_0000002370251185__li0437172884019">tensor高维切分计算接口完整调用示例:</a>中，计算结果为[0.01034, 2.104e-05]，2.104e-05需要使用reinterpret_cast方法转换得到索引值353。转换示例如下：
