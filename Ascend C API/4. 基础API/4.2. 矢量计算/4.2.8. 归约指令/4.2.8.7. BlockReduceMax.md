    <h4 class="sectiontitle">约束说明</h4>
    <ul id="ZH-CN_TOPIC_0000002336333794__ul1554144871311">
     <li id="ZH-CN_TOPIC_0000002336333794__li151671047171411">为了节省地址空间，您可以定义一个Tensor，供源操作数与目的操作数同时使用（即地址重叠），需要注意计算后的目的操作数数据不能覆盖未参与计算的源操作数，需要谨慎使用。</li>
     <li id="ZH-CN_TOPIC_0000002336333794__li49152583917">对于<span id="ZH-CN_TOPIC_0000002336333794__ph582162318212"><term id="ZH-CN_TOPIC_0000002336333794__zh-cn_topic_0000002336176798_term354143892110_2">
        Atlas 200I/500 A2 推理产品
       </term></span>，若配置mask/mask[]参数后，存在某个datablock里的任何一个元素都不参与计算，则该datablock内所有元素的最大值会填充为-inf返回。比如float场景下，当mask配置为32，即只计算前4个datablock，则后四个datablock内的最大值会返回-inf。half场景下会返回-65504。</li>
     <li id="ZH-CN_TOPIC_0000002336333794__li124011313290">操作数地址偏移对齐要求请参见<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0004.html">通用约束</a>。</li>
     <li id="ZH-CN_TOPIC_0000002336333794__li62301276515">针对不同场景合理使用归约指令可以带来性能提升，相关介绍请参考<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/opdevg/ascendcbestP/atlas_ascendc_best_practices_10_0031.html">针对不同场景合理使用归约指令</a>，具体样例请参考<span id="ZH-CN_TOPIC_0000002336333794__ph75302464319"><a href="https://gitee.com/ascend/samples/tree/v1.5-8.2.RC1/operator/ascendc/0_introduction/14_reduce_frameworklaunch/ReduceCustom" target="_blank" rel="noopener noreferrer">ReduceCustom</a></span>。</li>
