    <h4 class="sectiontitle">功能说明</h4>
    <p id="ZH-CN_TOPIC_0000002370171365__p1030820286145">数据格式转换，一般用于将NCHW格式转换成NC1HWC0格式。特别的，也可以用于二维矩阵数据块的转置。完成转置功能时，相比于<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0199.html">Transpose</a>接口，Transpose仅支持16*16大小的矩阵转置；本接口单次repeat内可处理512Byte的数据（16个datablock），根据数据类型不同，支持不同shape的矩阵转置（比如数据类型为half时，单次repeat可完成16*16大小的矩阵转置），同还可以支持多次repeat操作。</p>
    <p id="ZH-CN_TOPIC_0000002370171365__p149761955112">单次repeat内转换规则如下：</p>
    <ul id="ZH-CN_TOPIC_0000002370171365__ul9157123734520">
     <li id="ZH-CN_TOPIC_0000002370171365__li1883175813114">当输入数据类型位宽为16位时，每个datablock中包含16个数，指令内部会循环16次，每次循环都会分别从指定的16个datablock中的对应位置取值，组成一个新的datablock单元放入目的地址中。如下图所示，图中的srcLocalList[0]-srcLocalList[15]代表源操作数的16个datablock。 
      <div class="fignone" id="ZH-CN_TOPIC_0000002370171365__fig1361914810458">
       <span class="figcap"><b>图1 </b>输入数据类型位宽为16位时的转换规则</span>
       <br><span><img class="eddx" id="ZH-CN_TOPIC_0000002370171365__image1950919410207" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002370173001.png"></span>
      </div></li>
     <li id="ZH-CN_TOPIC_0000002370171365__li49541643148">当数据类型位宽为32位时，每个datablock包含8个数，指令内部会循环8次，每次循环都会分别从指定的16个datablock中的对应位置取值，组成2个新的datablock放入目的地址中。如下图所示： 
      <div class="fignone" id="ZH-CN_TOPIC_0000002370171365__fig186798494611">
       <span class="figcap"><b>图2 </b>输入数据类型位宽为32位时的转换规则</span>
       <br><span><img class="imgResize" id="ZH-CN_TOPIC_0000002370171365__image633165111283" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002336334646.png" title="点击放大"></span>
      </div></li>
     <li id="ZH-CN_TOPIC_0000002370171365__li471819513135">当数据类型位宽为8位时，每个datablock包含32个数，指令内部会循环16次，每次循环都会分别从指定的16个datablock中的对应位置取值，组成半个datablock放入目的地址中，读取和存放是在datablock的高半部还是低半部由参数srcHighHalf和dstHighHalf决定。如下图所示： 
      <div class="fignone" id="ZH-CN_TOPIC_0000002370171365__fig29071549185211">
       <span class="figcap"><b>图3 </b>输入数据类型位宽为8位时的转换规则</span>
       <br><span><img class="imgResize" id="ZH-CN_TOPIC_0000002370171365__image1907154915527" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002370252857.png" title="点击放大"></span>
      </div></li>
    </ul>
    <p id="ZH-CN_TOPIC_0000002370171365__p65789217242">基于以上的转换规则，使用该接口进行NC1HWC0格式转换或者矩阵转置。NC1HWC0格式转换相对复杂，这里给出其具体的转换方法：</p>
    <p id="ZH-CN_TOPIC_0000002370171365__p9818121495118">NCHW格式转换成NC1HWC0格式时，如果是数据类型的位宽为32位或者16位，则C0=16；如果数据类型的位宽为8位，则C0=32。下图以C0=16为例进行介绍：</p>
    <p id="ZH-CN_TOPIC_0000002370171365__p59819112710"><span><img class="eddx" id="ZH-CN_TOPIC_0000002370171365__image3902122112714" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002370252849.png"></span></p>
   </div>

    <h4 class="sectiontitle">约束说明</h4>
    <ul id="ZH-CN_TOPIC_0000002370171365__zh-cn_topic_0000001521260417_ul1121114715127">
     <li id="ZH-CN_TOPIC_0000002370171365__li3976423185010">进行NCHW格式到NC1HWC0格式的转换时，一般用法是将srcLocalList/dstLocalList中的每个元素配置为每个HW平面的起点。</li>
     <li id="ZH-CN_TOPIC_0000002370171365__li1497682375017">为了性能更优，数据类型位宽为8位时建议先固定dstHighHalf、srcHighHalf，在HW方向repeat后，再改变dstHighHalf、srcHighHalf。</li>
     <li id="ZH-CN_TOPIC_0000002370171365__li59761423135018">为了节省地址空间，开发者可以定义一个Tensor，供源操作数与目的操作数同时使用（即地址重叠），相关约束如下： 
      <ul id="ZH-CN_TOPIC_0000002370171365__ul3976723185019">
       <li id="ZH-CN_TOPIC_0000002370171365__li2976123185010">对于单次repeat（repeatTimes=1），且源操作数序列与目的操作数序列之间要求100%完全重叠，不支持部分重叠，且每一个block都必须相等。</li>
       <li id="ZH-CN_TOPIC_0000002370171365__li20976192311508">对于多次repeat（repeatTimes&gt;1），若源操作数序列与目的操作数序列之间存在依赖，即第N次迭代的目的操作数是第N+1次的源操作数，这种情况是不支持地址重叠的。</li>
      </ul></li>
     <li id="ZH-CN_TOPIC_0000002370171365__li124011313290">操作数地址偏移对齐要求请参见<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0004.html">通用约束</a>。</li>
     <li id="ZH-CN_TOPIC_0000002370171365__li14448142313478">dstLocal与srcLocal中的地址需要连续存放，详见调用示例。</li>
    </ul>
