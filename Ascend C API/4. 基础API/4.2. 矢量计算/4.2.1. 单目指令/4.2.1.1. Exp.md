        <td class="cellrowborder" valign="top" width="11.93%" headers="mcps1.3.4.3.2.4.1.2 ">

         <ul id="ZH-CN_TOPIC_0000002370171669__ul1255411133132">
          <li id="ZH-CN_TOPIC_0000002370171669__li855401313131">逐bit模式：可以按位控制哪些元素参与计算，bit位的值为1表示参与计算，0表示不参与。
           <p id="ZH-CN_TOPIC_0000002370171669__p121114581013"><a name="ZH-CN_TOPIC_0000002370171669__li855401313131"></a><a name="li855401313131"></a>mask为数组形式，数组长度和数组元素的取值范围和操作数的数据类型有关。当操作数为16位时，数组长度为2，mask[0]、mask[1]∈[0, 2<sup id="ZH-CN_TOPIC_0000002370171669__sup1411059101">64</sup>-1]并且不同时为0；当操作数为32位时，数组长度为1，mask[0]∈(0, 2<sup id="ZH-CN_TOPIC_0000002370171669__sup1711155161017">64</sup>-1]；当操作数为64位时，数组长度为1，mask[0]∈(0, 2<sup id="ZH-CN_TOPIC_0000002370171669__sup181195111019">32</sup>-1]。</p>
           <p id="ZH-CN_TOPIC_0000002370171669__p711354105">例如，mask=[8, 0]，8=0b1000，表示仅第4个元素参与计算。</p></li>
         </ul>
         <ul id="ZH-CN_TOPIC_0000002370171669__ul18554121313135">

    <h4 class="sectiontitle">约束说明</h4>
    <ul id="ZH-CN_TOPIC_0000002370171669__ul11256124104818">
     <li id="ZH-CN_TOPIC_0000002370171669__li38161226123420">为了节省地址空间，开发者可以定义一个Tensor，供源操作数与目的操作数同时使用（即地址重叠），约束如下，具体以各指令约束为准。
      <ul id="ZH-CN_TOPIC_0000002370171669__ul139621524134813">
       <li id="ZH-CN_TOPIC_0000002370171669__li996272494817">对于单次repeat（repeatTimes=1），且源操作数与目的操作数之间要求100%完全重叠，不支持部分重叠。</li>
       <li id="ZH-CN_TOPIC_0000002370171669__li147013402420">对于多次repeat（repeatTimes&gt;1），若源操作数与目的操作数之间存在依赖，即第N次迭代的目的操作数是第N+1次的源操作数，这种情况是不支持地址重叠的。</li>
      </ul></li>
     <li id="ZH-CN_TOPIC_0000002370171669__li124011313290">操作数地址偏移对齐要求请参见<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0004.html">通用约束</a>。</li>
    </ul>
