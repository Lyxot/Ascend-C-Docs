    <h4 class="sectiontitle">功能说明</h4>
    <p id="ZH-CN_TOPIC_0000002336333450__p121251142797">根据padMode（pad模式）与padSide（pad方向）对源操作数按照datablock进行填充操作。</p>
    <p id="ZH-CN_TOPIC_0000002336333450__p1472153316179">假设源操作数的一个datablock有16个数，datablock[0:15]=a~p：</p>
    <ul id="ZH-CN_TOPIC_0000002336333450__ul1773892716455">
     <li id="ZH-CN_TOPIC_0000002336333450__li57381827134520">padSide==false：从datablock的左边开始填充，即datablock的起始值方向(a-&gt;p)</li>
    </ul>
    <ul id="ZH-CN_TOPIC_0000002336333450__ul1448442964510">
     <li id="ZH-CN_TOPIC_0000002336333450__li74841296456">padSide==true：从datablock的右边开始填充，即datablock的结束值方向(p-&gt;a)</li>
     <li id="ZH-CN_TOPIC_0000002336333450__li6968104016454">padMode==0：用邻近数作为填充值，例：aaa|abc(padSide=false)、nop|ppp(padSide=true)</li>
     <li id="ZH-CN_TOPIC_0000002336333450__li1387813499459">padMode==1：用邻近datablock值对称填充，例：cba|abc(padSide=false)、nop|pon(padSide=true)</li>
     <li id="ZH-CN_TOPIC_0000002336333450__li1646755204515">padMode==2：用邻近datablock值填充，偏移一个数，做对称填充，例：
      <ul id="ZH-CN_TOPIC_0000002336333450__ul32171819317">
       <li id="ZH-CN_TOPIC_0000002336333450__li579841611316">padSide=false：xcb|abc，xcb被填充，填充过程描述：a被丢弃，对称填充，x处填充0</li>
       <li id="ZH-CN_TOPIC_0000002336333450__li20799161610314">padSide=true：nop|onx，onx被填充，填充过程描述：p被丢弃，对称填充，x处填充0</li>
      </ul></li>
    </ul>
