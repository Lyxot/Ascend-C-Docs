<div class="section" id="ZH-CN_TOPIC_0000002336333642__section618mcpsimp"><a name="ZH-CN_TOPIC_0000002336333642__section618mcpsimp"></a><a name="section618mcpsimp"></a><h4 class="sectiontitle">功能说明</h4><p id="ZH-CN_TOPIC_0000002336333642__p124281245667">完成矩阵乘加（C += A * B）操作。矩阵ABC分别为A2/B2/CO1中的数据。</p>
<p id="ZH-CN_TOPIC_0000002336333642__p357441365219">ABC矩阵的数据排布格式分别为ZZ，ZN，NZ。</p>
<p id="ZH-CN_TOPIC_0000002336333642__p9136205318181">下图中每个小方格代表一个分形矩阵，Z字形的黑色线条代表数据的排列顺序，起始点是左上角，终点是右下角。</p>
<p id="ZH-CN_TOPIC_0000002336333642__p114444141348">矩阵A：每个分形矩阵内部是行主序，分形矩阵之间是行主序。简称小Z大Z格式。分形shape为16 x (32B/sizeof(AType))，大小为512Byte。</p>
<p id="ZH-CN_TOPIC_0000002336333642__p12136175314181">矩阵B：每个分形矩阵内部是列主序，分形矩阵之间是行主序。简称小N大Z格式。分形shape为 (32B/sizeof(BType)) x 16，大小为512Byte。</p>
<p id="ZH-CN_TOPIC_0000002336333642__p1613615534185">矩阵C：每个分形矩阵内部是行主序，分形矩阵之间是列主序。简称小Z大N格式。分形shape为16 x 16，大小为256个元素。</p>
