    <h4 class="sectiontitle">功能说明</h4>
    <p id="ZH-CN_TOPIC_0000002336173244__p2589451153214">LoadData分为Load2D和Load3D，其功能分别如下：</p>
    <ul id="ZH-CN_TOPIC_0000002336173244__ul1133715418344">
     <li id="ZH-CN_TOPIC_0000002336173244__li83376433413">Load2D：
      <p id="ZH-CN_TOPIC_0000002336173244__p57476358503"><a name="ZH-CN_TOPIC_0000002336173244__li83376433413"></a><a name="li83376433413"></a>源操作数/目的操作数的数据类型为uint8_t/int8_t时，分形矩阵大小在A1/A2上为16*32， 在B1/B2上为32*16。</p>
      <p id="ZH-CN_TOPIC_0000002336173244__p97472035175015">源操作数/目的操作数的数据类型为uint16_t/int16_t/half/bfloat16_t时，分形矩阵在A1/B1/A2/B2上的大小为16*16。</p>
      <p id="ZH-CN_TOPIC_0000002336173244__p1641079112817">源操作数/目的操作数的数据类型为uint32_t/int32_t/float时，分形矩阵大小在A1/A2上为16*8， 在B1/B2上为8*16。</p>
      <p id="ZH-CN_TOPIC_0000002336173244__p47471535205015">支持如下数据通路：</p>
      <p id="ZH-CN_TOPIC_0000002336173244__p17947164317528">GM-&gt;A1; GM-&gt;B1; GM-&gt;A2; GM-&gt;B2;</p>
      <p id="ZH-CN_TOPIC_0000002336173244__p125720720714">A1-&gt;A2; B1-&gt;B2。</p></li>
    </ul>
    <ul id="ZH-CN_TOPIC_0000002336173244__ul773638133412">
     <li id="ZH-CN_TOPIC_0000002336173244__li0736189341">Load3D：
      <p id="ZH-CN_TOPIC_0000002336173244__p248395917507"><a name="ZH-CN_TOPIC_0000002336173244__li0736189341"></a><a name="li0736189341"></a>image to column操作，将多维feature map转为二维矩阵。</p>
      <p id="ZH-CN_TOPIC_0000002336173244__p1271914227516">支持如下数据通路：</p>
      <p id="ZH-CN_TOPIC_0000002336173244__p184845597506">A1-&gt;A2; B1-&gt;B2。</p></li>
    </ul>

    <h4 class="sectiontitle">load3d数据格式说明</h4>
    <p id="ZH-CN_TOPIC_0000002336173244__p73272195199">要求输入的feature map和filter的格式是 NC1HWC0，其中 C0 是最低维度而且 C0 是固定值为 16（对于u8/s8类型为32），C1=C/C0。</p>
    <p id="ZH-CN_TOPIC_0000002336173244__p3365132919196"></p>
    <p id="ZH-CN_TOPIC_0000002336173244__p17674102120198">为了简化场景，以下场景假设输入的 feature map 的 channel 为4，即 Ci=4。输入 feature maps 在 A1 中的形状为 (Hi,Wi,Ci)，经过 load3dv1 处理后在 A2 的数据形状为(Wo*Ho, Hk*Wk*Ci)。其中 Wo 和 Ho 是卷积后输出的shape，Hk 和 Wk 是 filter 的 shape。</p>
    <p id="ZH-CN_TOPIC_0000002336173244__p74473051910"></p>
    <p id="ZH-CN_TOPIC_0000002336173244__p350001711586">直观的来看，img2col 的过程就是 filter 在 feature map 上扫过，将对应 feature map 的数据展开成输出数据的每一行的过程。filter 首先在W方向上滑动 Wo 步,然后在 H 方向上走一步然后重复以上过程，最终输出 Wo*Ho 行数据。下图中红色和黄色的数据分别代表第一行和第二行。数字表示原始输入数据，filter 和输出数据三者之间的关联关系。可以看到，load3dv1 首先在输入数据的 Ci 维度搬运对应于 00 的 4 个数，然后搬运对应于 01 的四个数，最终这一行的大小为 Hk*Wk*Ci 即 3*3*4=36 个数。</p>
    <p id="ZH-CN_TOPIC_0000002336173244__p18383173511210">对应的feature map格式如下图：</p>
    <p id="ZH-CN_TOPIC_0000002336173244__p1483153361918"><span><img id="ZH-CN_TOPIC_0000002336173244__image1189419190208" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002370172961.png" title="点击放大" class="imgResize"></span></p>
    <p id="ZH-CN_TOPIC_0000002336173244__p1419044312312">对应的 filter 的格式如下图：</p>
    <p id="ZH-CN_TOPIC_0000002336173244__p131909437235">其中 n 为 filter 的个数，可以看出维度排布为 (Hk,Wk,Ci,n)，但是需要注意的是下图的格式还需要根据Mmad中B矩阵的格式转换。</p>
    <p id="ZH-CN_TOPIC_0000002336173244__p42031711172112"><span><img id="ZH-CN_TOPIC_0000002336173244__image13681549102218" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002370172969.png" title="点击放大" class="imgResize"></span></p>
    <p id="ZH-CN_TOPIC_0000002336173244__p1057313217231">实际操作中，由于存储空间或者计算能力限制，我们通常会将整个卷积计算分块，一次只搬运并计算一小块数据。</p>
    <p id="ZH-CN_TOPIC_0000002336173244__p17649818132317"><span><img id="ZH-CN_TOPIC_0000002336173244__image17564352162314" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002336334610.png" title="点击放大" class="imgResize"></span></p>
    <p id="ZH-CN_TOPIC_0000002336173244__p1019004311237">对于 A2 的 feature map 来说有两种方案，水平分块和垂直分块。分别对应参数中 repeatMode 的 0 和 1。</p>
