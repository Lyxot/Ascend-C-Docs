   <div class="section" id="ZH-CN_TOPIC_0000002336173530__section618mcpsimp">
    <h4 class="sectiontitle">功能说明</h4>
    <p id="ZH-CN_TOPIC_0000002336173530__p162351222192118">设置图片预处理（AIPP，AI core pre-process）相关参数。和<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0241.html">LoadImageToLocal</a>接口配合使用。设置后，调用<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0241.html">LoadImageToLocal</a>接口可在搬运过程中完成图像预处理操作：包括数据填充，通道交换，单行读取、数据类型转换、通道填充、色域转换。调用SetAippFunctions接口时需传入源图片在Global Memory上的矩阵、源图片的图片格式。</p>
    <ul id="ZH-CN_TOPIC_0000002336173530__ul420912117223">
     <li id="ZH-CN_TOPIC_0000002336173530__li32099112222"><strong id="ZH-CN_TOPIC_0000002336173530__b6486843113811">数据填充</strong>：在图片HW方向上padding。分为如下几种模式：
      <ul id="ZH-CN_TOPIC_0000002336173530__ul846421719199">
       <li id="ZH-CN_TOPIC_0000002336173530__li13403181311916">模式0：常量填充模式，padding区域各位置填充为常数，支持设置每个通道填充的常数。该模式下仅支持左右padding，不支持上下padding。
        <div class="fignone" id="ZH-CN_TOPIC_0000002336173530__fig56681157121916">
         <span class="figcap"><b>图1 </b>常量填充模式（图片中间的绿色区域表示原始数据，其他为padding数据）</span>
         <br><span><img id="ZH-CN_TOPIC_0000002336173530__image2035273742515" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002336334866.png"></span>
        </div></li>
       <li id="ZH-CN_TOPIC_0000002336173530__li1567112576190">模式1：行列填充模式，padding区域各位置填充行/列上最邻近源图片位置的数据。
        <div class="fignone" id="ZH-CN_TOPIC_0000002336173530__fig4239143712713">
         <span class="figcap"><b>图2 </b>行列填充模式（图片中间的绿色区域表示原始数据，其他为padding数据）</span>
         <br><span><img id="ZH-CN_TOPIC_0000002336173530__image1633094817612" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002370253053.png" title="点击放大" class="imgResize"></span>
        </div></li>
       <li id="ZH-CN_TOPIC_0000002336173530__li153681619152617">模式2：块填充模式，按照padding的宽高，从源图片拷贝数据块进行padding区域填充。
        <div class="fignone" id="ZH-CN_TOPIC_0000002336173530__fig38821202817">
         <span class="figcap"><b>图3 </b>块填充模式（图片中间的绿色区域表示原始数据，其他为padding数据）</span>
         <br><span><img id="ZH-CN_TOPIC_0000002336173530__image28810182810" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002370253065.png"></span>
        </div></li>
       <li id="ZH-CN_TOPIC_0000002336173530__li12953183118272">模式3：镜像块填充模式，按照padding的宽高，从源图片拷贝数据块的镜像进行padding区域填充。
        <div class="fignone" id="ZH-CN_TOPIC_0000002336173530__fig14371141920261">
         <span class="figcap"><b>图4 </b>镜像块填充模式（图片中间的绿色区域表示原始数据，其他为padding数据）</span>
         <br><span><img id="ZH-CN_TOPIC_0000002336173530__image5371919182611" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002370253061.png"></span>
        </div></li>
      </ul></li>
    </ul>
    <ul id="ZH-CN_TOPIC_0000002336173530__ul820931162212">
     <li id="ZH-CN_TOPIC_0000002336173530__li5608318182310"><strong id="ZH-CN_TOPIC_0000002336173530__b1981964943815">通道交换</strong>：将图片通道进行交换。
      <p id="ZH-CN_TOPIC_0000002336173530__p3218254195810">对于RGB888格式，支持交换R和B通道。</p>
      <p id="ZH-CN_TOPIC_0000002336173530__p4885131255910">对于YUV420SP格式，支持交换U和V通道。</p>
      <p id="ZH-CN_TOPIC_0000002336173530__p19225630165918">对于XRGB8888格式，支持X通道后移（XRGB-&gt;RGBX）、支持交换R和B通道。</p>
      <p id="ZH-CN_TOPIC_0000002336173530__p1355692012313">例：对于XRGB格式的数据，芯片在处理的时候会默认丢弃掉第四个通道的数据留下XRG。因此如果要保留RGB通道的数据，对于XRGB输入的需要后移X通道，将输入的通道转换为RGBX即可。</p></li>
    </ul>
    <ul id="ZH-CN_TOPIC_0000002336173530__ul1920981112228">
     <li id="ZH-CN_TOPIC_0000002336173530__li1209141117225"><strong id="ZH-CN_TOPIC_0000002336173530__b1359885119386">单行读取</strong>：源图片中仅读取一行。

       <div class="notebody">
        <p id="ZH-CN_TOPIC_0000002336173530__p5235843612">调用数据搬运接口时，开启单行读取后设置的目的图片高度参数无效，如<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0241.html">LoadImageToLocal</a>接口的loadImageToLocalParams.verSize。</p>
