<div class="section" id="ZH-CN_TOPIC_0000002336173096__section618mcpsimp"><h4 class="sectiontitle">功能说明</h4><p id="ZH-CN_TOPIC_0000002336173096__p124281245667">该接口实现带转置的2D格式数据从A1/B1到A2/B2的加载。</p>
<p id="ZH-CN_TOPIC_0000002336173096__p17900712549">下面通过示例来讲解接口功能和关键参数：下文图中一个N形或者一个Z形代表一个分形。</p>
<ul id="ZH-CN_TOPIC_0000002336173096__ul17325124917916"><li id="ZH-CN_TOPIC_0000002336173096__li19950154911157">对于uint8_t/int8_t数据类型，每次迭代处理32*32*1B数据，可处理2个分形(一个分形512B)，每次迭代中，源操作数中2个连续的16*32分形将被合并为1个32*32的方块矩阵，基于方块矩阵做转置，转置后分裂为2个16*32分形，根据目的操作数分形间隔等参数可以有不同的排布。<div class="p" id="ZH-CN_TOPIC_0000002336173096__p84525543150"><a name="ZH-CN_TOPIC_0000002336173096__li19950154911157"></a><a name="li19950154911157"></a>如下图示例：<ul id="ZH-CN_TOPIC_0000002336173096__ul462762091518"><li id="ZH-CN_TOPIC_0000002336173096__li14647339141510">因为每次迭代处理32*32*1B数据，需要3次迭代可以完成，repeatTimes = 3；</li><li id="ZH-CN_TOPIC_0000002336173096__li7777171572119">srcStride = 1，表示相邻迭代间，源操作数前一个方块矩阵与后一个方块矩阵起始地址的间隔为1（单位：32*32*1B），这里的单位实际上是拼接后的方块矩阵的大小；</li><li id="ZH-CN_TOPIC_0000002336173096__li12573171921515">dstGap = 1，表示相邻迭代间，目的操作数前一个迭代第一个分形的结束地址到下一个迭代第一个分形起始地址的间隔为1（单位：512B）；</li><li id="ZH-CN_TOPIC_0000002336173096__li17668182671610">dstFracGap = 0，表示每个迭代内目的操作数前一个分形的结束地址与后一个分形起始地址的间隔为0（单位：512B）。</li></ul>
</div>
<p id="ZH-CN_TOPIC_0000002336173096__p82371331537"><span><img class="eddx" id="ZH-CN_TOPIC_0000002336173096__image144578505526" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002336334530.png"></span></p>
<p id="ZH-CN_TOPIC_0000002336173096__p11174249163">如下图示例：</p>
<ul id="ZH-CN_TOPIC_0000002336173096__ul194685514165"><li id="ZH-CN_TOPIC_0000002336173096__li94205468160">repeatTimes和srcStride的解释和上图示例一致。</li><li id="ZH-CN_TOPIC_0000002336173096__li892714771614">dstGap = 0，表示相邻迭代间，目的操作数前一个迭代第一个分形的结束地址和下一个迭代第一个分形起始地址无间隔。</li><li id="ZH-CN_TOPIC_0000002336173096__li538456507">dstFracGap = 2，表示每个迭代内目的操作数前一个分形的结束地址与后一个分形起始地址的间隔为2（单位：512B）。</li></ul>
<p id="ZH-CN_TOPIC_0000002336173096__p13164121413318"></p>
<p id="ZH-CN_TOPIC_0000002336173096__p206341141934"><span><img class="eddx" id="ZH-CN_TOPIC_0000002336173096__image548671352914" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002370172873.png"></span></p>
</li></ul>
<ul id="ZH-CN_TOPIC_0000002336173096__ul207481127151119"><li id="ZH-CN_TOPIC_0000002336173096__li14748182716118">对于half/bfloat16_t数据类型，每次迭代处理16*16*2B数据，可处理1个分形(一个分形512B)，每次迭代中，源操作数中1个16*16分形将被转置。<ul id="ZH-CN_TOPIC_0000002336173096__ul26571358111220"><li id="ZH-CN_TOPIC_0000002336173096__li147815134144">因为每次迭代处理16*16*2B数据，需要3次迭代可以完成，repeatTimes = 3；</li><li id="ZH-CN_TOPIC_0000002336173096__li7331194831210">srcStride = 1，表示相邻迭代间，源操作数前一个方块矩阵与后一个方块矩阵起始地址的间隔为1 （单位：16*16*2B）；</li><li id="ZH-CN_TOPIC_0000002336173096__li4998165314122">dstGap = 0，表示相邻迭代间，目的操作数前一个迭代第一个分形的结束地址到下一个迭代第一个分形起始地址无间隔；</li><li id="ZH-CN_TOPIC_0000002336173096__li102631558141510">该场景下，因为其分形即为方块矩阵，每个迭代处理一个分形，不存在迭代内分形的间隔，该参数设置无效。</li></ul>
<p id="ZH-CN_TOPIC_0000002336173096__p430112491312"><span><img class="eddx" id="ZH-CN_TOPIC_0000002336173096__image173331221131119" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002336174754.png"></span></p>
</li></ul>

<ul id="ZH-CN_TOPIC_0000002336173096__ul97193212197"><li id="ZH-CN_TOPIC_0000002336173096__li3475153543020">对于float/int32_t/uint32_t数据类型，每次迭代处理16*16*4B数据，可处理2个分形（一个分形512B），每次迭代中，源操作数2个连续的16*8分形将被合并为1个16*16的方块矩阵，基于方块矩阵做转置，转置后分裂为2个16*8分形，根据目的操作数分形间隔等参数可以有不同的排布。<div class="p" id="ZH-CN_TOPIC_0000002336173096__p426616290593"><a name="ZH-CN_TOPIC_0000002336173096__li3475153543020"></a><a name="li3475153543020"></a>如下图示例：<ul id="ZH-CN_TOPIC_0000002336173096__ul626612292598"><li id="ZH-CN_TOPIC_0000002336173096__li16266102910593">因为每次迭代处理16*16*4B数据，需要3次迭代可以完成，repeatTimes = 3；</li><li id="ZH-CN_TOPIC_0000002336173096__li62666297595">srcStride = 1，表示相邻迭代间，源操作数前一个方块矩阵与后一个方块矩阵起始地址的间隔为1（单位：16*16*4B），这里的单位实际上是拼接后的方块矩阵的大小；</li><li id="ZH-CN_TOPIC_0000002336173096__li17266152919597">dstGap = 1，表示相邻迭代间，目的操作数前一个迭代第一个分形的结束地址到下一个迭代第一个分形起始地址的间隔为1（单位：512B）；</li><li id="ZH-CN_TOPIC_0000002336173096__li162661929185917">dstFracGap = 0，表示每个迭代内目的操作数前一个分形结束地址与后一个分形起始地址的间隔为0（单位：512B）。</li></ul>
