<div class="section" id="ZH-CN_TOPIC_0000002370171377__section84021317123613"><h4 class="sectiontitle">约束说明</h4><ul id="ZH-CN_TOPIC_0000002370171377__ul64021717183618"><li id="ZH-CN_TOPIC_0000002370171377__li1940231743614">假设芯片的AIV核数为x，那么blockStart + blockSize &lt;= x - 1, msgQueueSize &lt;= x。</li><li id="ZH-CN_TOPIC_0000002370171377__li11402217183610">每个AIC至少被分配1个msgQueue。</li><li id="ZH-CN_TOPIC_0000002370171377__li10402417153611">blockStart和blockSize必须为偶数。</li><li id="ZH-CN_TOPIC_0000002370171377__li188313199347">使用该接口，UB空间末尾的1600B + sizeof(CubeMsgType)将被占用。</li><li id="ZH-CN_TOPIC_0000002370171377__li19228175416425">1个AIC只能属于1个CubeGroupHandle，即多个CubeGroupHandle的[blockStart / 2, blockStart / 2 + blockSize / 2]区间不能重叠。</li><li id="ZH-CN_TOPIC_0000002370171377__li115035433211">不能和<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0628.html">REGIST_MATMUL_OBJ</a>接口同时使用。使用资源管理API时，用户自主管理AIC和AIV的核间通信，REGIST_MATMUL_OBJ内部是由框架管理AIC和AIV的核间通信，同时使用可能会导致通信消息错误等异常。</li></ul>
