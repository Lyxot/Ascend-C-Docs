    <h4 class="sectiontitle">功能说明</h4>
    <p id="ZH-CN_TOPIC_0000002336333574__zh-cn_topic_0000001526206862_p0824144014589">构造CubeResGroupHandle对象，完成组内的AIC和消息队列分配。构造CubeResGroupHandle对象时需要传入模板参数CubeMsgType，CubeMsgType是由用户定义的消息结构体，请参考<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0290.html#ZH-CN_TOPIC_0000002370251213__table189051237164018">表1</a>。使用此接口需要用户自主管理地址、同步事件等，因此更推荐使用<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0291.html">CreateCubeResGroup</a>接口快速创建CubeResGroupHandle对象。</p>

    <h4 class="sectiontitle">约束说明</h4>
    <ul id="ZH-CN_TOPIC_0000002336333574__ul19741223193310">
     <li id="ZH-CN_TOPIC_0000002336333574__li9740232337">假设芯片的AIV核数为x，那么blockStart + blockSize &lt;= x - 1, msgQueueSize &lt;= x。</li>
     <li id="ZH-CN_TOPIC_0000002336333574__li9741423103314">每个AIC至少被分配1个消息队列msgQueue。</li>
     <li id="ZH-CN_TOPIC_0000002336333574__li1781084081918">blockStart和blockSize必须为偶数。</li>
     <li id="ZH-CN_TOPIC_0000002336333574__li188313199347">使用该接口，UB空间末尾的1600B + sizeof(CubeMsgType)将被占用。</li>
     <li id="ZH-CN_TOPIC_0000002336333574__li1142719092512">1个AIC只能属于1个CubeGroupHandle，即多个CubeGroupHandle的[blockStart / 2, blockStart / 2+blockSize / 2]区间不能重叠。</li>
     <li id="ZH-CN_TOPIC_0000002336333574__li115035433211">不能和<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0628.html">REGIST_MATMUL_OBJ</a>接口同时使用。使用资源管理API时，用户自主管理AIC和AIV的核间通信，REGIST_MATMUL_OBJ内部是由框架管理AIC和AIV的核间通信，同时使用可能会导致通信消息错误等异常。</li>
    </ul>
