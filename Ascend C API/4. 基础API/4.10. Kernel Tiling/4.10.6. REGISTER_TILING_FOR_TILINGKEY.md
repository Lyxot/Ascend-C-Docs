<div class="section" id="ZH-CN_TOPIC_0000002370172337__zh-cn_topic_0000001526206862_section65498832"><h4 class="sectiontitle">约束说明</h4><ul id="ZH-CN_TOPIC_0000002370172337__ul165206523446"><li id="ZH-CN_TOPIC_0000002370172337__li1252085214413">使用该接口时，需确保已使用REGISTER_TILING_DEFAULT注册默认的用户自定义TilingData结构体，用于告知框架侧用户使用标准C++语法来定义TilingData。</li><li id="ZH-CN_TOPIC_0000002370172337__li1395032422316">EXPRESSION当前支持位运算：&amp;、|、~、^；移位运算符：&lt;&lt;、&gt;&gt;；算术运算：+、-、*、/、%；条件运算符：==、!=、&gt;、&lt;、&gt;=、&lt;=；逻辑与&amp;&amp;、或||以及()。优先级同C++。</li><li id="ZH-CN_TOPIC_0000002370172337__li6321192041711">若TilingData结构体在命名空间内，注册时需要携带对应的命名空间作用域符。</li><li id="ZH-CN_TOPIC_0000002370172337__li11149153217228">不支持同个TilingKey指向不同TilingData结构体，会出现拦截报错。</li><li id="ZH-CN_TOPIC_0000002370172337__li9520175218444">暂不支持kernel直调工程。</li></ul>
</div>
