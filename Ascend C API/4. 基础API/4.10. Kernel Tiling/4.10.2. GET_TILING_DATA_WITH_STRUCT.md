<div class="section" id="ZH-CN_TOPIC_0000002336173606__zh-cn_topic_0000001526206862_section212607105720"><h4 class="sectiontitle">功能说明</h4><p id="ZH-CN_TOPIC_0000002336173606__zh-cn_topic_0000001526206862_p0824144014589">使用该接口指定结构体名称，可获取指定的tiling信息，并填入对应的Tiling结构体中，此函数会以宏展开的方式进行编译。与<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0214.html">GET_TILING_DATA</a>的区别是：<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0214.html">GET_TILING_DATA</a>只能获取默认注册的结构体，该接口可以根据指定的结构体名称获取对应的结构体，常用于针对不同的TilingKey注册了不同结构体的情况下。</p>
