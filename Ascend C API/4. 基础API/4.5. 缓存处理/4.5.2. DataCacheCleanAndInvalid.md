<div class="section" id="ZH-CN_TOPIC_0000002370172009__section618mcpsimp"><h4 class="sectiontitle">功能说明</h4><p id="ZH-CN_TOPIC_0000002370172009__p647301034415">在AI Core内部，Scalar单元和DMA单元都可能对Global Memory进行访问。</p>
<div class="fignone" id="ZH-CN_TOPIC_0000002370172009__fig1161014168448"><span class="figcap"><b>图1 </b>DataCache内存层次示意图</span><br><span><img class="eddx" id="ZH-CN_TOPIC_0000002370172009__image1666215764419" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002336175578.png"></span></div>
<p id="ZH-CN_TOPIC_0000002370172009__p57911102557">如上图所示：</p>
<ul id="ZH-CN_TOPIC_0000002370172009__ul1551382111514"><li id="ZH-CN_TOPIC_0000002370172009__li05429475195">DMA搬运单元读写Global Memory，数据通过DataCopy等接口在UB等Local Memory和Global Memory间交互，没有Cache一致性问题；</li><li id="ZH-CN_TOPIC_0000002370172009__li1851362195114">Scalar单元访问Global Memory，首先会访问每个核内的Data Cache，因此存在Data Cache与Global Memory的Cache一致性问题。</li></ul>
<p id="ZH-CN_TOPIC_0000002370172009__p147615151513">该接口用来刷新Cache，保证Cache的一致性，使用场景如下：</p>
<ul id="ZH-CN_TOPIC_0000002370172009__ul6843184115812"><li id="ZH-CN_TOPIC_0000002370172009__li12843104205810">读取Global Memory的数据，但该数据可能在外部被其余核修改，此时需要使用DataCacheCleanAndInvalid接口，直接访问Global Memory，获取最新数据；</li></ul>
<ul id="ZH-CN_TOPIC_0000002370172009__ul79931891588"><li id="ZH-CN_TOPIC_0000002370172009__li1799313916582">用户通过Scalar单元写Global Memory的数据，希望立刻写出，也需要使用DataCacheCleanAndInvalid接口。</li></ul>
</div>
