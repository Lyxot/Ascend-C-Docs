    <h4 class="sectiontitle">约束说明</h4>
    <ul id="ZH-CN_TOPIC_0000002336174114__ul134371084241">
     <li id="ZH-CN_TOPIC_0000002336174114__li4322155610239">对空队列执行DeQue是一种异常行为，会在CPU调测时报错。</li>
     <li id="ZH-CN_TOPIC_0000002336174114__li1126335542519">non-inplace接口和指定源和目的位置的接口，需要将TQueBind的depth模板参数设置为非零值；inplace接口，需要将TQueBind的depth模板参数设置为0。</li>
    </ul>
   </div>
   <div class="section" id="ZH-CN_TOPIC_0000002336174114__section640mcpsimp">
