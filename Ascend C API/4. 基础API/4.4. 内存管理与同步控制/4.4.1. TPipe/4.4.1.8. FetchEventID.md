<div class="section" id="ZH-CN_TOPIC_0000002336333958__section633mcpsimp"><h4 class="sectiontitle">约束说明</h4><p id="ZH-CN_TOPIC_0000002336333958__p58832029102413">相比于<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0114.html">AllocEventID</a>，FetchEventID适用于临时使用ID的场景，获取ID后，不会对ID进行占用。在一些复杂的使用场景下，需要开发者自行保证使用正确。比如相同流水连续调用SetFlag/WaitFlag，如果两次传入的ID都是使用FetchEventID获取的，因为两者ID相同会出现程序卡死等未定义行为，这时推荐用户使用AllocEventID。</p>
