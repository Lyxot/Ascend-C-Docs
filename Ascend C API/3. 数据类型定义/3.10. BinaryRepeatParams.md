  <h1 class="topictitle1">BinaryRepeatParams</h1>
  <div id="body0000001533390357">
   <p id="ZH-CN_TOPIC_0000002370171385__p12596185919348">BinaryRepeatParams为用于控制操作数地址步长的数据结构。结构体内包含操作数相邻迭代间相同<span id="ZH-CN_TOPIC_0000002370171385__ph1256166185416">DataBlock</span>的地址步长，操作数同一迭代内不同<span id="ZH-CN_TOPIC_0000002370171385__ph1672554912125">DataBlock</span>的地址步长等参数。</p>
   <p id="ZH-CN_TOPIC_0000002370171385__p1156819418442">相邻迭代间的地址步长参数说明请参考<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0022.html#ZH-CN_TOPIC_0000002370254921__zh-cn_topic_0000002267504656_zh-cn_topic_0000001764162593_section139459347420">repeatStride</a>；同一迭代内DataBlock的地址步长参数说明请参考<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0022.html#ZH-CN_TOPIC_0000002370254921__zh-cn_topic_0000002267504656_zh-cn_topic_0000001764162593_section2815124173416">dataBlockStride</a>。</p>
