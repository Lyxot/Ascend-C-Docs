<h1 class="topictitle1">简介</h1>
<div id="body8662426"><p id="ZH-CN_TOPIC_0000002370171561__p6587184214249">Layout&lt;Shape, Stride&gt;数据结构是描述多维张量内存布局的基础模板类，通过编译时的形状（Shape）和步长（Stride）信息，实现逻辑坐标空间到一维内存地址空间的映射，为复杂张量操作和硬件优化提供基础支持。借助模板元编程技术，该类在编译时完成计算和代码生成，从而降低运行时开销。</p>
<p id="ZH-CN_TOPIC_0000002370171561__p1286755381218">Layout包含两个核心组成部分：</p>
<ul id="ZH-CN_TOPIC_0000002370171561__ul1676435152910"><li id="ZH-CN_TOPIC_0000002370171561__li97641851172919">Shape：定义数据的逻辑形状，例如二维矩阵的行数和列数或多维张量的各维度大小。</li><li id="ZH-CN_TOPIC_0000002370171561__li2076420513293">Stride：定义各维度在内存中的步长，即同维度相邻元素在内存中的间隔，间隔的单位为元素，与Shape的维度信息一一对应。</li></ul>
<p id="ZH-CN_TOPIC_0000002370171561__p155282276386">例如，一个二维矩阵的Shape为(4, 2)，Stride为(1, 4)，表示：</p>
<ul id="ZH-CN_TOPIC_0000002370171561__ul1252812703816"><li id="ZH-CN_TOPIC_0000002370171561__li8528152715388">矩阵有4行、2列。</li><li id="ZH-CN_TOPIC_0000002370171561__li1952892763811">列方向上的步长为1，即每行中相邻元素在内存中的间隔为1个元素；行方向上的步长为4，即相邻行的起始地址间隔为4个元素。</li></ul>
<p id="ZH-CN_TOPIC_0000002370171561__p14767658134914"><a href="#ZH-CN_TOPIC_0000002370171561__table12525201245615">表1</a>中给出了一维内存地址空间视图，<a href="#ZH-CN_TOPIC_0000002370171561__table17519406546">表2</a>中给出了该二维矩阵的逻辑视图。</p>
