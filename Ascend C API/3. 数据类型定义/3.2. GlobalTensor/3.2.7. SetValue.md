<h1 class="topictitle1">SetValue</h1>
<div id="body0000002167530617"><div class="section" id="ZH-CN_TOPIC_0000002336334282__section618mcpsimp"><h4 class="sectiontitle">功能说明</h4><p id="ZH-CN_TOPIC_0000002336334282__p1794014387449">设置GlobalTensor相应偏移位置的值。</p>
<ul id="ZH-CN_TOPIC_0000002336334282__ul197461614185710"><li id="ZH-CN_TOPIC_0000002336334282__li14404191014016">因为硬件实现不同，其与通用CPU标量赋值操作存在差异。SetValue赋值操作首先改写的是每个AI Core内部的<span id="ZH-CN_TOPIC_0000002336334282__ph186921949921">DCache</span>， 不会立刻写出到Global Memory，且后续写出时以CacheLine（64B）为单位。使用该接口之前必须了解<span id="ZH-CN_TOPIC_0000002336334282__ph6837163918201">DCache</span>结构和Cache一致性原理（参见<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0177.html">DataCacheCleanAndInvalid</a>），否则可能存在误用的情况，<strong id="ZH-CN_TOPIC_0000002336334282__b1839213121513">请谨慎使用。</strong></li><li id="ZH-CN_TOPIC_0000002336334282__li9746111417577">调用SetValue后，首先改写的是每个AI Core内部的<span id="ZH-CN_TOPIC_0000002336334282__ph550416467209">DCache</span>，如果需要立即写出到Global Memory，需要在调用此接口后，再调用<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0177.html">DataCacheCleanAndInvalid</a>，确保<span id="ZH-CN_TOPIC_0000002336334282__ph46365508205">DCache</span>与Global Memory的Cache一致性。</li><li id="ZH-CN_TOPIC_0000002336334282__li1139518188578">多核操作GM地址时，要求不同核操作的地址（通过offset参数设置元素偏移，可以转换为地址）至少有CacheLine大小的偏移，否则会出现多核数据随机覆盖。同时需要考虑地址对齐(64B)的问题。详细内容请参考<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0177.html#ZH-CN_TOPIC_0000002370172009__section837496171220">调用示例</a>。</li></ul>
</div>
