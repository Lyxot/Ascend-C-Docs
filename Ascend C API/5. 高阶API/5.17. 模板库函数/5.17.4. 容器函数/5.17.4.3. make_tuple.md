<div class="section" id="ZH-CN_TOPIC_0000002370172369__section1564510486314"><h4 class="sectiontitle">约束说明</h4><ul id="ZH-CN_TOPIC_0000002370172369__ul14981124132918"><li id="ZH-CN_TOPIC_0000002370172369__li109811043294">tuple实例化深度为64，即支持64个元素以内的基础数据类型的聚合。</li><li id="ZH-CN_TOPIC_0000002370172369__li1498217442913">make_tuple中需要特别指定数据类型的元素，必须对该元素的数据类型增加强转，否则由编译器自行推断，可能与预期不符。</li><li id="ZH-CN_TOPIC_0000002370172369__li149821149292">不支持数组等可变长度的数据类型。</li><li id="ZH-CN_TOPIC_0000002370172369__li14982746295">不支持隐式转换构造函数。</li></ul>
