  <h1 class="topictitle1">使用说明</h1>
  <div id="body0000001621515197">
   <p id="ZH-CN_TOPIC_0000002336174174__p163531516134517"><span id="ZH-CN_TOPIC_0000002336174174__ph975583562710">Ascend C</span>提供一组Matmul <a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0037.html#ZH-CN_TOPIC_0000002370175001__section68451031218">Tiling</a> API，方便用户获取<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0614.html#ZH-CN_TOPIC_0000002370251917__li5878185413338">Matmul kernel计算</a>时所需的Tiling参数。用户只需要传入A/B/C矩阵的Position位置、Format格式和DType数据类型等信息，调用API接口，即可获取到<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0630.html">Init</a>中TCubeTiling结构体中的相关参数。</p>
   <p id="ZH-CN_TOPIC_0000002336174174__p35811237523">Matmul Tiling API分为Matmul单核Tiling接口、多核Tiling接口和BatchMatmul Tiling接口，分别用于Matmul单核计算、多核计算和BatchMatmul计算场景。获取Tiling参数的流程如下：</p>
   <ol id="ZH-CN_TOPIC_0000002336174174__ol98672522">
    <li id="ZH-CN_TOPIC_0000002336174174__li6813712520">创建一个单核Tiling对象，或多核Tiling对象，或BatchMatmul Tiling对象。</li>
    <li id="ZH-CN_TOPIC_0000002336174174__li18325165523">设置A、B、C、Bias的参数类型信息；M、N、Ka、Kb形状信息等。</li>
    <li id="ZH-CN_TOPIC_0000002336174174__li597563313541">调用<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0692.html">GetTiling</a>接口，获取Tiling信息。</li>
   </ol>
   <p id="ZH-CN_TOPIC_0000002336174174__p188441525111413">使用Matmul单核Tiling接口、多核Tiling接口和BatchMatmul Tiling接口获取Tiling参数的样例如下：</p>
