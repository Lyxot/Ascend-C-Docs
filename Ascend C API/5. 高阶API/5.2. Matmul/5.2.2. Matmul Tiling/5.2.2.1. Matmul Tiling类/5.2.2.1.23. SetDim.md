  <h1 class="topictitle1">SetDim</h1>
  <div id="body0000001621676565">
   <div class="section" id="ZH-CN_TOPIC_0000002370251221__section618mcpsimp">
    <h4 class="sectiontitle">功能说明</h4>
    <p id="ZH-CN_TOPIC_0000002370251221__p167911504113">设置多核Matmul时，参与运算的核数。不同场景下的设置规则如下：</p>
    <ul id="ZH-CN_TOPIC_0000002370251221__ul17577178125917">
     <li id="ZH-CN_TOPIC_0000002370251221__li9806105391312">纯Cube模式（只有矩阵计算）
      <p id="ZH-CN_TOPIC_0000002370251221__p8700125817138"><a name="ZH-CN_TOPIC_0000002370251221__li9806105391312"></a><a name="li9806105391312"></a>SetDim设置当前AI处理器可用的核数，通过<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0692.html">Tiling计算</a>得到执行Matmul计算实际使用的核数，实际使用的核数小于等于AI处理器可用的核数。<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/basicdataapi/atlasopapi_07_00236.html">SetBlockDim</a>按照实际使用的核数由用户进行配置，<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/basicdataapi/atlasopapi_07_00236.html">SetBlockDim</a>加载的核全部用于Matmul API的计算。</p></li>
     <li id="ZH-CN_TOPIC_0000002370251221__li843612467181">MIX模式（包含矩阵计算和矢量计算）
      <ul id="ZH-CN_TOPIC_0000002370251221__ul108896819308">
       <li id="ZH-CN_TOPIC_0000002370251221__li1588958133020">分离架构：Matmul API都是从AIV侧发起的，调用Iterate计算时在AIV侧只会起到通知的作用，通知AIC去做矩阵计算，计算完成后AIC告知AIV计算完成，在开发者层面感知的是AIV的核数，SetDim设置为当前AI处理器可用的AIV核的数量，通过<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0692.html">Tiling计算</a>得到实际使用的AIV核数。SetBlockDim设置为实际使用的AI Core（AIC、AIV组合）的数量。例如，SetDim设置为40，表示可以使用40个AIV核发起多核Matmul运算，<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0692.html">Tiling计算</a>得到实际使用的AIV核数是20。当前AI处理器的AIC:AIV为1:2，则SetBlockDim设置为10，表示实际使用10个AI Core（AIC AIV的组合）。</li>
       <li id="ZH-CN_TOPIC_0000002370251221__li14239161293019">耦合架构：SetDim设置当前AI处理器可用的核数，通过<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0692.html">Tiling计算</a>得到实际使用的核数，实际使用的核数小于等于AI处理器可用的核数。<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/basicdataapi/atlasopapi_07_00236.html">SetBlockDim</a>按照实际使用的核数由用户进行配置，<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/basicdataapi/atlasopapi_07_00236.html">SetBlockDim</a>加载的核全部用于Matmul API的计算。</li>
      </ul></li>
    </ul>
   </div>
