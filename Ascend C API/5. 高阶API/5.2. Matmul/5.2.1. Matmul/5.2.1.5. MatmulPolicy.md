   <div class="section" id="ZH-CN_TOPIC_0000002370252405__section451064612817">
    <h4 class="sectiontitle">功能说明</h4>
    <div class="p" id="ZH-CN_TOPIC_0000002370252405__p1951054617283">
     模板参数MatmulPolicy用于定义Matmul可拓展模块策略。目前支持设置以下四种Matmul内置模板策略。 
     <ul id="ZH-CN_TOPIC_0000002370252405__ul12141312382">
      <li id="ZH-CN_TOPIC_0000002370252405__li1414111143813">MatmulPolicy（默认模板策略） 
       <p id="ZH-CN_TOPIC_0000002370252405__p131635168397"><a name="ZH-CN_TOPIC_0000002370252405__li1414111143813"></a><a name="li1414111143813"></a>使能Matmul API的默认实现策略。</p></li>
      <li id="ZH-CN_TOPIC_0000002370252405__li1892181110422"><a name="ZH-CN_TOPIC_0000002370252405__li1892181110422"></a><a name="li1892181110422"></a>TrianUpperMatmulPolicy（上三角模板策略） 
       <p id="ZH-CN_TOPIC_0000002370252405__p1389121172219"><a name="ZH-CN_TOPIC_0000002370252405__li1892181110422"></a><a name="li1892181110422"></a>一次矩阵乘指令计算的结果为<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0673.html#ZH-CN_TOPIC_0000002336174434__p17899165811566">baseM * baseN</a>大小的矩阵块，称该矩阵块为基本块。若Matmul结果矩阵C中的基本块位于下三角位置，则Matmul内部做数据计算和数据搬出时，将忽略该基本块，最后得到的矩阵C为一个上三角矩阵。上三角模板策略如下图所示，图示中矩阵形状的相关大小为M=N=512，K=256，baseM=baseN=baseK=32。</p>

      <li id="ZH-CN_TOPIC_0000002370252405__li17292359134915"><a name="ZH-CN_TOPIC_0000002370252405__li17292359134915"></a><a name="li17292359134915"></a>TrianLowerMatmulPolicy（下三角模板策略） 
       <p id="ZH-CN_TOPIC_0000002370252405__p62786471817"><a name="ZH-CN_TOPIC_0000002370252405__li17292359134915"></a><a name="li17292359134915"></a>一次矩阵乘指令计算的结果为<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0673.html#ZH-CN_TOPIC_0000002336174434__p17899165811566">baseM * baseN</a>大小的矩阵块，称该矩阵块为基本块。若Matmul结果矩阵C中的基本块位于上三角位置，则Matmul内部做数据计算和数据搬出时，将忽略该基本块，最后得到的矩阵C为一个下三角矩阵。下三角模板策略如下图所示，图示中矩阵形状的相关大小为M=N=512，K=256，baseM=baseN=baseK=32。</p>

     <li id="ZH-CN_TOPIC_0000002370252405__li194081238103913">NBuffer33MatmulPolicy（NBuffer33模板策略） 
      <p id="ZH-CN_TOPIC_0000002370252405__p8514154415401"><a name="ZH-CN_TOPIC_0000002370252405__li194081238103913"></a><a name="li194081238103913"></a>一次矩阵乘指令计算的结果为<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0673.html#ZH-CN_TOPIC_0000002336174434__p17899165811566">baseM * baseN</a>大小的矩阵块，称该矩阵块为基本块。单核计算的A矩阵切分为3x3个基本块，该3x3个A矩阵的基本块全载和保持在<span id="ZH-CN_TOPIC_0000002370252405__ph478622416511">L1 Buffer</span>中，每次与3x1个B矩阵的基本块计算矩阵乘，同时<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0090.html">DoubleBuffer</a>并行搬入下次计算所需的3x1个B矩阵基本块，直到singleCoreN方向的矩阵乘计算完成。NBuffer33模板策略如下图所示，图中<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0673.html#ZH-CN_TOPIC_0000002336174434__p11899125875617">singleCoreM、singleCoreN、singleCoreK</a>表示单核内A、B矩阵的shape大小，单核计算的A矩阵切分为3x3个基本块，3x3个基本块全载在<span id="ZH-CN_TOPIC_0000002370252405__ph18286193610174">L1 Buffer</span>上，这些基本块每次与B矩阵的3x1个基本块计算矩阵乘。</p>

    <h4 class="sectiontitle">约束说明</h4>
    <ul id="ZH-CN_TOPIC_0000002370252405__ul15712167174815">
     <li id="ZH-CN_TOPIC_0000002370252405__li8179412143713">TrianUpperMatmulPolicy当前只支持<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0616.html#ZH-CN_TOPIC_0000002336332840__p159827389308">Norm模板</a>和<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0616.html#ZH-CN_TOPIC_0000002336332840__p109823386305">MDL模板</a>。</li>
     <li id="ZH-CN_TOPIC_0000002370252405__li197121474484">TrianLowerMatmulPolicy当前只支持<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0616.html#ZH-CN_TOPIC_0000002336332840__p159827389308">Norm模板</a>和<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0616.html#ZH-CN_TOPIC_0000002336332840__p109823386305">MDL模板</a>。</li>
     <li id="ZH-CN_TOPIC_0000002370252405__li373711917486">NBuffer33MatmulPolicy： 
      <ul id="ZH-CN_TOPIC_0000002370252405__ul17289192120485">
       <li id="ZH-CN_TOPIC_0000002370252405__li17834162420421">当前只支持<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0616.html#ZH-CN_TOPIC_0000002336332840__p109823386305">MDL模板</a>。</li>
       <li id="ZH-CN_TOPIC_0000002370252405__li18552384439">A矩阵、B矩阵的内存逻辑位置只支持TPosition::GM。</li>
       <li id="ZH-CN_TOPIC_0000002370252405__li6921113674810">暂不支持MIX模式（包含矩阵计算和矢量计算），仅支持纯Cube模式（只有矩阵计算）。</li>
       <li id="ZH-CN_TOPIC_0000002370252405__li79708482480">只支持通过<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0640.html">IterateAll</a>接口获取Matmul的计算结果C矩阵。</li>
       <li id="ZH-CN_TOPIC_0000002370252405__li3158136134911"><a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0673.html#ZH-CN_TOPIC_0000002336174434__p139009583566">stepM、stepKa、stepKb</a>小于等于3，且满足：stepKa=stepKb=ceil(<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0673.html#ZH-CN_TOPIC_0000002336174434__p11899125875617">singleCoreK</a>/baseK)。</li>
       <li id="ZH-CN_TOPIC_0000002370252405__li8324024104910">A矩阵全载的基本块大小与B矩阵载入的基本块大小之和不超过<span id="ZH-CN_TOPIC_0000002370252405__ph15468131351">L1 Buffer</span>大小。</li>
      </ul></li>

    <h4 class="sectiontitle">调用示例</h4>
    <p id="ZH-CN_TOPIC_0000002370252405__p1210214316444">默认模板策略MatmulPolicy为模板参数的默认值，下面主要介绍TrianUpperMatmulPolicy（上三角模板策略）和TrianLowerMatmulPolicy（下三角模板策略）的使用方式。</p>
    <ul id="ZH-CN_TOPIC_0000002370252405__ul84295248152">
     <li id="ZH-CN_TOPIC_0000002370252405__li184291224111519">上三角模板策略使用示例 
      <div class="p" id="ZH-CN_TOPIC_0000002370252405__p12216121473019">
