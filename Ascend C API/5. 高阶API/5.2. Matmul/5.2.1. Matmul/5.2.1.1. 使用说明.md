  <h1 class="topictitle1">使用说明</h1>
  <div id="body0000001570911006">
   <p id="ZH-CN_TOPIC_0000002370251917__p1086012264526"><span id="ZH-CN_TOPIC_0000002370251917__ph975583562710">Ascend C</span>提供一组Matmul高阶API，方便用户快速实现Matmul矩阵乘法的运算操作。</p>
   <p id="ZH-CN_TOPIC_0000002370251917__p3919148172714">Matmul的计算公式为：C = A * B + Bias，其示意图如下。</p>
   <ul id="ZH-CN_TOPIC_0000002370251917__ul16919138172718">
    <li id="ZH-CN_TOPIC_0000002370251917__li79197822716">A、B为源操作数，A为左矩阵，形状为[M, K]；B为右矩阵，形状为[K, N]。</li>
    <li id="ZH-CN_TOPIC_0000002370251917__li0919985270">C为目的操作数，存放矩阵乘结果的矩阵，形状为[M, N]。</li>
    <li id="ZH-CN_TOPIC_0000002370251917__li209191885272">Bias为矩阵乘偏置，形状为[1, N]。对A*B结果矩阵的每一行都采用该Bias进行偏置。</li>
   </ul>
   <div class="fignone" id="ZH-CN_TOPIC_0000002370251917__fig1677675717556">
    <span class="figcap"><b>图1 </b>Matmul矩阵乘示意图</span>
    <br><span><img class="eddx" id="ZH-CN_TOPIC_0000002370251917__image117761057115514" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002445918813.png"></span>
   </div>
   <div class="note" id="ZH-CN_TOPIC_0000002370251917__note5724151414442">
    <img src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/public_sys-resources/note_3.0-zh-cn.png"><span class="notetitle"> </span>
    <div class="notebody">
     <p id="ZH-CN_TOPIC_0000002370251917__p198991658115617">下文中提及的M轴方向，即为A矩阵纵向；K轴方向，即为A矩阵横向或B矩阵纵向；N轴方向，即为B矩阵横向；尾轴，即为矩阵最后一个维度。</p>
    </div>
   </div>
   <p id="ZH-CN_TOPIC_0000002370251917__p31619241207">实现Matmul矩阵乘运算的具体步骤如下：</p>
   <ol id="ZH-CN_TOPIC_0000002370251917__ol13151531172018">
    <li id="ZH-CN_TOPIC_0000002370251917__li10315231192015">创建Matmul对象。</li>
    <li id="ZH-CN_TOPIC_0000002370251917__li1498432619484">初始化操作。</li>
    <li id="ZH-CN_TOPIC_0000002370251917__li15498124152710">设置左矩阵A、右矩阵B、Bias。</li>
    <li id="ZH-CN_TOPIC_0000002370251917__li19830155115212">完成矩阵乘操作。</li>
    <li id="ZH-CN_TOPIC_0000002370251917__li20285053142319">结束矩阵乘操作。</li>
   </ol>
   <ol id="ZH-CN_TOPIC_0000002370251917__ol1832114477339">
    <li id="ZH-CN_TOPIC_0000002370251917__li1032116474330"><span>创建Matmul对象。</span>
     <p></p>

     </ul>

    <h4 class="sectiontitle">实现原理</h4>
    <div class="p" id="ZH-CN_TOPIC_0000002370251917__p17169135114576">
     以输入矩阵A (GM, ND, half)、矩阵B(GM, ND, half)，输出矩阵C (GM, ND, float)，无Bias场景为例，其中(GM, ND, half)表示数据存放在GM上，数据格式为ND，数据类型为half，描述Matmul高阶API典型场景的内部算法框图，如下图所示。
     <div class="fignone" id="ZH-CN_TOPIC_0000002370251917__fig072411991916">
      <span class="figcap"><b>图2 </b>Matmul算法框图</span>
      <br><span><img class="eddx" id="ZH-CN_TOPIC_0000002370251917__image10339181818511" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002370253577.png"></span>
     </div>
    </div>
    <p id="ZH-CN_TOPIC_0000002370251917__p1537351834116">计算过程分为如下几步：</p>
    <ol id="ZH-CN_TOPIC_0000002370251917__ol2011483773214">
     <li id="ZH-CN_TOPIC_0000002370251917__li811417377325">数据从GM搬到A1：DataCopy每次从矩阵A，搬出一个stepM*baseM*stepKa*baseK的矩阵块a1，循环多次完成矩阵A的搬运；数据从GM搬到B1：DataCopy每次从矩阵B，搬出一个stepKb*baseK*stepN*baseN的矩阵块b1，循环多次完成矩阵B的搬运；</li>
     <li id="ZH-CN_TOPIC_0000002370251917__li72978285346">数据从A1搬到A2：LoadData每次从矩阵块a1，搬出一个baseM * baseK的矩阵块a0；数据从B1搬到B2，并完成转置：LoadData每次从矩阵块b1，搬出一个baseK * baseN的矩阵块，并将其转置为baseN * baseK的矩阵块b0；</li>
     <li id="ZH-CN_TOPIC_0000002370251917__li128536415613">矩阵乘：每次完成一个矩阵块a0 * b0的计算，得到baseM * baseN的矩阵块co1；</li>
     <li id="ZH-CN_TOPIC_0000002370251917__li153795975620">数据从矩阵块co1搬到矩阵块co2： DataCopy每次搬运一块baseM * baseN的矩阵块co1到singleCoreM * singleCoreN的矩阵块co2中；</li>
     <li id="ZH-CN_TOPIC_0000002370251917__li594491315574">重复2-4步骤，完成矩阵块a1 * b1的计算；</li>
     <li id="ZH-CN_TOPIC_0000002370251917__li220882514578">数据从矩阵块co2搬到矩阵块C：DataCopy每次搬运一块singleCoreM * singleCoreN的矩阵块co2到矩阵块C中；</li>
     <li id="ZH-CN_TOPIC_0000002370251917__li1694235815719">重复1-6步骤，完成矩阵A * B = C的计算。</li>
    </ol>
    <p id="ZH-CN_TOPIC_0000002370251917__p10843914182614">注意：stepM、baseM等参数的含义请参考<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0037.html#ZH-CN_TOPIC_0000002370175001__section68451031218">Tiling参数</a>。</p>
