    <h4 class="sectiontitle">功能说明</h4>
    <p id="ZH-CN_TOPIC_0000002336173870__p1545163111131">用于配置BasicBlock模板的参数，获取自定义BasicBlock模板。BasicBlock模板的介绍请参考<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0616.html#ZH-CN_TOPIC_0000002336332840__table6981133810309">表 模板特性</a>。</p>
    <p id="ZH-CN_TOPIC_0000002336173870__p1189513593292">使用该接口时可以优先考虑使用模板常量化。相比BasicBlock模板可以实现baseM/N/K常量化，模板常量化可以在此基础上实现singleCoreM/N/K、baseM/N/K的常量化，模板常量化的具体使用方式请参考<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0666.html#ZH-CN_TOPIC_0000002370252217__section618mcpsimp">Matmul Tiling常量化</a>。</p>
