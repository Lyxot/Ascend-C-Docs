<div class="section" id="ZH-CN_TOPIC_0000002336333522__section618mcpsimp"><h4 class="sectiontitle">功能说明</h4><p id="ZH-CN_TOPIC_0000002336333522__p1088765210146">对于某些场景Matmul内部需要额外占用VECCALC空间，如果用户希望在算子中复用这个额外占用的VECCALC空间，则该空间需要用户预留，并申请好LocalTensor，将其起始物理地址传入给Matmul。具体需要申请的VECCALC临时空间大小由tiling接口<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0710.html">MatmulGetTmpBufSize</a>给出，满足以下几个条件之一就需要使用该接口传入UB临时空间：</p>
<ul id="ZH-CN_TOPIC_0000002336333522__ul1226651199"><li id="ZH-CN_TOPIC_0000002336333522__li4226152919">C矩阵Position为TPosition::GM；</li><li id="ZH-CN_TOPIC_0000002336333522__li7518197094">C矩阵CubeFormat为CubeFormat::ND；</li><li id="ZH-CN_TOPIC_0000002336333522__li420317111299">A矩阵或者B矩阵CubeFormat为CubeFormat::ND；</li><li id="ZH-CN_TOPIC_0000002336333522__li159010161598">存在Bias且Bias的Position不是VECCALC。</li></ul>
<p id="ZH-CN_TOPIC_0000002336333522__p924414441654">请在<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0638.html">Iterate</a>或者<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0640.html">IterateAll</a>之前调用该接口。</p>
<p id="ZH-CN_TOPIC_0000002336333522__p2481184912517">获取到的UB临时空间大小以字节为单位。</p>
</div>
