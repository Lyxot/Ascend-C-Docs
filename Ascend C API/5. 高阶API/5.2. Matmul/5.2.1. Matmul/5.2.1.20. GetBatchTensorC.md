<div class="section" id="ZH-CN_TOPIC_0000002370172649__section618mcpsimp"><h4 class="sectiontitle">功能说明</h4><p id="ZH-CN_TOPIC_0000002370172649__p14794143013467">调用一次GetBatchTensorC，会获取C矩阵片，该接口可以与<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0644.html">IterateNBatch</a>异步接口配合使用。用于在调用IterateNBatch迭代计算后，获取一片std::max(batchA, batchB) * singleCoreM * singleCoreN大小的矩阵分片。</p>
