    <h4 class="sectiontitle">功能说明</h4>
    <p id="ZH-CN_TOPIC_0000002370252473__p822512521032">每调用一次Iterate，会计算出一块baseM * baseN的C矩阵。接口内部会维护迭代进度，调用一次后会对A、B矩阵首地址进行偏移。默认以先M轴再N轴的迭代顺序，也可以通过调整tiling参数iterateOrder，转换为先N轴再M轴的迭代顺序。当传入数据未对齐，存在尾块时，会在最后一次迭代输出尾块的计算结果。</p>
    <p id="ZH-CN_TOPIC_0000002370252473__p172641846983">一次Iterate矩阵乘的结果C矩阵存放在<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0037.html#ZH-CN_TOPIC_0000002370175001__zh-cn_topic_0000001455771256_li42261523152714">逻辑位置CO1</a>的内存中，对于CO1内存中计算结果的获取，当前支持如下两种方式：</p>
    <ul id="ZH-CN_TOPIC_0000002370252473__ul15556123371413">
     <li id="ZH-CN_TOPIC_0000002370252473__li355620331145">用户无需自行管理存放矩阵乘结果的CO1内存的申请和释放，由Matmul API内部实现管理。调用<a href="#ZH-CN_TOPIC_0000002370252473__li135771283591">接口内部管理CO1</a>的Iterate函数原型后，调用<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0639.html">GetTensorC</a>接口完成CO1上计算结果的搬出。</li>
     <li id="ZH-CN_TOPIC_0000002370252473__li1255663316142">用户可以灵活自主地控制矩阵乘计算结果的搬运，例如将多次Iterate计算的矩阵乘结果缓存在CO1内存中，在需要搬出该结果时，一次性搬出多块baseM * baseN的C矩阵。这种灵活搬运场景下，用户需要提前申请CO1的内存，调用<a href="#ZH-CN_TOPIC_0000002370252473__li4843165185812">用户自主管理CO1</a>的Iterate函数原型后，一次Iterate的计算结果会输出到用户申请的CO1内存上。在需要搬出计算结果时，调用<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0251.html">Fixpipe</a>接口搬运CO1上的结果，完成后释放申请的CO1内存。具体示例请参考<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0614.html#ZH-CN_TOPIC_0000002370251917__li12765161915318">用户自主管理CO1的矩阵乘场景</a>。</li>
    </ul>
   </div>

     <li id="ZH-CN_TOPIC_0000002370252473__li288643214593">对于用户自主管理CO1的Iterate函数，创建Matmul对象时，必须定义C矩阵的内存逻辑位置为TPosition::CO1、数据排布格式为CubeFormat::NZ、数据类型为float或int32_t。</li>
