    <h4 class="sectiontitle">功能说明</h4>
    <p id="ZH-CN_TOPIC_0000002336173156__p2072613419195">Iterate后，获取一块或者两块C矩阵片，可以直接输出到GM tensor中，也可以输出到VECIN tensor中。当<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0616.html#ZH-CN_TOPIC_0000002336332840__table1761013213153">MatmulConfig</a>参数中的ScheduleType取值为ScheduleType::INNER_PRODUCT时，获取一块C矩阵片；当<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0616.html#ZH-CN_TOPIC_0000002336332840__table1761013213153">MatmulConfig</a>参数中的ScheduleType取值为ScheduleType::OUTER_PRODUCT时，获取两块C矩阵片。</p>
    <p id="ZH-CN_TOPIC_0000002336173156__p872611413195">该接口和<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0638.html">Iterate</a>接口配合使用，用于在调用Iterate完成迭代计算后，根据<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0616.html#ZH-CN_TOPIC_0000002336332840__table1761013213153">MatmulConfig</a>参数中的ScheduleType取值获取一块或两块baseM * baseN大小的矩阵分片。</p>
    <p id="ZH-CN_TOPIC_0000002336173156__p2314131071416">迭代获取C矩阵分片的过程分为同步和异步两种模式：</p>
    <ul id="ZH-CN_TOPIC_0000002336173156__ul101321025155310">
     <li id="ZH-CN_TOPIC_0000002336173156__li165987200146"><strong id="ZH-CN_TOPIC_0000002336173156__b18450458153116">同步：</strong>执行完一次Iterate后执行一次GetTensorC，需要同步等待C矩阵分片获取完成。</li>
     <li id="ZH-CN_TOPIC_0000002336173156__li17508136205415"><a name="ZH-CN_TOPIC_0000002336173156__li17508136205415"></a><a name="li17508136205415"></a><strong id="ZH-CN_TOPIC_0000002336173156__b72671419326">异步：</strong>调用Iterate后，无需立即调用GetTensorC同步等待，可以先执行其他逻辑，待需要获取结果时再调用GetTensorC。异步方式可以减少同步等待，提高并行度，开发者对计算性能要求较高时，可以选用该方式。</li>
    </ul>
