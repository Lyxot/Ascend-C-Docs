    <h4 class="sectiontitle">功能说明</h4>
    <p id="ZH-CN_TOPIC_0000002370171685__p124034914256">单次Matmul计算处理的shape比较小时，由于每次计算均涉及到内部的通信，可能会影响性能，该接口提供批量处理Matmul的功能，调用一次IterateBatch，可以计算出多个singleCoreM * singleCoreN大小的C矩阵。</p>
    <p id="ZH-CN_TOPIC_0000002370171685__p2071942861519">在使用该接口前，需要了解一些必备的数据排布格式：</p>
    <ul id="ZH-CN_TOPIC_0000002370171685__ul3906122819164">
     <li id="ZH-CN_TOPIC_0000002370171685__li536045110115"><a name="ZH-CN_TOPIC_0000002370171685__li536045110115"></a><a name="li536045110115"></a><strong id="ZH-CN_TOPIC_0000002370171685__b1050513519316">通用数据格式（NORMAL）</strong>：BMNK的数据排布格式
      <p id="ZH-CN_TOPIC_0000002370171685__p553564441013"><a name="ZH-CN_TOPIC_0000002370171685__p553564441013"></a><a name="p553564441013"></a><span><img id="ZH-CN_TOPIC_0000002370171685__image1053514471015" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002370173241.png"></span></p></li>
     <li id="ZH-CN_TOPIC_0000002370171685__li179761010122211"><strong id="ZH-CN_TOPIC_0000002370171685__b1898342132015">BSH/SBH：</strong>B：Batch，批处理的大小； S：sequence length，序列长度；H = N * D，其中，N为head的数量，D为head的大小。Layout格式如下图所示：
      <p id="ZH-CN_TOPIC_0000002370171685__p1885115515537"><span><img class="eddx" id="ZH-CN_TOPIC_0000002370171685__image798152511012" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002336334886.png"></span></p>
      <p id="ZH-CN_TOPIC_0000002370171685__p959711205297"><span><img class="eddx" id="ZH-CN_TOPIC_0000002370171685__image1477715216296" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002370173221.png"></span></p></li>
     <li id="ZH-CN_TOPIC_0000002370171685__li298041002213"><a name="ZH-CN_TOPIC_0000002370171685__li298041002213"></a><a name="li298041002213"></a><strong id="ZH-CN_TOPIC_0000002370171685__b2098081019226">BSNGD：</strong>为原始BSH shape做reshape后的shape，S和D为单Batch的矩阵乘的M轴（或N轴）和K轴，一个SD为一个batch的计算数据，Layout格式如下图所示：
      <p id="ZH-CN_TOPIC_0000002370171685__p398021020227"><span><img class="eddx" id="ZH-CN_TOPIC_0000002370171685__image598031052219" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002336175090.png"></span></p></li>
     <li id="ZH-CN_TOPIC_0000002370171685__li6785191319227"><a name="ZH-CN_TOPIC_0000002370171685__li6785191319227"></a><a name="li6785191319227"></a><strong id="ZH-CN_TOPIC_0000002370171685__b4785113192218">SBNGD：</strong>为原始SBH shape做reshape后shape，S和D为的矩阵乘的M轴（或N轴）和K轴，一个SD为一个Batch的计算数据，Layout格式如下图所示：
      <p id="ZH-CN_TOPIC_0000002370171685__p078515132220"><span><img class="eddx" id="ZH-CN_TOPIC_0000002370171685__image378531316226" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002370253093.png"></span></p></li>
     <li id="ZH-CN_TOPIC_0000002370171685__li1922441712222"><a name="ZH-CN_TOPIC_0000002370171685__li1922441712222"></a><a name="li1922441712222"></a><strong id="ZH-CN_TOPIC_0000002370171685__b122431715227">BNGS1S2：</strong>一般为前两种Layout进行矩阵乘的输出，S1S2数据连续存放，一个S1S2为一个Batch的计算数据，Layout格式如下图所示：
      <p id="ZH-CN_TOPIC_0000002370171685__p2224131752220"><span><img class="eddx" id="ZH-CN_TOPIC_0000002370171685__image10224181710226" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002370173217.png"></span></p></li>
    </ul>
    <p id="ZH-CN_TOPIC_0000002370171685__p133761542454">实例化Matmul时，需要通过MatmulType设置输入输出的Layout格式，当前支持4种Layout类型：BSNGD、SBNGD、BNGS1S2、NORMAL（BMNK的数据排布格式使用NORMAL表示）。</p>
    <p id="ZH-CN_TOPIC_0000002370171685__p7823145957">对于BSNGD、SBNGD、BNGS1S2 Layout格式，调用该接口之前需要在host Tiling实现中使用<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0699.html">SetALayout</a>、<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0700.html">SetBLayout</a>、<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0701.html">SetCLayout</a>、<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0702.html">SetBatchNum</a>设置A/B/C的Layout轴信息和最大BatchNum数；对于NORMAL Layout格式则需使用<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0703.html">SetBatchInfoForNormal</a>设置A/B/C的M/N/K轴信息和A/B矩阵的BatchNum数。</p>
    <p id="ZH-CN_TOPIC_0000002370171685__p1843615153413">单个矩阵乘迭代顺序可通过tiling参数iterateOrder调整。</p>
    <p id="ZH-CN_TOPIC_0000002370171685__p164751514288">更多矩阵编程batch场景的相关内容请参考<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0041.html">Batch Matmul基础功能</a>。</p>

     <li id="ZH-CN_TOPIC_0000002370171685__li4822114111443">对于BSNGD、SBNGD、BNGS1S2 Layout格式，输入A、B矩阵按分形对齐后的多Batch数据总和应小于<span id="ZH-CN_TOPIC_0000002370171685__ph188413550332">L1 Buffer</span>的大小；对于NORMAL Layout格式没有这种限制，但需通过MatmulConfig配置输入A、B矩阵多Batch数据大小与<span id="ZH-CN_TOPIC_0000002370171685__ph83512444571">L1 Buffer</span>的大小关系；</li>
     <li id="ZH-CN_TOPIC_0000002370171685__li67942076332">对于BSNGD、SBNGD、BNGS1S2 Layout格式，称左矩阵、右矩阵的G轴分别为ALayoutInfoG、BLayoutInfoG，则ALayoutInfoG / batchA = BLayoutInfoG / batchB；对于NORMAL Layout格式，batchA 、batchB必须满足倍数关系。</li>
     <li id="ZH-CN_TOPIC_0000002370171685__li12557443123716">如果接口输出到<span id="ZH-CN_TOPIC_0000002370171685__ph112711223502">Unified Buffer</span>上，输出C矩阵大小BaseM*BaseN应小于分配的<span id="ZH-CN_TOPIC_0000002370171685__ph878952819500">Unified Buffer</span>内存大小。</li>
     <li id="ZH-CN_TOPIC_0000002370171685__li557433832310">对于BSNGD、SBNGD Layout格式，输入输出只支持ND格式数据。对于BNGS1S2、NORMAL Layout格式， 输入支持ND/NZ格式数据。</li>
     <li id="ZH-CN_TOPIC_0000002370171685__li2935152517">该接口不支持量化模式，即不支持SetQuantScalar、SetQuantVector接口。</li>
     <li id="ZH-CN_TOPIC_0000002370171685__li2557114318378">BSNGD场景，不支持一次计算多行SD，需要算子程序中循环计算。</li>
     <li id="ZH-CN_TOPIC_0000002370171685__li11557443113720"><strong id="ZH-CN_TOPIC_0000002370171685__b17941104153717">异步模式</strong>不支持IterateBatch搬运到UB上。</li>
     <li id="ZH-CN_TOPIC_0000002370171685__li1062316284305">模板参数<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0616.html#ZH-CN_TOPIC_0000002336332840__p9218181073719">enableMixDualMaster</a>（默认取值为false）设置为true，即使能MixDualMaster（双主模式）场景时，不支持使用该接口。</li>
     <li id="ZH-CN_TOPIC_0000002370171685__li1816725152217"><span id="ZH-CN_TOPIC_0000002370171685__ph0695139123817"><term id="ZH-CN_TOPIC_0000002370171685__zh-cn_topic_0000002336176798_term1964153212227_3">
        Atlas 推理系列产品
       </term>AI Core</span>上，只支持NORMAL Layout格式。</li>
     <li id="ZH-CN_TOPIC_0000002370171685__li136952393388"><span id="ZH-CN_TOPIC_0000002370171685__ph580814016190"><term id="ZH-CN_TOPIC_0000002370171685__zh-cn_topic_0000002336176798_term1964153212227_4">
        Atlas 推理系列产品
       </term>AI Core</span>上，不支持A、B矩阵内存逻辑位置为TPosition::TSCM的输入。</li>
     <li id="ZH-CN_TOPIC_0000002370171685__li0474956129"><span id="ZH-CN_TOPIC_0000002370171685__ph1722012144287"><term id="ZH-CN_TOPIC_0000002370171685__zh-cn_topic_0000002336176798_term1964153212227_5">
        Atlas 推理系列产品
       </term>AI Core</span>上，Bias不支持复用，Bias的shape大小必须为Batch * N。</li>
     <li id="ZH-CN_TOPIC_0000002370171685__li913131914451">使用该接口时，A矩阵、B矩阵不支持int4b_t类型的输入，即BatchMatmul不支持int4b_t类型的矩阵输入。</li>
