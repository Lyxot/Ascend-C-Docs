    <h4 class="sectiontitle">约束说明</h4>
    <ul id="ZH-CN_TOPIC_0000002370172085__ul1920315129188">
     <li id="ZH-CN_TOPIC_0000002370172085__li15203412191816">在<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0008.html#ZH-CN_TOPIC_0000002336176974__section349312501823">分离架构</a>中，本接口必须在<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0110.html">InitBuffer</a>接口前调用。</li>
     <li id="ZH-CN_TOPIC_0000002370172085__li1447181451815">在程序中，最多支持定义4个Matmul对象。</li>
     <li id="ZH-CN_TOPIC_0000002370172085__li1932055175510">当代码中只有一个Matmul对象时，本接口可以不传入tiling参数，通过<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0630.html">Init</a>接口单独传入tiling参数。</li>
     <li id="ZH-CN_TOPIC_0000002370172085__li18397311165714">当代码中有多个Matmul对象时，必须满足Matmul对象与其tiling参数一一对应，依次传入，具体方式请参考调用示例。</li>
    </ul>
