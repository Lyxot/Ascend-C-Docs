    <h4 class="sectiontitle">功能说明</h4>
    <p id="ZH-CN_TOPIC_0000002336174386__p05116051416">按元素做量化计算，比如将half/float数据类型量化为int8_t数据类型。计算公式如下，其中PAR表示矢量计算单元一个迭代能够处理的元素个数，round表示四舍六入五成双取整：</p>
    <ul id="ZH-CN_TOPIC_0000002336174386__ul14831736122910">
     <li id="ZH-CN_TOPIC_0000002336174386__li18483336182919">PER_TENSOR量化：整个srcTensor对应一个量化参数，量化参数的shape为[1]。
      <p id="ZH-CN_TOPIC_0000002336174386__p61097528570"><a name="ZH-CN_TOPIC_0000002336174386__li18483336182919"></a><a name="li18483336182919"></a><span><img class="mathml" id="ZH-CN_TOPIC_0000002336174386__image1260144902516" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_formulaimage_0000002370254225.png"></span></p></li>
     <li id="ZH-CN_TOPIC_0000002336174386__li1626114417291">PER_CHANNEL量化：srcTensor的shape为[m, n], 每个channel维度对应一个量化参数，量化参数的shape为[n]。
      <p id="ZH-CN_TOPIC_0000002336174386__p10621173554317"><a name="ZH-CN_TOPIC_0000002336174386__li1626114417291"></a><a name="li1626114417291"></a><span><img class="mathml" id="ZH-CN_TOPIC_0000002336174386__image15560131242612" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_formulaimage_0000002370254209.png"></span></p></li>
    </ul>
   </div>

    <h4 class="sectiontitle">实现原理</h4>
    <div class="fignone" id="ZH-CN_TOPIC_0000002336174386__fig966236152318">
     <span class="figcap"><b>图1 </b>AscendQuant算法框图scale和offset都是scalar</span>
     <br><span><img class="imgResize" id="ZH-CN_TOPIC_0000002336174386__image61660225461" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002336176138.png" title="点击放大"></span>
    </div>
    <div class="fignone" id="ZH-CN_TOPIC_0000002336174386__fig2405134711019">
     <span class="figcap"><b>图2 </b>AscendQuant算法框图scale和offset都是Tensor</span>
     <br><span><img class="eddx" id="ZH-CN_TOPIC_0000002336174386__image2760957118" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002370174325.png"></span>
    </div>
    <div class="fignone" id="ZH-CN_TOPIC_0000002336174386__fig6542182812108">
     <span class="figcap"><b>图3 </b>AscendQuant算法框图scale是Tensor&amp;offset是Scalar</span>
     <br><span><img class="eddx" id="ZH-CN_TOPIC_0000002336174386__image73547219262" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002336176178.png"></span>
    </div>
    <p id="ZH-CN_TOPIC_0000002336174386__p278514483591">如上图所示是AscendQuant内部算法框图，计算过程大致描述为如下几步，均在Vector上进行：</p>
    <ol id="ZH-CN_TOPIC_0000002336174386__ol163741345153310">
     <li id="ZH-CN_TOPIC_0000002336174386__li53744457333">精度转换：当输入的src，scale或者offset是float类型时，将其转换为half类型；</li>
     <li id="ZH-CN_TOPIC_0000002336174386__li698414773316">broadcast：当输入的scale或者offset是向量时，将其broadcast成和src相同维度；</li>
     <li id="ZH-CN_TOPIC_0000002336174386__li1875414502334">计算scale：当src和scale为向量时做Mul计算，当scale是scalar时做Muls计算，得到Tmp1；</li>
     <li id="ZH-CN_TOPIC_0000002336174386__li19740105283310">计算offset：当Tmp1和offset为向量时做Add计算，当offset是scalar时做Adds计算，得到Tmp2；</li>
     <li id="ZH-CN_TOPIC_0000002336174386__li178311854203314">精度转换：将Tmp2从half转换成int8_t类型，得到output。</li>
    </ol>

    <p id="ZH-CN_TOPIC_0000002336174386__p11387712203914">由于该接口的内部实现中涉及复杂的数学计算，需要额外的临时空间来存储计算过程中的中间变量。临时空间支持<strong id="ZH-CN_TOPIC_0000002336174386__b238721253910">接口框架申请</strong>和开发者<strong id="ZH-CN_TOPIC_0000002336174386__b2038791213393">通过sharedTmpBuffer入参传入</strong>两种方式。</p>
    <ul id="ZH-CN_TOPIC_0000002336174386__ul13871412153910">
     <li id="ZH-CN_TOPIC_0000002336174386__li338781273911">接口框架申请临时空间，开发者无需申请，但是需要预留临时空间的大小。</li>
    </ul>
    <ul id="ZH-CN_TOPIC_0000002336174386__ul738781243918">
     <li id="ZH-CN_TOPIC_0000002336174386__li63871124390">通过sharedTmpBuffer入参传入，使用该tensor作为临时空间进行处理，接口框架不再申请。该方式开发者可以自行管理sharedTmpBuffer内存空间，并在接口调用完成后，复用该部分内存，内存不会反复申请释放，灵活性较高，内存利用率也较高。</li>
    </ul>
    <p id="ZH-CN_TOPIC_0000002336174386__p132151454835">接口框架申请的方式，开发者需要预留临时空间；通过sharedTmpBuffer传入的情况，开发者需要为sharedTmpBuffer申请空间。临时空间大小BufferSize的获取方式如下：通过<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0819.html">GetAscendQuantMaxMinTmpSize</a>中提供的GetAscendQuantMaxMinTmpSize接口获取需要预留空间的范围大小。</p>
