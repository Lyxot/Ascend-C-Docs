<div class="section" id="ZH-CN_TOPIC_0000002336333180__section618mcpsimp"><h4 class="sectiontitle">功能说明</h4><p id="ZH-CN_TOPIC_0000002336333180__p54748558575">按元素做伪量化计算，比如将int8_t数据类型伪量化为half数据类型，计算公式如下：</p>
<ul id="ZH-CN_TOPIC_0000002336333180__ul580281484714"><li id="ZH-CN_TOPIC_0000002336333180__li9330171814478">PER_CHANNEL场景（按通道量化）<ul id="ZH-CN_TOPIC_0000002336333180__ul1409163219476"><li id="ZH-CN_TOPIC_0000002336333180__li197551924812">不使能输入转置<p id="ZH-CN_TOPIC_0000002336333180__p11992149355"><a name="ZH-CN_TOPIC_0000002336333180__li197551924812"></a><a name="li197551924812"></a>groupSize = src.shape[0] / offset.shape[0]</p>
<p id="ZH-CN_TOPIC_0000002336333180__p1784601518484"><strong id="ZH-CN_TOPIC_0000002336333180__b18334132754710">dst[i][j] = scale[i / groupSize][j] * (src[i][j] + offset[i / groupSize][j])</strong></p>
</li><li id="ZH-CN_TOPIC_0000002336333180__li71121720124818">使能输入转置<p id="ZH-CN_TOPIC_0000002336333180__p51341731134118"><a name="ZH-CN_TOPIC_0000002336333180__li71121720124818"></a><a name="li71121720124818"></a>groupSize = src.shape[1] / offset.shape[1]</p>
<p id="ZH-CN_TOPIC_0000002336333180__p207241434104812"><strong id="ZH-CN_TOPIC_0000002336333180__b18547175623320">dst[i][j] = scale[i][j / groupSize] * (src[i][j] + offset[i][j / groupSize])</strong></p>
</li></ul>
</li></ul>
<ul id="ZH-CN_TOPIC_0000002336333180__ul091714330328"><li id="ZH-CN_TOPIC_0000002336333180__li197781243339">PER_TENSOR场景 （按张量量化）<p id="ZH-CN_TOPIC_0000002336333180__p47782432031"><a name="ZH-CN_TOPIC_0000002336333180__li197781243339"></a><a name="li197781243339"></a><strong id="ZH-CN_TOPIC_0000002336333180__b07787433312">dst[i][j] = scale * (src[i][j] + offset)</strong>l</p>
</li></ul>
</div>
<div class="section" id="ZH-CN_TOPIC_0000002336333180__section13229175017585"><h4 class="sectiontitle">实现原理</h4><div class="fignone" id="ZH-CN_TOPIC_0000002336333180__fig18399121215208"><span class="figcap"><b>图1 </b>AscendAntiQuant算法框图</span><br><span><img class="eddx" id="ZH-CN_TOPIC_0000002336333180__image19141327121215" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002370173097.png"></span></div>
<p id="ZH-CN_TOPIC_0000002336333180__p278514483591">如上图所示，为AscendAntiQuant的典型场景算法框图，计算过程分为如下几步，均在Vector上进行：</p>
<ol id="ZH-CN_TOPIC_0000002336333180__ol757018294453"><li id="ZH-CN_TOPIC_0000002336333180__li9570172924512">精度转换：将输入src转换为half类型；</li><li id="ZH-CN_TOPIC_0000002336333180__li136305611457">计算offset：当offset为向量时做Add计算，当offset为scalar时做Adds计算；</li><li id="ZH-CN_TOPIC_0000002336333180__li1812723194714">计算scale：当scale为向量时做Mul计算，当scale为scalar时做Muls计算。</li></ol>
<div class="fignone" id="ZH-CN_TOPIC_0000002336333180__fig20930182422019"><span class="figcap"><b>图2 </b>isTranspose为False且输出为bfloat16的AscendAntiQuant算法框图</span><br><span><img class="eddx" id="ZH-CN_TOPIC_0000002336333180__image3902144011124" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002336174974.png"></span></div>
<p id="ZH-CN_TOPIC_0000002336333180__p996415271714">在<span id="ZH-CN_TOPIC_0000002336333180__ph1896418231710"><term id="ZH-CN_TOPIC_0000002336333180__zh-cn_topic_0000002336176798_term11962195213215_1">Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件</term></span>上，当输出为bfloat16时，计算过程分为如下几步：</p>
<ol id="ZH-CN_TOPIC_0000002336333180__ol18444135925113"><li id="ZH-CN_TOPIC_0000002336333180__li16444145945117">src精度转换：将输入的src转换为half类型，再转换为float类型，存放到tmp1；</li><li id="ZH-CN_TOPIC_0000002336333180__li16964161155218">offset精度转换：当输入的offset为向量时转换为float类型，存放到tmp2，为scalar时做ToFloat转换为float类型；</li><li id="ZH-CN_TOPIC_0000002336333180__li118471933525">计算offset：当输入的offset为向量时与tmp2做Add计算，为scalar时做Adds计算；</li><li id="ZH-CN_TOPIC_0000002336333180__li49933516521">scale精度转换：当输入的scale为向量时转换为float类型，存放到tmp2，为scalar时做ToFloat转换为float类型；</li><li id="ZH-CN_TOPIC_0000002336333180__li1395977115215">计算scale：当输入的scale为向量时用tmp2做Mul计算，为scalar时做Muls计算；</li><li id="ZH-CN_TOPIC_0000002336333180__li3163191215524">dst精度转换：将tmp1转换为bf16类型。</li></ol>
</div>
