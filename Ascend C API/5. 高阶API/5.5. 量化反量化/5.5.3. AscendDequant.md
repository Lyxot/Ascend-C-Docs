    <h4 class="sectiontitle">功能说明</h4>
    <p id="ZH-CN_TOPIC_0000002336173710__p1839012973818">按元素做反量化计算，比如将int32_t数据类型反量化为half/float等数据类型。<strong id="ZH-CN_TOPIC_0000002336173710__b161906673614">本接口最多支持输入为二维数据，不支持更高维度的输入。</strong></p>
    <ul id="ZH-CN_TOPIC_0000002336173710__ul75721946153517">
     <li id="ZH-CN_TOPIC_0000002336173710__li1657213467357">假设输入srcTensor的shape为<strong id="ZH-CN_TOPIC_0000002336173710__b12448629155516">（m, n）</strong>，每行数据（即n个输入数据）所占字节数要求<strong id="ZH-CN_TOPIC_0000002336173710__b1356121425514">32字节对齐</strong>，每行中进行反量化的元素个数为<strong id="ZH-CN_TOPIC_0000002336173710__b2023164218353">calCount</strong>；</li>
     <li id="ZH-CN_TOPIC_0000002336173710__li117722054114319">反量化系数deqScale可以为标量或者向量，为向量的情况下，calCount &lt;= deqScale的元素个数，只有前CalCount个反量化系数生效；</li>
     <li id="ZH-CN_TOPIC_0000002336173710__li1172134814359">输出dstTensor的shape为<strong id="ZH-CN_TOPIC_0000002336173710__b87431432115511">（m, n_dst）</strong>， n * sizeof(dstT)不满足32字节对齐时，需要<strong id="ZH-CN_TOPIC_0000002336173710__b263602415550">向上补齐为32字节</strong>，n_dst为向上补齐后的列数。</li>
    </ul>
    <p id="ZH-CN_TOPIC_0000002336173710__p1015334103211">下面通过两个具体的示例来解释参数的配置和计算逻辑（下文中DequantParams类型为存储shape信息的结构体{m, n, calCount}）：</p>
    <ul id="ZH-CN_TOPIC_0000002336173710__ul13877242151617">
     <li id="ZH-CN_TOPIC_0000002336173710__li5877174210166">如下图示例中，srcTensor的数据类型为int32_t，m = 4，n = 8，calCount = 4，表明srcTensor中每行进行反量化的元素个数为4，deqScale中的前4个数生效，后12个数不参与反量化计算；dstTensor的数据类型为bfloat16_t，m = 4，n_dst = 16 (16 * sizeof(bfloat16_t) % 32 = 0)。计算逻辑是srcTensor的每n个数为一行，对于每行中的前calCount个元素，该行srcTensor的第i个元素与deqScale的第i个元素进行相乘写入dstTensor对应行的第i个元素，dstTensor对应行的第calCount + 1个元素~第n_dst个元素均为不确定的值。
      <p id="ZH-CN_TOPIC_0000002336173710__p1493610480562"><a name="ZH-CN_TOPIC_0000002336173710__li5877174210166"></a><a name="li5877174210166"></a><span><img id="ZH-CN_TOPIC_0000002336173710__image13572191184617" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002370173385.png"></span></p></li>
     <li id="ZH-CN_TOPIC_0000002336173710__li14305124831617">如下示例中，srcTensor的数据类型为int32_t，m = 4，n = 8， calCount = 4，表明srcTensor中每行进行反量化的元素个数为4；dstTensor的数据类型为float，m = 4，n_dst = 8 (8 * sizeof(float) % 32 = 0)。对于srcTensor每行中的前4个元素都和标量deqScale相乘并写入dstTensor中每行的对应位置。
      <p id="ZH-CN_TOPIC_0000002336173710__p1633210528103"><a name="ZH-CN_TOPIC_0000002336173710__li14305124831617"></a><a name="li14305124831617"></a><span><img id="ZH-CN_TOPIC_0000002336173710__image26411649181014" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002336335026.png"></span></p></li>
    </ul>
    <p id="ZH-CN_TOPIC_0000002336173710__p16885152213379">当用户将模板参数中的mode配置为<strong id="ZH-CN_TOPIC_0000002336173710__b2994141752">DEQUANT_WITH_SINGLE_ROW</strong>时：</p>
    <p id="ZH-CN_TOPIC_0000002336173710__p03236342516">针对DequantParams {m, n, calCount}， 若同时满足以下3个条件：</p>
    <ol id="ZH-CN_TOPIC_0000002336173710__ol293834711515">
     <li id="ZH-CN_TOPIC_0000002336173710__li1593820477516">m = 1</li>
     <li id="ZH-CN_TOPIC_0000002336173710__li893994795110">calCount为 32 / sizeof(dstT)的倍数</li>
     <li id="ZH-CN_TOPIC_0000002336173710__li11939947185117">n % calCount = 0</li>
    </ol>
    <p id="ZH-CN_TOPIC_0000002336173710__p549618314911">此时 {1, n, calCount}会被视作为<strong id="ZH-CN_TOPIC_0000002336173710__b95101115695"> {n / calCount, calCount, calCount}</strong> 进行反量化的计算。</p>
    <p id="ZH-CN_TOPIC_0000002336173710__p83573590714">具体效果可看下图所示，传入的DequantParams为 {1, 16, 8}。因为dstT为float，所以calCount满足为8的倍数，在<strong id="ZH-CN_TOPIC_0000002336173710__b1460010459114">DEQUANT_WITH_SINGLE_ROW</strong>模式下会将{1, 2 * 8, 8}转换为 {2, 8, 8}进行计算。</p>
    <p id="ZH-CN_TOPIC_0000002336173710__p730753093914"><span><img id="ZH-CN_TOPIC_0000002336173710__image155811433144912" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002370253249.png" title="点击放大" class="imgResize"></span></p>
    <p id="ZH-CN_TOPIC_0000002336173710__p793251642316"><span><img id="ZH-CN_TOPIC_0000002336173710__image6816317142310" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002336335054.png" title="点击放大" class="imgResize"></span></p>

    <h4 class="sectiontitle">实现原理</h4>
    <p id="ZH-CN_TOPIC_0000002336173710__p12341423112016">以数据类型int32_t，shape为[m, n]的输入srcTensor，数据类型scaleT，shape为[n]的输入deqScale和数据类型dstT，shape为[m, n]的输出dstTensor为例，描述AscendDequant高阶API内部算法框图，如下图所示。</p>
    <div class="fignone" id="ZH-CN_TOPIC_0000002336173710__fig15964941122">
     <span class="figcap"><b>图1 </b>AscendDequant内部算法框图</span>
     <br><span><img class="eddx" id="ZH-CN_TOPIC_0000002336173710__image296444524" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002336175262.png"></span>
    </div>
    <p id="ZH-CN_TOPIC_0000002336173710__p278514483591">计算过程分为如下几步，均在Vector上进行：</p>
    <ol id="ZH-CN_TOPIC_0000002336173710__ol10323161812128">
     <li id="ZH-CN_TOPIC_0000002336173710__li1323171881219">精度转换：将srcTensor和deqScale都转换成FP32精度的tensor，分别得到srcFP32和deqScaleFP32；</li>
     <li id="ZH-CN_TOPIC_0000002336173710__li191165214121">Mul计算：srcFP32一共有m行，每行长度为n；通过m次循环，将srcFP32的每行与deqscaleFP32相乘，通过mask控制仅对前dequantParams.calcount个数进行mul计算，图中index的取值范围为 [0, m)，对应srcFP32的每一行；计算所得结果为mulRes，shape为[m, n]；</li>
     <li id="ZH-CN_TOPIC_0000002336173710__li16444823151212">结果数据精度转换：mulRes从FP32转换成dstT类型的tensor，所得结果为dstTensor，shape为[m, n]。</li>
    </ol>

    </ul>
