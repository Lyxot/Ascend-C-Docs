<h1 class="topictitle1">GetAsinhTmpBufferFactorSize</h1>
<div id="body0000001817928824"><div class="section" id="ZH-CN_TOPIC_0000002370171737__section943714520116"><h4 class="sectiontitle">功能说明</h4><p id="ZH-CN_TOPIC_0000002370171737__p1696210489202">kernel侧Asinh接口的计算需要开发者预留/申请临时空间，最大临时空间（maxTmpBuffer）和输入所占空间（inputSize * typeSize）存在以下关系：</p>
<p id="ZH-CN_TOPIC_0000002370171737__p4245143814343"><strong id="ZH-CN_TOPIC_0000002370171737__b22951813105512">maxTmpBuffer = maxLivedNodeCount * inputSize * typeSize + </strong><strong id="ZH-CN_TOPIC_0000002370171737__b3859151725516">extraBuffer</strong></p>
<p id="ZH-CN_TOPIC_0000002370171737__p142971851152811">其中maxLivedNodeCount表示最大临时空间是输入所占空间的多少倍；extraBuffer表示使用的额外临时空间大小。</p>
<p id="ZH-CN_TOPIC_0000002370171737__p127261711141518">该接口用于获取maxLivedNodeCount和extraBuffer，在固定空间大小的情况下，通过maxLivedNodeCount和extraBuffer可以推算算子单次最大计算元素数量；另外，接口获取的maxLiveNodeCount值可能为0，计算时需要判断该值非0，避免除0错误。</p>
<p id="ZH-CN_TOPIC_0000002370171737__p164222104118">示例如下：</p>
<p id="ZH-CN_TOPIC_0000002370171737__p356319151415">算子实现需要调用Asinh接口，开发者为其预留currBuff大小的空间，利用GetAsinhTmpBufferFactorSize接口得到maxLivedNodeCount 、extraBuffer输出值，反推Asinh算子单次最大计算元素数量为：</p>
<p id="ZH-CN_TOPIC_0000002370171737__p841710184217"><strong id="ZH-CN_TOPIC_0000002370171737__b157264116158">currentShapeSize = (currBuff - extraBuffer) / maxLivedNodeCount / typeSize</strong></p>
</div>
