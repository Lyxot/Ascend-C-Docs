<div class="section" id="ZH-CN_TOPIC_0000002336332864__section618mcpsimp"><h4 class="sectiontitle">功能说明</h4><p id="ZH-CN_TOPIC_0000002336332864__p195567911913"><strong id="ZH-CN_TOPIC_0000002336332864__b567703817712">注意：该接口后续即将废弃，请使用精度和性能更好的SoftmaxFlashV2接口</strong>。</p>
<p id="ZH-CN_TOPIC_0000002336332864__p12181154891915">Softmax增强版本，除了可以对输入tensor做SoftmaxFlash计算，还可以根据上一次Softmax计算的sum和max来更新本次的Softmax计算结果。last轴切轴的情况，每次计算的reduce结果并非是全轴的，需要根据上一次Softmax计算的sum和max来更新本次的Softmax计算结果，可以使用该增强接口。不支持NZ格式。</p>
<p id="ZH-CN_TOPIC_0000002336332864__p78981217102718">当前仅支持传入shape为ND格式，内部的reduce过程都是按last轴进行。不使能update时，该接口等同于<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0754.html">SoftMax</a>。</p>
