<div class="section" id="ZH-CN_TOPIC_0000002370171893__section13229175017585"><h4 class="sectiontitle">实现原理</h4><p id="ZH-CN_TOPIC_0000002370171893__p1544517171295">以float类型，ND格式，shape为[m,k]的输入Tensor为例，描述SoftmaxGrad高阶API内部算法框图，如下图所示。</p>
<div class="fignone" id="ZH-CN_TOPIC_0000002370171893__fig1590310503117"><span class="figcap"><b>图1 </b>SoftmaxGrad算法框图</span><br><span><img class="eddx" id="ZH-CN_TOPIC_0000002370171893__image1190318506112" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002370173577.png"></span></div>
<p id="ZH-CN_TOPIC_0000002370171893__p278514483591">计算过程分为如下几步，均在Vector上进行：</p>
<ol id="ZH-CN_TOPIC_0000002370171893__ol19937610351"><li id="ZH-CN_TOPIC_0000002370171893__li1693712104519">mul步骤：对输入x和y所有数据相乘，计算结果会保存到一个临时空间temp中；</li><li id="ZH-CN_TOPIC_0000002370171893__li1393701015519">reducesum步骤：对temp数据([m, k])每一行求和得到[m, 1]，计算结果会保存到临时空间中；</li><li id="ZH-CN_TOPIC_0000002370171893__li139371510354">broadcast步骤：对reducesum结果[m, 1]的数据做一个按<span id="ZH-CN_TOPIC_0000002370171893__ph885316116307">datablock</span>为单位的填充，比如float类型下，把[m, 1]扩展成[m, 8]；</li><li id="ZH-CN_TOPIC_0000002370171893__li1493712105512">判断是否isFront模式，如果是，则输出broadcast后的结果，计算结束；如果不是，则继续执行后续步骤；</li><li id="ZH-CN_TOPIC_0000002370171893__li1393715101655">broadcast步骤：对[m, 8]做一个扩维，扩展成[m, k]，计算结果会保存到临时空间中；</li><li id="ZH-CN_TOPIC_0000002370171893__li1193711101958">sub步骤：输入x的所有数据减去上一步broadcast后的结果；</li><li id="ZH-CN_TOPIC_0000002370171893__li793710102514">mul步骤：sub后的所有数据和输入y相乘，输出结果z。</li></ol>
</div>

<p id="ZH-CN_TOPIC_0000002370171893__p11387712203914">由于该接口的内部实现中涉及复杂的计算，需要额外的临时空间来存储计算过程中的中间变量。临时空间支持<strong id="ZH-CN_TOPIC_0000002370171893__b133601846172616">接口框架申请</strong>和开发者<strong id="ZH-CN_TOPIC_0000002370171893__b736019468264">通过sharedTmpBuffer入参传入</strong>两种方式。</p>

<p id="ZH-CN_TOPIC_0000002370171893__p132151454835">接口框架申请的方式，开发者需要预留临时空间；通过sharedTmpBuffer传入的情况，开发者需要为tensor申请空间。临时空间大小BufferSize的获取方式如下：通过<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0764.html">SoftmaxGrad Tiling接口</a>中提供的GetSoftMaxGradMaxTmpSize/GetSoftMaxGradMinTmpSize接口获取所需最大和最小临时空间大小，最小空间可以保证功能正确，最大空间用于提升性能。</p>
