<div class="section" id="ZH-CN_TOPIC_0000002370171933__section618mcpsimp"><h4 class="sectiontitle">功能说明</h4><p id="ZH-CN_TOPIC_0000002370171933__p0844111515813">将输入tensor[m<sub id="ZH-CN_TOPIC_0000002370171933__sub136771029184911">0</sub>, m<sub id="ZH-CN_TOPIC_0000002370171933__sub553721319505">1</sub>, ...m<sub id="ZH-CN_TOPIC_0000002370171933__sub17105924155015">t</sub>, n]（t大于等于0）的非尾轴长度相乘的结果看作m，则输入tensor的shape看作[m, n]。对输入tensor[m,n]按行做如下计算，与<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0754.html">SoftMax</a>接口不同，该接口内部没有reduce过程计算sum和max数据，而是使用计算好的sum和max数据对输入tensor做Softmax计算。计算公式如下：</p>

<div class="section" id="ZH-CN_TOPIC_0000002370171933__section13229175017585"><h4 class="sectiontitle">实现原理</h4><p id="ZH-CN_TOPIC_0000002370171933__p2615570284">以float类型，ND格式，shape为[m, k]的输入Tensor为例，描述SimpleSoftMax高阶API内部算法框图，如下图所示。</p>
<div class="fignone" id="ZH-CN_TOPIC_0000002370171933__fig8262115061111"><span class="figcap"><b>图1 </b>SimpleSoftMax算法框图</span><br><span><img class="eddx" id="ZH-CN_TOPIC_0000002370171933__image52620501119" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002336335186.png"></span></div>
<p id="ZH-CN_TOPIC_0000002370171933__p278514483591">计算过程分为如下几步，均在Vector上进行：</p>
<p id="ZH-CN_TOPIC_0000002370171933__p159631152204813">1.sub步骤：对输入x的所有数据按行减去输入的max；</p>
<p id="ZH-CN_TOPIC_0000002370171933__p55231510195012">2.exp步骤：对sub之后的所有数据求exp；</p>
<p id="ZH-CN_TOPIC_0000002370171933__p0911323125112">3.div步骤：对exp结果的所有数据按行除以输入的sum，得到结果；</p>
