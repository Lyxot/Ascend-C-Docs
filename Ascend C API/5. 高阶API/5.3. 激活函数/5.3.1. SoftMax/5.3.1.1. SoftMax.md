    <h4 class="sectiontitle">功能说明</h4>
    <p id="ZH-CN_TOPIC_0000002370171461__p05116051416">将输入tensor[m<sub id="ZH-CN_TOPIC_0000002370171461__sub136771029184911">0</sub>, m<sub id="ZH-CN_TOPIC_0000002370171461__sub553721319505">1</sub>, ...m<sub id="ZH-CN_TOPIC_0000002370171461__sub17105924155015">t</sub>, n]（t大于等于0）的非尾轴长度相乘的结果看作m，则输入tensor的shape看作[m, n]。对输入tensor[m, n]按行做如下SoftMax计算：</p>
    <p id="ZH-CN_TOPIC_0000002370171461__p88611720533"><span><img class="mathml" id="ZH-CN_TOPIC_0000002370171461__image464351854418" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_formulaimage_0000002370252913.png"></span></p>

    <h4 class="sectiontitle">实现原理</h4>
    <p id="ZH-CN_TOPIC_0000002370171461__p12341423112016">以float类型，ND格式，shape为[m, k]的输入Tensor为例，描述SoftMax高阶API内部算法框图，如下图所示。</p>
    <div class="fignone" id="ZH-CN_TOPIC_0000002370171461__fig03757321297">
     <span class="figcap"><b>图3 </b>SoftMax算法框图</span>
     <br><span><img class="eddx" id="ZH-CN_TOPIC_0000002370171461__image137511325292" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002336174946.png"></span>
    </div>
    <p id="ZH-CN_TOPIC_0000002370171461__p278514483591">计算过程分为如下几步，均在Vector上进行：</p>
    <ol id="ZH-CN_TOPIC_0000002370171461__ol135043385411">
     <li id="ZH-CN_TOPIC_0000002370171461__li55049382411">reducemax步骤：对输入x的每一行数据求最大值得到[m, 1]的结果，计算结果会保存到一个临时空间temp中；</li>
     <li id="ZH-CN_TOPIC_0000002370171461__li91684217413">broadcast步骤：对temp中的数据[m, 1]做一个按<span id="ZH-CN_TOPIC_0000002370171461__ph885316116307">datablock</span>为单位的填充，比如float类型下，把[m, 1]扩展成[m, 8]，同时输出max；</li>
     <li id="ZH-CN_TOPIC_0000002370171461__li122152469411">sub步骤：对输入x的所有数据按行减去max；</li>
     <li id="ZH-CN_TOPIC_0000002370171461__li1876318911426">exp步骤：对sub之后的所有数据求exp；</li>
     <li id="ZH-CN_TOPIC_0000002370171461__li133441284219">reducesum步骤：对exp后的结果的每一行数据求和得到[m, 1]，计算结果会保存到临时空间temp中；</li>
     <li id="ZH-CN_TOPIC_0000002370171461__li64171614184218">broadcast步骤：对temp([m, 1])做一个按<span id="ZH-CN_TOPIC_0000002370171461__ph155642518295">datablock</span>为单位的填充，比如float类型下，把[m, 1]扩展成[m, 8]，同时输出sum；</li>
     <li id="ZH-CN_TOPIC_0000002370171461__li35821716184211">div步骤：对exp后的结果的所有数据按行除以sum，得到最终结果。</li>
    </ol>
