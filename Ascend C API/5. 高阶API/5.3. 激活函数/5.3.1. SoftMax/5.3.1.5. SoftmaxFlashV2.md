<div class="section" id="ZH-CN_TOPIC_0000002336174214__section618mcpsimp"><h4 class="sectiontitle">功能说明</h4><p id="ZH-CN_TOPIC_0000002336174214__p585642713367">SoftmaxFlash增强版本，对应FlashAttention-2算法。将输入tensor[m<sub id="ZH-CN_TOPIC_0000002336174214__sub136771029184911">0</sub>, m<sub id="ZH-CN_TOPIC_0000002336174214__sub553721319505">1</sub>, ...m<sub id="ZH-CN_TOPIC_0000002336174214__sub17105924155015">t</sub>, n]（t大于等于0）的非尾轴长度相乘的结果看作m，则输入tensor的shape看作[m, n]。对输入tensor[m,n]按行做如下计算，不同的update值对应不同的计算公式，其中x、inmax和insum为输入，M、S、E均为输出。</p>
<ul id="ZH-CN_TOPIC_0000002336174214__ul89301738375"><li id="ZH-CN_TOPIC_0000002336174214__li49302310376">update为false：<p id="ZH-CN_TOPIC_0000002336174214__p88611720533"><a name="ZH-CN_TOPIC_0000002336174214__li49302310376"></a><a name="li49302310376"></a><span><img class="mathml" id="ZH-CN_TOPIC_0000002336174214__image21932381368" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_formulaimage_0000002370253841.png"></span></p>
<p id="ZH-CN_TOPIC_0000002336174214__p128201837114917"></p>
</li><li id="ZH-CN_TOPIC_0000002336174214__li8621413103810">update为true：<p id="ZH-CN_TOPIC_0000002336174214__p15847123615386"><a name="ZH-CN_TOPIC_0000002336174214__li8621413103810"></a><a name="li8621413103810"></a><span><img class="mathml" id="ZH-CN_TOPIC_0000002336174214__image9621448183810" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_formulaimage_0000002370253853.png"></span></p>

<div class="section" id="ZH-CN_TOPIC_0000002336174214__section13229175017585"><h4 class="sectiontitle">实现原理</h4><p id="ZH-CN_TOPIC_0000002336174214__p756173010298">以float类型，ND格式，shape为[m, k]的输入Tensor为例，描述SoftmaxFlashV2高阶API内部算法框图，如下图所示。</p>
<div class="fignone" id="ZH-CN_TOPIC_0000002336174214__fig137619450117"><span class="figcap"><b>图1 </b>SoftmaxFlashV2算法框图</span><br><span><img class="eddx" id="ZH-CN_TOPIC_0000002336174214__image2376114518111" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002336335650.png"></span></div>
<p id="ZH-CN_TOPIC_0000002336174214__p278514483591">计算过程根据isUpdate是否使能分为两个分支处理，均在Vector上进行。</p>
<ul id="ZH-CN_TOPIC_0000002336174214__ul5643155065511"><li id="ZH-CN_TOPIC_0000002336174214__li26448508554">当isUpdate为False时，分为如下几步：<ol id="ZH-CN_TOPIC_0000002336174214__ol2306857115514"><li id="ZH-CN_TOPIC_0000002336174214__li83061257155514">reducemax步骤：对输入x的每一行数据求最大值得到[m, 1]，计算结果会保存到一个临时空间temp中；</li><li id="ZH-CN_TOPIC_0000002336174214__li530610573553">broadcast步骤：对temp中的数据[m, 1]做一个按<span id="ZH-CN_TOPIC_0000002336174214__ph885316116307">datablock</span>为单位的填充，比如float类型下，把[m, 1]扩展成[m, 8]，同时输出max；</li><li id="ZH-CN_TOPIC_0000002336174214__li11306857105516">sub步骤：对输入x的所有数据按行减去max；</li><li id="ZH-CN_TOPIC_0000002336174214__li1130614579553">exp步骤：对sub之后的所有数据求exp，并且输出y；</li><li id="ZH-CN_TOPIC_0000002336174214__li83071577551">reducesum步骤：对exp结果的每一行数据求和得到[m, 1]，计算结果会保存到临时空间temp中；</li><li id="ZH-CN_TOPIC_0000002336174214__li53071857175510">broadcast步骤：对temp[m, 1]做一个按<span id="ZH-CN_TOPIC_0000002336174214__ph1451053018332">datablock</span>为单位的填充，比如float类型下，把[m, 1]扩展成[m, 8]，同时输出sum。</li></ol>
</li></ul>
<ul id="ZH-CN_TOPIC_0000002336174214__ul11716653155519"><li id="ZH-CN_TOPIC_0000002336174214__li47161653145519">当isUpdate为True时，分为如下几步：<ol id="ZH-CN_TOPIC_0000002336174214__ol1197313065610"><li id="ZH-CN_TOPIC_0000002336174214__li19973130125617">reducemax步骤：对输入x的每一行数据求最大值得到[m, 1]，计算结果会保存到一个临时空间temp中；</li><li id="ZH-CN_TOPIC_0000002336174214__li597317035612">broadcast步骤：对temp中的数据[m, 1]做一个按<span id="ZH-CN_TOPIC_0000002336174214__ph1219083413313">datablock</span>为单位的填充，比如float类型下，把[m, 1]扩展成[m, 8]，保存为max;</li><li id="ZH-CN_TOPIC_0000002336174214__li1397314075614">max步骤：对输入inmax和上一步计算的max做max操作，得到新的max并输出；</li><li id="ZH-CN_TOPIC_0000002336174214__li19731904568">sub步骤：将输入inmax和新的max相减，然后做exp，计算得到expmax并输出；</li><li id="ZH-CN_TOPIC_0000002336174214__li17973140175618">sub步骤：将输入x和新的max按行相减；</li><li id="ZH-CN_TOPIC_0000002336174214__li9973170105610">exp步骤：对sub之后的所有数据求exp，并且输出y；</li><li id="ZH-CN_TOPIC_0000002336174214__li1897313035619">reducesum步骤：对exp结果的每一行数据求和得到[m, 1]，计算结果会保存到临时空间temp中；</li><li id="ZH-CN_TOPIC_0000002336174214__li3973706567">broadcast步骤：对temp数据[m, 1]做一个按<span id="ZH-CN_TOPIC_0000002336174214__ph3215173883317">datablock</span>为单位的填充，比如float类型下，把[m, 1]扩展成[m, 8]，保存到sum中；</li><li id="ZH-CN_TOPIC_0000002336174214__li1597411012567">mul步骤：将输入insum和expmax结果相乘；</li><li id="ZH-CN_TOPIC_0000002336174214__li397418045610">add步骤：将相乘结果和sum相加，保存到sum并输出。</li></ol>
</li></ul>
