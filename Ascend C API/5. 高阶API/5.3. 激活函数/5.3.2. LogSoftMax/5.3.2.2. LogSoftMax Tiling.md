<h1 class="topictitle1">LogSoftMax Tiling</h1>
<div id="body0000001808615541"><div class="section" id="ZH-CN_TOPIC_0000002336333834__section618mcpsimp"><h4 class="sectiontitle">功能说明</h4><p id="ZH-CN_TOPIC_0000002336333834__p812143041512">kernel侧LogSoftMax接口的计算需要开发者预留/申请临时空间，以下接口用于在host侧获取预留/申请的最大最小临时空间大小，开发者基于此范围选择合适的空间大小，并调用LogSoftMaxTilingFunc函数获取reduceSize，splitSize等参数，作为Tiling参数传递到kernel侧使用。</p>
<ul id="ZH-CN_TOPIC_0000002336333834__ul1219154692816"><li id="ZH-CN_TOPIC_0000002336333834__li91911846122811">为保证功能正确，预留/申请的临时空间大小不能小于最小临时空间大小；</li><li id="ZH-CN_TOPIC_0000002336333834__li370834813281">在最小临时空间-最大临时空间范围内，随着临时空间增大，kernel侧接口计算性能会有一定程度的优化提升。为了达到更好的性能，开发者可以根据实际的内存使用情况进行空间预留/申请。</li></ul>
</div>
