    <p id="ZH-CN_TOPIC_0000002336174082__p05116051416">对输入tensor做LogSoftmax计算。计算公式如下，其中PAR表示矢量计算单元一个迭代能够处理的元素个数 ：</p>

    <p id="ZH-CN_TOPIC_0000002336174082__p88611720533"><span><img class="mathml" id="ZH-CN_TOPIC_0000002336174082__image56911442563" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_formulaimage_0000002370253729.png"></span></p>

    <h4 class="sectiontitle">实现原理</h4>
    <p id="ZH-CN_TOPIC_0000002336174082__p159001039154414">以float类型，ND格式，shape为[m, k]的输入Tensor为例，描述LogSoftMax高阶API内部算法框图，如下图所示。</p>
    <div class="fignone" id="ZH-CN_TOPIC_0000002336174082__fig138551349173015">
     <span class="figcap"><b>图1 </b>LogSoftMax算法框图</span>
     <br><span><img class="imgResize" id="ZH-CN_TOPIC_0000002336174082__image78551495303" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002336175742.png" title="点击放大"></span>
    </div>
    <p id="ZH-CN_TOPIC_0000002336174082__p278514483591">计算过程分为如下几步，均在Vector上进行：</p>
    <ol id="ZH-CN_TOPIC_0000002336174082__ol8498545457">
     <li id="ZH-CN_TOPIC_0000002336174082__li12491954184518">reducemax步骤：对输入x的每一行数据求最大值得到[m, 1]，计算结果会保存到一个临时空间temp中；</li>
     <li id="ZH-CN_TOPIC_0000002336174082__li16321569454">broadcast步骤：对temp中的数据([m, 1])做一个按<span id="ZH-CN_TOPIC_0000002336174082__ph885316116307">datablock</span>为单位的填充，比如float类型下，把[m, 1]扩展成[m, 8]，同时输出max；</li>
     <li id="ZH-CN_TOPIC_0000002336174082__li11283164104619">sub步骤：对输入x的所有数据按行减去max；</li>
     <li id="ZH-CN_TOPIC_0000002336174082__li19283544469">exp步骤：对sub之后的所有数据求exp；</li>
     <li id="ZH-CN_TOPIC_0000002336174082__li14283164184615">reducesum步骤：对exp后的结果的每一行数据求和得到[m, 1]，计算结果会保存到临时空间temp中；</li>
     <li id="ZH-CN_TOPIC_0000002336174082__li142831343462">broadcast步骤：对temp([m, 1])做一个按<span id="ZH-CN_TOPIC_0000002336174082__ph11996202443919">datablock</span>为单位的填充，比如float类型下，把[m, 1]扩展成[m, 8]，同时输出sum；</li>
     <li id="ZH-CN_TOPIC_0000002336174082__li1728315464610">div步骤：对exp结果的所有数据按行除以sum；</li>
     <li id="ZH-CN_TOPIC_0000002336174082__li152833494615">log步骤：对div后的所有数据按行做log10计算，输出y。</li>
    </ol>
