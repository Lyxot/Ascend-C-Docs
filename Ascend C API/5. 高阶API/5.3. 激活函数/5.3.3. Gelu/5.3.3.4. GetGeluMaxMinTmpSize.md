<h1 class="topictitle1">GetGeluMaxMinTmpSize</h1>
<div id="body0000001697649481"><div class="section" id="ZH-CN_TOPIC_0000002336333236__section618mcpsimp"><h4 class="sectiontitle">功能说明</h4><p id="ZH-CN_TOPIC_0000002336333236__p812143041512">kernel侧Gelu、FasterGelu、FasterGeluV2接口的计算需要开发者预留/申请临时空间，本接口用于在host侧获取预留/申请的最大最小临时空间大小，开发者基于此范围选择合适的空间大小作为Tiling参数传递到kernel侧使用。</p>
