<h1 class="topictitle1">使用说明</h1>
<div id="body0000002103020073"><p id="ZH-CN_TOPIC_0000002336173072__p17178131293111"><span id="ZH-CN_TOPIC_0000002336173072__ph975583562710">Ascend C</span>提供一组Conv3DBackpropFilter Tiling API，方便用户获取Conv3DBackpropFilter Kernel计算时所需的Tiling参数。用户只需要传入Input/GradOutput/GradWeight的Position位置、Format格式和DType数据类型及相关参数等信息，调用API接口，即可获取<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0896.html">Init</a>中TConv3DBpFilterTiling结构体中的相关参数。</p>
<p id="ZH-CN_TOPIC_0000002336173072__p1231510253210">Conv3DBackpropFilter Tiling API提供一个GetTiling接口获取Tiling参数，获取Tiling参数的流程如下：</p>
<ol id="ZH-CN_TOPIC_0000002336173072__ol98672522"><li id="ZH-CN_TOPIC_0000002336173072__li6813712520">创建一个单核Tiling对象。</li><li id="ZH-CN_TOPIC_0000002336173072__li18325165523">设置Input、GradOutput、GradWeight的参数类型信息以及Shape信息，如果存在Padding、Stride参数，通过<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0915.html">SetPadding</a>、<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0916.html">SetStride</a>接口设置。</li><li id="ZH-CN_TOPIC_0000002336173072__li597563313541">调用<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0908.html">GetTiling</a>接口，获取Tiling信息。</li></ol>
