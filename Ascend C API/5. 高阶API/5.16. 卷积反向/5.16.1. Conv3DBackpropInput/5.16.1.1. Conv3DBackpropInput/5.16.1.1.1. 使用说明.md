  <h1 class="topictitle1">使用说明</h1>
  <div id="body0000002103020077">
   <p id="ZH-CN_TOPIC_0000002336332852__p19954652112311"><span id="ZH-CN_TOPIC_0000002336332852__ph975583562710">Ascend C</span>提供一组Conv3DBackpropInput高阶API，便于用户快速实现卷积的反向运算，求解反向传播的误差。转置卷积Conv3DTranspose与Conv3DBackpropInput具有相同的数学过程，因此用户也可以使用Conv3DBackpropInput高阶API实现转置卷积算子。卷积的正反向传播如<a href="#ZH-CN_TOPIC_0000002336332852__fig1069918872512">图1</a>，反向传播误差计算如<a href="#ZH-CN_TOPIC_0000002336332852__fig1953483815252">图2 反向传播误差计算示意图</a>。</p>
   <p id="ZH-CN_TOPIC_0000002336332852__p3919148172714">Conv3DBackpropInput的计算公式为：</p>
   <p id="ZH-CN_TOPIC_0000002336332852__p4663152812615"><span><img class="mathml" id="ZH-CN_TOPIC_0000002336332852__image10916020204617" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_formulaimage_0000002336334490.png"></span></p>
   <ul id="ZH-CN_TOPIC_0000002336332852__ul1490444414920">
    <li id="ZH-CN_TOPIC_0000002336332852__li49041044695">∂L/∂Y为卷积正向损失函数对输出Y的梯度GradOutput，作为求反向传播误差∂L/∂X的输入。</li>
    <li id="ZH-CN_TOPIC_0000002336332852__li1448047293">W为卷积正向Weight权重，即矩阵核Kernel，也是滤波器Filter，作为求反向传播误差∂L/∂X的输入，W<sup id="ZH-CN_TOPIC_0000002336332852__sup639474534811">T</sup>表示W的转置。</li>
    <li id="ZH-CN_TOPIC_0000002336332852__li1348544721319">∂L/∂X为特征矩阵的反向传播误差GradInput。</li>
   </ul>
   <div class="fignone" id="ZH-CN_TOPIC_0000002336332852__fig1069918872512">
    <a name="ZH-CN_TOPIC_0000002336332852__fig1069918872512"></a><a name="fig1069918872512"></a><span class="figcap"><b>图1 </b>卷积层的前后向传播示意图</span>
    <br><span><img class="imgResize" id="ZH-CN_TOPIC_0000002336332852__image385314524407" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002336174710.png" title="点击放大"></span>
   </div>
   <div class="fignone" id="ZH-CN_TOPIC_0000002336332852__fig1953483815252">
    <a name="ZH-CN_TOPIC_0000002336332852__fig1953483815252"></a><a name="fig1953483815252"></a><span class="figcap"><b>图2 </b>反向传播误差计算示意图</span>
    <br><span><img class="imgResize" id="ZH-CN_TOPIC_0000002336332852__image1344953124811" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002336334470.png" title="点击放大"></span>
   </div>
   <p id="ZH-CN_TOPIC_0000002336332852__p17641537192417">实现Conv3DBackpropInput求解反向传播误差运算的具体步骤如下：</p>
   <ol id="ZH-CN_TOPIC_0000002336332852__ol3905153313275">
    <li id="ZH-CN_TOPIC_0000002336332852__li16905133142716">创建Conv3DBackpropInput对象。</li>
    <li id="ZH-CN_TOPIC_0000002336332852__li12905533172716">初始化操作。</li>
    <li id="ZH-CN_TOPIC_0000002336332852__li3905133122713">设置卷积的输出反向GradOutput、卷积的输入Weight。</li>
    <li id="ZH-CN_TOPIC_0000002336332852__li290563313277">完成卷积反向操作。</li>
    <li id="ZH-CN_TOPIC_0000002336332852__li6905173312713">结束卷积反向操作。
     <div class="note" id="ZH-CN_TOPIC_0000002336332852__note5724151414442">
      <img src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/public_sys-resources/note_3.0-zh-cn.png"><span class="notetitle"> </span>
      <div class="notebody">
       <p id="ZH-CN_TOPIC_0000002336332852__p198991658115617">下文中提及的M轴方向，即为GradOutput矩阵纵向；K轴方向，即为GradOutput矩阵横向或Weight矩阵纵向；N轴方向，即为Weight矩阵横向。</p>
      </div>
     </div></li>
   </ol>
