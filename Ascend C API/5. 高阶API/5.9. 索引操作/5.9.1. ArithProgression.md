<div class="section" id="ZH-CN_TOPIC_0000002370251569__section13229175017585"><h4 class="sectiontitle">实现原理</h4><p id="ZH-CN_TOPIC_0000002370251569__p2052712461539">以float类型，ND格式，firstValue和diffValue输入Scalar为例，描述ArithProgression高阶API内部算法框图，如下图所示。</p>
<div class="fignone" id="ZH-CN_TOPIC_0000002370251569__fig574573212104"><span class="figcap"><b>图1 </b>ArithProgression算法框图</span><br><span><img class="eddx" id="ZH-CN_TOPIC_0000002370251569__image27451232121016" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002336175154.png"></span></div>
<p id="ZH-CN_TOPIC_0000002370251569__p278514483591">计算过程分为如下几步，均在Vector上进行：</p>
<ol id="ZH-CN_TOPIC_0000002370251569__ol1991111472393"><li id="ZH-CN_TOPIC_0000002370251569__li15911104716394">等差数列长度8以内步骤：按照firstValue和diffValue的值，使用SetValue实现等差数列扩充，扩充长度最大为8，如果等差数列长度小于8，算法结束；</li><li id="ZH-CN_TOPIC_0000002370251569__li13912134773912">等差数列长度8至64的步骤：对第一步中的等差数列结果使用Adds进行扩充，最大循环7次扩充至64，如果等差数列长度小于64，算法结束；</li><li id="ZH-CN_TOPIC_0000002370251569__li14912134710394">等差数列长度64以上的步骤：对第二步中的等差数列结果使用Adds进行扩充，不断循环直至达到等差数列长度为止。</li></ol>
</div>
