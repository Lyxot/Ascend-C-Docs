<div class="section" id="ZH-CN_TOPIC_0000002370171745__section1010511378106"><h4 class="sectiontitle">功能说明</h4><p id="ZH-CN_TOPIC_0000002370171745__p1747973114010">对height * width的二维Tensor在width方向上进行unpad，如果Tensor的width非32B对齐，则不支持调用本接口unpad。本接口具体功能场景如下：Tensor的width已32B对齐，以half为例，如16*16，进行UnPad，变成16*15。</p>
</div>
<div class="section" id="ZH-CN_TOPIC_0000002370171745__section1834111321944"><h4 class="sectiontitle">函数原型</h4><p id="ZH-CN_TOPIC_0000002370171745__p1781143710108">由于该接口的内部实现中涉及复杂的计算，需要额外的临时空间来存储计算过程中的中间变量。临时空间大小BufferSize的获取方法：通过<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0852.html">UnPad Tiling</a>中提供的<strong id="ZH-CN_TOPIC_0000002370171745__b258572012552">GetUnPadMaxMinTmpSize</strong>接口获取所需最大和最小临时空间大小，最小空间可以保证功能正确，最大空间用于提升性能。</p>
<p id="ZH-CN_TOPIC_0000002370171745__p1456420308517">临时空间支持<strong id="ZH-CN_TOPIC_0000002370171745__b15519311951">接口框架申请</strong>和开发者<strong id="ZH-CN_TOPIC_0000002370171745__b1355314511">通过sharedTmpBuffer入参传入</strong>两种方式，因此UnPad接口的函数原型有两种：</p>
