<div class="section" id="ZH-CN_TOPIC_0000002370171909__section618mcpsimp"><h4 class="sectiontitle">功能说明</h4><p id="ZH-CN_TOPIC_0000002370171909__p1033815127410">BatchNorm是对于每一层的输入做规范化处理，使得每一层的分布尽可能的相同，从而加速训练过程和提高模型的泛化能力（有效减少梯度消失和梯度爆炸问题）。基本思想是对于每个batch中的样本，对其输入的每个特征在batch的维度上进行归一化。具体来说，对于输入特征x，BatchNorm的计算过程可以表示为：</p>
<ol id="ZH-CN_TOPIC_0000002370171909__ol1127213415588"><li id="ZH-CN_TOPIC_0000002370171909__li162721541165816">对输入特征x，在batch维度上计算均值μ和方差σ：<p id="ZH-CN_TOPIC_0000002370171909__p1826215351569"><a name="ZH-CN_TOPIC_0000002370171909__li162721541165816"></a><a name="li162721541165816"></a><span><img class="mathml" id="ZH-CN_TOPIC_0000002370171909__image1628413016587" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_formulaimage_0000002370253337.png"></span></p>
</li><li id="ZH-CN_TOPIC_0000002370171909__li18214175605820">对于每个特征i，对输入特征x进行归一化：<p id="ZH-CN_TOPIC_0000002370171909__p16621581936"><a name="ZH-CN_TOPIC_0000002370171909__li18214175605820"></a><a name="li18214175605820"></a><span><img class="mathml" id="ZH-CN_TOPIC_0000002370171909__image1827417484313" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_formulaimage_0000002370173485.png"></span></p>
</li><li id="ZH-CN_TOPIC_0000002370171909__li1475158426">对归一化后的特征进行缩放和平移：<p id="ZH-CN_TOPIC_0000002370171909__p154601533159"><a name="ZH-CN_TOPIC_0000002370171909__li1475158426"></a><a name="li1475158426"></a><span><img class="mathml" id="ZH-CN_TOPIC_0000002370171909__image125012244710" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_formulaimage_0000002336175370.png"></span></p>
</li></ol>
</div>
