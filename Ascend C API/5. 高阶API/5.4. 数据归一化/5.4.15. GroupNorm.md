<div class="section" id="ZH-CN_TOPIC_0000002336333292__section24260390593"><h4 class="sectiontitle">功能说明</h4><p id="ZH-CN_TOPIC_0000002336333292__p1655161161410">对一个特征进行标准化的一般公式如下所示：</p>

<p id="ZH-CN_TOPIC_0000002336333292__p1355121113142">其中，i表示特征中的索引，<span><img class="mathml" id="ZH-CN_TOPIC_0000002336333292__image11462517154" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_formulaimage_0000002336175098.png"></span> 和 <span><img class="mathml" id="ZH-CN_TOPIC_0000002336333292__image5886431161513" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_formulaimage_0000002336175118.png"></span> 表示特征中每个值标准化前后的值，μ和σ表示特征的均值和标准差，计算公式如下所示：</p>
