    <h4 class="sectiontitle">功能说明</h4>
    <p id="ZH-CN_TOPIC_0000002336173894__p5725113216402">根据接口输出的不同，本节介绍如下两种LayerNorm接口。</p>
    <ul id="ZH-CN_TOPIC_0000002336173894__ul83431177406">
     <li id="ZH-CN_TOPIC_0000002336173894__li334351794017">输出归一化结果、均值和方差
      <p id="ZH-CN_TOPIC_0000002336173894__p19710202115436"><a name="ZH-CN_TOPIC_0000002336173894__li334351794017"></a><a name="li334351794017"></a>在深层神经网络训练过程中，前面层训练参数的更新，会引起后面层输入数据分布的变化，导致权重更新不均衡及学习效率变慢。通过采用归一化策略，将网络层输入数据收敛到[0, 1]之间，可以规范网络层输入输出数据分布，加速训练参数收敛过程，使学习效率提升更加稳定。<strong id="ZH-CN_TOPIC_0000002336173894__b13476644131216">LayerNorm是许多归一化方法中的一种。</strong></p>

    <h4 class="sectiontitle">实现原理</h4>
    <ul id="ZH-CN_TOPIC_0000002336173894__ul05522443113">
     <li id="ZH-CN_TOPIC_0000002336173894__li1552184441118">输出归一化结果、均值和方差
      <p id="ZH-CN_TOPIC_0000002336173894__p667364503418"><a name="ZH-CN_TOPIC_0000002336173894__li1552184441118"></a><a name="li1552184441118"></a>以float类型，ND格式，输入为inputX[B, S, H]，gamma[H]和beta[H]为例，描述LayerNorm高阶API内部算法框图，如下图所示。</p>
      <div class="fignone" id="ZH-CN_TOPIC_0000002336173894__fig465593873413">
       <span class="figcap"><b>图1 </b>LayerNorm算法框图</span>
       <br><span><img class="imgResize" id="ZH-CN_TOPIC_0000002336173894__image13655438103412" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002370253481.png" title="点击放大"></span>
      </div>
      <p id="ZH-CN_TOPIC_0000002336173894__p278514483591">计算过程分为如下几步，均在Vector上进行：</p>
      <ol id="ZH-CN_TOPIC_0000002336173894__ol182161932183920">
       <li id="ZH-CN_TOPIC_0000002336173894__li2216432143910">计算均值：Muls计算x*1/m的值，再计算累加值ReduceSum，得到均值outputMean；</li>
       <li id="ZH-CN_TOPIC_0000002336173894__li1421610323393">计算方差：Sub计算出输入x与均值的差值，再用Mul进行平方计算，最后用Muls乘上1/m并计算累加值，得到方差outputVariance；</li>
       <li id="ZH-CN_TOPIC_0000002336173894__li1221633214391">处理gamma和beta：通过broadcast得到BSH维度的gamma和beta；</li>
       <li id="ZH-CN_TOPIC_0000002336173894__li162161832103912">计算输出：方差通过broadcast得到BSH维度的tensor，再依次经过Adds(outputVariance, eps), Ln, Muls, Exp，最后与(x-均值)相乘，得到的结果乘上gamma，加上beta，得到输出结果。</li>
      </ol></li>
    </ul>
    <ul id="ZH-CN_TOPIC_0000002336173894__ul47386610115">
     <li id="ZH-CN_TOPIC_0000002336173894__li1738146191113">输出归一化结果、均值和标准差的倒数
      <p id="ZH-CN_TOPIC_0000002336173894__p176921850192617"><a name="ZH-CN_TOPIC_0000002336173894__li1738146191113"></a><a name="li1738146191113"></a>以float类型，ND格式，输入为inputX[A, R]，gamma[R] 和beta[R]为例，描述LayerNorm高阶API内部算法框架，如下图所示。</p>
      <div class="fignone" id="ZH-CN_TOPIC_0000002336173894__fig125521522105515">
       <span class="figcap"><b>图2 </b>LayerNorm-Rstd版本算法框图</span>
       <p id="ZH-CN_TOPIC_0000002336173894__p6511165119308"><span><img class="imgResize" id="ZH-CN_TOPIC_0000002336173894__image121684104556" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002370253473.png" title="点击放大"></span></p>
       <p id="ZH-CN_TOPIC_0000002336173894__p5540695559">计算过程分为如下几步，均在Vector上进行，整体按照以A轴为最外层循环进行计算：</p>
      </div>
      <ol id="ZH-CN_TOPIC_0000002336173894__ol9831123611018">
       <li id="ZH-CN_TOPIC_0000002336173894__li168311836909">计算均值：首先对x的每个元素乘以1/(2^k+m)，防止后续累加溢出。然后使用二分累加方式对数据进行求和：将数据拆分成一个整块和一个尾块，其中整块为2^k个元素，尾块为m个元素，将尾块数据叠加到整块数据。为方便描述，定义Vnum为参与单次计算的元素个数。对整块中，以Vnum长度为单位，奇偶位数据进行Vadd，得到一个Vnum长度的结果，对该结果做WholeReduceSum计算，得到输出均值mean；</li>
       <li id="ZH-CN_TOPIC_0000002336173894__li88318367012">计算rstd：用Sub计算出输入x与均值的差值，再用Mul计算，计算该差值的平方，为防止溢出，按照同样的二分累加方式，计算出该平方结果的方差Variance；方差与防除零系数ε相加，通过Rsqrt计算，得到输出rstd；</li>
       <li id="ZH-CN_TOPIC_0000002336173894__li13832193620016">计算输出：用Sub计算出输入x与均值的差值，再与rstd相乘，得到的结果与gamma相乘，与beta相加，得到输出结果。</li>
      </ol></li>
    </ul>
   </div>

     <li id="ZH-CN_TOPIC_0000002336173894__li124011313290">操作数地址偏移对齐要求请参见<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0004.html">通用约束</a>。</li>
     <li id="ZH-CN_TOPIC_0000002336173894__li178631019205117">对于输出归一化结果、均值和方差的接口：

       <li id="ZH-CN_TOPIC_0000002336173894__li8777195805116">src和dst的Tensor空间可以复用。</li>
