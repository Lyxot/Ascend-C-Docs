<h1 class="topictitle1">BatchNorm Tiling</h1>
<div id="body0000001740410133"><div class="section" id="ZH-CN_TOPIC_0000002336333256__section663724118466"><h4 class="sectiontitle">功能说明</h4><p id="ZH-CN_TOPIC_0000002336333256__p19701228131615">BatchNorm Tiling API用于获取BatchNorm kernel计算时所需的Tiling参数。获取Tiling参数主要分为如下两步：</p>
<ol id="ZH-CN_TOPIC_0000002336333256__ol18970162881619"><li id="ZH-CN_TOPIC_0000002336333256__li0970182810162">通过<strong id="ZH-CN_TOPIC_0000002336333256__b10425811131711">GetBatchNormMaxMinTmpSize</strong>获取BatchNorm接口计算所需最大和最小临时空间大小。<div class="p" id="ZH-CN_TOPIC_0000002336333256__p8567191234017">kernel侧BatchNorm接口的计算需要开发者预留/申请临时空间，<strong id="ZH-CN_TOPIC_0000002336333256__b2451047171720">GetBatchNormMaxMinTmpSize</strong>用于在host侧获取预留/申请的最大最小临时空间大小，开发者基于此范围选择合适的空间大小作为Tiling参数传递到kernel侧使用。<ul id="ZH-CN_TOPIC_0000002336333256__ul1219154692816"><li id="ZH-CN_TOPIC_0000002336333256__li7970428121619">为保证功能正确，预留/申请的临时空间大小不能小于最小临时空间大小；</li><li id="ZH-CN_TOPIC_0000002336333256__li6970162812164">在最小临时空间-最大临时空间范围内，随着临时空间增大，kernel侧接口计算性能会有一定程度的优化提升。为了达到更好的性能，开发者可以根据实际的内存使用情况进行空间预留/申请。</li></ul>
