<div class="section" id="ZH-CN_TOPIC_0000002370251585__section618mcpsimp"><h4 class="sectiontitle">功能说明</h4><p id="ZH-CN_TOPIC_0000002370251585__p324221815217">在深层神经网络训练过程中，执行层LayerNorm归一化时，可以使用DeepNorm进行替代，通过扩大残差连接来提高Transformer的稳定性。</p>
<p id="ZH-CN_TOPIC_0000002370251585__p128611164017">本接口实现了对shape大小为[B，S，H]的输入数据的DeepNorm归一化，其计算公式如下：</p>
<p id="ZH-CN_TOPIC_0000002370251585__p279364471715">DeepNorm(x) = LayerNorm(α * X + SubLayer(X))</p>
<p id="ZH-CN_TOPIC_0000002370251585__p16583192061310">SubLayer(X)通常是指在DeepNorm模型中的一个子层（sub-layer），用于实现自注意力机制（self-attention mechanism）。本接口中会整体作为一个输入Tensor传入。</p>
</div>
