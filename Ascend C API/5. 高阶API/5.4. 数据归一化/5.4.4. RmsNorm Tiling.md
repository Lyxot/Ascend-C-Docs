<h1 class="topictitle1">RmsNorm Tiling</h1>
<div id="body0000001740410129"><div class="section" id="ZH-CN_TOPIC_0000002370251465__section663724118466"><h4 class="sectiontitle">功能说明</h4><p id="ZH-CN_TOPIC_0000002370251465__p8060118"><span id="ZH-CN_TOPIC_0000002370251465__ph78101811113916">Ascend C</span>提供RmsNorm Tiling API，方便用户获取RmsNorm kernel计算时所需的Tiling参数。</p>
<p id="ZH-CN_TOPIC_0000002370251465__p55788219376">获取Tiling参数主要分为如下两步：</p>
<ol id="ZH-CN_TOPIC_0000002370251465__ol13393192514376"><li id="ZH-CN_TOPIC_0000002370251465__li61302029103711">通过<strong id="ZH-CN_TOPIC_0000002370251465__b7217175663612">GetRmsNormMaxMinTmpSize</strong>获取RmsNorm接口计算所需最大和最小临时空间大小。<div class="p" id="ZH-CN_TOPIC_0000002370251465__p8567191234017">kernel侧RmsNorm接口的计算需要开发者预留/申请临时空间，<strong id="ZH-CN_TOPIC_0000002370251465__b7320102874312">GetRmsNormMaxMinTmpSize</strong>用于在host侧获取预留/申请的最大最小临时空间大小，开发者基于此范围选择合适的空间大小作为Tiling参数传递到kernel侧使用。<ul id="ZH-CN_TOPIC_0000002370251465__ul1219154692816"><li id="ZH-CN_TOPIC_0000002370251465__li91911846122811">为保证功能正确，预留/申请的临时空间大小不能小于最小临时空间大小；</li><li id="ZH-CN_TOPIC_0000002370251465__li370834813281">在最小临时空间-最大临时空间范围内，随着临时空间增大，kernel侧接口计算性能会有一定程度的优化提升。为了达到更好的性能，开发者可以根据实际的内存使用情况进行空间预留/申请。</li></ul>
</div>
</li><li id="ZH-CN_TOPIC_0000002370251465__li1539317253378">通过<strong id="ZH-CN_TOPIC_0000002370251465__b1350617619373">GetRmsNormTilingInfo</strong>获取RmsNorm kernel侧接口所需tiling参数。<p id="ZH-CN_TOPIC_0000002370251465__p139212010583">RmsNorm Tiling结构体的定义如下，开发者无需关注该tiling结构的具体信息，只需要传递到kernel侧，传入RmsNorm高阶API接口，直接进行使用即可。</p>
