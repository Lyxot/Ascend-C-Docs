<h1 class="topictitle1">DeepNorm Tiling</h1>
<div id="body0000001740570001"><div class="section" id="ZH-CN_TOPIC_0000002370171749__section663724118466"><h4 class="sectiontitle">功能说明</h4><p id="ZH-CN_TOPIC_0000002370171749__p8060118"><span id="ZH-CN_TOPIC_0000002370171749__ph78101811113916">Ascend C</span>提供DeepNorm Tiling API，方便用户获取DeepNorm kernel计算时所需的Tiling参数。</p>
<p id="ZH-CN_TOPIC_0000002370171749__p55788219376">获取Tiling参数主要分为如下两步：</p>
<ol id="ZH-CN_TOPIC_0000002370171749__ol13393192514376"><li id="ZH-CN_TOPIC_0000002370171749__li61302029103711">通过<strong id="ZH-CN_TOPIC_0000002370171749__b1271838193419">GetDeepNormMaxMinTmpSize</strong>获取DeepNorm接口计算所需最大和最小临时空间大小。<div class="p" id="ZH-CN_TOPIC_0000002370171749__p8567191234017">kernel侧DeepNorm接口的计算需要开发者预留/申请临时空间，<strong id="ZH-CN_TOPIC_0000002370171749__b16594152163410">GetDeepNormMaxMinTmpSize</strong>用于在host侧获取预留/申请的最大最小临时空间大小，开发者基于此范围选择合适的空间大小作为Tiling参数传递到kernel侧使用。<ul id="ZH-CN_TOPIC_0000002370171749__ul2029610523418"><li id="ZH-CN_TOPIC_0000002370171749__li32964533411">为保证功能正确，预留/申请的临时空间大小不能小于最小临时空间大小；</li><li id="ZH-CN_TOPIC_0000002370171749__li162961052342">在最小临时空间-最大临时空间范围内，随着临时空间增大，kernel侧接口计算性能会有一定程度的优化提升。为了达到更好的性能，开发者可以根据实际的内存使用情况进行空间预留/申请。</li></ul>
</div>
