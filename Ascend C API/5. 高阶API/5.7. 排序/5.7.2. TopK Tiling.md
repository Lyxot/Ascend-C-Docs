   <div class="section" id="ZH-CN_TOPIC_0000002370172705__section10757913172313">
    <h4 class="sectiontitle">功能说明</h4>
    <p id="ZH-CN_TOPIC_0000002370172705__p119423018911">用于获取Topk Tiling参数。</p>
    <p id="ZH-CN_TOPIC_0000002370172705__p8060118"><span id="ZH-CN_TOPIC_0000002370172705__ph78101811113916">Ascend C</span>提供Topk Tiling API，方便用户获取Topk kernel计算时所需的Tiling参数。阅读本节之前，请先参考<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0064.html">Tiling实现</a>了解Tiling实现基本流程。</p>
    <p id="ZH-CN_TOPIC_0000002370172705__p55788219376">获取Tiling参数主要分为如下两步：</p>
    <ol id="ZH-CN_TOPIC_0000002370172705__ol13393192514376">
     <li id="ZH-CN_TOPIC_0000002370172705__li61302029103711">获取Topk接口计算所需最小和最大临时空间大小，注意该步骤不是必须的，只是作为一个参考，供合理分配计算空间。</li>
     <li id="ZH-CN_TOPIC_0000002370172705__li1539317253378">获取Topk kernel侧接口所需tiling参数。
      <div class="p" id="ZH-CN_TOPIC_0000002370172705__p139212010583">
       <a name="ZH-CN_TOPIC_0000002370172705__li1539317253378"></a><a name="li1539317253378"></a>Topk Tiling结构体的定义如下，开发者无需关注该tiling结构的具体信息，只需要传递到kernel侧，传入Topk高阶API接口，直接进行使用即可。
