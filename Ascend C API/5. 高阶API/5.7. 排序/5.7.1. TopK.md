    <h4 class="sectiontitle">功能说明</h4>
    <p id="ZH-CN_TOPIC_0000002336174002__p1617163732919">获取最后一个维度的前k个最大值或最小值及其对应的索引。</p>
    <p id="ZH-CN_TOPIC_0000002336174002__p4174766342">如果输入是向量，则在向量中找到前k个最大值或最小值及其对应的索引；如果输入是矩阵，则沿最后一个维度计算每行中前k个最大值或最小值及其对应的索引。<strong id="ZH-CN_TOPIC_0000002336174002__b161906673614">本接口最多支持输入为二维数据，不支持更高维度的输入。</strong></p>
    <p id="ZH-CN_TOPIC_0000002336174002__p842119263012">如下图所示，对shape为(4, 32)的二维矩阵进行排序，k设置为1，输出结果为[[32] [32] [32] [32]]。</p>
    <p id="ZH-CN_TOPIC_0000002336174002__p348911242263"><span><img class="eddx" id="ZH-CN_TOPIC_0000002336174002__image10172165862212" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002336335282.png"></span></p>
    <ul id="ZH-CN_TOPIC_0000002336174002__ul298991931914">
     <li id="ZH-CN_TOPIC_0000002336174002__li199897198199"><strong id="ZH-CN_TOPIC_0000002336174002__b13825152184511">必备概念</strong>
      <p id="ZH-CN_TOPIC_0000002336174002__p13761195310279">基于如上样例，我们引入一些必备概念：行数称之为<strong id="ZH-CN_TOPIC_0000002336174002__b147364149532">外轴长度（outter）</strong>，每行实际的元素个数称之为<strong id="ZH-CN_TOPIC_0000002336174002__b17525178185420">内轴的实际长度（n）</strong>。本接口要求输入的内轴长度为32的整数倍，所以当n不是32的整数倍时，需要开发者将其向上补齐到32的整数倍，补齐后的长度称之为<strong id="ZH-CN_TOPIC_0000002336174002__b114817180545">内轴长度（inner）</strong>。比如，如下的样例中，每行的实际长度n为31，不是32的整数倍，向上补齐后得到inner为32，图中的padding代表补齐操作。n和inner的关系如下：当n是32的整数倍时，inner=n；否则，inner &gt; n。</p>
      <p id="ZH-CN_TOPIC_0000002336174002__p17372104114559"><span><img class="eddx" id="ZH-CN_TOPIC_0000002336174002__image108574725517" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002336335294.png"></span></p></li>
     <li id="ZH-CN_TOPIC_0000002336174002__li3450143611192"><strong id="ZH-CN_TOPIC_0000002336174002__b69813482453">接口模式</strong>
      <p id="ZH-CN_TOPIC_0000002336174002__p122213101556">本接口支持两种模式：<strong id="ZH-CN_TOPIC_0000002336174002__b415919511517">Normal模式</strong>和<strong id="ZH-CN_TOPIC_0000002336174002__b18689125319512">Small模式</strong>。Normal模式是通用模式；Small模式是为内轴长度固定为32（单位：元素个数）的场景提供的高性能模式。因为Small模式inner固定为32，可以进行更有针对性的处理，所以相关的约束较少，性能较高。内轴长度inner为32时建议使用Small模式。</p></li>
     <li id="ZH-CN_TOPIC_0000002336174002__li17979132204518"><strong id="ZH-CN_TOPIC_0000002336174002__b197138620443">附加功能</strong>：本接口支持开发者指定某些行的排序是无效排序。通过传入finishLocal参数值来控制，finishLocal对应行的值为true时，表示该行排序无效，此时排序后输出的dstIndexLocal的k个索引值会全部被置为无效索引n。
      <p id="ZH-CN_TOPIC_0000002336174002__p137965451759"><span><img class="imgResize" id="ZH-CN_TOPIC_0000002336174002__image1758622710472" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002336335286.png" title="点击放大"></span></p></li>
    </ul>

        <p id="ZH-CN_TOPIC_0000002336174002__p1598714134237"><a name="ZH-CN_TOPIC_0000002336174002__li231511182179"></a><a name="li231511182179"></a><span id="ZH-CN_TOPIC_0000002336174002__ph1074811618230"><term id="ZH-CN_TOPIC_0000002336174002__zh-cn_topic_0000002336176798_term1253731311225_2">

         <li id="ZH-CN_TOPIC_0000002336174002__li12916164014211">方式一：
          <p id="ZH-CN_TOPIC_0000002336174002__p86561047525"><a name="ZH-CN_TOPIC_0000002336174002__li12916164014211"></a><a name="li12916164014211"></a>使用高阶API Sort对数据完成全排序。</p></li>

          <ol type="a" id="ZH-CN_TOPIC_0000002336174002__ol1318811421918">
           <li id="ZH-CN_TOPIC_0000002336174002__li11188742919">使用Sort32对数据排序，保证每32个数据是有序的。</li>

        </ul></li>

    </ul>

        <p id="ZH-CN_TOPIC_0000002336174002__p1137274213311"><a name="ZH-CN_TOPIC_0000002336174002__li15372142163311"></a><a name="li15372142163311"></a><span id="ZH-CN_TOPIC_0000002336174002__ph1137234218337"><term id="ZH-CN_TOPIC_0000002336174002__zh-cn_topic_0000002336176798_term1253731311225_3">

         <li id="ZH-CN_TOPIC_0000002336174002__li18372104220331">方式二：使用ArithProgression生成0到inner - 1的索引。</li>

       <li id="ZH-CN_TOPIC_0000002336174002__li1559233913610">使用GatherMask指令提取前k个数据和索引；</li>
       <li id="ZH-CN_TOPIC_0000002336174002__li35921939968">isLargest参数为false，则给输入数据乘以-1还原数据。</li>
