<div class="section" id="ZH-CN_TOPIC_0000002370251557__section618mcpsimp"><h4 class="sectiontitle">功能说明</h4><p id="ZH-CN_TOPIC_0000002370251557__p18977181620346">排序函数，按照数值大小进行降序排序。排序后的数据按照如下排布方式进行保存：</p>
<p id="ZH-CN_TOPIC_0000002370251557__p161633959"><span id="ZH-CN_TOPIC_0000002370251557__ph15110183813153"><term id="ZH-CN_TOPIC_0000002370251557__zh-cn_topic_0000002336176798_term1253731311225_1">Atlas A3 训练系列产品/Atlas A3 推理系列产品</term></span>采用方式一</p>
<p id="ZH-CN_TOPIC_0000002370251557__p5731163812618"><span id="ZH-CN_TOPIC_0000002370251557__ph2785164692810"><term id="ZH-CN_TOPIC_0000002370251557__zh-cn_topic_0000002336176798_term11962195213215_1">Atlas A2 训练系列产品/Atlas 800I A2 推理产品/A200I A2 Box 异构组件</term></span>采用方式一</p>
<p id="ZH-CN_TOPIC_0000002370251557__p189505301837"><span id="ZH-CN_TOPIC_0000002370251557__ph8513182481511"><term id="ZH-CN_TOPIC_0000002370251557__zh-cn_topic_0000002336176798_term1964153212227_1">Atlas 推理系列产品</term>AI Core</span>采用方式二</p>
<ul id="ZH-CN_TOPIC_0000002370251557__ul1837710144396"><li id="ZH-CN_TOPIC_0000002370251557__li14976173313170">排布方式一：<div class="p" id="ZH-CN_TOPIC_0000002370251557__p11318435151719"><a name="ZH-CN_TOPIC_0000002370251557__li14976173313170"></a><a name="li14976173313170"></a>一次迭代可以完成32个数的排序，排序好的score与其对应的index一起以（score, index）的结构存储在dstLocal中。不论score为half还是float类型，dstLocal中的（score, index）结构总是占据8Bytes空间。如下所示：<ul id="ZH-CN_TOPIC_0000002370251557__ul13377121417391"><li id="ZH-CN_TOPIC_0000002370251557__li33771145393">当score为float，index为uint32类型时，计算结果中index存储在高4Bytes，score存储在低4Bytes。<p id="ZH-CN_TOPIC_0000002370251557__p43774149399"><a name="ZH-CN_TOPIC_0000002370251557__li33771145393"></a><a name="li33771145393"></a><span><img id="ZH-CN_TOPIC_0000002370251557__image53773149392" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002370173389.png"></span></p>
</li><li id="ZH-CN_TOPIC_0000002370251557__li153771114143917">当score为half，index为uint32类型时，计算结果中index存储在高4Bytes，score存储在低2Bytes， 中间的2Bytes保留。<p id="ZH-CN_TOPIC_0000002370251557__p437771414394"><a name="ZH-CN_TOPIC_0000002370251557__li153771114143917"></a><a name="li153771114143917"></a><span><img id="ZH-CN_TOPIC_0000002370251557__image10377314163911" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/figure/zh-cn_image_0000002370253245.png"></span></p>
</li></ul>
</div>
</li></ul>
<ul id="ZH-CN_TOPIC_0000002370251557__ul8365729191016"><li id="ZH-CN_TOPIC_0000002370251557__li615510991818">排布方式二：Region Proposal排布<div class="p" id="ZH-CN_TOPIC_0000002370251557__p0768191816194"><a name="ZH-CN_TOPIC_0000002370251557__li615510991818"></a><a name="li615510991818"></a>输入输出数据均为Region Proposal，一次迭代可以完成16个region proposal的排序。每个Region Proposal占用连续8个half/float类型的元素，约定其格式：<div class="codecoloring" codetype="Cpp" id="ZH-CN_TOPIC_0000002370251557__screen164011814162216"><div class="highlight"><table class="highlighttable"><tr><td class="linenos"><div class="linenodiv"><pre><span class="normal">1</span></pre></div></td><td class="code"><div><pre><span></span><span class="p">[</span><span class="n">x1</span><span class="p">,</span><span class="w"> </span><span class="n">y1</span><span class="p">,</span><span class="w"> </span><span class="n">x2</span><span class="p">,</span><span class="w"> </span><span class="n">y2</span><span class="p">,</span><span class="w"> </span><span class="n">score</span><span class="p">,</span><span class="w"> </span><span class="n">label</span><span class="p">,</span><span class="w"> </span><span class="n">reserved_0</span><span class="p">,</span><span class="w"> </span><span class="n">reserved_1</span><span class="p">]</span>

<p id="ZH-CN_TOPIC_0000002370251557__p1739222113177">对于数据类型half，每一个Region Proposal占16Bytes，Byte[15:12]是无效数据，Byte[11:0]包含6个half类型的元素，其中Byte[11:10]定义为label，Byte[9:8]定义为score，Byte[7:6]定义为y2，Byte[5:4]定义为x2，Byte[3:2]定义为y1，Byte[1:0]定义为x1。</p>

<p id="ZH-CN_TOPIC_0000002370251557__p9273112710318">对于数据类型float，每一个Region Proposal占32Bytes，Byte[31:24]是无效数据，Byte[23:0]包含6个float类型的元素，其中Byte[23:20]定义为label，Byte[19:16]定义为score，Byte[15:12]定义为y2，Byte[11:8]定义为x2，Byte[7:4]定义为y1，Byte[3:0]定义为x1。</p>
