   <div class="section" id="ZH-CN_TOPIC_0000002336173136__section618mcpsimp">
    <h4 class="sectiontitle">功能说明</h4>
    <p id="ZH-CN_TOPIC_0000002336173136__p5292165919221">集合通信BatchWrite的任务下发接口，返回该任务的标识handleId给用户。</p>
    <p id="ZH-CN_TOPIC_0000002336173136__p174526538263">BatchWrite实现了一种不同昇腾AI Server（通常是8卡或16卡的昇腾NPU设备组成的服务器形态的统称）间批量的点对点通信，即多卡环境下，不同AI Server间的卡直接传输数据的通信模式。本接口支持将本卡的多份数据同时发送到不同AI Server的多张卡上。</p>
   </div>

    <h4 class="sectiontitle">约束说明</h4>
    <ul id="ZH-CN_TOPIC_0000002336173136__ul230123110167">
     <li id="ZH-CN_TOPIC_0000002336173136__li15577411505">调用本接口前确保已调用过<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0871.html">Init</a>和<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_10047.html">SetCcTiling</a>接口。</li>
     <li id="ZH-CN_TOPIC_0000002336173136__li248815231179">若Hccl对象的<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0870.html#ZH-CN_TOPIC_0000002370251565__table884518212555">config模板参数</a>未指定下发通信任务的核，该接口只能在AI Cube核或者AI Vector核两者之一上调用。若Hccl对象的<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0870.html#ZH-CN_TOPIC_0000002370251565__table884518212555">config模板参数</a>中指定了下发通信任务的核，则该接口可以在AI Cube核和AI Vector核上同时调用，接口内部会根据指定的核的类型，只在AI Cube核、AI Vector核二者之一下发该通信任务。</li>
     <li id="ZH-CN_TOPIC_0000002336173136__li10695172134312">一个通信域内，所有Prepare接口和InterHcclGroupSync接口的总调用次数不能超过63。</li>
     <li id="ZH-CN_TOPIC_0000002336173136__li133451649105517">当前接口仅支持不同AI Server间的通信，同时通信任务信息中指定的目的卡号不能是本卡号。</li>
     <li id="ZH-CN_TOPIC_0000002336173136__li208250421157">通信任务信息写入batchWriteInfo时，必须通过调用<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0177.html">DataCacheCleanAndInvalid</a>接口，保证预期的数据成功刷新到Global Memory上。</li>
    </ul>
