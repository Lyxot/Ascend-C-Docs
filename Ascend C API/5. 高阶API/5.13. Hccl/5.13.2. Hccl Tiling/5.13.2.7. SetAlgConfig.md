            Atlas A3 训练系列产品/Atlas A3 推理系列产品
           </term></span>，当前支持的取值为：</p>
         <ul id="ZH-CN_TOPIC_0000002336333224__ul13413418111314">
          <li id="ZH-CN_TOPIC_0000002336333224__li71731516228">"AllReduce=level0:doublering"：AllReduce通信任务。</li>

          <li id="ZH-CN_TOPIC_0000002336333224__li8413181871312">"ReduceScatter=level0:doublering"：ReduceScatter通信任务。</li>
          <li id="ZH-CN_TOPIC_0000002336333224__li641311816132">"AlltoAll=level0:fullmesh;level1:pairwise"：AlltoAllV和AlltoAll通信任务。</li>
          <li id="ZH-CN_TOPIC_0000002336333224__li125779299363">"BatchWrite=level0:fullmesh"：BatchWrite通信任务。</li>
