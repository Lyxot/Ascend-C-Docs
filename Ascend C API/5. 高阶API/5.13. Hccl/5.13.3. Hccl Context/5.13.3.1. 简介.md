<h1 class="topictitle1">简介</h1>
<div id="body0000001962613929"><p id="ZH-CN_TOPIC_0000002336332848__zh-cn_topic_0000001339105488_p4805102810120">本章节的接口用于在kernel侧设置/获取通算融合算子每个通信域对应的context（消息区）地址。需要同步在host侧调用<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_1002.html">HcclGroup</a>接口配置通信域名称后，才可以调用<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_1219.html">GetHcclContext</a>获取对应的context地址。</p>
