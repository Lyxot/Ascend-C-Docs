  <h1 class="topictitle1">Ascend C API列表</h1>
  <div id="body0000001917094304">
   <p id="ZH-CN_TOPIC_0000002370252257__zh-cn_topic_0000001762058545_zh-cn_topic_0000001589265601_p131911195110"><span id="ZH-CN_TOPIC_0000002370252257__zh-cn_topic_0000001762058545_zh-cn_topic_0000001589265601_ph10546143515149">Ascend C</span>提供一组类库API，开发者使用标准C++语法和类库API进行编程。<span id="ZH-CN_TOPIC_0000002370252257__zh-cn_topic_0000001762058545_ph19399631793">Ascend C</span>编程类库API示意图如下所示，分为：</p>
   <ul id="ZH-CN_TOPIC_0000002370252257__ul16640154315913">
    <li id="ZH-CN_TOPIC_0000002370252257__li1064034320914">Kernel API：用于实现算子核函数的API接口。包括：
     <ul id="ZH-CN_TOPIC_0000002370252257__ul178033061311">
      <li id="ZH-CN_TOPIC_0000002370252257__li16122723171312"><strong id="ZH-CN_TOPIC_0000002370252257__b153981819101112">基本数据结构：</strong>kernel API中使用到的基本数据结构，比如GlobalTensor和LocalTensor。</li>
      <li id="ZH-CN_TOPIC_0000002370252257__li58329249132"><strong id="ZH-CN_TOPIC_0000002370252257__zh-cn_topic_0000001762058545_b10837185661418">基础API：</strong>实现对硬件能力的抽象，开放芯片的能力，保证完备性和兼容性。标注为ISASI（Instruction Set Architecture Special Interface，硬件体系结构相关的接口）类别的API，不能保证跨硬件版本兼容。</li>
      <li id="ZH-CN_TOPIC_0000002370252257__li7347152641316"><strong id="ZH-CN_TOPIC_0000002370252257__zh-cn_topic_0000001762058545_b1283765651415">高阶API：</strong>实现一些常用的计算算法，用于提高编程开发效率，通常会调用多种基础API实现。高阶API包括数学库、Matmul、Softmax等API。高阶API可以保证兼容性。</li>
     </ul></li>
    <li id="ZH-CN_TOPIC_0000002370252257__li165020508920"><strong id="ZH-CN_TOPIC_0000002370252257__b1524102383717">Host API</strong>：
     <ul id="ZH-CN_TOPIC_0000002370252257__ul1183494919138">
      <li id="ZH-CN_TOPIC_0000002370252257__li358934181319">高阶API配套的Tiling API：kernel侧高阶API配套的Tiling API，方便开发者获取kernel计算时所需的Tiling参数。</li>
      <li id="ZH-CN_TOPIC_0000002370252257__li1411735211134">Ascend C算子原型注册与管理API：用于Ascend C算子原型定义和注册的API。</li>
      <li id="ZH-CN_TOPIC_0000002370252257__li1645219259148">Tiling数据结构注册API：用于Ascend C算子TilingData数据结构定义和注册的API。</li>
      <li id="ZH-CN_TOPIC_0000002370252257__li3336203420145">平台信息获取API：在实现Host侧的Tiling函数时，可能需要获取一些硬件平台的信息，来支撑Tiling的计算，比如获取硬件平台的核数等信息。平台信息获取API提供获取这些平台信息的功能。</li>
     </ul></li>
    <li id="ZH-CN_TOPIC_0000002370252257__li158996471106"><strong id="ZH-CN_TOPIC_0000002370252257__b1885324377">算子调测API</strong>：用于算子调测的API，包括孪生调试，性能调测等。</li>
   </ul>
   <p id="ZH-CN_TOPIC_0000002370252257__p9392132621120">进行Ascend C算子Host侧编程时，需要使用基础数据结构和API，请参考<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/basicdataapi/atlasopapi_07_00002.html">基础数据结构与接口</a>；完成算子开发后，需要使用Runtime API完成算子的调用，请参考<span id="ZH-CN_TOPIC_0000002370252257__ph319591120438"><a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/appdevgapi/aclcppdevg_03_0020.html">“AscendCL API（C&amp;C++）”</a></span>。</p>
