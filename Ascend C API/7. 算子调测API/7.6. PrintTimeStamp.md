    <h4 class="sectiontitle">功能说明</h4>
    <p id="ZH-CN_TOPIC_0000002370251517__p55701620163216">提供时间戳打点功能，用于在算子Kernel代码中标记关键执行点，调用后会打印如下信息：</p>
    <ul id="ZH-CN_TOPIC_0000002370251517__ul77042342011">
     <li id="ZH-CN_TOPIC_0000002370251517__li19704334114">descId： 用户自定义标识符，用于区分不同打点位置；</li>
     <li id="ZH-CN_TOPIC_0000002370251517__li15428648251">rsv ：保留值，默认为0，无需关注；</li>
     <li id="ZH-CN_TOPIC_0000002370251517__li169861210267">timeStamp ： 当前系统cycle数，用于计算时间差，时间换算规则可参考<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0282.html">GetSystemCycle(ISASI)</a>；</li>
     <li id="ZH-CN_TOPIC_0000002370251517__li3567174911618">pcPtr：pc指针数值，若无特殊需求，用户无需关注。</li>
    </ul>
    <p id="ZH-CN_TOPIC_0000002370251517__p144607161136">打印示例如下：</p>

      <div class="cautionbody">
       <p id="ZH-CN_TOPIC_0000002370251517__p13676311428">该功能主要用于<strong id="ZH-CN_TOPIC_0000002370251517__b8141182624218">调试和性能分析</strong>，开启后会对算子性能产生一定影响，<strong id="ZH-CN_TOPIC_0000002370251517__b1614118269421">生产环境建议关闭</strong>。</p>
       <div class="p" id="ZH-CN_TOPIC_0000002370251517__p18942162119133">
        默认情况下，该功能关闭，开发者可以按需通过如下方式开启打点功能。

    <h4 class="sectiontitle">约束说明</h4>
    <ul id="ZH-CN_TOPIC_0000002370251517__ul10616832887">
     <li id="ZH-CN_TOPIC_0000002370251517__li477303424019"><strong id="ZH-CN_TOPIC_0000002370251517__b51631595268">该功能仅用于NPU上板调试，且仅在如下场景支持</strong><strong id="ZH-CN_TOPIC_0000002370251517__b31634992612">：</strong>
      <ul id="ZH-CN_TOPIC_0000002370251517__ul785019469549">
       <li id="ZH-CN_TOPIC_0000002370251517__li1976744075412">通过<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0056.html">Kernel直调</a>方式调用算子。</li>
       <li id="ZH-CN_TOPIC_0000002370251517__li1580284044015">通过<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0070.html">单算子API调用</a>方式调用算子。</li>
       <li id="ZH-CN_TOPIC_0000002370251517__li17171141595413">间接调用单算子API(aclnnxxx)接口：Pytorch框架单算子直调的场景。</li>
      </ul></li>
     <li id="ZH-CN_TOPIC_0000002370251517__li1985341134317">该接口使用Dump功能，所有使用Dump功能的接口在每个核上Dump的数据总量不可超过1M。请开发者自行控制待打印的内容数据量，超出则不会打印。</li>
    </ul>
