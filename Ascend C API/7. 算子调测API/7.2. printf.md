    <h4 class="sectiontitle">功能说明</h4>

   <div class="caution" id="ZH-CN_TOPIC_0000002370172577__note8593154012113">
    <span class="cautiontitle"><img src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/public_sys-resources/caution_3.0-zh-cn.png"> </span>
    <div class="cautionbody">
     <div class="p" id="ZH-CN_TOPIC_0000002370172577__p18942162119133">
      printf（PRINTF）接口打印功能会对算子实际运行的性能带来一定影响，通常在调测阶段使用。开发者可以按需通过如下方式关闭打印功能。
      <ul id="ZH-CN_TOPIC_0000002370172577__ul16828741191113">
       <li id="ZH-CN_TOPIC_0000002370172577__li1082864111110">自定义算子工程
        <div class="p" id="ZH-CN_TOPIC_0000002370172577__p17828241141118">
         <a name="ZH-CN_TOPIC_0000002370172577__li1082864111110"></a><a name="li1082864111110"></a>修改算子工程op_kernel目录下的CMakeLists.txt文件，首行增加编译选项-DASCENDC_DUMP=0，关闭ASCENDC_DUMP开关，示例如下：
         <div class="codecoloring" codetype="Cpp" id="ZH-CN_TOPIC_0000002370172577__screen18828144171117">
          <div class="highlight">
           <table class="highlighttable">
            <tbody>
             <tr>
              <td class="linenos">
               <div class="linenodiv">
                <pre><span class="normal">1</span>
<span class="normal">2</span></pre>
               </div></td>
              <td class="code">
               <div>
                <pre><span></span><span class="c1">// 关闭所有算子的printf打印功能</span>
<span class="n">add_ops_compile_options</span><span class="p">(</span><span class="n">ALL</span><span class="w"> </span><span class="n">OPTIONS</span><span class="w"> </span><span class="o">-</span><span class="n">DASCENDC_DUMP</span><span class="o">=</span><span class="mi">0</span><span class="p">)</span>
</pre>
               </div></td>
             </tr>
            </tbody>
           </table>
          </div>
         </div>
        </div></li>
       <li id="ZH-CN_TOPIC_0000002370172577__li14828104112119">Kernel直调工程
        <ul id="ZH-CN_TOPIC_0000002370172577__ul139812004213">
         <li id="ZH-CN_TOPIC_0000002370172577__li8410205718417">修改cmake目录下的npu_lib.cmake文件，在ascendc_compile_definitions命令中增加-DASCENDC_DUMP=0宏定义来关闭NPU侧ASCENDC_DUMP开关。示例如下：
          <div class="codecoloring" codetype="Cpp" id="ZH-CN_TOPIC_0000002370172577__screen582834121112">

                </div></td>

                 <pre><span></span><span class="c1">// 关闭所有算子的printf打印功能</span>

<span class="w">    </span><span class="o">-</span><span class="n">DASCENDC_DUMP</span><span class="o">=</span><span class="mi">0</span>

   <p id="ZH-CN_TOPIC_0000002370172577__p472311281812">根据算子执行方式的不同，printf的打印结果输出方式不同。动态图或者单算子直调场景下，待输出内容会被解析并打印在屏幕上；静态图场景下，整图算子需要全下沉到NPU侧执行，无法直接调用接口打印出单个算子的信息，因此需要在模型执行完毕后，将待输出内容落盘在dump文件中，dump文件需要通过工具解析为可读内容。</p>
   <ul id="ZH-CN_TOPIC_0000002370172577__ul77271616277">
    <li id="ZH-CN_TOPIC_0000002370172577__li1887430134012">dump文件落盘路径按照优先级排列如下:
     <ul id="ZH-CN_TOPIC_0000002370172577__ul1876319447405">
      <li id="ZH-CN_TOPIC_0000002370172577__li1088425891915">如果开启了Data Dump功能，dump文件落盘到开发者配置的dump_path路径下。如何开启Dump功能依赖于具体的网络运行方式。以TensorFlow在线推理为例，通过enable_dump、dump_path、dump_mode等参数进行配置。配置方式可参考<span id="ZH-CN_TOPIC_0000002370172577__ph14666211142012">《<a href="https://www.hiascend.com/document/detail/zh/TensorFlowCommercial/82RC1/migration/tfmigr2/tfmigr2_000001.html" target="_blank" rel="noopener noreferrer">TensorFlow 2.6.5模型迁移指南</a>》</span>中的API参考 &gt; TF Adapter 接口（2.x）&gt; npu.global_options &gt; 配置参数说明章节。</li>
      <li id="ZH-CN_TOPIC_0000002370172577__li7396114418244">如果未开启Data Dump功能，但配置了ASCEND_WORK_PATH环境变量，dump文件落盘到ASCEND_WORK_PATH下的printf目录下。ASCEND_WORK_PATH环境变量的配置方式可参考<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/maintenref/envvar/envref_07_0007.html">ASCEND_WORK_PATH</a>。</li>
      <li id="ZH-CN_TOPIC_0000002370172577__li1281431123617">如果未开启Data Dump功能也没有配置ASCEND_WORK_PATH环境变量，dump文件落盘到当前程序执行目录下的printf路径下。</li>
     </ul></li>

        <td class="cellrowborder" valign="top" width="71.58%" headers="mcps1.3.8.2.1.4.1.3 ">
         <p id="ZH-CN_TOPIC_0000002370172577__p1965816506312">格式控制字符串，包含两种类型的对象：普通字符和转换说明。</p>
         <ul id="ZH-CN_TOPIC_0000002370172577__ul419411543310">
          <li id="ZH-CN_TOPIC_0000002370172577__li21151156123111">普通字符将原样不动地打印输出。</li>
          <li id="ZH-CN_TOPIC_0000002370172577__li3361141412121">转换说明并不直接输出而是用于控制printf中参数的转换和打印。每个转换说明都由一个百分号字符（%）开始，以转换说明结束，从而说明输出数据的类型 。
           <div class="p" id="ZH-CN_TOPIC_0000002370172577__p158820115597">
            <a name="ZH-CN_TOPIC_0000002370172577__li3361141412121"></a><a name="li3361141412121"></a>支持的转换类型包括：
            <ul id="ZH-CN_TOPIC_0000002370172577__ul541124915329">
             <li id="ZH-CN_TOPIC_0000002370172577__li1566632623213">%d / %i：输出十进制数，支持打印的数据类型：bool/int8_t/int16_t/int32_t/int64_t</li>
             <li id="ZH-CN_TOPIC_0000002370172577__li1715292814325">%f：输出实数，支持打印的数据类型：float/half/bfloat16_t</li>
             <li id="ZH-CN_TOPIC_0000002370172577__li2077882943219">%x：输出十六进制整数，支持打印的数据类型：int8_t/int16_t/int32_t/int64_t/uint8_t/uint16_t/uint32_t/uint64_t</li>
             <li id="ZH-CN_TOPIC_0000002370172577__li13232203119322">%s：输出字符串</li>
             <li id="ZH-CN_TOPIC_0000002370172577__li3827153215323">%u：输出unsigned类型数据，支持打印的数据类型：bool/uint8_t/uint16_t/uint32_t/uint64_t</li>
             <li id="ZH-CN_TOPIC_0000002370172577__li1817342415324">%p：输出指针地址</li>
            </ul>
           </div>
           <p id="ZH-CN_TOPIC_0000002370172577__p1133101265017"><strong id="ZH-CN_TOPIC_0000002370172577__b164621818125011">注意</strong>：上文列出的数据类型是NPU域调试支持的数据类型，CPU域调试时，支持的数据类型和C/C++规范保持一致。</p></li>
         </ul></td>
       </tr>

        <td class="cellrowborder" valign="top" width="11.93%" headers="mcps1.3.8.2.1.4.1.2 ">
         <p id="ZH-CN_TOPIC_0000002370172577__p59396564285">输入</p></td>
        <td class="cellrowborder" valign="top" width="71.58%" headers="mcps1.3.8.2.1.4.1.3 ">
         <p id="ZH-CN_TOPIC_0000002370172577__p1257115311337">附加参数，个数和类型可变的参数列表：根据不同的fmt字符串，函数可能需要一系列的附加参数，每个参数包含了一个要被插入的值，替换了fmt参数中指定的每个%标签。参数的个数应与%标签的个数相同。</p></td>

   <div class="section" id="ZH-CN_TOPIC_0000002370172577__section43265506459">
    <h4 class="sectiontitle">约束说明</h4>
    <ul id="ZH-CN_TOPIC_0000002370172577__ul118412044152514">
     <li id="ZH-CN_TOPIC_0000002370172577__li184589234416">本接口不支持打印除换行符之外的其他转义字符。</li>
     <li id="ZH-CN_TOPIC_0000002370172577__li4382173204411">如果开发者需要包含标准库头文件stdio.h和cstdio，请在kernel_operator.h头文件之前包含，避免printf符号冲突。</li>
     <li id="ZH-CN_TOPIC_0000002370172577__li95631150191912">该接口使用Dump功能，所有使用Dump功能的接口在每个核上Dump的数据总量不可超过1M。请开发者自行控制待打印的内容数据量，超出则不会打印。</li>
    </ul>
