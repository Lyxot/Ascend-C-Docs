<h1 class="topictitle1">算子与高阶API共享临时Buffer</h1>
<div id="body206mcpsimp"><p id="ZH-CN_TOPIC_0000002336158464__p183571644812">【优先级】高</p>
<p id="ZH-CN_TOPIC_0000002336158464__p1348183174818">【描述】如果算子使用的高阶API需要传入临时Buffer，如SoftMax，该临时空间会挤占算子其他计算的空间，从而导致单次计算搬运的数据量变少，搬运的次数变多。此场景可通过共享临时Buffer空间，提升单次搬运的数据量，减少搬运的次数，提升内存使用效率。</p>
<p id="ZH-CN_TOPIC_0000002336158464__p207mcpsimp">【反例】</p>
<div class="p" id="ZH-CN_TOPIC_0000002336158464__p18194932121417">SoftMax高阶API计算需要临时Buffer空间，算子在进行其他计算时拥有独立临时Buffer。UB空间是固定的，假设可以给SoftMax和Add能分配临时空间为64KB，SoftMax计算需要的临时Buffer空间tmpSoftmaxBuffer占用32KB，则存储Add计算结果的LocalTensor tmpSumBuffer最多只能分配32KB。如果src0Tensor计算的数据量是512KB，则需要搬运512 / 32 = <strong id="ZH-CN_TOPIC_0000002336158464__b18123236171417">16</strong>次。<pre class="screen" id="ZH-CN_TOPIC_0000002336158464__screen422115618149">...
constexpr int32_t blockLen = 32 * 1024;
TBuf&lt;TPosition::VECCALC&gt; tmpSoftmaxBuf; 
pipe.InitBuffer(tmpSoftmaxBuf, softmaxBufSize * sizeof(uint8_t));  // 单独分配Softmax的临时Buf 32KB
TBuf&lt;TPosition::VECCALC&gt; tmpSumBuf;
pipe.InitBuffer(tmpSumBuf, sumBufSize * sizeof(T)); // 单独分配Add的临时Buf，且softmaxBufSize * sizeof(uint8_t) + sumBufSize * sizeof(T) &lt;= 64KB
...
for (int i = 0, i &lt; 16; i++) {
    ...
    LocalTensor&lt;uint8_t&gt; tmpSoftmaxTensor = tmpSoftmaxBuf.Get&lt;uint8_t&gt;(softmaxBufSize);
    SoftMax&lt;T, true, true&gt;(dstTensor, expSumTensor, dstMaxTensor, srcTensor, tmpSoftmaxTensor, tiling);
    ...
    DataCopy(src0Tensor, src0Gm[i * blockLen / sizeof(T)], Params);
    ...
    LocalTensor&lt;T&gt; tmpSumTensor = tmpSumBuf.Get&lt;T&gt;(sumBufSize);
    Add&lt;T&gt;(tmpSumTensor, src0Tensor, src1Tensor, count);
    ...
}
...</pre>
</div>
<p id="ZH-CN_TOPIC_0000002336158464__p227mcpsimp">【正例】</p>
<p id="ZH-CN_TOPIC_0000002336158464__p119089114296">SoftMax高阶API计算需要临时Buffer空间，算子在进行其他计算时可以共享此临时Buffer，按照上述假设只需要搬运512 / 64 = <strong id="ZH-CN_TOPIC_0000002336158464__b8821513133115">8</strong>次。</p>
<pre class="screen" id="ZH-CN_TOPIC_0000002336158464__screen1974820122919">...
constexpr int32_t blockLen = 64 * 1024;
TBuf&lt;TPosition::VECCALC&gt; tmpSharedBuf;
pipe.InitBuffer(tmpSharedBuf, bufferSize); // 共享分配bufferSize = MAX(softmaxBufSize * sizeof(uint8_t), sumBufSize * sizeof(T)) &lt;= 64KB
...
for (int i = 0, i &lt; 8; i++) {
    ...
    LocalTensor&lt;uint8_t&gt; tmpSharedTensor = tmpSharedBuf.Get&lt;uint8_t&gt;(softmaxBufSize);
    SoftMax&lt;T, true, true&gt;(dstTensor, expSumTensor, dstMaxTensor, srcTensor, tmpSharedTensor, tiling);
    ...
    DataCopy(src0Tensor, src0Gm[i * blockLen / sizeof(T)], Params);
    ...
    LocalTensor&lt;T&gt; tmpSumTensor = tmpSharedBuf.Get&lt;T&gt;(sumBufSize);
    Add&lt;T&gt;(tmpSumTensor, src0Tensor, src1Tensor, count);
    ...
}
...</pre>
