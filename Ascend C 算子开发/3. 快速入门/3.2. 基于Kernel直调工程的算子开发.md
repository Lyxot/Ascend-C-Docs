     <li id="ZH-CN_TOPIC_0000002336336634__zh-cn_topic_0000001552186366_li9665184310426">CANN软件安装

     <li id="ZH-CN_TOPIC_0000002336336634__zh-cn_topic_0000001552186366_li955351595818">环境变量配置
      <p id="ZH-CN_TOPIC_0000002336336634__zh-cn_topic_0000001552186366_p1217520164583"><a name="ZH-CN_TOPIC_0000002336336634__zh-cn_topic_0000001552186366_li955351595818"></a><a name="zh-cn_topic_0000001552186366_li955351595818"></a><span id="ZH-CN_TOPIC_0000002336336634__ph864083114387">安装CANN软件后，使用CANN运行用户进行编译、运行时，需要以CANN运行用户登录环境，执行<span id="ZH-CN_TOPIC_0000002336336634__zh-cn_topic_0000002400092065_ph181328298353"><strong id="ZH-CN_TOPIC_0000002336336634__zh-cn_topic_0000002400092065_b5132142919357">source ${install_path}/set_env.sh</strong></span>命令设置环境变量。其中${install_path}为CANN软件的安装目录，例如：/usr/local/Ascend/ascend-toolkit。</span></p></li>

   <div class="section" id="ZH-CN_TOPIC_0000002336336634__zh-cn_topic_0000001552186366_section1242991675619">
    <h4 class="sectiontitle">算子分析</h4>
    <p id="ZH-CN_TOPIC_0000002336336634__zh-cn_topic_0000001552186366_p11243161473112">主要分析算子的数学表达式、输入输出的数量、Shape范围以及计算逻辑的实现，明确需要调用的<span id="ZH-CN_TOPIC_0000002336336634__zh-cn_topic_0000001552186366_ph975583562710">Ascend C</span>接口。下文以Add算子为例，介绍具体的分析过程。</p>
    <ol id="ZH-CN_TOPIC_0000002336336634__zh-cn_topic_0000001552186366_ol2056893115211">
     <li id="ZH-CN_TOPIC_0000002336336634__zh-cn_topic_0000001552186366_zh-cn_topic_0229825559_zh-cn_topic_0229823837_zh-cn_topic_0211294710_zh-cn_topic_0206739556_li56141550526"><span>明确算子的数学表达式及计算逻辑。</span>
      <p></p>
      <p id="ZH-CN_TOPIC_0000002336336634__zh-cn_topic_0000001552186366_zh-cn_topic_0229825559_zh-cn_topic_0229823837_zh-cn_topic_0211294710_zh-cn_topic_0206739556_p039812624519">Add算子的数学表达式为：</p>
      <p id="ZH-CN_TOPIC_0000002336336634__p188611220103117"><span><img class="mathml" id="ZH-CN_TOPIC_0000002336336634__image08841040143214" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/figure/zh-cn_formulaimage_0000002336336870.png"></span></p>
      <p id="ZH-CN_TOPIC_0000002336336634__p14555918141817">计算逻辑是：从外部存储Global Memory搬运数据至内部存储Local Memory，然后使用<span id="ZH-CN_TOPIC_0000002336336634__ph92451920201919">Ascend C</span>计算接口完成两个输入参数相加，得到最终结果，再搬运到Global Memory上。</p>
      <p></p></li>
     <li id="ZH-CN_TOPIC_0000002336336634__zh-cn_topic_0000001552186366_zh-cn_topic_0229825559_zh-cn_topic_0229823837_zh-cn_topic_0211294710_zh-cn_topic_0206739556_li28689589526"><span>明确输入和输出。</span>
      <p></p>
      <ul id="ZH-CN_TOPIC_0000002336336634__zh-cn_topic_0000001552186366_zh-cn_topic_0229825559_zh-cn_topic_0229823837_zh-cn_topic_0211294710_zh-cn_topic_0206739556_ul676191385713">
       <li id="ZH-CN_TOPIC_0000002336336634__zh-cn_topic_0000001552186366_zh-cn_topic_0229825559_zh-cn_topic_0229823837_zh-cn_topic_0211294710_zh-cn_topic_0206739556_li8761151319575">Add算子有两个输入：x与y，输出为z。</li>
       <li id="ZH-CN_TOPIC_0000002336336634__zh-cn_topic_0000001552186366_zh-cn_topic_0229825559_zh-cn_topic_0229823837_zh-cn_topic_0211294710_zh-cn_topic_0206739556_li1286941614573">本样例中算子输入支持的数据类型为half（float16），算子输出的数据类型与输入数据类型相同。</li>
       <li id="ZH-CN_TOPIC_0000002336336634__zh-cn_topic_0000001552186366_zh-cn_topic_0229825559_zh-cn_topic_0229823837_zh-cn_topic_0211294710_zh-cn_topic_0206739556_li36551518105710">算子输入支持的shape为（8，2048），输出shape与输入shape相同。</li>
       <li id="ZH-CN_TOPIC_0000002336336634__zh-cn_topic_0000001552186366_zh-cn_topic_0229825559_zh-cn_topic_0229823837_zh-cn_topic_0211294710_li1594111362917">算子输入支持的<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0099.html">format</a>为：ND。</li>
      </ul>
      <p></p></li>
     <li id="ZH-CN_TOPIC_0000002336336634__zh-cn_topic_0000001552186366_li168621918591"><span>确定核函数名称和参数。</span>
      <p></p>
      <ul id="ZH-CN_TOPIC_0000002336336634__zh-cn_topic_0000001552186366_ul113768745911">
       <li id="ZH-CN_TOPIC_0000002336336634__zh-cn_topic_0000001552186366_li1440818134598">本样例中核函数命名为add_custom。</li>
       <li id="ZH-CN_TOPIC_0000002336336634__zh-cn_topic_0000001552186366_li1337737125912">根据对算子输入输出的分析，确定核函数有3个参数x，y，z；x，y为输入参数，z为输出参数。</li>
      </ul>
      <p></p></li>
     <li id="ZH-CN_TOPIC_0000002336336634__zh-cn_topic_0000001552186366_zh-cn_topic_0229825559_zh-cn_topic_0229823837_zh-cn_topic_0211294710_zh-cn_topic_0206739556_li1866407154416"><span>确定算子实现所需接口。</span>
      <p></p>
      <ul id="ZH-CN_TOPIC_0000002336336634__zh-cn_topic_0000001552186366_ul6741329145317">
       <li id="ZH-CN_TOPIC_0000002336336634__zh-cn_topic_0000001552186366_li37411329105311">实现涉及外部存储和内部存储间的数据搬运，查看<span id="ZH-CN_TOPIC_0000002336336634__zh-cn_topic_0000001552186366_ph22912514213">Ascend C</span> API参考中的数据搬移接口，需要使用<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0101.html">DataCopy</a>来实现数据搬移。</li>
       <li id="ZH-CN_TOPIC_0000002336336634__zh-cn_topic_0000001552186366_li1741729205311">本样例只涉及矢量计算的加法操作，查看<span id="ZH-CN_TOPIC_0000002336336634__zh-cn_topic_0000001552186366_ph5140455182115">Ascend C</span> API参考中的矢量计算接口<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0023.html">矢量计算</a>，初步分析可使用双目指令Add接口<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0035.html">Add</a>实现x+y。</li>
       <li id="ZH-CN_TOPIC_0000002336336634__li1874835175">计算中使用到的Tensor数据结构，使用<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0138.html">AllocTensor</a>、<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0139.html">FreeTensor</a>进行申请和释放。</li>
       <li id="ZH-CN_TOPIC_0000002336336634__zh-cn_topic_0000001552186366_li774112918533">并行流水任务之间使用Queue队列完成同步，会使用到<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0140.html">EnQue</a>、<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0141.html">DeQue</a>等接口。</li>
      </ul>
      <p></p></li>
    </ol>

    <p id="ZH-CN_TOPIC_0000002336336634__p133171742737">完成环境准备和初步的算子分析后，即可开始Ascend C核函数的开发。开发之前请先从<span id="ZH-CN_TOPIC_0000002336336634__ph360220395287"><a href="https://gitee.com/ascend/samples/tree/master/operator/ascendc/0_introduction/3_add_kernellaunch/AddKernelInvocationNeo" target="_blank" rel="noopener noreferrer">矢量算子样例</a></span>获取样例代码，以下样例代码在add_custom.cpp中实现。</p>

    <p id="ZH-CN_TOPIC_0000002336336634__p593243404113">异构计算架构中，NPU（kernel侧）与CPU（host侧）是协同工作的，完成了kernel侧核函数开发后，即可编写host侧的核函数调用程序，实现从host侧的APP程序调用算子，执行计算过程。</p>
    <p id="ZH-CN_TOPIC_0000002336336634__p2093233464117">除了上文核函数实现文件add_custom.cpp外，核函数的调用与验证还需要准备以下文件：</p>

     <li id="ZH-CN_TOPIC_0000002336336634__li38412253343">适用于CPU或NPU模式运行的算子编译工程文件：CMakeLists.txt。</li>
