  <h1 class="topictitle1">创建算子工程</h1>
  <div id="body8662426">
   <p id="shortdesc1089771513119">CANN开发套件包中提供了自定义算子工程生成工具msOpGen，可基于算子原型定义输出算子工程：包括<strong id="b661515105714">算子host侧代码实现文件</strong>、<strong id="b986451220713">算子kernel侧实现文件</strong>以及<strong id="b16776117771">工程编译配置文件等</strong>。</p>
   <div class="note" id="ZH-CN_TOPIC_0000002336336726__note511916486141">
    <img src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/public_sys-resources/note_3.0-zh-cn.png"><span class="notetitle"> </span>
    <div class="notebody">
     <p id="ZH-CN_TOPIC_0000002336336726__li13891223112413p0">使用msOpGen工具创建算子工程之前，需要参考<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0002.html">环境准备</a>章节安装驱动固件和CANN软件包，完成开发环境和运行环境的准备。</p>
    </div>
   </div>
   <p id="ZH-CN_TOPIC_0000002336336726__p377285571017">使用msOpGen工具创建算子开发工程的步骤如下：</p>
   <ol id="ZH-CN_TOPIC_0000002336336726__zh-cn_topic_0000001502825998_ol1626512810440">
    <li id="ZH-CN_TOPIC_0000002336336726__li10517111596"><span>编写算子的原型定义json文件，用于生成算子开发工程。json文件的配置参数详细说明请参考<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/devaids/optool/atlasopdev_16_0021.html#ZH-CN_TOPIC_0000002370267097__zh-cn_topic_0000001740005677_table8534182020116">表1</a>。</span>
     <p></p>
     <div class="p" id="ZH-CN_TOPIC_0000002336336726__zh-cn_topic_0000001502825998_p948313013819">
      例如，AddCustom算子的json文件命名为add_custom.json，文件内容如下：
      <pre class="screen" id="ZH-CN_TOPIC_0000002336336726__screen92191143105016">[
    {
        "op": "AddCustom",
        "input_desc": [
            {
                "name": "x",
                "param_type": "required",
                "format": [
                    "ND",
                    "ND",
                    "ND"
                ],
                "type": [
                    "float16",
                    "float",
                    "int32"
                ]
            },
            {
                "name": "y",
                "param_type": "required",
                "format": [
                    "ND",
                    "ND",
                    "ND"
                ],
                "type": [
                    "float16",
                    "float",
                    "int32"
                ]
            }
        ],
        "output_desc": [
            {
                "name": "z",
                "param_type": "required",
                "format": [
                    "ND",
                    "ND",
                    "ND"
                ],
                "type": [
                    "float16",
                    "float",
                    "int32"
                ]
            }
        ]
    }
]</pre>
     </div>
     <div class="p" id="ZH-CN_TOPIC_0000002336336726__p1760354121715">
      例如，ReduceMaxCustom算子（包含属性）的json文件命名为reduce_max_custom.json，文件内容如下：
      <pre class="screen" id="ZH-CN_TOPIC_0000002336336726__screen14288940122117">[
    {
        "op": "ReduceMaxCustom",
         "input_desc": [
            {
                "name": "x",
                "param_type": "required",
                "format": ["ND"],
                "type": ["float16"]
            }
        ],
        "output_desc": [
            {
                "name": "y",
                "param_type": "required",
                "format": ["ND"],
                "type": ["float16"]
            },
            {
                "name": "idx",
                "param_type": "required",
                "format": ["ND"],
                "type": ["int32"]
            }
        ],
        "attr": [                                                                   
            {
                "name": "reduceDim",
                "param_type": "required",
                "type": "int"
            },
            {
                "name": "isKeepDim",
                "param_type": "optional",
                "type": "int",
                "default_value": 1
            }
        ]
    }
]</pre>
     </div>
     <p></p></li>
    <li id="ZH-CN_TOPIC_0000002336336726__zh-cn_topic_0000001502825998_li89761353472"><span>使用msOpGen工具生成算子的开发工程。以生成AddCustom的算子工程为例，下文仅针对关键参数进行解释，详细参数说明请参见<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/devaids/optool/atlasopdev_16_0017.html">算子工程创建（msOpGen）</a>。</span>
     <p></p>
     <pre class="screen" id="ZH-CN_TOPIC_0000002336336726__screen62467580520"><strong id="ZH-CN_TOPIC_0000002336336726__b257852431512"><span id="ZH-CN_TOPIC_0000002336336726__ph1957812416155">${INSTALL_DIR}</span></strong>/python/site-packages/bin/msopgen gen -i<strong id="ZH-CN_TOPIC_0000002336336726__b2803820141512"> </strong>$HOME/sample/add_custom.json -c ai_core-<strong id="ZH-CN_TOPIC_0000002336336726__b2322194051510"><span id="ZH-CN_TOPIC_0000002336336726__ph103221940191517"><em id="ZH-CN_TOPIC_0000002336336726__zh-cn_topic_0000001682787961_i79331727136">&lt;soc_version&gt;</em></span> </strong>-lan cpp -out $HOME/sample/AddCustom</pre>
     <ul id="ZH-CN_TOPIC_0000002336336726__ul814311210385">
      <li id="ZH-CN_TOPIC_0000002336336726__li1735619823819"><strong id="ZH-CN_TOPIC_0000002336336726__b9823114104919"><span id="ZH-CN_TOPIC_0000002336336726__ph1282312410496">${INSTALL_DIR}</span></strong>为CANN软件安装后文件存储路径，请根据实际环境进行替换。</li>
      <li id="ZH-CN_TOPIC_0000002336336726__li1127452442312">-i：指定算子原型定义文件<em id="ZH-CN_TOPIC_0000002336336726__i77197446232">add_custom</em>.json所在路径，请根据实际情况修改。</li>
      <li id="ZH-CN_TOPIC_0000002336336726__li595191863811">-c：ai_core-<span id="ZH-CN_TOPIC_0000002336336726__zh-cn_topic_0000001502825998_ph81480341636"><em id="ZH-CN_TOPIC_0000002336336726__zh-cn_topic_0000002400092065_i79331727136">&lt;soc_version&gt;</em></span>代表算子在AI Core上执行，<span id="ZH-CN_TOPIC_0000002336336726__zh-cn_topic_0000001502825998_ph14215154001316"><em id="ZH-CN_TOPIC_0000002336336726__zh-cn_topic_0000002400092065_i79331727136_1">&lt;soc_version&gt;</em></span>为<span id="ZH-CN_TOPIC_0000002336336726__ph1555712386204">昇腾AI处理器</span>的型号。
       <div class="note" id="ZH-CN_TOPIC_0000002336336726__note91342214442">
        <img src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/public_sys-resources/note_3.0-zh-cn.png"><span class="notetitle"> </span>
        <div class="notebody">
         <p id="ZH-CN_TOPIC_0000002336336726__p15587811201611">AI处理器的型号<span id="ZH-CN_TOPIC_0000002336336726__ph7380192118169"><em id="ZH-CN_TOPIC_0000002336336726__zh-cn_topic_0000002400092065_i79331727136_2">&lt;soc_version&gt;</em></span>请通过如下方式获取：</p>
         <ul id="ZH-CN_TOPIC_0000002336336726__ul1124912113117">
          <li id="ZH-CN_TOPIC_0000002336336726__zh-cn_topic_0000002336350326_li048917175169">非<span id="ZH-CN_TOPIC_0000002336336726__zh-cn_topic_0000002336350326_ph126871512141617"><term id="ZH-CN_TOPIC_0000002336336726__zh-cn_topic_0000002336350326_zh-cn_topic_0000002336176798_term1253731311225">
             Atlas A3 训练系列产品/Atlas A3 推理系列产品
            </term></span>：在安装<span id="ZH-CN_TOPIC_0000002336336726__zh-cn_topic_0000002336350326_ph196874123168">昇腾AI处理器</span>的服务器执行<strong id="ZH-CN_TOPIC_0000002336336726__zh-cn_topic_0000002336350326_b17687612191618">npu-smi info</strong>命令进行查询，获取<strong id="ZH-CN_TOPIC_0000002336336726__zh-cn_topic_0000002336350326_b10161437131915">Name</strong>信息。实际配置值为AscendName，例如<strong id="ZH-CN_TOPIC_0000002336336726__zh-cn_topic_0000002336350326_b16284944181920">Name</strong>取值为<em id="ZH-CN_TOPIC_0000002336336726__zh-cn_topic_0000002336350326_i1478775919179">xxxyy</em>，实际配置值为Ascend<em id="ZH-CN_TOPIC_0000002336336726__zh-cn_topic_0000002336350326_i1678775901719">xxxyy</em>。</li>
          <li id="ZH-CN_TOPIC_0000002336336726__zh-cn_topic_0000002336350326_li13249210117"><span id="ZH-CN_TOPIC_0000002336336726__zh-cn_topic_0000002336350326_ph13754548217"><term id="ZH-CN_TOPIC_0000002336336726__zh-cn_topic_0000002336350326_zh-cn_topic_0000002336176798_term1253731311225_1">
             Atlas A3 训练系列产品/Atlas A3 推理系列产品
            </term></span>：在安装<span id="ZH-CN_TOPIC_0000002336336726__zh-cn_topic_0000002336350326_ph17911124171120">昇腾AI处理器</span>的服务器执行<strong id="ZH-CN_TOPIC_0000002336336726__zh-cn_topic_0000002336350326_zh-cn_topic_0000001264656721_zh-cn_topic_0000001117597244_b206066255591">npu-smi info -t board -i </strong><em id="ZH-CN_TOPIC_0000002336336726__zh-cn_topic_0000002336350326_zh-cn_topic_0000001264656721_zh-cn_topic_0000001117597244_i16609202515915">id</em><strong id="ZH-CN_TOPIC_0000002336336726__zh-cn_topic_0000002336350326_zh-cn_topic_0000001264656721_zh-cn_topic_0000001117597244_b14358631175910"> -c </strong><em id="ZH-CN_TOPIC_0000002336336726__zh-cn_topic_0000002336350326_zh-cn_topic_0000001264656721_zh-cn_topic_0000001117597244_i16269732165915">chip_id</em>命令进行查询，获取<strong id="ZH-CN_TOPIC_0000002336336726__zh-cn_topic_0000002336350326_b11257114917192">Chip Name</strong>和<strong id="ZH-CN_TOPIC_0000002336336726__zh-cn_topic_0000002336350326_b72671651121916">NPU Name</strong>信息，实际配置值为Chip Name_NPU Name。例如<strong id="ZH-CN_TOPIC_0000002336336726__zh-cn_topic_0000002336350326_b13136111611203">Chip Name</strong>取值为Ascend<em id="ZH-CN_TOPIC_0000002336336726__zh-cn_topic_0000002336350326_i68701996189">xxx</em>，<strong id="ZH-CN_TOPIC_0000002336336726__zh-cn_topic_0000002336350326_b51347352112">NPU Name</strong>取值为1234，实际配置值为Ascend<em id="ZH-CN_TOPIC_0000002336336726__zh-cn_topic_0000002336350326_i82901912141813">xxx</em><em id="ZH-CN_TOPIC_0000002336336726__zh-cn_topic_0000002336350326_i154501458102213">_</em>1234。
           <p id="ZH-CN_TOPIC_0000002336336726__zh-cn_topic_0000002336350326_p7807144923215">其中：</p>
           <ul id="ZH-CN_TOPIC_0000002336336726__zh-cn_topic_0000002336350326_ul2747601334">
            <li id="ZH-CN_TOPIC_0000002336336726__zh-cn_topic_0000002336350326_li475875783215">id：设备id，通过<strong id="ZH-CN_TOPIC_0000002336336726__zh-cn_topic_0000002336350326_b83171930133314">npu-smi info -l</strong>命令查出的NPU ID即为设备id。</li>
            <li id="ZH-CN_TOPIC_0000002336336726__zh-cn_topic_0000002336350326_li29761534103314">chip_id：芯片id，通过<strong id="ZH-CN_TOPIC_0000002336336726__zh-cn_topic_0000002336350326_b18888204343317">npu-smi info -m</strong>命令查出的Chip ID即为芯片id。</li>
           </ul></li>
         </ul>
         <p id="ZH-CN_TOPIC_0000002336336726__p127461720132915">基于同系列的AI处理器型号创建的算子工程，其基础功能（基于该工程进行算子开发、编译和部署）通用。</p>
        </div>
       </div></li>
      <li id="ZH-CN_TOPIC_0000002336336726__li369418872311">-lan： 参数cpp代表算子基于Ascend C编程框架，使用C/C++编程语言开发。</li>
      <li id="ZH-CN_TOPIC_0000002336336726__li64977167349">-out：生成文件所在路径，可配置为绝对路径或者相对路径，并且工具执行用户对路径具有可读写权限。若不配置，则默认生成在执行命令的当前路径。</li>
     </ul>
     <p></p></li>
    <li id="ZH-CN_TOPIC_0000002336336726__li659514491696"><span>命令执行完后，会在-out指定目录或者默认路径下生成算子工程目录，工程中包含算子实现的模板文件，编译脚本等，以AddCustom算子为例，目录结构如下所示：</span>
     <p></p>
     <pre class="screen" id="ZH-CN_TOPIC_0000002336336726__zh-cn_topic_0000001502825998_zh-cn_topic_0000001265396074_screen26651351124816">AddCustom
├── build.sh         // 编译入口脚本
├── cmake            // 算子工程编译所需脚本及公共编译文件存放目录

├── op_host                      // host侧实现文件
│   ├── <strong id="ZH-CN_TOPIC_0000002336336726__zh-cn_topic_0000001502825998_b559835015156">add_custom_tiling.h</strong><strong id="ZH-CN_TOPIC_0000002336336726__zh-cn_topic_0000001502825998_b51201235123917">    // 算子tiling定义文件</strong>
│   ├── <strong id="ZH-CN_TOPIC_0000002336336726__zh-cn_topic_0000001502825998_b172209471151">add_custom.cpp</strong><strong id="ZH-CN_TOPIC_0000002336336726__zh-cn_topic_0000001502825998_b17393123953918">         // 算子原型注册、shape推导、信息库、tiling实现等内容文件</strong>

└── scripts                     // 自定义算子工程打包相关脚本所在目录</pre>
     <div class="note" id="ZH-CN_TOPIC_0000002336336726__note196007495914">
      <img src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/public_sys-resources/note_3.0-zh-cn.png"><span class="notetitle"> </span>
      <div class="notebody">
       <ul id="ZH-CN_TOPIC_0000002336336726__ul9907195783012">
        <li id="ZH-CN_TOPIC_0000002336336726__li12907115715308">上述目录结构中的粗体文件为后续算子开发过程中需要修改的文件，其他文件无需修改。</li>
        <li id="ZH-CN_TOPIC_0000002336336726__li1099765143217">kernel侧实现依赖的所有文件需全部放置在op_kernel目录下，不遵循该约束会导致<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0068.html#ZH-CN_TOPIC_0000002336336606__li139988411333">源码发布</a>场景在线编译失败。因为在后续的算子源码发布时，只会打包发布op_kernel目录下的文件。</li>
       </ul>
      </div>
     </div>
     <p></p></li>
   </ol>
   <p id="ZH-CN_TOPIC_0000002336336726__p47233916455">工程目录中的op_kernel和op_host包含了算子的核心实现文件。op_kernel下存放<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0063.html">kernel侧算子实现</a>。op_host下存放host侧代码实现，包括<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0062.html">算子原型定义</a>、<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0064.html">host侧tiling实现</a>。其中kernel侧算子实现和host侧tiling实现在<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0030.html">算子实现</a>章节已经介绍了其核心的实现方法，在该章节会侧重于介绍接入CANN框架后的编程模式和API的使用。工程目录中的CMakePresets.json，用于开发者完成工程编译相关配置，之后即可进行编译部署。</p>
