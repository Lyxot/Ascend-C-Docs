  <h1 class="topictitle1">矩阵乘输出的量化/反量化</h1>
  <div id="body0000002298767893">
   <div class="section" id="ZH-CN_TOPIC_0000002336336714__section310824820358">
    <h4 class="sectiontitle">功能介绍</h4>
    <p id="ZH-CN_TOPIC_0000002336336714__p6289154713562">对于<a href="#ZH-CN_TOPIC_0000002336336714__table1996113269499">特定输入输出数据类型</a>，Matmul支持将计算结果从CO1搬出到Global Memory时，对输出C矩阵元素执行数据量化或反量化操作。</p>
    <ul id="ZH-CN_TOPIC_0000002336336714__ul243555814347">
     <li id="ZH-CN_TOPIC_0000002336336714__li204351358183416">Matmul量化场景：Matmul计算时左矩阵A、右矩阵B为half或bfloat16_t数据类型，输出C矩阵为int8_t数据类型。该场景下，C矩阵的数据从CO1搬出到Global Memory时，会执行量化操作，将最终结果量化为int8_t类型，如下图所示。
      <div class="fignone" id="ZH-CN_TOPIC_0000002336336714__fig75041653154019">
       <span class="figcap"><b>图1 </b>Matmul量化场景示意图</span>
       <br><span><img class="eddx" id="ZH-CN_TOPIC_0000002336336714__image127951919145818" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/figure/zh-cn_image_0000002336337042.png"></span>
      </div></li>
    </ul>
    <ul id="ZH-CN_TOPIC_0000002336336714__ul718857102816">
     <li id="ZH-CN_TOPIC_0000002336336714__li5576108290">Matmul反量化场景：Matmul计算时左矩阵A、右矩阵B为int8_t或int4b_t数据类型，输出C矩阵为half数据类型，或者左矩阵A、右矩阵B为int8_t数据类型，输出C矩阵为int8_t数据类型。该场景下，C矩阵的数据从CO1搬出到Global Memory时，会执行反量化操作，将最终结果反量化为对应的half类型或int8_t类型，如下图所示。
      <div class="fignone" id="ZH-CN_TOPIC_0000002336336714__fig1968611469412">
       <span class="figcap"><b>图2 </b>Matmul反量化场景示意图</span>
       <br><span><img class="eddx" id="ZH-CN_TOPIC_0000002336336714__image13207141055118" src="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/figure/zh-cn_image_0000002336177266.png"></span>
      </div></li>
    </ul>
    <div class="p" id="ZH-CN_TOPIC_0000002336336714__p578017564010">
     Matmul量化/反量化包含两种模式：同一系数的量化/反量化模式、向量的量化/反量化模式，开发者在算子Tiling侧调用<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0698.html">SetDequantType</a>接口设置量化或反量化模式，这两种模式的具体区别为：
     <ul id="ZH-CN_TOPIC_0000002336336714__ul18552145514019">
      <li id="ZH-CN_TOPIC_0000002336336714__li105529551209">同一系数的量化/反量化模式（PER_TENSOR模式）：整个C矩阵对应一个量化参数，量化参数的shape为[1]。开发者在算子Kernel侧调用接口<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0649.html">SetQuantScalar</a>设置量化参数。</li>
      <li id="ZH-CN_TOPIC_0000002336336714__li65525551017">向量的量化/反量化模式（PER_CHANNEL模式）：C矩阵的shape为[m, n]，每个channel维度即C矩阵的每一列，对应一个量化参数，量化参数的shape为[n]。开发者在算子Kernel侧调用接口<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0650.html">SetQuantVector</a>设置量化参数。</li>
     </ul>
    </div>

    <h4 class="sectiontitle">约束说明</h4>
    <ul id="ZH-CN_TOPIC_0000002336336714__ul715451821817">
     <li id="ZH-CN_TOPIC_0000002336336714__li1915410184186"><a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0649.html">SetQuantScalar</a>和<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0650.html">SetQuantVector</a>接口必须在<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0638.html">Iterate</a>或者<a href="https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1/API/ascendcopapi/atlasascendc_api_07_0640.html">IterateAll</a>接口前调用。</li>
    </ul>
    <ul id="ZH-CN_TOPIC_0000002336336714__ul10931021151615">
     <li id="ZH-CN_TOPIC_0000002336336714__li992283518175">在Kernel侧与Tiling侧设置的量化/反量化模式需要保持一致：
      <ul id="ZH-CN_TOPIC_0000002336336714__ul13891195163012">
       <li id="ZH-CN_TOPIC_0000002336336714__li108928516306">Kernel侧调用SetQuantScalar接口设置同一系数的量化/反量化模式，对应Tiling侧调用SetDequantType接口配置模式为DequantType::SCALAR。</li>
       <li id="ZH-CN_TOPIC_0000002336336714__li0830125819313">Kernel侧调用SetQuantVector接口设置向量的量化/反量化模式，对应Tiling侧调用SetDequantType接口配置模式为DequantType::TENSOR。</li>
      </ul></li>
    </ul>
