    <h4 class="sectiontitle">Pybind调用介绍</h4>
    <p id="ZH-CN_TOPIC_0000002336336674__p81062321720">通过PyTorch框架进行模型的训练、推理时，会调用很多算子进行计算，其中的调用方式与kernel编译流程有关。对于自定义算子工程，需要使用PyTorch Ascend Adapter中的OP-Plugin算子插件对功能进行扩展，让torch可以直接调用自定义算子包中的算子，详细内容可以参考<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0082.html">PyTorch框架</a>；对于KernelLaunch开放式算子编程的方式，通过适配Pybind调用，可以实现PyTorch框架调用算子kernel程序。</p>
    <p id="ZH-CN_TOPIC_0000002336336674__p75975240243">Pybind是一个用于将C++代码与Python解释器集成的库，实现原理是通过将C++代码编译成动态链接库（DLL）或共享对象（SO）文件，使用Pybind提供的API将算子核函数与Python解释器进行绑定。在Python解释器中使用绑定的C++函数、类和变量，从而实现Python与C++代码的交互。在Kernel直调中使用时，就是将Pybind模块与算子核函数进行绑定，将其封装成Python模块，从而实现两者交互。</p>
   </div>
   <p id="ZH-CN_TOPIC_0000002336336674__p1860314417341">Pybind调用方式中，使用的主要接口有：</p>
   <ul id="ZH-CN_TOPIC_0000002336336674__ul9721154320342">
    <li id="ZH-CN_TOPIC_0000002336336674__li147211843123414">c10_npu::getCurrentNPUStream：获取当前npu流，返回值类型NPUStream，使用方式请参考<span id="ZH-CN_TOPIC_0000002336336674__ph963712461518">《<a href="https://www.hiascend.com/document/detail/zh/Pytorch/710/apiref/torchnpuCustomsapi/context/概述.md" target="_blank" rel="noopener noreferrer">Ascend Extension for PyTorch 自定义API参考</a>》</span>中的<span id="ZH-CN_TOPIC_0000002336336674__ph1776945310177">“<a href="https://www.hiascend.com/document/detail/zh/Pytorch/710/apiref/torchnpuCustomsapi/context/（beta）c10_npu-getCurrentNPUStream.md" target="_blank" rel="noopener noreferrer">（beta）c10_npu::getCurrentNPUStream</a>”</span>章节。</li>
    <li id="ZH-CN_TOPIC_0000002336336674__li18335164653418">ACLRT_LAUNCH_KERNEL：同<a href="https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_0052.html#ZH-CN_TOPIC_0000002336336722__section132401276414">Kernel Launch方式</a>中ACLRT_LAUNCH_KERNEL接口。</li>
   </ul>

     <pre class="screen" id="ZH-CN_TOPIC_0000002336336674__screen893510171513">import torch

from torch_npu.testing.testcase import TestCase, run_tests
import sys, os

import add_custom
torch.npu.config.allow_internal_format = False
class TestCustomAdd(TestCase):
    def test_add_custom_ops(self):
        # 分配Host侧输入内存，并进行数据初始化
